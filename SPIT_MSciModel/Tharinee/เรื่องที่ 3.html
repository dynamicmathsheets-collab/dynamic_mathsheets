หน่วยการเรียนรู้: อัตราส่วน สัดส่วน และร้อยละ

เรื่องที่ 3: อัตราส่วนของจำนวนหลายๆ จำนวน (Ratios of Three or More Quantities)

การเปรียบเทียบปริมาณตั้งแต่ 3 ปริมาณขึ้นไป การเชื่อมโยงอัตราส่วนต่อเนื่อง และการคำนวณปริมาณรวม

มาตรฐานการเรียนรู้ ค 1.1 ม.1

สรุปหลักการ: อัตราส่วนของจำนวนหลายๆ จำนวน

⚖️ รูปแบบอัตราส่วนต่อเนื่อง a : b : c

อัตราส่วนสามารถเปรียบเทียบปริมาณมากกว่า 2 ปริมาณพร้อมกันได้ เมื่อต้องการขยายหรือทอนอัตราส่วน จะต้องคูณหรือหารทุกจำนวนด้วยจำนวนบวกเดียวกัน (k) ทั้งหมด

a : b : c = (a × k) : (b × k) : (c × k) (เมื่อ k > 0)
🔗 การหาอัตราส่วนร่วม (Common Term)

ถ้ามีอัตราส่วนสองชุด เช่น a : b และ b : c จะเขียนรวมเป็น a : b : c ได้ โดยการทำจำนวนที่เป็นตัวเชื่อม (b) ให้มีค่าเท่ากันก่อน ด้วยการหา ค.ร.น. ของ b

ถ้า a : b = 2 : 3 และ b : c = 4 : 5 → ทำ b = 12
จะได้ a : b : c = 8 : 12 : 15

📌 ข้อควรจำ:

  • อัตราส่วน a : b : c ต้องรักษาความสัมพันธ์ของทั้ง 3 จำนวนพร้อมกันเสมอ การเปลี่ยนค่าเฉพาะตัวใดตัวหนึ่งจะทำให้อัตราส่วนเปลี่ยนไป
  • ปริมาณรวมของส่วนประกอบทั้งหมดคิดเป็น (a + b + c) ส่วน ซึ่งนำไปใช้แบ่งสัดส่วนของจริงได้

ห้องทดลองโมเดล: สูตรผสมเครื่องดื่ม (น้ำ : น้ำเชื่อม : น้ำมะนาว)

คำชี้แจง: จงหาอัตราส่วนของจำนวนหลายจำนวน หรือคำนวณปริมาณของแต่ละส่วนประกอบให้ถูกต้องสมบูรณ์

เกณฑ์การประเมินใบงาน (Scoring Rubrics)

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม - 9-10 คะแนน) ระดับ 2 (พอใช้ - 6-8 คะแนน) ระดับ 1 (ปรับปรุง - ต่ำกว่า 6 คะแนน)
1. การเชื่อมโยงอัตราส่วนต่อเนื่อง หาตัวเชื่อมร่วม (ค.ร.น.) และปรับตัวคูณทุกจำนวนได้อย่างถูกต้อง เพื่อเขียน a : b : c ได้สมบูรณ์ทุกข้อ หาตัวเชื่อมร่วมได้ถูกต้องเป็นส่วนใหญ่ (3-4 ข้อ) มีข้อผิดพลาดเล็กน้อยในการคำนวณคูณขยายบางจำนวน ไม่ปรับตัวเชื่อมร่วมให้เท่ากัน หรือนำตัวเลขมาต่อกันโดยตรงโดยไม่คำนวณมากกว่า 2 ข้อ
2. การแบ่งสัดส่วนและปริมาณรวม คำนวณหาผลรวมของส่วนประกอบ และคำนวณปริมาณของแต่ละส่วนประกอบได้แม่นยำทุกขั้นตอน รวมจำนวนส่วนได้ถูกต้อง และคำนวณปริมาณแต่ละส่วนได้ถูกต้องส่วนใหญ่ มีข้อผิดพลาดในการคิดเลขเล็กน้อย คำนวณผลรวมส่วนผิด ส่งผลให้หาค่าแต่ละปริมาณไม่ถูกต้องเป็นส่วนใหญ่
3. ความเป็นระเบียบและความสมบูรณ์ แสดงวิธีทำและระบุคำตอบพร้อมหน่วยอย่างชัดเจน ครบถ้วนทั้ง 5 ข้อ ทำงานครบ 5 ข้อ ลืมระบุหน่วยในบางข้อ หรือข้ามขั้นตอนการทดเลขเล็กน้อย ทำงานไม่ครบ 5 ข้อ ไม่แสดงขั้นตอนการคิด หรือคำตอบไม่สมบูรณ์
