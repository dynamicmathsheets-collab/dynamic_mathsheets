เรื่องที่ 4: ความหมายของสัดส่วนและการตรวจสอบสัดส่วน (Proportions)

การประโยคที่แสดงการเท่ากันของอัตราส่วนสองอัตราส่วน และการตรวจสอบด้วยผลคูณไขว้

มาตรฐานการเรียนรู้ ค 1.1 ม.1

สรุปหลักการ: สัดส่วนและการตรวจสอบสัดส่วน

📐 ความหมายของสัดส่วน

สัดส่วน (Proportion) คือ ประโยคที่แสดงถึงการเท่ากันของอัตราส่วนสองอัตราส่วน เช่น อัตราส่วน a : b เท่ากับ c : d สามารถเขียนแทนด้วย a : b = c : d หรือเขียนในรูปเศษส่วน

a : b = c : d  หรือ  ab = cd
✖️ สมบัติการคูณไขว้ (Cross-Multiplication)

อัตราส่วน ab = cd เป็นสัดส่วนก็ต่อเมื่อ ผลคูณไขว้มีค่าเท่ากัน คือ a × d = b × c (เมื่อ b, d ≠ 0)

ถ้า a × d = b × c แล้ว สองอัตราส่วนนี้เป็นสัดส่วน
ถ้า a × d ≠ b × c แล้ว สองอัตราส่วนนี้ไม่เป็นสัดส่วน

📌 ข้อควรจำ:

  • เมื่อทราบค่าปริมาณ 3 ค่า และมีค่าตัวแปรหายไปหนึ่งค่า (เช่น x) สามารถใช้การแก้สมการการคูณไขว้เพื่อหาค่า x ได้เสมอ
  • ลำดับตำแหน่งของปริมาณที่นำมาเปรียบเทียบในทั้งสองอัตราส่วนต้องตรงกัน เช่น (สินค้า : ราคา) = (สินค้า : ราคา)

💡 สิ่งที่ค้นพบจากการสังเกต:

  • สัดส่วนคือความสัมพันธ์เมื่ออัตราส่วนทั้งสองมีค่าเท่ากันจริง
  • ตรวจสอบความเท่ากันได้อย่างรวดเร็วโดยนำตัวเศษคูณตัวส่วนตรงข้าม (คูณไขว้)
  • ถ้าผลคูณไขว้ a × d = b × c แสดงว่าอัตราส่วนคู่นี้เป็นสัดส่วน

เกณฑ์การประเมินใบงาน (Scoring Rubrics)

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม - 9-10 คะแนน) ระดับ 2 (พอใช้ - 6-8 คะแนน) ระดับ 1 (ปรับปรุง - ต่ำกว่า 6 คะแนน)
1. การใช้สมบัติการคูณไขว้ นำตัวเลขมาคูณไขว้เพื่อตรวจสอบการเท่ากัน หรือตั้งสมการหาค่าตัวแปรได้อย่างถูกต้องแม่นยำครบถ้วน คูณไขว้ได้ถูกต้องเป็นส่วนใหญ่ (3-4 ข้อ) มีข้อผิดพลาดในการคิดคำนวณตัวเลขเล็กน้อย จับคู่คูณไขว้ผิดตำแหน่ง หรือไม่ใช้สมบัติการคูณไขว้ในการหาคำตอบมากกว่า 2 ข้อ
2. การหาค่าตัวแปรและการสรุปผล สรุปได้ถูกต้องว่าอัตราส่วนใดเป็นหรือไม่เป็นสัดส่วน พร้อมหาค่าตัวแปรได้ถูกต้องทุกข้อ สรุปความสัมพันธ์ของสัดส่วนและหาค่าตัวแปรได้ถูกต้องเป็นส่วนใหญ่ มีข้อผิดพลาดในขั้นตอนสุดท้ายบางข้อ สรุปผลการเป็นสัดส่วนไม่สอดคล้องกับผลคูณ หรือแก้สมการหาค่าตัวแปรไม่ถูกต้องเป็นส่วนใหญ่
3. ความเป็นระเบียบและความสมบูรณ์ แสดงร่องรอยการคิดคำนวณและเขียนคำตอบอย่างเป็นระเบียบ เรียบร้อยครบ 5 ข้อ ทำงานครบ 5 ข้อ ลืมเขียนขั้นตอนการคิดในบางข้อ หรือมีรอยขีดฆ่าเล็กน้อย ทำงานไม่ครบ 5 ข้อ หรือแสดงเฉพาะคำตอบโดยไม่มีขั้นตอนการตรวจสอบ
