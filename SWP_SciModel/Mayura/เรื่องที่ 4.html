ทฤษฎีและหลักการพื้นฐาน

สรุปสาระสำคัญ: การเชื่อมโยงโมล มวล และปริมาตรแก๊ส

หลักการที่ 1

มวลต่อโมล (Molar Mass: $M$)

มวลของสาร 1 โมล มีค่าเชิงตัวเลขเท่ากับมวลอะตอมหรือมวลโมเลกุลของสารนั้น แต่มีหน่วยเป็น กรัมต่อโมล ($\text{g/mol}$)

สูตรเชื่อมโยงโมลกับมวล:
$$n = \frac{g}{M} \iff g = n \times M$$

$g$ คือ มวลของสาร (กรัม), $M$ คือ มวลต่อโมล ($\text{g/mol}$)

ธาตุต่างชนิดกัน 1 โมล จะมีมวลจริงในหน่วยกรัมไม่เท่ากัน
หลักการที่ 2

ปริมาตรแก๊สต่อโมลที่ STP

ตามกฎของอาโวกาโดร แก๊สใดๆ ที่อุณหภูมิและความดันมาตรฐาน (STP : $0^\circ\text{C}, 1\text{ atm}$) ปริมาณ $1\text{ mol}$ จะมีปริมาตรเท่ากันเสมอ

ปริมาตรต่อโมลที่ STP:
$$V_{\text{molar}} = 22.4 \text{ dm}^3\text{/mol (หรือ L/mol)}$$
$$n = \frac{V}{22.4} \iff V = n \times 22.4$$
ที่ RTP ($25^\circ\text{C}, 1\text{ atm}$) ปริมาตรจะขยายตัวเป็น $\approx 24.5\text{ dm}^3\text{/mol}$
หลักการที่ 3

สะพานเชื่อมโมลสมบูรณ์แบบ

โมล ($n$) ทำหน้าที่เป็นศูนย์กลางเชื่อมโยงระหว่าง มวล ($g$), ปริมาตรแก๊ส ($V$), และ จำนวนอนุภาค ($N$)

สมการสะพานเชื่อมสากล (Mole Bridge):
$$n = \frac{g}{M} = \frac{V}{22.4} = \frac{N}{6.022 \times 10^{23}}$$
สามารถเปลี่ยนข้ามปริมาณใดๆ ได้ทันทีโดยใช้โมลเป็นตัวกลาง
ถ้าทราบเพียง 1 ค่า จะสามารถคำนวณหาอีก 3 ค่าที่เหลือได้ทั้งหมด
ความจริงทางเคมีที่สำคัญยิ่ง : ปริมาตรเท่ากัน แต่มวลต่างกัน

เปรียบเทียบแก๊สไฮโดรเจน ($\text{H}_2$) กับ แก๊สออกซิเจน ($\text{O}_2$) ปริมาณ $1.00\text{ โมล}$ ที่ STP

แก๊สไฮโดรเจน ($\text{H}_2$, $M = 2.02\text{ g/mol}$) 1.00 mol
• ปริมาตรที่ STP : $V = 1.00 \times 22.4 = \mathbf{22.4\text{ dm}^3}$
• มวลของแก๊ส : $g = 1.00 \times 2.02 = \mathbf{2.02\text{ กรัม}}$
• จำนวนโมเลกุล : $N = \mathbf{6.022 \times 10^{23}\text{ โมเลกุล}}$
แก๊สออกซิเจน ($\text{O}_2$, $M = 32.00\text{ g/mol}$) 1.00 mol
• ปริมาตรที่ STP : $V = 1.00 \times 22.4 = \mathbf{22.4\text{ dm}^3}$ (เท่ากันเป๊ะ!)
• มวลของแก๊ส : $g = 1.00 \times 32.00 = \mathbf{32.00\text{ กรัม}}$ (หนักกว่าเกือบ 16 เท่า!)
• จำนวนโมเลกุล : $N = \mathbf{6.022 \times 10^{23}\text{ โมเลกุล}}$ (เท่ากันเป๊ะ!)

บทเรียนสำคัญ: ที่ STP ปริมาตรและจำนวนโมเลกุลของแก๊สขึ้นอยู่กับ "จำนวนโมล" เท่านั้น ไม่เกี่ยวกับชนิดหรือขนาดของโมเลกุล แต่มวลจะขึ้นอยู่กับ "มวลต่อโมล ($M$)" ของแก๊สนั้นๆ

ตอบ : .........................................................................................................................................................
แนวทางการเฉลยละเอียด :
1) หามวลต่อโมลของ $\text{O}_2 = 2 \times 16.00 = 32.00\text{ g/mol}$
$$n = \frac{g}{M} = \frac{16.00\text{ g}}{32.00\text{ g/mol}} = \mathbf{0.50\text{ โมล}}$$
2) หาปริมาตรที่ STP จาก $V = n \times 22.4$ :
$$V = 0.50\text{ mol} \times 22.4\text{ dm}^3\text{/mol} = \mathbf{11.20\text{ dm}^3}$$

ข้อ 2. แก๊สคาร์บอนไดออกไซด์ ($\text{CO}_2$) ปริมาตร $5.60\text{ dm}^3$ ที่ STP คิดเป็นกี่โมล และมีมวลกี่กรัม

ตอบ : .........................................................................................................................................................
แนวทางการเฉลยละเอียด :
1) หาจำนวนโมลจากปริมาตรที่ STP :
$$n = \frac{V}{22.4} = \frac{5.60\text{ dm}^3}{22.4\text{ dm}^3\text{/mol}} = \mathbf{0.25\text{ โมล}}$$
2) มวลต่อโมลของ $\text{CO}_2 = 12.01 + 2(16.00) = 44.01\text{ g/mol}$
$$g = n \times M = 0.25\text{ mol} \times 44.01\text{ g/mol} = \mathbf{11.00\text{ กรัม}}$$
ตอบ : คิดเป็น $0.25\text{ โมล}$ และมีมวลเท่ากับ $11.00\text{ กรัม}$
ข้อ 3. ก๊าซมีเทน ($\text{CH}_4$) มีจำนวนโมเลกุลเท่ากับ $3.01 \times 10^{23}\text{ โมเลกุล}$ จงหามวลของก๊าซนี้ในหน่วยกรัม และหาปริมาตรที่ STP

1) หาโมลจากจำนวนอนุภาค :
$$n = \frac{N}{6.02 \times 10^{23}} = \frac{3.01 \times 10^{23}}{6.02 \times 10^{23}} = \mathbf{0.50\text{ โมล}}$$
2) มวลต่อโมลของ $\text{CH}_4 = 12.01 + 4(1.01) = 16.05\text{ g/mol}$
$$g = n \times M = 0.50 \times 16.05 = \mathbf{8.025\text{ กรัม}}$$

ข้อ 5. ถ้ามีแก๊สไฮโดรเจน ($\text{H}_2$) และแก๊สออกซิเจน ($\text{O}_2$) ปริมาณอย่างละ $2.00\text{ โมล}$ เท่ากันที่สภาวะ STP จงเปรียบเทียบปริมาตรและมวลของแก๊สทั้งสองชนิดนี้

1) เปรียบเทียบปริมาตรที่ STP :
เนื่องจากมีจำนวนโมลเท่ากัน ($2.00\text{ mol}$) ดังนั้นทั้งสองแก๊สจึงมีปริมาตรเท่ากันคือ :
$$V = 2.00 \times 22.4 = \mathbf{44.80\text{ dm}^3\text{ เท่ากันทั้งคู่}}$$

ตอบ : ปริมาตรเท่ากันคือ $44.80\text{ dm}^3$ แต่มวลต่างกัน โดย $\text{O}_2$ หนัก $64.00\text{ g}$ มากกว่า $\text{H}_2$ ซึ่งหนักเพียง $4.04\text{ g}$
ข้อ 6. แก๊สชนิดหนึ่งปริมาตร $1.12\text{ dm}^3$ ที่ STP มีมวลเท่ากับ $3.20\text{ กรัม}$ จงคำนวณหามวลต่อโมล ($M$) ของแก๊สนี้ และระบุว่าน่าจะเป็นแก๊สใดระหว่าง $\text{O}_2$ หรือ $\text{SO}_2$

แนวทางการเฉลยละเอียด :
1) หาโมลของแก๊สจากปริมาตรที่ STP :
$$n = \frac{V}{22.4} = \frac{1.12}{22.4} = \mathbf{0.050\text{ โมล}}$$

3) เปรียบเทียบกับมวลโมเลกุล : $\text{SO}_2 = 32.06 + 2(16.00) = 64.06\text{ g/mol}$ (ส่วน $\text{O}_2 = 32.00\text{ g/mol}$)
ตอบ : มวลต่อโมลเท่ากับ $64.00\text{ g/mol}$ ดังนั้น แก๊สนี้คือ ซัลเฟอร์ไดออกไซด์ ($\text{SO}_2$)
ข้อ 7. แก๊สไนโตรเจนมอนอกไซด์ ($\text{NO}$) ปริมาณ $300\text{ มิลลิกรัม (mg)}$ จะมีปริมาตรกี่ลูกบาศก์เซนติเมตร ($\text{cm}^3$) ที่ STP (กำหนด $1\text{ dm}^3 = 1000\text{ cm}^3$)

แนวทางการเฉลยละเอียด :
1) แปลงมิลลิกรัมเป็นกรัม : $g = 300\text{ mg} = 0.300\text{ กรัม}$

ข้อ 8. แก๊สผสมในถังปิดใบหนึ่งประกอบด้วยแก๊สฮีเลียม ($\text{He}$) $8.00\text{ กรัม}$ และแก๊สนีออน ($\text{Ne}$) $10.09\text{ กรัม}$ จงคำนวณหาปริมาตรรวมของแก๊สผสมนี้ที่ STP

ตอบ : .........................................................................................................................................................
แนวทางการเฉลยละเอียด :
1) หาโมลของแก๊สแต่ละชนิด :
• $n_{\text{He}} = \frac{8.00\text{ g}}{4.00\text{ g/mol}} = 2.00\text{ โมล}$
• $n_{\text{Ne}} = \frac{10.09\text{ g}}{20.18\text{ g/mol}} = 0.50\text{ โมล}$

ข้อ 9. สารไฮโดรคาร์บอนในสถานะแก๊สชนิดหนึ่งมีสูตรโมเลกุลเป็น $\text{C}_n\text{H}_{2n+2}$ ถ้าแก๊สนี้ปริมาณ $4.48\text{ dm}^3$ ที่ STP มีมวลเท่ากับ $8.80\text{ กรัม}$ จงแสดงวิธีทำเพื่อหาค่าตัวแปร $n$
วิธีทำ :

ตอบ : .........................................................................................................................................................
แนวทางการเฉลยละเอียด :
1) หาโมลของแก๊ส : $n = \frac{4.48\text{ dm}^3}{22.4\text{ dm}^3\text{/mol}} = 0.20\text{ โมล}$
2) หามวลโมเลกุลรวม ($M$) :
$$M = \frac{g}{n} = \frac{8.80\text{ g}}{0.20\text{ mol}} = \mathbf{44.00\text{ g/mol}}$$
3) แก้สมการหาสูตร $\text{C}_n\text{H}_{2n+2}$ :
$$12.01(n) + 1.01(2n + 2) = 44.00$$

ตอบ : ค่า $n = 3$ (สูตรโมเลกุลคือ โพรเพน : $\text{C}_3\text{H}_8$)
ข้อ 10. ลูกโป่งสำรวจสภาพอากาศใบหนึ่งบรรจุก๊าซฮีเลียม ($\text{He}$) จนมีปริมาตร $448\text{ dm}^3$ ที่สภาวะ STP จงคำนวณหามวลของก๊าซฮีเลียมที่บรรจุอยู่ในลูกโป่ง และถ้าเปลี่ยนไปบรรจุก๊าซไฮโดรเจน ($\text{H}_2$) ที่ปริมาตรเท่ากัน ลูกโป่งจะเบากว่าเดิมกี่กรัม
วิธีทำ :

ตอบ : .........................................................................................................................................................
แนวทางการเฉลยละเอียด :
1) หาโมลของแก๊สที่บรรจุ : $n = \frac{448\text{ dm}^3}{22.4\text{ dm}^3\text{/mol}} = \mathbf{20.00\text{ โมล}}$

เกณฑ์การประเมินตามสภาพจริง 3 ระดับ (คะแนนเต็ม 20 คะแนน, ข้อละ 2 คะแนน)

ประเมินความเข้าใจมโนทัศน์มวลต่อโมลและปริมาตรแก๊สที่ STP ทักษะการตั้งสมการคณิตศาสตร์ และความถูกต้องของหน่วย

ประเด็นการประเมิน
3 ระดับดีมาก (2.0 คะแนน/ข้อ)
2 ระดับปานกลาง (1.0 - 1.5 คะแนน)
1 ระดับปรับปรุง (0.0 - 0.5 คะแนน)
1. มโนทัศน์มวลและปริมาตรที่ STP
ความเข้าใจนิยาม $M$, ค่าคงที่ $22.4\text{ dm}^3\text{/mol}$ ที่ STP และเงื่อนไขสภาวะ
เลือกใช้ค่าคงที่ $22.4\text{ dm}^3\text{/mol}$ และคำนวณมวลต่อโมล $M$ ได้ถูกต้องแม่นยำ 100% แยกแยะความแตกต่างระหว่างมวลและปริมาตรของแก๊สต่างชนิดได้อย่างชัดเจน เข้าใจหลักการ แต่มีจุดคลาดเคลื่อนเล็กน้อยในการคิดมวลโมเลกุลของสารประกอบแก๊ส หรือสับสนเงื่อนไขหน่วยของปริมาตร 1 จุด สับสนความสัมพันธ์ ใช้ค่าคงที่ผิด เช่น สับสนระหว่าง $22.4$ กับเลขอาโวกาโดร หรือคิดว่าแก๊สต่างชนิดที่มีโมลเท่ากันจะมีมวลเท่ากัน
2. การแปลงหน่วยและตั้งสมการ
การใช้สูตร $n = \frac{g}{M} = \frac{V}{22.4}$ และการแปลงหน่วย $\text{mg} \rightarrow \text{g}, \text{cm}^3 \rightarrow \text{dm}^3$
ตั้งสมการสะพานเชื่อมโมลและแสดงขั้นตอนย้ายข้างสมการทางพีชคณิตถูกต้อง แปลงหน่วยคำอุปสรรคและหน่วยปริมาตรได้อย่างสมบูรณ์แบบ ตั้งสมการถูกต้อง แต่แสดงขั้นตอนข้ามไป หรือมีข้อผิดพลาดในการแปลงหน่วยคำอุปสรรค เช่น ลืมคูณ $1000$ ในบางตำแหน่ง ไม่แสดงสมการความสัมพันธ์ แทนค่าผิดสลับตำแหน่งระหว่างเศษและส่วน หรือไม่สามารถย้ายข้างหาตัวแปร $n, M, V$ ได้
3. ความถูกต้องของคำตอบและหน่วย
ความแม่นยำของการคิดเลขทศนิยม เลขนัยสำคัญ และการระบุหน่วยวิทยาศาสตร์กำกับ
คำนวณตัวเลขได้แม่นยำถูกต้อง ปัดเศษทศนิยมตามหลักการ และระบุหน่วยกำกับชัดเจนทุกข้อ ($\text{mol}, \text{g}, \text{dm}^3, \text{cm}^3$) ตัวเลขคำตอบคลาดเคลื่อนจากการปัดเศษทศนิยมเล็กน้อย หรือได้คำตอบถูกแต่ลืมระบุหน่วยทางเคมีกำกับ คำนวณผลลัพธ์ผิดพลาดหลายข้อ และไม่ระบุหน่วยกำกับท้ายคำตอบ

เกณฑ์สรุปการแปลผลระดับคุณภาพโดยรวม (คะแนนเต็ม 20 คะแนน) :

16 - 20 คะแนน (ระดับดีมาก)

เข้าใจมโนทัศน์โมล มวล และปริมาตรแก๊สที่ STP อย่างถ่องแท้ แก้โจทย์ผสมผสานและย้อนกลับหาสูตรแก๊สได้อย่างคล่องแคล่ว

10 - 15 คะแนน (ระดับปานกลาง)

คำนวณเปลี่ยนโมลเป็นมวลและปริมาตรขั้นตอนเดียวได้ดี ควรฝึกทักษะการคำนวณแก๊สผสมและการแก้สมการหลายชั้นเพิ่มเติม

0 - 9 คะแนน (ระดับปรับปรุง)

ยังสับสนการเชื่อมโยงด้วยสูตร $n = \frac{V}{22.4}$ แนะนำให้ฝึกปฏิบัติผ่านโมเดลจำลองในส่วนที่ 2 อย่างสม่ำเสมอ
