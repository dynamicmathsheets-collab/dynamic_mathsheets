ข้อ 1. ข้อใดต่อไปนี้กล่าวถึงความหมายและประเภทของ ตัวแปรสุ่ม (Random Variable) ได้อย่างถูกต้องตามหลักคณิตศาสตร์

ข้อ 2. กำหนดให้ $X$ เป็นตัวแปรสุ่มไม่ต่อเนื่องที่มีเซตของค่าที่เป็นไปได้คือ $\{x_1, x_2, \dots, x_k\}$ ข้อใดเป็น สมบัติพื้นฐาน ของฟังก์ชันการแจกแจงความน่าจะเป็น $P(X = x)$ เสมอ

เฉลย ค. การสุ่มหยิบโดยไม่ใส่คืนจะทำให้การทดลองในแต่ละครั้ง ไม่เป็นอิสระต่อกัน และความน่าจะเป็นของความสำเร็จ ($p$) เปลี่ยนแปลงไปในแต่ละครั้ง จึงไม่เป็นการแจกแจงทวินาม (แต่เป็นการแจกแจงไฮเพอร์จีโอเมตริก)

เฉลย ข. สำหรับตัวแปรสุ่มต่อเนื่อง ความน่าจะเป็นที่จุดเดี่ยวเป็นศูนย์เสมอ ($P(X = c) = 0$) ดังนั้นการรวมหรือไม่รวมจุดปลายจึงได้ความน่าจะเป็นเท่ากัน นั่นคือ $P(a \le X \le b) = P(a < X < b)$

ข้อ 5. พิจารณาข้อความเกี่ยวกับการแจกแจงปกติ $X \sim N(\mu, \sigma^2)$ ต่อไปนี้:
(1) ถ้าคงค่า $\mu$ ไว้เดิม แต่เพิ่มค่า $\sigma$ กราฟจะมียอดโด่งสูงขึ้นและแคบลง
(2) เส้นโค้งปกติมีแกนสมมาตรอยู่ที่เส้นตรง $x = \mu$ และจุดเปลี่ยนเว้าอยู่ที่ $x = \mu \pm \sigma$
(3) เมื่อแปลง $X$ เป็น $Z = \frac{X - \mu}{\sigma}$ จะได้ $Z \sim N(0, 1)$ เสมอ
ข้อความใดถูกต้องบ้าง
เฉลย ข. ข้อ (1) ผิด เพราะเมื่อ $\sigma$ เพิ่มขึ้น ข้อมูลจะกระจายตัวมากขึ้น กราฟจะกว้างแบนลงและยอดเตี้ยลง ส่วนข้อ (2) และ (3) ถูกต้องตามทฤษฎีบทการแจกแจงปกติ
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านกระบวนการ (P) ระดับ: ง่าย
ข้อ 6. กำหนดตารางการแจกแจงความน่าจะเป็นของตัวแปรสุ่มไม่ต่อเนื่อง $X$ ดังนี้: $$\begin{array}{|c|c|c|c|c|} \hline x & 0 & 1 & 2 & 3 \\ \hline P(X = x) & 0.15 & c & 2c & 0.25 \\ \hline \end{array}$$ ค่าของค่าคงตัว $c$ และค่าความน่าจะเป็น $P(X \ge 2)$ มีค่าเท่ากับข้อใดตามลำดับ
เฉลย ก. จากผลรวมความน่าจะเป็น: $0.15 + c + 2c + 0.25 = 1 \implies 3c + 0.40 = 1 \implies 3c = 0.60 \implies c = 0.20$
ดังนั้น $P(X \ge 2) = P(X = 2) + P(X = 3) = 2(0.20) + 0.25 = 0.40 + 0.25 = 0.65$
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านกระบวนการ (P) ระดับ: ปานกลาง
ข้อ 7. ในการทอดลูกเต๋าที่เที่ยงตรง 1 ลูกจำนวน 4 ครั้ง กำหนดให้ความสำเร็จคือการทอดได้แต้มที่หารด้วย 3 ลงตัว ความน่าจะเป็นที่จะทอดได้แต้มที่หารด้วย 3 ลงตัว จำนวน 2 ครั้งพอดี เท่ากับข้อใด
เฉลย ก. แต้มที่หารด้วย 3 ลงตัวคือ $\{3, 6\}$ ดังนั้น $p = \frac{2}{6} = \frac{1}{3}$ และ $1 - p = \frac{2}{3}$ โดย $n = 4$
สูตรทวินาม: $P(X = 2) = \binom{4}{2} \left(\frac{1}{3}\right)^2 \left(\frac{2}{3}\right)^2 = 6 \times \frac{1}{9} \times \frac{4}{9} = \frac{24}{81} = \frac{8}{27}$
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านกระบวนการ (P) ระดับ: ปานกลาง
ข้อ 8. ตัวแปรสุ่ม $X$ มีการแจกแจงทวินาม $X \sim B(n, p)$ ถ้าทราบว่าค่าเฉลี่ยเท่ากับ $12$ และความแปรปรวนเท่ากับ $4.8$ ค่าของพารามิเตอร์ $n$ และ $p$ เท่ากับข้อใดตามลำดับ
เฉลย ข. จากสูตร $\mu = np = 12$ และ $\sigma^2 = np(1 - p) = 4.8$
แทนค่า $np = 12$ จะได้ $12(1 - p) = 4.8 \implies 1 - p = 0.4 \implies p = 0.6$ ... เอ๊ะ! เช็ค: ถ้า $p = 0.4$ จะได้ $1-p = 0.6 \implies 12(0.6) = 7.2$
คำนวณใหม่: $1 - p = \frac{4.8}{12} = 0.40 \implies p = 0.60$ และ $n = \frac{12}{0.60} = 20$ (ตอบข้อ ก) หรือถ้าโจทย์คือ $p=0.4$ ความแปรปรวนจะเป็น $7.2$
คำนวณถูกต้องตามโจทย์ $np=12, np(1-p)=4.8 \implies 1-p = 0.4 \implies p = 0.6 \implies n = 20$ (ดังนั้นข้อ ก. ถูกต้อง)
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านกระบวนการ (P) ระดับ: ยาก
ข้อ 9. กำหนดให้ $X$ เป็นตัวแปรสุ่มต่อเนื่องที่มีฟังก์ชันความหนาแน่นความน่าจะเป็น: $$f(x) = \begin{cases} k(4 - x) & \text{เมื่อ } 0 \le x \le 4 \\ 0 & \text{เมื่อเป็นค่าอื่น ๆ} \end{cases}$$ ค่าของค่าคงตัว $k$ และความน่าจะเป็น $P(1 \le X \le 3)$ มีค่าเท่ากับข้อใด
เฉลย ก. พื้นที่ใต้กราฟทั้งหมดเป็นรูปสามเหลี่ยมมุมฉาก มีฐานยาว 4 และสูง $f(0) = 4k$
พื้นที่ $= \frac{1}{2} \times 4 \times 4k = 8k = 1 \implies k = \frac{1}{8}$
หา $P(1 \le X \le 3) = \int_1^3 \frac{1}{8}(4 - x)\,dx = \frac{1}{8} \left[ 4x - \frac{x^2}{2} \right]_1^3 = \frac{1}{8} \left( (12 - 4.5) - (4 - 0.5) \right) = \frac{1}{8}(7.5 - 3.5) = \frac{4}{8} = \frac{1}{2}$
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านกระบวนการ (P) ระดับ: ยาก
ข้อ 10. ตัวแปรสุ่ม $X \sim N(80, 16)$ ถ้ากำหนดตารางพื้นที่ใต้เส้นโค้งปกติมาตรฐาน $P(Z \le 1.25) = 0.8944$ และ $P(Z \le 2.00) = 0.9772$ ค่าของ $P(75 \le X \le 88)$ เท่ากับข้อใด
เฉลย ข. $\mu = 80, \sigma = \sqrt{16} = 4$
แปลง $Z_1 = \frac{75 - 80}{4} = -1.25$ และ $Z_2 = \frac{88 - 80}{4} = +2.00$
จากความสมมาตร $P(Z \le -1.25) = 1 - P(Z \le 1.25) = 1 - 0.8944 = 0.1056$
$P(75 \le X \le 88) = P(-1.25 \le Z \le 2.00) = 0.9772 - 0.1056 = 0.8716$ (ตอบ ก)
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านการประยุกต์ (A) ระดับ: ง่าย
ข้อ 11. ในการแข่งขันตอบปัญหาวิชาการ 2 รายการ ปรากฏผลคะแนนของนายสมคิดดังนี้:
$\bullet$ คณิตศาสตร์: สอบได้ 78 คะแนน (ค่าเฉลี่ยของกลุ่ม $\mu = 70$, $\sigma = 5$)
$\bullet$ วิทยาศาสตร์: สอบได้ 84 คะแนน (ค่าเฉลี่ยของกลุ่ม $\mu = 80$, $\sigma = 2$)
ในแง่ของ ตำแหน่งสัมพัทธ์ (Relative Standing) เมื่อเปรียบเทียบกับผู้เข้าแข่งขันในแต่ละกลุ่ม นายสมคิดทำผลงานในวิชาใดได้โดดเด่นกว่ากัน เพราะเหตุใด
เฉลย ข. การเปรียบเทียบผลงานข้ามกลุ่มต้องใช้ค่ามาตรฐาน $Z$:
$Z_{\text{Math}} = \frac{78 - 70}{5} = +1.60$ และ $Z_{\text{Sci}} = \frac{84 - 80}{2} = +2.00$
เนื่องจาก $Z_{\text{Sci}} > Z_{\text{Math}}$ แสดงว่าเมื่อเทียบกับกลุ่มแล้ว วิชาวิทยาศาสตร์อยู่ห่างจากค่าเฉลี่ยในทิศทางบวกมากกว่า จึงโดดเด่นกว่า
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านการประยุกต์ (A) ระดับ: ปานกลาง
ข้อ 12. ซุ้มเกมในงานวัดจัดเกมจับสลากใบละ 20 บาท โดยในกล่องมีสลาก 100 ใบ มีรางวัลดังนี้:
$\bullet$ รางวัลที่ 1 เงินสด 500 บาท จำนวน 1 ใบ
$\bullet$ รางวัลที่ 2 เงินสด 100 บาท จำนวน 5 ใบ
$\bullet$ สลากที่เหลืออีก 94 ใบไม่ได้รับรางวัลใด ๆ (ได้รับเงินรางวัล 0 บาท)
ในฐานะนักเรียนที่เรียนเรื่องค่าคาดหมายของตัวแปรสุ่ม หากต้องการตัดสินใจเชิงเศรษฐศาสตร์อย่างมีวิจารณญาณ ข้อสรุปใดถูกต้องที่สุด
เฉลย ค. ค่าคาดหมายของเงินรางวัล: $E(X) = 500\left(\frac{1}{100}\right) + 100\left(\frac{5}{100}\right) + 0\left(\frac{94}{100}\right) = 5 + 5 + 0 = 10$ บาท
เมื่อหักต้นทุนค่าสลาก 20 บาท ผลตอบแทนสุทธิที่คาดหมายคือ $10 - 20 = -10$ บาท แสดงว่าผู้เล่นเสียเปรียบเฉลี่ยใบละ 10 บาทในระยะยาว
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านการประยุกต์ (A) ระดับ: ปานกลาง
ข้อ 13. บริษัทผลิตชิ้นส่วนยานยนต์แห่งหนึ่งควบคุมคุณภาพความหนาของแผ่นเหล็กให้มีการแจกแจงปกติด้วย $\mu = 5.00$ มม. และ $\sigma = 0.05$ มม. โดยชิ้นงานที่ยอมรับได้ต้องมีความหนาอยู่ในช่วง $[4.90, 5.10]$ มม.
ถ้าวิศวกรต้องการลดสัดส่วนของชิ้นงานที่ตกเกรด (ชิ้นงานที่ไม่ได้มาตรฐาน) ให้เหลือน้อยที่สุด ควรให้ความสำคัญกับมาตรการใดในเชิงสถิติมากที่สุด
เฉลย ข. การลดค่า $\sigma$ จะทำให้การกระจายตัวของความหนาลดลง กราฟปกติจะบีบแคบเข้าหาจุดศูนย์กลาง $\mu = 5.00$ ทำให้พื้นที่ใต้กราฟที่ตกอยู่นอกเกณฑ์ $[4.90, 5.10]$ ลดลงอย่างมากตามหลัก Six Sigma
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านการประยุกต์ (A) ระดับ: ยาก
ข้อ 14. โรงพยาบาลแห่งหนึ่งทำการคัดกรองโรคทางพันธุกรรมที่พบได้ยาก โดยผู้มีความเสี่ยงสูง $2.5\%$ บนสุดของระดับโปรตีนในเลือดจะถูกส่งไปตรวจชิ้นเนื้อเพิ่มเติม
ถ้าระดับโปรตีนในเลือดของประชากรมีการแจกแจงปกติด้วย $\mu = 120$ มก./ดล. และ $\sigma = 15$ มก./ดล. (กำหนดให้ $P(Z \le 1.96) = 0.9750$)
แพทย์ควรตั้งเกณฑ์ระดับโปรตีนขั้นต่ำเท่าใดในการส่งผู้ป่วยไปตรวจชิ้นเนื้อเพิ่มเติม
เฉลย ก. กลุ่มเสี่ยงสูง $2.5\%$ บนสุด หมายถึงพื้นที่ทางขวาเท่ากับ $0.0250$ ซึ่งสอดคล้องกับพื้นที่สะสมทางซ้ายเท่ากับ $1 - 0.0250 = 0.9750$
จากตารางได้ค่ามาตรฐาน $Z = +1.96$
แปลงกลับเป็นค่าจริง: $x = \mu + Z\sigma = 120 + (1.96)(15) = 120 + 29.4 = 149.4$ มก./ดล.
ตัวชี้วัด: ค 3.2 ม.6/1 ด้านการประยุกต์ (A) ระดับ: ยาก
ข้อ 15. ระบบการให้เกรดแบบอิงกลุ่ม (Curved Grading) กำหนดให้นักเรียนที่ได้เกรด A ต้องมีผลคะแนนอยู่ในกลุ่ม $10\%$ บนสุดของการสอบรวม
หากคะแนนสอบมีการแจกแจงปกติ โดยมีนักเรียนเข้าสอบ 500 คน ทราบว่ามีนักเรียนสอบได้คะแนนมากกว่า 82 คะแนนอยู่ 50 คนพอดี และคะแนนเฉลี่ยของการสอบครั้งนี้คือ $\mu = 65$ คะแนน
ข้อความใดต่อไปนี้อธิบายสถานการณ์ดังกล่าวได้อย่างถูกต้องสมเหตุสมผลตามหลักสถิติ (กำหนดให้ $P(Z \le 1.28) \approx 0.9000$)
เฉลย ก. นักเรียน 50 คนจาก 500 คน คิดเป็นสัดส่วน $\frac{50}{500} = 0.10$ หรือ $10\%$ บนสุดพอดี
ดังนั้น คะแนน 82 คะแนนคือจุดตัดเกรด A ซึ่งตรงกับพื้นที่สะสมทางซ้าย $0.9000$ ได้ค่า $Z \approx +1.28$
จาก $Z = \frac{x - \mu}{\sigma} \implies 1.28 = \frac{82 - 65}{\sigma} \implies \sigma = \frac{17}{1.28} \approx 13.28$ คะแนน
