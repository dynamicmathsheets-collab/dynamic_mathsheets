ตัวจำลองการลดรูป แบบฝึกหัดจำแนก

ยุทธวิธีการแยกตัวประกอบและ ลดรูปสมการกำลังสี่

ก่อนจะก้าวไปสู่วิธีทั่วไปของแฟร์รารี (Ferrari's General Solution) ที่ซับซ้อน นักคณิตศาสตร์มักสำรวจ "โครงสร้างทางพีชคณิตจำเพาะ" เพื่อลดสมการกำลังสี่ลงเป็นผลคูณของสมการกำลังสอง หรือเปลี่ยนตัวแปรให้กลายเป็นสมการกำลังสองในทันที

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

วิเคราะห์โครงสร้างพหุนามกำลังสี่

นักศึกษาสามารถระบุโครงสร้างเฉพาะของสมการกำลังสี่ เช่น สมการไบคอนดราติก (Biquadratic), สมการสมมาตร (Palindromic/Symmetric) หรือสมการที่มีตัวประกอบตรรกยะได้อย่างแม่นยำ

เลือกกลยุทธ์การลดรูปและคำนึงถึงสนามจำนวน

นักศึกษาสามารถเลือกวิธีแยกตัวประกอบหรือการแทนตัวแปร \(u = x^2\) หรือ \(z = x + \frac{1}{x}\) ได้สอดคล้องกับโครงสร้าง พร้อมแปลงคำตอบกลับมายังสนามจำนวนจริงหรือจำนวนเชิงซ้อนได้อย่างถูกต้อง

Classification of Quartic Forms & Reduction Strategies

แบบที่ 1: มีเฉพาะกำลังคู่ Biquadratic Form

สมการกำลังสี่ที่มีเฉพาะกำลังคู่ (\(x^4 + px^2 + q = 0\))

พจน์ดีกรีคี่ (\(x^3\) และ \(x\)) มีสัมประสิทธิ์เป็นศูนย์ ทำให้สามารถแปลงตัวแปรโดยตรง:

แทน \(u = x^2 \quad (u \ge 0 \text{ สำหรับ } x \in \mathbb{R})\)
ได้สมการกำลังสอง: \[ u^2 + pu + q = 0 \]
ข้อควรระวังเรื่องสนามจำนวน (Number Fields):

• หาก \(u > 0 \implies x = \pm\sqrt{u}\) (ให้รากจริง 2 ราก)

• หาก \(u < 0 \implies x = \pm i\sqrt{|u|}\) (ให้รากเชิงซ้อนแท้ 2 ราก)

แบบที่ 2: ผลต่างกำลังสอง Difference of Squares

การเติมพจน์กำลังสองสมบูรณ์ (\(A^2 - B^2\))

สำหรับสมการเช่น \(x^4 + 4 = 0\) หรือสมการที่พจน์กลางไม่เอื้อต่อการแยกตรงๆ:

จัดรูป: \[ x^4 + 4 = (x^4 + 4x^2 + 4) - 4x^2 \] \[ = (x^2 + 2)^2 - (2x)^2 \] \[ = (x^2 - 2x + 2)(x^2 + 2x + 2) \]
ผลลัพธ์: แตกสมการกำลังสี่ออกเป็นผลคูณของพหุนามกำลังสอง 2 พจน์ ซึ่งสามารถแก้แต่ละวงเล็บด้วยสูตรกำลังสองได้ทันที
แบบที่ 3: สัมประสิทธิ์สมมาตร Palindromic Quartics

สมการสมมาตร (\(ax^4 + bx^3 + cx^2 + bx + a = 0\))

เมื่อสัมประสิทธิ์หน้า-หลังสมมาตรกัน (\(a = e, b = d\)) เนื่องจาก \(x = 0\) ไม่ใช่คำตอบ ให้นำ \(x^2\) หารตลอด:

\[ a\left(x^2 + \frac{1}{x^2}\right) + b\left(x + \frac{1}{x}\right) + c = 0 \] แทน \(z = x + \frac{1}{x} \implies x^2 + \frac{1}{x^2} = z^2 - 2\)
ได้สมการกำลังสองในรูป \(z\): \[ a(z^2 - 2) + bz + c = 0 \iff az^2 + bz + (c - 2a) = 0 \] หาค่า \(z\) แล้วนำกลับมาแก้ \(x^2 - zx + 1 = 0\) เพื่อหาราก \(x\)
แบบที่ 4: รากตรรกยะ & การจัดกลุ่ม Factor Theorem & Grouping

ทฤษฎีบทรากตรรกยะและการหารสังเคราะห์

สำหรับสมการทั่วไปที่มีสัมประสิทธิ์เป็นจำนวนเต็ม ให้ทดสอบรากตรรกยะ \(\frac{p}{q}\) โดยที่ \(p \mid e\) และ \(q \mid a\):

ถ้า \(P(r) = 0\) จะได้ว่า \((x - r)\) เป็นตัวประกอบ
ใช้การหารสังเคราะห์ลดทอนดีกรีลงเหลือพหุนามกำลังสาม \(\to\) กำลังสอง
การจัดกลุ่มพจน์ (Grouping): จัดคู่ที่มีตัวประกอบร่วม เช่น \(x^3(x - 2) - 8(x - 2) = 0 \implies (x - 2)(x^3 - 8) = 0\)

คำถามนำเพื่อค้นพบ (Guided Inquiry Questions)

สำรวจหลักการทางพีชคณิตเพื่อทำความเข้าใจเงื่อนไขของแต่ละวิธีอย่างลึกซึ้ง

ไม่ได้เด็ดขาด วิธีนี้ใช้ได้เฉพาะเมื่อสัมประสิทธิ์ของดีกรีคี่เป็นศูนย์ทั้งคู่ (\(b = 0\) และ \(d = 0\))

หากมีพจน์ \(bx^3\) หรือ \(dx\) ปรากฏอยู่ เมื่อเราแทน \(x^2 = u\) พจน์เหล่านั้นจะกลายเป็น \(b u \sqrt{u}\) หรือ \(d \sqrt{u}\) ซึ่งทำให้สมการติดเครื่องหมายกรณฑ์ (Radical) และไม่สามารถคงสถานะเป็นสมการกำลังสองพหุนามของ \(u\) ได้

ดังนั้น การแทน \(u = x^2\) จึงสงวนไว้เฉพาะสมการ Biquadratic ที่มีเฉพาะกำลังคู่ (\(ax^4 + cx^2 + e = 0\)) เท่านั้น

ตามทฤษฎีกาลัวส์ (Galois Theory) กรุปกาลัวส์ของสมการกำลังสี่ทั่วไปคือสมมาตรกรุป \(S_4\) ซึ่งมีอันดับ 24 การแก้สมการกำลังสี่โดยทั่วไปจึงเทียบเท่ากับการแก้สมการกำลังสามช่วย (Resolvent Cubic) เสียก่อน

แต่หากสมการมี ความสมมาตรทางพีชคณิต (Symmetry) เช่น:

  • กำลังคู่ทั้งหมด (Biquadratic): รากมีความสมมาตรคู่ \((\pm x_1, \pm x_2)\) กรุปย่อยจะลดรูปลงเหลือ Klein four-group \(V_4\)
  • สมการสมมาตร (Palindromic): หาก \(r\) เป็นราก \(\frac{1}{r}\) จะเป็นรากด้วยเสมอ ทำให้สามารถจับคู่ \(z = x + \frac{1}{x}\) ได้

โครงสร้างจำเพาะเหล่านี้ช่วย "ยุบตัวแปร" ทำให้เราข้ามขั้นตอนการแก้สมการกำลังสาม และลดรูปเป็นสมการกำลังสองได้ทันที

1. การแทน \(u = x^2\) (Biquadratic) เป็นวิธีที่ง่ายและรวดเร็วที่สุด เพราะใช้สูตรกำลังสอง (Quadratic Formula) เพียง 2 จังหวะ: หา \(u\) แล้วถอดกรณฑ์หา \(x\)

2. การจัดกลุ่มพจน์ (Grouping) หรือพบรากตรรกยะโดยตรง: หากสังเกตเห็นตัวประกอบร่วม การดึงตัวประกอบออกทันทีจะทำให้ดีกรีลดลงเหลือสมการกำลังสองได้อย่างไม่ซับซ้อน

ลำดับการตรวจสอบที่แนะนำ: เช็กว่ามีพจน์คี่หรือไม่ (\(u=x^2\)) \(\to\) เช็กความสมมาตรสัมประสิทธิ์ (\(z=x+\frac{1}{x}\)) \(\to\) เช็กผลต่างกำลังสอง \((x^2+k)^2 - (mx)^2\) \(\to\) ทดสอบรากตรรกยะ \(P(\pm 1, \pm 2, \dots)\)
