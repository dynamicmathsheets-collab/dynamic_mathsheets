เรื่องที่ 6: การเลือกวิธีแก้และการประยุกต์สมการกำลังสี่

ตัวเปรียบเทียบกลยุทธ์ แบบฝึกหัด

ยุทธศาสตร์การตัดสินใจ: เลือกวิธีแก้ที่ทรงคุณค่าและแม่นยำ

แม้ วิธีของแฟร์รารี (Ferrari's General Solution) จะสามารถแก้สมการกำลังสี่ได้ทุกรูปแบบในทางทฤษฎี แต่นักคณิตศาสตร์ที่เชี่ยวชาญจะ วินิจฉัยโครงสร้างของสัมประสิทธิ์ก่อนเสมอ เพื่อเลือกยุทธวิธีที่สง่างาม รัดกุม ลดทอนขั้นตอนการคำนวณ และตรวจสอบรากด้วยสูตรของวีเอตาได้อย่างสมบูรณ์

1

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

วิเคราะห์โครงสร้างสัมประสิทธิ์

จำแนกรูปแบบสมการกำลังสี่ได้อย่างรวดเร็ว ไม่ว่าจะเป็นไบคอนดราติก สมมาตร หรือสมการที่มีรากตรรกยะ

เปรียบเทียบกลยุทธ์เชิงพีชคณิต

ประเมินข้อดีข้อจำกัดระหว่างการแทนตัวแปร การแยกตัวประกอบ และวิธีแฟร์รารี โดยคำนึงถึงความกระชับและความถูกต้อง

ตรวจสอบรากและพหุภาพ

ใช้ความสัมพันธ์ของวีเอตา (Vieta) และการแทนค่ากลับเพื่อยืนยันชนิดและพหุภาพของรากทั้งสี่อย่างเป็นระบบ

2

เนื้อหาหลัก: ลำดับขั้นการตัดสินใจเลือกวิธีแก้ (Decision Hierarchy)

Method Selection Tree & Strategy Comparison Matrix

ลำดับการตรวจสอบโครงสร้างของ \(ax^4 + bx^3 + cx^2 + dx + e = 0\) (จากง่ายไปซับซ้อน):
ลำดับที่ 1 b = 0, d = 0

สมการไบคอนดราติก

มีเฉพาะกำลังคู่ แทน \(u = x^2\) แล้วใช้สูตรกำลังสองทันที

ความซับซ้อน: 1-2 บรรทัด
ลำดับที่ 2 a = e, b = d

สมการสมมาตร (Palindromic)

หาร \(x^2\) แล้วแทน \(z = x + \frac{1}{x}\) ได้สมการกำลังสองในรูป \(z\)

ความซับซ้อน: ปานกลาง
ลำดับที่ 3 e = 0 หรือ P(r)=0

รากตรรกยะ / ดึงตัวร่วม

ดึง \(x\) หรือหารสังเคราะห์ด้วยตัวหารของ \(e\) ลดทอนดีกรี

ความซับซ้อน: ต่ำ-ปานกลาง
ลำดับที่ 4 A² - B² = 0

ผลต่างกำลังสองจำเพาะ

เติมพจน์ \((x^2+k)^2 - (mx)^2\) เช่นกรณี \(x^4+4=0\)

ความซับซ้อน: ปานกลาง
ลำดับที่ 5 ทั่วไป / ไม่มีรูปพิเศษ

วิธีของแฟร์รารี (Ferrari)

ทำสมการรูปกด \(\to\) แก้สมการช่วยกำลังสาม \(\to\) 2 ควอดราติก

ครอบคลุม 100% แต่ขั้นตอนมากสุด
ตารางเปรียบเทียบมิติเชิงพีชคณิตของแต่ละยุทธวิธี:
กลยุทธ์ เงื่อนไขเชิงโครงสร้าง จำนวนขั้นตอน ชนิดของรากที่รองรับ ความเสี่ยงต่อการคำนวณพลาด
1. การแทน \(u = x^2\) (Biquadratic) b = 0 \text{ และ } d = 0 น้อยมาก (2-3 ขั้น) จริงคู่บวกลบ หรือเชิงซ้อนคู่สังยุคจินตภาพแท้ ต่ำมาก (แก้สมการกำลังสองครั้งเดียว)
2. สมการสมมาตร (\(z = x + 1/x\)) a = e, b = d \text{ (หรือกึ่งสมมาตร)} ปานกลาง (4-5 ขั้น) รากที่จับคู่ส่วนกลับกัน \((r, 1/r)\) ต่ำ-ปานกลาง (คำนึง \(x \ne 0\))
3. รากตรรกยะและการจัดกลุ่ม P(p/q) = 0 \text{ โดย } p \mid e, q \mid a ปานกลาง (หารสังเคราะห์) ต้องมีรากตรรกยะอย่างน้อย 1 หรือ 2 ตัว ปานกลาง (ขึ้นกับการสุ่มทดสอบราก)
4. วิธีทั่วไปของแฟร์รารี (Ferrari) \text{ใช้ได้กับทุกสมการ } a \ne 0 มากที่สุด (7-9 ขั้น) ทุกรูปแบบ (จริง อตรรกยะ เชิงซ้อน) สูง (มีสมการช่วยกำลังสามและถอดกรณฑ์ซ้อน)
การใช้สูตรของวีเอตาเป็น "ด่านตรวจรับรองความถูกต้อง" (Sanity Check):

เมื่อคำนวณราก \(r_1, r_2, r_3, r_4\) ครบทั้งสี่ตัว ไม่ว่าจะใช้วิธีใดก็ตาม เราสามารถตรวจเช็กความถูกต้องได้ทันทีโดยไม่ต้องนำรากไปยกกำลังสี่แทนกลับ:

\[ \sum_{i=1}^4 r_i = r_1 + r_2 + r_3 + r_4 = -\frac{b}{a} \]
\[ \prod_{i=1}^4 r_i = r_1 r_2 r_3 r_4 = \frac{e}{a} \]
3

แบบจำลองโต้ตอบ: ห้องปฏิบัติการวินิจฉัยและเปรียบเทียบวิธีแก้ (Decision Lab)

เลือกโจทย์โครงสร้างต่าง ๆ เลือดยุทธวิธีที่ต้องการทดสอบ และเปรียบเทียบกับวิธีแฟร์รารี

เลือกกรณีศึกษาโครงสร้างสมการตัวอย่าง:
กำหนดสัมประสิทธิ์: \(ax^4 + bx^3 + cx^2 + dx + e = 0\)
เลือกยุทธวิธีที่ต้องการนำไปแก้สมการนี้:
หากแก้ด้วยวิธีทั่วไปของแฟร์รารี (Benchmark) 7-8 ขั้นตอน (General)
การตรวจสอบความถูกต้องของรากทั้งสี่ด้วยสูตรของวีเอตา (Vieta Verification): Validated 100%
4

คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

สำรวจแนวคิดเบื้องหลังการเลือกกลยุทธ์และการตรวจสอบคำตอบ

ไม่จำเป็นอย่างยิ่ง แม้วิธีแฟร์รารีจะเป็นวิธีทั่วไป (General Method) ที่รับประกันว่าสามารถแก้สมการกำลังสี่ได้ทุกรูปแบบ แต่การนำวิธีแฟร์รารีไปใช้กับสมการที่มีโครงสร้างพิเศษ เช่น ไบคอนดราติก (\(x^4 - 5x^2 + 4 = 0\)) ถือเป็น "Overkill" (การใช้เครื่องมือที่ซับซ้อนเกินความจำเป็น)

การใช้วิธีที่ซับซ้อนเกินไปจะเพิ่มจำนวนขั้นตอนจาก 2 บรรทัดกลายเป็น 8 บรรทัด ต้องแก้สมการช่วยกำลังสาม และต้องถอดรากที่ซ้อนกัน ซึ่งเพิ่มโอกาสเกิดความผิดพลาดในการคำนวณอย่างมหาศาล

เราใช้ หลักการวินิจฉัยเชิงลำดับชั้น (Decision Hierarchy) ดังนี้:

  • ตรวจดูพจน์คี่ก่อน: ถ้า \(b = 0\) และ \(d = 0\) \(\implies\) เลือก การแทน \(u = x^2\) ทันทีเพราะง่ายที่สุด
  • ตรวจดูความสมมาตรหน้า-หลัง: ถ้า \(a = e\) และ \(b = d\) \(\implies\) เลือก การแทน \(z = x + \frac{1}{x}\)
  • ตรวจดูพจน์คงตัวและผลรวมสัมประสิทธิ์: ถ้า \(a+b+c+d+e = 0\) แสดงว่า \(x = 1\) เป็นราก หรือถ้าพจน์คงตัว \(e\) แยกตัวประกอบง่าย \(\implies\) ใช้ ทฤษฎีบทรากตรรกยะและการหารสังเคราะห์
  • หากไม่พบรูปแบบพิเศษใด ๆ: จึงค่อยใช้วิธีทั่วไปของแฟร์รารี

การนำรากที่ได้ (โดยเฉพาะรากที่ติดค่ากรณฑ์หรือจำนวนเชิงซ้อน) ไปแทนกลับในสมการเดิมเพื่อยกกำลังสี่ \(P(x) = 0\) ทำได้ยากและเสี่ยงต่อการคำนวณผิดพลาด

แต่ สูตรของวีเอตา (Vieta's Formulas) อาศัยการบวกและคูณอย่างง่าย:

\[ r_1 + r_2 + r_3 + r_4 = -\frac{b}{a}, \qquad r_1 r_2 r_3 r_4 = \frac{e}{a} \]

หากผลรวมหรือผลคูณไม่ตรงกับสัมประสิทธิ์เดิม จะชี้ชัดได้ทันทีว่ามีข้อผิดพลาดเรื่องเครื่องหมายบวกลบหรือการถอดกรณฑ์ ทำให้แก้ไขได้อย่างตรงจุด

5
