เรื่องที่ 3: วิธีของแฟร์รารี (Ferrari's Method)

ตัวจำลองแฟร์รารี แบบฝึกหัด

วิธีของแฟร์รารี: การแยกตัวประกอบด้วย สมการช่วยกำลังสาม

ค้นพบโดย โลโดวีโก แฟร์รารี (Lodovico Ferrari) ในปี 1540 โดยใช้แนวคิดเติมพารามิเตอร์เพื่อสร้างกำลังสองสมบูรณ์ทั้งสองข้างของสมการ จนนำไปสู่ สมการช่วยกำลังสาม (Resolvent Cubic) ซึ่งทำให้แยกตัวประกอบสมการกำลังสี่เป็นผลคูณของพหุนามกำลังสองได้สำเร็จ

1

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

อธิบายแนวคิดของแฟร์รารี

เข้าใจกลยุทธ์การเติมพารามิเตอร์ \(z\) เพื่อบังคับให้สมการกำลังสี่กลายเป็นสมการผลต่างกำลังสอง \(A^2 - B^2 = 0\)

สร้างสมการช่วยกำลังสาม

พิสูจน์ที่มาของ Resolvent Cubic จากเงื่อนไขดิสคริมิแนนต์เป็นศูนย์ (\(\Delta_y = 0\)) ของพหุนามด้านขวา

แยกตัวประกอบและคำนวณราก

แยกตัวประกอบเป็นผลคูณของพหุนามกำลังสอง 2 พหุนาม พร้อมตรวจสอบความถูกต้องด้วยการคูณกระจายกลับ

2

เนื้อหาหลัก: 5 ขั้นตอนสู่สูตรผลเฉลยของแฟร์รารี

Mathematical Proof and Construction of Ferrari's Resolvent Cubic

ขั้นที่ 1: ตั้งต้นจากสมการรูปกด

ย้ายข้างจัดกลุ่มพจน์

จากสมการรูปกด \(y^4 + py^2 + qy + r = 0\) ย้ายข้างพจน์ดีกรีต่ำไปทางขวา:

\[ y^4 + py^2 = -qy - r \]
ขั้นที่ 2: เติมพารามิเตอร์ \(z\)

ทำด้านซ้ายเป็น \((y^2 + z)^2\)

บวกพจน์ \((2z - p)y^2 + z^2\) เข้าทั้งสองข้างของสมการ:

\[ (y^2 + z)^2 = (2z - p)y^2 - qy + (z^2 - r) \]
ขั้นที่ 3: จุดพลิกผัน (Crucial Step)

บังคับให้พหุนามกำลังสองด้านขวาเป็น "กำลังสองสมบูรณ์"

Discriminant = 0

พิจารณาด้านขวา: \(P(y) = (2z - p)y^2 - qy + (z^2 - r)\) เป็นพหุนามกำลังสองในตัวแปร \(y\)
พหุนามกำลังสอง \(Ay^2 + By + C\) จะเขียนเป็นกำลังสองสมบูรณ์ได้ ก็ต่อเมื่อดิสคริมิแนนต์ \(\Delta = B^2 - 4AC = 0\)

\[ (-q)^2 - 4(2z - p)(z^2 - r) = 0 \] \[ q^2 - 4\left(2z^3 - pz^2 - 2rz + pr\right) = 0 \]
\[ 8z^3 - 4pz^2 - 8rz + (4pr - q^2) = 0 \]
สมการนี้คือ "สมการช่วยกำลังสาม" (Resolvent Cubic) ในตัวแปร \(z\) ซึ่งการันตีว่ามีรากจริง \(z_0\) อย่างน้อยหนึ่งรากเสมอ!
ขั้นที่ 4: แทนราก \(z_0\)

ยุบด้านขวาเป็นกำลังสองสมบูรณ์

เมื่อเลือกรากจริง \(z_0\) ที่ทำให้ \(2z_0 - p > 0\) จะได้:

\[ (y^2 + z_0)^2 = (My - N)^2 \] \[ \text{โดยที่ } M = \sqrt{2z_0 - p}, \quad N = \frac{q}{2M} \]
ขั้นที่ 5: ผลต่างกำลังสอง

แยกเป็นผลคูณ 2 พหุนามกำลังสอง

ใช้เอกลักษณ์ \(A^2 - B^2 = (A - B)(A + B) = 0\):

\[ (y^2 - My + [z_0 + N])(y^2 + My + [z_0 - N]) = 0 \]

คำถามนำเพื่อค้นพบ (Guided Inquiry Questions)

คลิกที่คำถามเพื่อสำรวจเหตุผลทางคณิตศาสตร์และความลึกซึ้งของวิธีแฟร์รารี

สมการกำลังสี่ไม่มีสมมาตรที่ตรงไปตรงมาพอที่จะแก้ได้ด้วยรากกรณฑ์โดยตรงเหมือนสมการกำลังสอง แต่เอกลักษณ์ "ผลต่างกำลังสอง" (\(A^2 - B^2 = 0\)) คือเครื่องมือที่ทรงพลังที่สุดในการแยกตัวประกอบ:

\[ A^2 - B^2 = (A - B)(A + B) = 0 \]

แฟร์รารีมองเห็นว่า หากเราสามารถปรับแต่งทั้งสองข้างให้เป็นกำลังสองสมบูรณ์ \((y^2 + z)^2 = (My - N)^2\) เราจะสามารถ "ปลดดีกรีสี่" ออกเป็นสมการกำลังสอง 2 สมการที่อิสระจากกัน ซึ่งแก้ได้ทันทีด้วยสูตรกำลังสองของ มูฮัมหมัด อัลเคาะวาริซมี (Quadratic Formula)

สมการช่วยกำลังสามเกิดขึ้นจาก "เงื่อนไขดิสคริมิแนนต์เท่ากับศูนย์" (\(\Delta = 0\)) ของพหุนามกำลังสองทางด้านขวา:

\[ P(y) = (2z - p)y^2 - qy + (z^2 - r) \]
  • ในเชิงพีชคณิต: พหุนามกำลังสองจะมีรากซ้ำเพียงรากเดียว (ซึ่งหมายถึงสามารถเขียนในรูป \((My - N)^2\) ได้) ก็ต่อเมื่อ \(B^2 - 4AC = 0\) ซึ่งทำให้เกิดสมการดีกรี 3 ในตัวแปร \(z\)
  • ในเชิงเรขาคณิต: พาราโบลา \(P(y)\) จะต้องสัมผัสกับแกนนอน \(y\) พอดี (จุดยอดแตะแกน \(x\)) ไม่ตัดและไม่ลอย จึงทำให้ไม่มีพจน์คงตัวส่วนเกิน

ในมุมมองของ ทฤษฎีกาลัวส์ (Galois Theory):

สมการกำลังสี่ทั่วไปมีสมมาตรกรุปของรากเป็น \(S_4\) (มีขนาด \(4! = 24\) วิธีการเรียงสับเปลี่ยน) กรุป \(S_4\) มีนอร์มัลกรุปย่อยคือ Klein four-group \(V_4\) (ขนาด 4)

อันดับของกรุปผลหาร: \[ |S_4 / V_4| = \frac{24}{4} = 6 \cong S_3 \]

กรุปที่มีขนาด 6 หรือสมมาตร \(S_3\) นี้ตรงกับกรุปของ สมการกำลังสาม (Cubic Equation) พอดี! นั่นคือรากทั้ง 3 ของสมการช่วยกำลังสาม (\(z_1, z_2, z_3\)) สอดคล้องกับการจับคู่แบ่งราก 4 ตัวของสมการกำลังสี่ออกเป็น 2 คู่:

\(z_1 = \frac{1}{2}(y_1 y_2 + y_3 y_4), \quad z_2 = \frac{1}{2}(y_1 y_3 + y_2 y_4), \quad z_3 = \frac{1}{2}(y_1 y_4 + y_2 y_3)\)
