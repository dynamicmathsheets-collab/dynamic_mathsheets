เรื่องที่ 1: รูปทั่วไปและการลดรูปสมการกำลังสี่

จำลองเชิงกราฟ แบบฝึกหัด

การลดรูปสมการกำลังสี่เป็น Depressed Quartic

ขั้นตอนสำคัญในการแก้สมการกำลังสี่ตามวิธีของโลโดวีโก แฟร์รารี (Lodovico Ferrari) โดยกำจัดพจน์กำลังสามผ่านการเลื่อนแกนตัวแปร ทำให้สมการอยู่ในรูปอย่างง่ายพร้อมเข้าสู่กระบวนการแยกตัวประกอบ

1

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

อธิบายรูปทั่วไปและรูปโมนิก

นักศึกษาสามารถอธิบายความแตกต่างระหว่างรูปทั่วไป (General Quartic) และรูปโมนิก (Monic Form) ของสมการพหุนามกำลังสี่ได้ถูกต้อง

ลดรูปและกำจัดพจน์กำลังสาม

นักศึกษาสามารถคำนวณการแทนตัวแปร \(x = y - \frac{A}{4}\) เพื่อกำจัดพจน์กำลังสามให้กลายเป็นสมการรูปกด (Depressed Quartic) ได้อย่างแม่นยำทุกขั้นตอน

2

เนื้อหาหลักและทฤษฎีการแปลงตัวแปร

Tschirnhaus Transformation for Quartic Polynomial

ขั้นที่ 1

สมการพหุนามกำลังสี่รูปทั่วไป

เมื่อ \(a \ne 0\) เป็นสัมประสิทธิ์นำ:

\[ ax^4 + bx^3 + cx^2 + dx + e = 0 \]
หารทั้งสองข้างด้วย \(a\) เพื่อแปลงเป็น รูปโมนิก (Monic Form)
ขั้นที่ 2

รูปโมนิก (Monic Polynomial)

โดยที่ \(A=\frac{b}{a}, B=\frac{c}{a}, C=\frac{d}{a}, D=\frac{e}{a}\):

\[ x^4 + Ax^3 + Bx^2 + Cx + D = 0 \]
สังเกตว่าพจน์ \(Ax^3\) ยังคงปรากฏอยู่
ขั้นที่ 3

สมการรูปกด (Depressed Quartic)

แทนตัวแปร \(x = y - \frac{A}{4}\) ได้รูป:

\[ y^4 + py^2 + qy + r = 0 \]
พจน์กำลังสาม (\(y^3\)) หายไปอย่างสมบูรณ์!

สูตรสำเร็จการคำนวณสัมประสิทธิ์ใหม่ \(p, q, r\)

เกิดจากการกระจายทวินามและจัดกลุ่มพจน์
สัมประสิทธิ์กำลังสอง (\(p\)):
\[ p = B - \frac{3A^2}{8} \]

ขึ้นอยู่กับสัมประสิทธิ์ลำดับที่หนึ่งและสอง (\(A, B\))

สัมประสิทธิ์กำลังหนึ่ง (\(q\)):
\[ q = C - \frac{AB}{2} + \frac{A^3}{8} \]

หาก \(q = 0\) สมการจะเป็น Biquadratic แก้ได้โดยทันที

พจน์คงตัว (\(r\)):
\[ r = D - \frac{AC}{4} + \frac{A^2 B}{16} - \frac{3A^4}{256} \]

เป็นการรวมพจน์คงตัวทั้งหมดหลังจากการเลื่อนแกน

ความสัมพันธ์ระหว่างรากเดิม (\(x_i\)) และรากรูปกด (\(y_i\)):
\(x_i = y_i - \dfrac{A}{4} \iff y_i = x_i + \dfrac{A}{4}\)
3

แบบจำลองโต้ตอบและการทดลองเชิงกราฟ

ปรับสัมประสิทธิ์เพื่อสังเกตการคำนวณและการเลื่อนแกนราก (Translation of Roots)

ไม่สามารถกำหนดค่า \(a = 0\) ได้

หากสัมประสิทธิ์นำ \(a = 0\) พหุนามจะไม่ใช่สมการกำลังสี่ กรุณาระบุค่า \(a \ne 0\)

ปรับสัมประสิทธิ์สมการเดิม: \(ax^4 + bx^3 + cx^2 + dx + e = 0\)
*a ≠ 0
สมการเดิม \(f(x) = 0\)
สมการรูปกด (Depressed Quartic) \(g(y) = 0\)

กราฟฟังก์ชัน \(f(t)\) เปรียบเทียบกับ \(g(t)\)

เดิม \(f(x)\) รูปกด \(g(y)\)

สังเกตกราฟ: กราฟรูปกด \(g(y)\) มีรูปร่างเหมือนกราฟ \(f(x)\) ทุกประการ แต่ถูกเลื่อนขนานแนวนอน (Horizontal Translation) ด้วยระยะ \(h = \frac{A}{4}\)

ขั้นตอนการคำนวณสัมประสิทธิ์

4

คำถามนำเพื่อค้นพบ (Guided Inquiry)

คลิกที่คำถามเพื่อดูคำอธิบายและแนวคิดทางคณิตศาสตร์เชิงลึก

พิจารณาการกระจายทวินาม (Binomial Expansion) เมื่อแทน \(x = y - h\):

\((y - h)^4 = y^4 - 4hy^3 + 6h^2 y^2 - 4h^3 y + h^4\)
\(A(y - h)^3 = Ay^3 - 3Ahy^2 + 3Ah^2 y - Ah^3\)

เมื่อรวมสัมประสิทธิ์ของพจน์ \(y^3\) จากทั้งสองพจน์ จะได้:

\[ \text{สัมประสิทธิ์ของ } y^3 = -4h + A \]

ต้องการให้พจน์ \(y^3\) หายไป นั่นคือ \(-4h + A = 0 \implies h = \dfrac{A}{4}\)

ดังนั้น การเลือกค่า \(h = \frac{A}{4}\) จึงทำให้สัมประสิทธิ์ของ \(y^3\) กลายเป็นศูนย์พอดีในทุกกรณี

1. ลดความซับซ้อนของตัวแปร: การกำจัดพจน์กำลังสาม (\(y^3\)) ทำให้จำนวนพจน์ตัวแปรลดลงจาก 4 พจน์ เหลือเพียง 3 พจน์ คือ \(y^4, y^2, y\)

2. นำไปสู่วิธีของแฟร์รารี (Ferrari's Method): รูปแบบ \(y^4 + py^2 = -qy - r\) ทำให้เราสามารถเติมพจน์ \(2zy^2 + z^2\) ทั้งสองข้างเพื่อทำเป็นกำลังสองสมบูรณ์ และสร้างสมการแก้ช่วย (Resolvent Cubic) เพื่อหารากได้อย่างเป็นระบบ

3. กรณีพิเศษ Biquadratic: หาก \(q = 0\) สมการจะกลายเป็น \(y^4 + py^2 + r = 0\) ซึ่งสามารถมองเป็นสมการกำลังสองของ \(u = y^2\) และแก้ได้ทันทีด้วยสูตรกำลังสอง

ในทางเรขาคณิต การแปลง \(x = y - \frac{A}{4}\) เปรียบเสมือนการ เลื่อนแกนพิกัด (Translation of Axes)

  • รากเดิม \(x_i\) ทั้ง 4 ราก จะถูกเลื่อนไปทางบวกด้วยระยะคงที่ \(\frac{A}{4}\) นั่นคือ \(y_i = x_i + \frac{A}{4}\)
  • จุดศูนย์ถ่วงของราก (Center of Mass): ผลรวมของรากในสมการโมนิกคือ \(\sum x_i = -A\) แต่ในสมการรูปกด ผลรวมของรากคือ \(\sum y_i = 0\) เสมอ (เนื่องจากไม่มีพจน์ \(y^3\))
  • กราฟของฟังก์ชันไม่ได้เปลี่ยนรูปร่าง เพียงแค่ถูกเลื่อนขนานแนวนอนเพื่อให้แกนสมมาตร/จุดสมดุลของพหุนามมาอยู่ที่แกนตั้ง \(y = 0\)
5

แบบฝึกหัดสำหรับนักศึกษา (Practice Quiz)

ทดสอบการคำนวณสัมประสิทธิ์รูปกด \(p, q, r\) และตรวจผลลัพธ์ทันที

โจทย์ข้อที่กำหนด: จงหาค่าสัมประสิทธิ์ p, q, r

คำสั่ง: จงลดรูปสมการกำลังสี่นี้ให้อยู่ในรูปกด \(y^4 + py^2 + qy + r = 0\) ผ่านการแปลง \(x = y - \frac{A}{4}\)
