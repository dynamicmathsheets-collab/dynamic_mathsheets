ความสัมพันธ์ระหว่างรากกับสัมประสิทธิ์ (Vieta's Formulas)

ค้นพบสะพานเชื่อมระหว่างมิติทางเรขาคณิตของรากสมการกับสัมประสิทธิ์เชิงพีชคณิต ผ่านสูตรของวีเอตา พหุนามสมมาตรมูลฐาน และเทคนิคการสร้างสมการพหุนาม

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

ทักษะและมโนทัศน์สำคัญที่นักศึกษาจะเชี่ยวชาญหลังเรียนจบหัวข้อนี้

เมื่อศึกษาและปฏิสัมพันธ์กับโมดูลจำลองนี้แล้ว นักศึกษาจะมีความสามารถดังต่อไปนี้:

  • ✓ อธิบายและพิสูจน์สูตรของวีเอตา (Vieta's Formulas) จากการเทียบสัมประสิทธิ์ระหว่างรูปผลคูณแยกตัวประกอบกับรูปมาตรฐานของพหุนามดีกรี $n$
  • ✓ คำนวณผลบวกของราก ผลคูณของราก และผลบวกของผลคูณรากเป็นคู่ได้ทันทีจากสัมประสิทธิ์ของสมการโดยไม่ต้องแก้หารากจริง
  • ✓ ประยุกต์สูตรของวีเอตาร่วมกับนิพจน์สมมาตรมูลฐาน (Symmetric Expressions) เช่น $\sum r_i^2$, $\sum \frac{1}{r_i}$ และสามารถสร้างสมการพหุนามใหม่จากรากหรือเงื่อนไขที่กำหนดได้อย่างแม่นยำ

2. เนื้อหาหลัก (Core Content)

ทฤษฎีบทการแยกตัวประกอบ สูตรของวีเอตา และพีชคณิตของนิพจน์สมมาตร

2.1 การแยกตัวประกอบของพหุนามโดยใช้ราก (Factorization via Roots)

จากทฤษฎีบทมูลฐานของพีชคณิต (Fundamental Theorem of Algebra) พหุนามดีกรี $n \ge 1$ ใด ๆ เหนือสนามจำนวนเชิงซ้อน:

$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 \quad (a_n \neq 0)$$

สามารถเขียนแยกตัวประกอบเป็นผลคูณของตัวประกอบเชิงเส้นได้ $n$ ตัวเสมอ โดยมีรากคือ $r_1, r_2, \dots, r_n$:

$$P(x) = a_n (x - r_1)(x - r_2)\cdots(x - r_n) = a_n \prod_{i=1}^n (x - r_i)$$

ทฤษฎีบท 2.2 สูตรของวีเอตา (Vieta's Formulas)

เมื่อทำการกระจายผลคูณ $a_n(x - r_1)\cdots(x - r_n)$ แล้วเทียบสัมประสิทธิ์ของตัวแปร $x$ ในแต่ละกำลังกับรูปมาตรฐาน จะได้ความสัมพันธ์ที่สอดคล้องกับพหุนามสมมาตรมูลฐาน (Elementary Symmetric Polynomials $e_k$):

ผลบวกของรากทั้งหมด ($e_1$):
$$\sum_{i=1}^n r_i = r_1 + r_2 + \dots + r_n = -\frac{a_{n-1}}{a_n}$$
ผลคูณของรากทั้งหมด ($e_n$):
$$\prod_{i=1}^n r_i = r_1 r_2 \cdots r_n = (-1)^n \frac{a_0}{a_n}$$
กรณีทั่วไปสำหรับพจน์ผลบวกของผลคูณทีละ $k$ ราก ($e_k$): $$\sum_{1 \le i_1 < i_2 < \dots < i_k \le n} r_{i_1} r_{i_2} \cdots r_{i_k} = (-1)^k \frac{a_{n-k}}{a_n}$$

เครื่องหมายจะสลับบวก-ลบเสมอ เริ่มต้นจากลบ ($k=1$), บวก ($k=2$), ลบ ($k=3$), $\dots$

กรณีดีกรี 2: $a x^2 + b x + c = 0$

• ผลบวกราก: $r_1 + r_2 = -\frac{b}{a}$
• ผลคูณราก: $r_1 r_2 = \frac{c}{a}$
สมการโมนิก: $x^2 - (r_1+r_2)x + (r_1 r_2) = 0$

กรณีดีกรี 3: $a x^3 + b x^2 + c x + d = 0$

• ผลบวกราก: $r_1 + r_2 + r_3 = -\frac{b}{a}$
• ผลบวกผลคูณทีละ 2: $r_1 r_2 + r_2 r_3 + r_1 r_3 = \frac{c}{a}$
• ผลคูณรากทั้งหมด: $r_1 r_2 r_3 = -\frac{d}{a}$

เทคนิคสำคัญ 2.4 นิพจน์สมมาตรของราก (Symmetric Expressions) และการสร้างสมการ

นิพจน์สมมาตรคือพหุนามที่ไม่เปลี่ยนค่าเมื่อสลับตำแหน่งรากใด ๆ เราสามารถแปลงให้อยู่ในรูปผลบวกและผลคูณของวีเอตาได้เสมอ เช่น:

ผลบวกกำลังสอง:
$r_1^2 + r_2^2 = (r_1+r_2)^2 - 2r_1r_2$
ผลบวกส่วนกลับ:
$\frac{1}{r_1} + \frac{1}{r_2} = \frac{r_1 + r_2}{r_1 r_2}$
ผลต่างกำลังสอง:
$(r_1 - r_2)^2 = (r_1+r_2)^2 - 4r_1r_2$

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

ท้าทายความคิดเพื่อสร้างความเข้าใจที่ลึกซึ้ง (คลิกเพื่อดูแนวทางคำตอบ)

คำถามที่ 1

เหตุใดผลบวกของรากจึงสัมพันธ์กับสัมประสิทธิ์ของพจน์ดีกรี $n-1$?

สังเกตการคูณกระจายวงเล็บ $(x - r_1)(x - r_2)\cdots(x - r_n)$ ในพจน์ที่ได้ $x^{n-1}$

แนวคำตอบ: เมื่อกระจาย $(x - r_1)(x - r_2)\cdots(x - r_n)$ การจะได้พจน์ที่มีกำลัง $x^{n-1}$ จะต้องเลือกตัวแปร $x$ มาจาก $(n-1)$ วงเล็บ และเลือกค่าคงที่ $-r_i$ มาจากวงเล็บที่เหลือเพียง 1 วงเล็บ เมื่อทำครบทุกรูปแบบแล้วนำมารวมกัน จะได้ $(-r_1 - r_2 - \dots - r_n)x^{n-1} = -(\sum r_i)x^{n-1}$ เมื่อคูณด้วยสัมประสิทธิ์นำ $a_n$ และเทียบกับ $a_{n-1}x^{n-1}$ จะได้ข้อสรุป $\sum r_i = -\frac{a_{n-1}}{a_n}$ ทันที
คำถามที่ 2

หากเปลี่ยนรากหนึ่งราก สัมประสิทธิ์ใดได้รับผลกระทบบ้าง?

ทดลองเลื่อนสไลเดอร์ราก $r_1$ ในแบบจำลอง แล้วสังเกตแถวสัมประสิทธิ์ในสมการมาตรฐาน

แนวคำตอบ: ได้รับผลกระทบทุกสัมประสิทธิ์ (ยกเว้นสัมประสิทธิ์นำ $a_n$)! เพราะสัมประสิทธิ์ $a_{n-1}, a_{n-2}, \dots, a_0$ ล้วนสร้างขึ้นจากพหุนามสมมาตรมูลฐานที่ประกอบด้วยราก $r_i$ ทุกตัว (ผลบวก, ผลบวกของผลคูณคู่, ผลคูณรวม) ดังนั้นการเปลี่ยนรากเพียงค่าเดียวจะส่งผลสะเทือนต่อเนื่องไปถึงสัมประสิทธิ์เกือบทั้งหมดของสมการ
คำถามที่ 3

เราสร้างสมการได้หรือไม่ หากทราบเพียงผลบวกและผลคูณของราก?

พิจารณาสมการกำลังสอง $x^2 - Sx + P = 0$ หรือสมการดีกรีสูงกว่า

แนวคำตอบ: สร้างได้แน่นอน! สำหรับดีกรี 2 เพียงทราบ $S = r_1+r_2$ และ $P = r_1r_2$ จะได้สมการโมนิก $x^2 - Sx + P = 0$ ทันที และสำหรับดีกรี $n$ ใด ๆ หากทราบค่าของพหุนามสมมาตรมูลฐานครบ $n$ ตัว ($e_1, e_2, \dots, e_n$) เราสามารถแทนค่าลงในสมการ $x^n - e_1 x^{n-1} + e_2 x^{n-2} - \dots + (-1)^n e_n = 0$ เพื่อสร้างสมการขึ้นมาใหม่ได้เสมอโดยไม่ต้องรู้ค่าของแต่ละราก

5. แบบฝึกหัดสำหรับนักศึกษา (Self-Check Exercises)

ทดสอบความเข้าใจสูตรของวีเอตา การหานิพจน์สมมาตร และการสร้างสมการพหุนาม

ข้อที่ 1: การใช้สูตรของวีเอตาหาผลรวมและผลคูณของราก

กำหนดสมการพหุนาม $3x^2 - 12x + 5 = 0$ ให้ $r_1, r_2$ เป็นรากของสมการ จงหาค่าของผลบวกของราก ($r_1 + r_2$) และผลคูณของราก ($r_1 r_2$)

ข้อที่ 2: การคำนวณค่านิพจน์สมมาตร $r_1^2 + r_2^2$

ถ้า $r_1, r_2$ เป็นรากของสมการ $2x^2 + 6x - 7 = 0$ จงหาค่าของ $r_1^2 + r_2^2$ โดยไม่ต้องแก้สมการ

ข้อที่ 3: การสร้างสมการพหุนามดีกรี 3 จากราก

จงหาสมการพหุนามโมนิก (สัมประสิทธิ์นำเท่ากับ 1) ดีกรี 3 ที่มีรากคือ $r_1 = 1, r_2 = -2, r_3 = 3$
