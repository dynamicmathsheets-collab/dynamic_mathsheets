รากตรรกยะของสมการพหุนาม (Rational Root Theorem)

ค้นหาและจำกัดขอบเขตของผลเฉลยที่เป็นจำนวนตรรกยะ $\pm \frac{p}{q}$ จากสัมประสิทธิ์จำนวนเต็ม สู่การทดสอบประสิทธิภาพด้วยกระบวนการฮอร์เนอร์และการลดทอนดีกรี

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

ทักษะสำคัญที่นักศึกษาจะได้รับหลังศึกษาจบหัวข้อนี้

เมื่อศึกษาและปฏิสัมพันธ์กับโมดูลการเรียนรู้นี้แล้ว นักศึกษาจะมีความสามารถดังต่อไปนี้:

  • ✓ อธิบายและพิสูจน์ทฤษฎีบทรากตรรกยะ (Rational Root Theorem) โดยใช้สมบัติการหารลงตัวของจำนวนเต็มและบทตั้งของยุคลิด (Euclid's Lemma) ได้อย่างรัดกุม
  • ✓ สร้างรายการรากตรรกยะที่เป็นไปได้ทั้งหมด $\pm \frac{p}{q}$ จากตัวประกอบของพจน์คงตัว $a_0$ และสัมประสิทธิ์นำ $a_n$ พร้อมตัดค่าซ้ำได้อย่างเป็นระบบ
  • ✓ นำกระบวนการฮอร์เนอร์มาตรวจสอบรากตรรกยะและลดทอนดีกรีของสมการ (Polynomial Deflation) เพื่อหารากจริงหรือรากเชิงซ้อนที่เหลือได้อย่างถูกต้อง

2. เนื้อหาหลัก (Core Content)

ทฤษฎีบท บทพิสูจน์ทางทฤษฎีจำนวน และขั้นตอนการวิเคราะห์

2.1 ทฤษฎีบทรากตรรกยะ (The Rational Root Theorem)

พิจารณาพหุนามที่มีสัมประสิทธิ์เป็นจำนวนเต็ม ($a_i \in \mathbb{Z}$):

$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 \quad (a_n \neq 0, a_0 \neq 0)$$

ถ้าจำนวนตรรกยะ $x = \frac{p}{q}$ เป็นรากของสมการ $P(x) = 0$ โดยที่ $p, q \in \mathbb{Z}$ เป็นเศษส่วนอย่างต่ำ ($\gcd(p, q) = 1$ และ $q > 0$) แล้ว:

ตัวเศษ $p$ ต้องหารพจน์คงตัว $a_0$ ลงตัว ($p \mid a_0$)
ตัวส่วน $q$ ต้องหารสัมประสิทธิ์นำ $a_n$ ลงตัว ($q \mid a_n$)

บทพิสูจน์ 2.2 การพิสูจน์โดยใช้สมบัติการหารลงตัวของจำนวนเต็ม

แทนค่า $x = \frac{p}{q}$ ลงในสมการ $P(x) = 0$:

$$a_n \left(\frac{p}{q}\right)^n + a_{n-1}\left(\frac{p}{q}\right)^{n-1} + \dots + a_1\left(\frac{p}{q}\right) + a_0 = 0$$

คูณตลอดทั้งสองข้างด้วย $q^n$ เพื่อกำจัดเศษส่วน:

$$a_n p^n + a_{n-1} p^{n-1} q + \dots + a_1 p q^{n-1} + a_0 q^n = 0 \quad (*)$$
• พิสูจน์ $p \mid a_0$:
ย้ายพจน์ $a_0 q^n$ ไปขวามือ แล้วดึงตัวร่วม $p$ ทางซ้ายมือ:
$p(a_n p^{n-1} + \dots + a_1 q^{n-1}) = -a_0 q^n$
แสดงว่า $p \mid a_0 q^n$ แต่เนื่องจาก $\gcd(p, q) = 1$ (จึงทำให้ $\gcd(p, q^n) = 1$) โดยบทตั้งของยุคลิดจะได้ว่า $p \mid a_0$
• พิสูจน์ $q \mid a_n$:
ย้ายพจน์ $a_n p^n$ ไปขวามือ แล้วดึงตัวร่วม $q$ ทางซ้ายมือ:
$q(a_{n-1} p^{n-1} + \dots + a_0 q^{n-1}) = -a_n p^n$
แสดงว่า $q \mid a_n p^n$ แต่เนื่องจาก $\gcd(p, q) = 1$ (จึงทำให้ $\gcd(p^n, q) = 1$) โดยบทตั้งของยุคลิดจะได้ว่า $q \mid a_n$ $\blacksquare$

2.3 ขั้นตอนการหารากตรรกยะ

  1. หาตัวประกอบทั้งหมดที่เป็นไปได้ของ $a_0$ (กำหนดเป็นค่า $p$)
  2. หาตัวประกอบทั้งหมดที่เป็นไปได้ของ $a_n$ (กำหนดเป็นค่า $q$)
  3. สร้างอัตราส่วน $\pm \frac{p}{q}$ ทั้งหมดและตัดเศษส่วนที่มีค่าซ้ำออก
  4. นำค่าผู้ท้าชิง (Candidates) ไปทดสอบด้วยกระบวนการฮอร์เนอร์

2.4 การลดทอนดีกรี (Deflation)

เมื่อพบว่า $\frac{p}{q}$ ตัวใดทำให้เศษเหลือ $R = 0$:

  • แสดงว่า $(x - \frac{p}{q})$ หรือ $(qx - p)$ เป็นตัวประกอบของ $P(x)$
  • นำแถวสัมประสิทธิ์ผลหาร $Q(x)$ ที่ได้จากตารางฮอร์เนอร์ไปตั้งเป็นสมการใหม่ที่มีดีกรีลดลง 1 ($n-1$)
  • หารากที่เหลือต่อด้วยสูตรกำลังสองหรือทำซ้ำขั้นตอนเดิม

3. แบบจำลองโต้ตอบ (Interactive Simulator)

สร้างรายการผู้ท้าชิง $\pm \frac{p}{q}$ อัตโนมัติ และทดสอบรากด้วยตารางฮอร์เนอร์

ชุดตัวอย่าง:
กำหนดสัมประสิทธิ์ $P(x) = a_3 x^3 + a_2 x^2 + a_1 x + a_0$ (จำนวนเต็ม)
P(x) = 2x³ - 3x² - 11x + 6
รายการรากตรรกยะที่เป็นไปได้ทั้งหมด ($\pm \frac{p}{q}$) พบ 16 ค่าผู้ท้าชิง
ตัวประกอบของ $a_0$ ($p$): ±1, ±2, ±3, ±6
ตัวประกอบของ $a_n$ ($q$): 1, 2
คลิกเลือกค่าเพื่อทดสอบด้วยฮอร์เนอร์ทันที:
การทดสอบด้วยตารางฮอร์เนอร์ (Horner Test) ทดสอบ x = 3
เศษเหลือ $R = P(c)$: 0
กราฟ $y = P(x)$ และจุดตัดแกน $X$
$P(x)$ ราก ($R=0$) จุดทดสอบปัจจุบัน
💡 จุดสีเขียวบนแกน $X$ คือรากตรรกยะที่ทดสอบผ่าน รากที่พบ: { 3, -2, 0.5 }

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

ท้าทายความคิดเพื่อสร้างความเข้าใจที่ลึกซึ้ง (คลิกเพื่อดูแนวทางคำตอบ)

คำถามที่ 1

เหตุใดทฤษฎีบทรากตรรกยะจึงช่วยลดจำนวนค่าที่ต้องทดลอง?

พิจารณาว่าบนเส้นจำนวนจริงมีจำนวนมากมายนับไม่ถ้วน ทฤษฎีบทนี้ช่วยคัดกรองขอบเขตได้อย่างไร

แนวคำตอบ: หากไม่มีทฤษฎีบทนี้ เราอาจต้องสุ่มทดสอบตัวเลขจากอนันต์จำนวน แต่ทฤษฎีบทรากตรรกยะการันตีว่า ถ้าสมการมีรากตรรกยะจริง รากนั้นต้องอยู่ในเซตจำกัด $\pm \frac{p}{q}$ นี้เท่านั้น ทำให้ลดจำนวนการสุ่มจากอนันต์เหลือเพียงไม่กี่ค่า (เช่น 8 หรือ 16 ค่า) ซึ่งสามารถทดสอบจนครบได้ในเวลาอันสั้น
คำถามที่ 2

รากที่เป็นไปได้ตามทฤษฎีบทจำเป็นต้องเป็นรากจริงของสมการหรือไม่?

ให้สังเกตความแตกต่างระหว่างคำว่า "ผู้ท้าชิงที่เป็นไปได้ (Candidates)" กับ "ผลเฉลยจริง (Actual Roots)"

แนวคำตอบ: ไม่จำเป็น! ทฤษฎีบทนี้บอกเพียง เงื่อนไขจำเป็น (Necessary Condition) แต่ไม่ใช่เงื่อนไขพอเพียง กล่าวคือ "ถ้ารากเป็นตรรกยะ จะต้องมีรูป $\pm \frac{p}{q}$" แต่ไม่ได้หมายความว่าทุกค่า $\pm \frac{p}{q}$ จะต้องเป็นรากเสมอไป เราจึงจำเป็นต้องนำแต่ละค่าไปตรวจสอบจริงด้วยวิธีฮอร์เนอร์อีกครั้ง
คำถามที่ 3

หากไม่มีรากตรรกยะ เราสรุปได้หรือไม่ว่าสมการไม่มีรากจริง?

ยกตัวอย่างสมการง่าย ๆ เช่น $x^3 - 2 = 0$ หรือ $x^2 - 2 = 0$

แนวคำตอบ: สรุปไม่ได้เด็ดขาด! การไม่พบรากตรรกยะบอกได้เพียงว่า "ไม่มีรากที่เป็นเศษส่วนของจำนวนเต็ม" เท่านั้น แต่สมการอาจมี รากอตรรกยะ (Irrational Roots) ได้ เช่น $x^2 - 2 = 0$ ไม่มีรากตรรกยะ แต่มีรากจริงคือ $\pm \sqrt{2}$ หรือ $x^3 - 2 = 0$ มีรากจริงคือ $\sqrt[3]{2} \approx 1.26$ ซึ่งตัดแกน $X$ ได้ตามปกติ

5. แบบฝึกหัดสำหรับนักศึกษา (Self-Check Exercises)

ทดสอบทักษะการหารายการรากตรรกยะ การทดสอบด้วยฮอร์เนอร์ และการวิเคราะห์รากอตรรกยะ

ข้อที่ 1: การสร้างรายการรากตรรกยะที่เป็นไปได้

สำหรับสมการ $3x^3 - 5x^2 - 4x + 4 = 0$ ข้อใดคือรายการรากตรรกยะที่เป็นไปได้ ($\pm \frac{p}{q}$) ทั้งหมดโดยไม่ซ้ำกัน?

ข้อที่ 2: การตรวจสอบรากด้วยฮอร์เนอร์และการลดทอน

กำหนด $P(x) = 2x^3 + x^2 - 7x - 6 = 0$ จงตรวจสอบว่าค่าใดต่อไปนี้เป็นรากตรรกยะ และพหุนามผลหารลดทอน $Q(x)$ คือข้อใด?

ข้อที่ 3: การพิสูจน์จำนวนอตรรกยะผ่านทฤษฎีบทรากตรรกยะ

เมื่อประยุกต์ทฤษฎีบทรากตรรกยะกับสมการ $x^3 - 2 = 0$ ข้อสรุปใดถูกต้องที่สุดเกี่ยวกับค่า $\sqrt[3]{2}$?
