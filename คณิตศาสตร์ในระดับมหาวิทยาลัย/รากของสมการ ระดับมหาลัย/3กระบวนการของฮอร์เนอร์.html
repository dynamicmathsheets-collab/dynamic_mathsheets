กระบวนการของฮอร์เนอร์ (Horner's Method)

เพิ่มประสิทธิภาพการคำนวณค่าพหุนามด้วยรูปกำลังซ้อน (Nested Form) เชื่อมโยงสู่ขั้นตอนวิธีการหารสังเคราะห์ และการลดดีกรีของสมการเพื่อหารากที่เหลือทั้งหมด

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

ผลลัพธ์การเรียนรู้ที่คาดหวังสำหรับหัวข้อนี้

เมื่อศึกษาและทดลองกับแบบจำลองในโมดูลนี้แล้ว นักศึกษาจะมีความสามารถดังต่อไปนี้:

  • ✓ อธิบายหลักการของกระบวนการฮอร์เนอร์และการจัดรูปพหุนามให้อยู่ในรูปกำลังซ้อน (Nested Multiplication Form) ได้อย่างถูกต้อง
  • ✓ คำนวณค่าพหุนามและหารพหุนามด้วยตัวประกอบเชิงเส้น $(x - a)$ ได้อย่างรวดเร็ว โดยเข้าใจความสัมพันธ์ระหว่างกระบวนการฮอร์เนอร์กับการหารสังเคราะห์ (Synthetic Division)
  • ✓ นำสัมประสิทธิ์ผลหารที่ได้ไปลดทอนดีกรีของสมการ (Polynomial Deflation) เมื่อทราบราก เพื่อหารากที่เหลือทั้งหมดของสมการดีกรีสูง

2. เนื้อหาหลัก (Core Content)

มโนทัศน์ ความซับซ้อนเชิงการคำนวณ และการพิสูจน์ความสัมพันธ์

2.1 การจัดรูปพหุนามให้อยู่ในรูปกำลังซ้อน (Nested Multiplication / Horner Form)

พหุนามดีกรี $n$ ทั่วไป $P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$ สามารถจัดกลุ่มตัวแปร $x$ ดึงตัวคูณร่วมออกมาซ้อนกันเป็นชั้น ๆ ได้ดังนี้:

$$P(x) = \Big( \dots \big((a_n x + a_{n-1})x + a_{n-2}\big)x + \dots + a_1 \Big)x + a_0$$

ตัวอย่างสำหรับพหุนามดีกรี 3: $P(x) = a_3 x^3 + a_2 x^2 + a_1 x + a_0$ จะเขียนเป็นรูปซ้อนได้คือ: $P(x) = ((a_3 x + a_2)x + a_1)x + a_0$

2.2 ขั้นตอนการคำนวณแบบเวียนเกิด (Horner's Recurrence Algorithm)

เมื่อต้องการหาค่า $P(c)$ ขั้นตอนวิธีจะเริ่มจากสัมประสิทธิ์นำ แล้วคูณด้วย $c$ และบวกสัมประสิทธิ์ตัวถัดไปวนซ้ำจนครบพจน์คงตัว:

• ค่าเริ่มต้น: $b_n = a_n$
• ขั้นตอนเวียนเกิด: $b_k = a_k + b_{k+1} \cdot c \quad \text{สำหรับ } k = n-1, n-2, \dots, 0$
• ผลลัพธ์สุดท้าย: ค่าพหุนาม $P(c) = b_0$

2.3 ความสัมพันธ์กับการหารสังเคราะห์

สัมประสิทธิ์ $b_n, b_{n-1}, \dots, b_1$ ที่ได้จากกระบวนการฮอร์เนอร์ แท้จริงแล้วคือสัมประสิทธิ์ของพหุนามผลหาร $Q(x)$ เมื่อหาร $P(x)$ ด้วย $(x - c)$ พอดี:

$$P(x) = (x - c)\underbrace{(b_n x^{n-1} + \dots + b_1)}_{Q(x)} + \underbrace{b_0}_{R = P(c)}$$

2.4 ความได้เปรียบเชิงการคำนวณ (Complexity)

การคำนวณด้วยวิธีของฮอร์เนอร์ช่วยลดภาระงานของคอมพิวเตอร์อย่างมหาศาล:

วิธีคำนวณ จำนวนการคูณ จำนวนการบวก
แทนค่าตรงไปตรงมา $\frac{n(n+1)}{2} \approx O(n^2)$ $n$ ครั้ง
กระบวนการฮอร์เนอร์ $n$ ครั้ง $(O(n))$ $n$ ครั้ง

การประยุกต์ 2.5 การลดทอนดีกรี (Polynomial Deflation) เมื่อทราบราก

หากเศษเหลือ $b_0 = P(c) = 0$ หมายความว่า $x = c$ เป็นรากของสมการ $P(x) = 0$ เราสามารถดึงตัวประกอบ $(x - c)$ ออกมาได้ทันที และนำพหุนามผลหาร $Q(x) = b_n x^{n-1} + \dots + b_1 = 0$ ซึ่งมีดีกรีลดลง 1 ($n-1$) ไปหารากที่เหลือต่อด้วยวิธีเชิงตัวเลขหรือสูตรพีชคณิตได้โดยตรง

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

ท้าทายความคิดเพื่อสร้างความเข้าใจเชิงสัจพจน์ (คลิกเพื่อดูแนวทางคำตอบ)

คำถามที่ 1

เหตุใดฮอร์เนอร์จึงลดจำนวนการคูณและการบวกได้?

พิจารณาการคำนวณพจน์ $x^4, x^3, x^2$ ซ้ำซ้อนในวิธีทั่วไป เทียบกับการดึงตัวประกอบร่วมออกไปทีละชั้น

แนวคำตอบ: การคำนวณแบบเดิมต้องยกกำลังค่า $x$ ในแต่ละพจน์แยกกัน (เช่น $x^3 = x \cdot x \cdot x$ ต้องคูณ 2 ครั้ง แล้วคูณด้วยสัมประสิทธิ์อีก 1 ครั้ง รวมเป็น 3 ครั้ง) ทำให้จำนวนการคูณพุ่งสูงถึง $\frac{n(n+1)}{2}$ แต่รูปกำลังซ้อนของฮอร์เนอร์ใช้คุณสมบัติการแจกแจงดึง $x$ ออกมา ทำให้ในแต่ละขั้นตอนมีเพียง การคูณ 1 ครั้ง และการบวก 1 ครั้งต่อ 1 ดีกรี จึงใช้การคูณเพียง $n$ ครั้งเท่านั้น
คำถามที่ 2

ค่าสุดท้ายจากกระบวนการฮอร์เนอร์มีความหมายอย่างไร?

พิจารณาความหมายของค่า $b_0$ ทั้งในมุมมองของค่าฟังก์ชันและการหารพหุนาม

แนวคำตอบ: มี 2 ความหมายสำคัญที่เชื่อมโยงกันอย่างสมบูรณ์:
  1. คือค่าของฟังก์ชันพหุนาม ณ จุดนั้น หรือ $b_0 = P(a)$
  2. คือ เศษเหลือ (Remainder, $R$) ที่ได้จากการหารพหุนาม $P(x)$ ด้วยทวินามเชิงเส้น $(x - a)$ ตามทฤษฎีบทเศษเหลือ
คำถามที่ 3

หากค่าสุดท้ายเป็นศูนย์ จะสรุปอะไรเกี่ยวกับพหุนามได้บ้าง?

เชื่อมโยงทฤษฎีบทตัวประกอบและผลประโยชน์ของแถวสัมประสิทธิ์ที่เหลือ

แนวคำตอบ: สรุปได้ทันทีว่า:
  • $x = a$ เป็น รากของสมการ $P(x) = 0$
  • $(x - a)$ เป็น ตัวประกอบ ที่หาร $P(x)$ ได้ลงตัว
  • สามารถ ลดทอนดีกรี ของสมการลง 1 ขั้น โดยใช้ตัวเลขแถวล่าง $b_n, \dots, b_1$ เป็นสัมประสิทธิ์ของสมการใหม่ $Q(x) = 0$ เพื่อหารากที่เหลือต่อไปได้อย่างง่ายดาย

5. แบบฝึกหัดสำหรับนักศึกษา (Self-Check Exercises)

ทดสอบทักษะการคำนวณ การหาผลหาร และการลดทอนดีกรีของสมการ

ข้อที่ 1: คำนวณค่าพหุนามด้วยกระบวนการฮอร์เนอร์

จงใช้กระบวนการฮอร์เนอร์หาค่าของ $P(x) = 3x^3 - 4x^2 + 2x - 5$ ณ จุด $x = 2$ (ค่า $b_0$ หรือ $P(2)$)

ข้อที่ 2: การหารพหุนามและหาพหุนามผลหาร

เมื่อนำ $P(x) = 2x^3 + 3x^2 - 8x + 3$ มาหารด้วย $(x - 1)$ โดยกระบวนการฮอร์เนอร์ สัมประสิทธิ์ของผลหาร $Q(x)$ และเศษเหลือ $R$ คือข้อใด?

ข้อที่ 3: ลดทอนดีกรีและหารากทั้งหมด

กำหนดสมการ $x^3 - 6x^2 + 11x - 6 = 0$ เมื่อทดสอบพบว่า $x = 1$ เป็นรากหนึ่งของสมการ จงใช้สมการลดทอน $Q(x) = 0$ หารากที่เหลืออีก 2 ตัว
