สูตรของเทย์เลอร์สำหรับพหุนาม (Taylor's Formula for Polynomials)

เปลี่ยนจุดมองศูนย์กลางของพหุนามจากรูปมาตรฐาน $x$ สู่รูปกำลังของ $(x - a)$ ด้วยอนุพันธ์อันดับสูง พร้อมเชื่อมโยงกับพฤติกรรมความชัน ความโค้ง และความซ้ำของรากสมการ

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

ผลลัพธ์การเรียนรู้และความเข้าใจสำคัญ

เมื่อศึกษาและทดลองกับแบบจำลองในโมดูลนี้แล้ว นักศึกษาจะมีความสามารถดังต่อไปนี้:

  • ✓ เขียนพหุนามในรูปการกระจายเทย์เลอร์รอบจุด $a$ ใด ๆ ในรูปกำลังของ $(x - a)$ ได้อย่างถูกต้องแม่นยำ
  • ✓ พิสูจน์สูตรของเทย์เลอร์สำหรับฟังก์ชันพหุนามโดยใช้อนุพันธ์อันดับสูงและการแทนค่า $x = a$ พร้อมอธิบายความจำเป็นของตัวส่วน $k!$ (แฟกทอเรียล)
  • ✓ เชื่อมโยงสัมประสิทธิ์เทย์เลอร์กับการประมาณค่าฟังก์ชันเฉพาะที่ และวิเคราะห์ความซ้ำของรากสมการ (Multiplicity of Roots) ผ่านเงื่อนไข $P(a) = P'(a) = \dots = 0$

2. เนื้อหาหลัก (Core Content)

ทฤษฎีบท บทพิสูจน์เชิงพีชคณิต และความหมายทางเรขาคณิต

2.1 สูตรของเทย์เลอร์สำหรับพหุนาม (Taylor's Formula for Polynomials)

ถ้า $P(x)$ เป็นพหุนามดีกรีไม่เกิน $n$ และ $a$ เป็นจำนวนจริงใด ๆ แล้ว $P(x)$ สามารถเขียนในรูปกำลังของ $(x - a)$ ได้อย่างสมบูรณ์แบบโดยไม่มีพจน์เศษเหลือของการประมาณค่า:

$$P(x) = \sum_{k=0}^{n} \frac{P^{(k)}(a)}{k!} (x - a)^k = P(a) + \frac{P'(a)}{1!}(x-a) + \frac{P''(a)}{2!}(x-a)^2 + \dots + \frac{P^{(n)}(a)}{n!}(x-a)^n$$

*ข้อสังเกต: สำหรับฟังก์ชันทั่วไป สูตรเทย์เลอร์มักเป็นอนุกรมอนันต์หรือมีพจน์เศษเหลือ $R_n(x)$ แต่สำหรับพหุนามดีกรี $n$ อนุพันธ์อันดับที่ $k > n$ จะเป็นศูนย์ทั้งหมด ($P^{(k)}(x) = 0$) ทำให้ผลรวมนี้เป็นเอกลักษณ์ที่เท่ากันทุกประการสำหรับทุก ๆ ค่า $x$

บทพิสูจน์ 2.2 การพิสูจน์สูตรเทย์เลอร์สำหรับพหุนาม

เนื่องจาก $P(x)$ เป็นพหุนามดีกรี $n$ เราสามารถเขียน $P(x)$ ในรูปผลรวมของกำลัง $(x - a)$ ได้อย่างแน่นอนโดยสมมติสัมประสิทธิ์คงตัว $c_0, c_1, \dots, c_n$:

$P(x) = c_0 + c_1(x-a) + c_2(x-a)^2 + c_3(x-a)^3 + \dots + c_n(x-a)^n$

เมื่อหาอนุพันธ์เทียบกับ $x$ ไปเรื่อย ๆ ทีละอันดับ:

$P'(x) = c_1 + 2c_2(x-a) + 3c_3(x-a)^2 + \dots + n c_n(x-a)^{n-1}$
$P''(x) = 2 \cdot 1 c_2 + 3 \cdot 2 c_3(x-a) + \dots + n(n-1)c_n(x-a)^{n-2}$
$P^{(k)}(x) = k!\, c_k + (x-a)(\text{พจน์อื่น ๆ})$

เมื่อแทนค่า $x = a$ ลงในแต่ละสมการ พจน์ที่มี $(x - a)$ ทั้งหมดจะกลายเป็น ศูนย์ เหลือเพียง:

$P^{(k)}(a) = k! \cdot c_k \implies c_k = \frac{P^{(k)}(a)}{k!} \quad (k = 0, 1, 2, \dots, n) \quad \blacksquare$

2.3 กรณีพิเศษ $a = 0$ (อนุกรมแมคลอริน)

เมื่อเลือกจุดศูนย์กลางเป็น $a = 0$ จะได้การกระจายรอบจุดกำเนิด:

$P(x) = \sum_{k=0}^{n} \frac{P^{(k)}(0)}{k!} x^k$

ซึ่งคืนรูปกลับสู่รูปมาตรฐาน (Standard Form) $P(x) = a_0 + a_1 x + \dots + a_n x^n$ นั่นเอง

2.4 การวิเคราะห์รากซ้ำ (Multiplicity of Roots)

สูตรเทย์เลอร์เผยให้เห็นโครงสร้างของรากซ้ำอย่างชัดเจนที่สุด:

  • $x = a$ เป็นรากเดี่ยว $\iff P(a) = 0$ แต่ $P'(a) \neq 0$
  • $x = a$ เป็นรากซ้ำอันดับ $m$ $\iff P(a) = P'(a) = \dots = P^{(m-1)}(a) = 0$ และ $P^{(m)}(a) \neq 0$ ทำให้ดึงตัวประกอบ $(x - a)^m$ ออกมาได้

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

ท้าทายความคิดเพื่อสร้างความเข้าใจที่ลึกซึ้ง (คลิกเพื่อดูแนวทางคำตอบ)

คำถามที่ 1

เหตุใดอนุพันธ์อันดับต่าง ๆ ณ จุด $a$ จึงกำหนดสัมประสิทธิ์ของรูปเทย์เลอร์ได้?

สังเกตสิ่งที่เกิดขึ้นเมื่อนำรูป $P(x) = \sum c_k (x-a)^k$ มาดิฟและแทนค่า $x = a$

แนวคำตอบ: เพราะพจน์ $(x - a)^k$ มีคุณสมบัติพิเศษคือ เมื่อแทนค่า $x = a$ พจน์ทั้งหมดที่มีดีกรีสูงกว่าจะกลายเป็น 0 ส่วนพจน์ที่มีดีกรีต่ำกว่าจะถูกอนุพันธ์กำจัดทิ้งไปแล้ว เหลือเพียงพจน์คงตัว $k! \cdot c_k$ ทำให้เราแยกสกัดสัมประสิทธิ์ $c_k$ แต่ละตัวออกมาได้อย่างอิสระผ่าน $c_k = \frac{P^{(k)}(a)}{k!}$
คำถามที่ 2

เมื่อเปลี่ยนจุด $a$ พหุนามเดิมเปลี่ยนไปหรือไม่?

สัมประสิทธิ์ $c_k$ มีค่าเปลี่ยนไปตาม $a$ แล้วตัวฟังก์ชันจริง ๆ เปลี่ยนแปลงหรือไม่?

แนวคำตอบ: พหุนามเดิมไม่เปลี่ยนเลย! เส้นโค้งกราฟ $y = P(x)$ และค่าฟังก์ชัน ณ ทุก ๆ จุดยังคงเหมือนเดิมทุกประการ สิ่งที่เปลี่ยนมีเพียง "พิกัดมุมมองอ้างอิง" จากการวัดเทียบจุดกำเนิด $x=0$ ไปเป็นการวัดระยะขจัดจากจุด $x=a$ (สัมประสิทธิ์ในวงเล็บ $(x-a)$ จึงต้องเปลี่ยนไปเพื่อชดเชยให้ผลลัพธ์รวมเท่าเดิม)
คำถามที่ 3

สูตรนี้ช่วยให้วิเคราะห์พหุนามใกล้รากที่ทราบได้อย่างไร?

ถ้า $a$ เป็นรากของสมการ ($P(a) = 0$) สัมประสิทธิ์พจน์แรกจะหายไป ส่งผลต่อพฤติกรรมกราฟอย่างไร?

แนวคำตอบ: เมื่อ $a$ เป็นราก จะได้ $c_0 = P(a) = 0$ ทำให้พหุนามเริ่มจาก $c_1(x-a) + c_2(x-a)^2 + \dots$ ซึ่งดึง $(x-a)$ ออกมาได้ทันที และถ้า $P'(a) = 0$ ด้วย ($c_1 = 0$) กราฟจะสัมผัสแกน $x$ กลายเป็นรากซ้ำอันดับ 2 ขึ้นไป ช่วยให้เราประมาณค่าเฉพาะที่ (Local behavior) และวิเคราะห์อัตราการลู่เข้าของระเบียบวิธีนิวตันได้อย่างแม่นยำ

5. แบบฝึกหัดสำหรับนักศึกษา (Self-Check Exercises)

ทดสอบทักษะการกระจายเทย์เลอร์ การวิเคราะห์รากซ้ำ และการประมาณค่าเฉพาะที่

ข้อที่ 1: การกระจายเทย์เลอร์รอบจุด $a$

กำหนดพหุนาม $P(x) = 2x^3 - 3x^2 + 4x - 5$ จงใช้สูตรของเทย์เลอร์หาสัมประสิทธิ์ $c_1$ หน้าพจน์ $(x - 2)$ ในการกระจายรอบจุด $a = 2$

ข้อที่ 2: การวิเคราะห์รากซ้ำด้วยอนุพันธ์

สำหรับพหุนาม $P(x) = x^3 - 3x + 2$ จงตรวจสอบว่าจุด $x = 1$ มีพฤติกรรมอย่างไรตามสูตรของเทย์เลอร์?

ข้อที่ 3: การประมาณค่าเชิงเส้นเฉพาะที่ (Local Approximation)

ถ้าพหุนาม $P(x)$ มีการกระจายรอบจุด $a = 3$ คือ $P(x) = 5 - 2(x - 3) + 4(x - 3)^2 + (x - 3)^3$ จงใช้การประมาณเชิงเส้น (พิจารณาเฉพาะพจน์ดีกรีไม่เกิน 1) ประมาณค่า $P(3.02)$
