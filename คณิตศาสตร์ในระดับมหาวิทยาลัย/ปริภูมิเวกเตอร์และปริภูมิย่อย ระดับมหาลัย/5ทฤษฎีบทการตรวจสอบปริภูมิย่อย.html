เรื่องที่ 5: ทฤษฎีบทการตรวจสอบปริภูมิย่อย (Subspace Test Theorem)

ขั้นตอนและระเบียบวิธีทางคณิตศาสตร์ในการพิสูจน์การเป็นปริภูมิย่อย และกลยุทธ์การหาตัวอย่างค้าน (Counterexample)

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถใช้เกณฑ์การตรวจสอบปริภูมิย่อยและพิสูจน์ผลการตรวจสอบอย่างเป็นระบบได้ พร้อมทั้งสามารถสร้างตัวอย่างค้านเพื่อโต้แย้งเซตที่ไม่เป็นปริภูมิย่อยได้อย่างถูกต้อง

คำถามนำเพื่อค้นพบ (Discovery Inquiry)

"หากเซตมีเวกเตอร์ศูนย์ แต่ไม่ปิดภายใต้การคูณด้วยสเกลาร์ เซตนั้นเป็นปริภูมิย่อยได้หรือไม่?"

ข้อสรุปชัดเจน: เป็นไม่ได้อย่างเด็ดขาด! เพราะการเป็นปริภูมิย่อยต้องมีสมบัติสอดคล้องกับสัจพจน์ครบทุกข้อ การมีเวกเตอร์ศูนย์เป็นเพียง "เงื่อนไขจำเป็นเบื้องต้น" หากขาดสมบัติปิดการคูณด้วยสเกลาร์แม้แต่กรณีเดียว (เช่น การคูณด้วยสเกลาร์ลบหรือเศษส่วนแล้วหลุดออกจากเซต) โครงสร้างพีชคณิตจะไม่สามารถปิดตัวเองได้ จึงไม่เป็นปริภูมิย่อย

เนื้อหาหลัก: เกณฑ์การทดสอบและการใช้ตัวอย่างค้าน

ทฤษฎีบทหลัก Two-Step / Three-Step Test

ทฤษฎีบทการตรวจสอบปริภูมิย่อย

ให้ $W$ เป็นเซตย่อยของปริภูมิเวกเตอร์ $V$ เหนือสนาม $F$ จะได้ว่า $W$ เป็นปริภูมิย่อยของ $V$ ก็ต่อเมื่อ:

  • $W \neq \emptyset$ (ตรวจสอบได้ง่ายที่สุดโดยดูว่า $\mathbf{0} \in W$)
  • ปิดภายใต้การบวก: สำหรับทุก $\mathbf{u}, \mathbf{v} \in W$ จะได้ว่า $\mathbf{u} + \mathbf{v} \in W$
  • ปิดภายใต้การคูณสเกลาร์: สำหรับทุก $c \in F$ และ $\mathbf{u} \in W$ จะได้ว่า $c\mathbf{u} \in W$
กลยุทธ์การพิสูจน์ Counterexample Method

การใช้ตัวอย่างค้าน (Counterexample)

เมื่อต้องการแสดงว่าเซต $W$ ไม่เป็น ปริภูมิย่อย ไม่จำเป็นต้องเขียนอธิบายรูปทั่วไปทั้งหมด เพียงแค่ยกตัวอย่างตัวเลขเฉพาะเจาะจง เพียง 1 กรณี ที่ขัดแย้งกับเงื่อนไขใดเงื่อนไขหนึ่ง เช่น:

  • แสดงว่า $\mathbf{0} \notin W$ (จบการพิสูจน์ทันที)
  • หรือยกเวกเตอร์เจาะจง 2 ตัวใน $W$ ที่บวกกันแล้วหลุดจาก $W$
  • หรือยกเวกเตอร์ใน $W$ กับสเกลาร์ $c$ ที่คูณแล้วหลุดจาก $W$
สูตรรวบรัด One-Step Subspace Test

เกณฑ์การตรวจสอบแบบรวมขั้นตอน (Linear Combination Test)

เราสามารถรวบการบวกและการคูณด้วยสเกลาร์เข้าด้วยกันได้: เซตย่อยที่ไม่ใช่เซตว่าง $W \subseteq V$ จะเป็นปริภูมิย่อยของ $V$ ก็ต่อเมื่อ สำหรับทุกสเกลาร์ $c, d \in F$ และทุกเวกเตอร์ $\mathbf{u}, \mathbf{v} \in W$ จะได้ว่า $c\mathbf{u} + d\mathbf{v} \in W$ (หรือทดสอบเพียง $c\mathbf{u} + \mathbf{v} \in W$) ซึ่งช่วยลดขั้นตอนการเขียนพิสูจน์ให้กระชับยิ่งขึ้น

แบบจำลองโต้ตอบ: ตรวจสอบทีละเงื่อนไข (Step-by-Step Verifier)

เลือกระบบสมการใน $\mathbb{R}^2$ หรือ $\mathbb{R}^3$ เพื่อวิเคราะห์ตามทฤษฎีบท 3 เงื่อนไขอย่างเป็นระบบ

สมการและเซตที่เลือก
สรุปเกณฑ์การผ่าน
ขั้นตอนการตรวจสอบตามทฤษฎีบท
1 การตรวจสอบการมีเวกเตอร์ศูนย์ (Zero Vector Test)
2 การตรวจสอบการปิดภายใต้การบวก (Closure under Vector Addition)
3 การตรวจสอบการปิดภายใต้การคูณสเกลาร์ (Closure under Scalar Multiplication)

แบบฝึกหัดสำหรับนักศึกษา

โจทย์: จงตรวจสอบว่าเซต $W = \{(x, y, z) \in \mathbb{R}^3 : x + y + z = 0\}$ เป็นปริภูมิย่อยของ $\mathbb{R}^3$ หรือไม่ โดยใช้ทฤษฎีบทการตรวจสอบปริภูมิย่อยและแสดงขั้นตอนการพิสูจน์โดยละเอียด

บทพิสูจน์ (Proof):

ต้องการแสดงว่า $W$ เป็นปริภูมิย่อยของ $\mathbb{R}^3$ จะตรวจสอบ 3 เงื่อนไขตามทฤษฎีบท:

1. ตรวจสอบว่า $\mathbf{0} \in W$:
พิจารณาเวกเตอร์ศูนย์ของ $\mathbb{R}^3$ คือ $\mathbf{0} = (0, 0, 0)$
แทนค่าพิกัดลงในเงื่อนไขของสมการ: $0 + 0 + 0 = 0$ ซึ่งเป็นจริง
ดังนั้น $\mathbf{0} \in W$ นั่นคือ $W \neq \emptyset$

2. ตรวจสอบการปิดภายใต้การบวก:
ให้ $\mathbf{u} = (x_1, y_1, z_1) \in W$ และ $\mathbf{v} = (x_2, y_2, z_2) \in W$
จะได้ว่า $x_1 + y_1 + z_1 = 0$ และ $x_2 + y_2 + z_2 = 0$
พิจารณาผลบวก $\mathbf{u} + \mathbf{v} = (x_1 + x_2, y_1 + y_2, z_1 + z_2)$
ตรวจสอบเงื่อนไขของผลบวก: $$(x_1 + x_2) + (y_1 + y_2) + (z_1 + z_2) = (x_1 + y_1 + z_1) + (x_2 + y_2 + z_2) = 0 + 0 = 0$$ ดังนั้น $\mathbf{u} + \mathbf{v} \in W$ (มีสมบัติปิดการบวก)

3. ตรวจสอบการปิดภายใต้การคูณด้วยสเกลาร์:
ให้ $c \in \mathbb{R}$ และ $\mathbf{u} = (x_1, y_1, z_1) \in W$
พิจารณา $c\mathbf{u} = (cx_1, cy_1, cz_1)$
ตรวจสอบเงื่อนไข: $$cx_1 + cy_1 + cz_1 = c(x_1 + y_1 + z_1) = c(0) = 0$$ ดังนั้น $c\mathbf{u} \in W$ (มีสมบัติปิดการคูณด้วยสเกลาร์)

สรุป: เนื่องจาก $W$ สอดคล้องตามเงื่อนไขของทฤษฎีบทการตรวจสอบปริภูมิย่อยครบถ้วนทั้ง 3 ประการ จึงสรุปได้ว่า $W$ เป็น ปริภูมิย่อยของ $\mathbb{R}^3$ $\blacksquare$
