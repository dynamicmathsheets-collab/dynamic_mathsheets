เรื่องที่ 7: การประยุกต์และการวิเคราะห์สมการกำลังสอง

Integration of Methods, Discriminant & Vieta's Theorem: การบูรณาการตัวจำแนก ($\Delta$) ร่วมกับผลบวก ($S$) และผลคูณ ($P$) ของราก เพื่อวิเคราะห์ตำแหน่ง เครื่องหมาย และหาค่าพารามิเตอร์ภายใต้เงื่อนไขเชิงซ้อนโดยไม่ต้องแก้สมการ

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

เมื่อศึกษาหัวข้อนี้จบแล้ว ผู้เรียนสามารถ:

  • บูรณาการวิธีแก้สมการ ตัวจำแนก (\(\Delta\)) และความสัมพันธ์ระหว่างรากกับสัมประสิทธิ์ (\(S, P\)) เพื่อวิเคราะห์ปัญหาที่ซับซ้อนขึ้นได้อย่างเป็นระบบ
  • เลือกกลยุทธ์การแก้สมการที่เหมาะสมและมีประสิทธิภาพสูงสุดตามโครงสร้างของสมการ
  • วิเคราะห์เงื่อนไขที่จำเป็นและเพียงพอ (Necessary & Sufficient Conditions) ที่ทำให้รากของสมการเป็นจำนวนจริงบวก จำนวนจริงลบ หรือมีเครื่องหมายตรงข้ามกัน
  • หาค่าหรือช่วงของพารามิเตอร์ภายใต้เงื่อนไขเชิงเรขาคณิตและพีชคณิตที่กำหนด พร้อมพิสูจน์ข้อความเกี่ยวกับรากได้อย่างรัดกุมตามหลักคณิตศาสตร์

2. เนื้อหาหลัก (Core Mathematical Synthesis)

เกณฑ์การตัดสินใจ การวิเคราะห์เครื่องหมายของราก และทฤษฎีบทการจำกัดขอบเขต

1. แผนภูมิการเลือกวิธีแก้สมการให้เหมาะกับรูปสมการ (Decision Strategy)

วิธีที่ 1: แยกตัวประกอบ

Factoring

ใช้เมื่อ: \(\Delta = b^2 - 4ac\) เป็นกำลังสองสมบูรณ์ และสัมประสิทธิ์เป็นจำนวนตรรกยะ หรือสมการขาดพจน์คงตัว (\(c = 0\)) หรือขาดพจน์กำลังหนึ่ง (\(b = 0\))

ตัวอย่าง: \(x^2 - 5x = 0\) หรือ \(x^2 - 9 = 0\)
วิธีที่ 2: กำลังสองสมบูรณ์

Completing the Square

ใช้เมื่อ: สัมประสิทธิ์นำ \(a = 1\) และ \(b\) เป็นเลขคู่ หรือเมื่อต้องการแปลงเป็นรูปจุดยอด (Vertex Form) เพื่อหาค่าสูงสุด/ต่ำสุดไปพร้อมกัน

ตัวอย่าง: \(x^2 + 6x - 2 = 0 \implies (x+3)^2 = 11\)
วิธีที่ 3: สูตรกำลังสอง

Quadratic Formula

ใช้เมื่อ: สัมประสิทธิ์มีค่าซับซ้อน เป็นทศนิยม/เศษส่วน หรือ \(\Delta < 0\) ซึ่งรากอยู่ในรูปจำนวนเชิงซ้อน หรือ \(\Delta\) ไม่เป็นกำลังสองสมบูรณ์

รูปทั่วไป: \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)

2. การวิเคราะห์เครื่องหมายและตำแหน่งของราก (Sign & Location of Roots)

สำหรับสมการ \(ax^2 + bx + c = 0\) ที่ \(a \neq 0\) โดยมีตัวจำแนก \(\Delta = b^2 - 4ac\), ผลบวกราก \(S = -\frac{b}{a}\), และผลคูณราก \(P = \frac{c}{a}\):

กรณีที่ 1 r₁, r₂ > 0

รากจริงบวกทั้งสองค่า

1. \(\Delta \ge 0\) (มีรากจริง)
2. \(S = -\frac{b}{a} > 0\) (ผลบวกเป็นบวก)
3. \(P = \frac{c}{a} > 0\) (ผลคูณเป็นบวก)

พาราโบลาตัด/สัมผัสแกน \(x\) ทางฝั่งบวก (\(x > 0\)) และแกนสมมาตรอยู่ทางขวาของแกน \(y\)

กรณีที่ 2 r₁, r₂ < 0

รากจริงลบทั้งสองค่า

1. \(\Delta \ge 0\) (มีรากจริง)
2. \(S = -\frac{b}{a} < 0\) (ผลบวกเป็นลบ)
3. \(P = \frac{c}{a} > 0\) (ผลคูณเป็นบวก)

พาราโบลาตัด/สัมผัสแกน \(x\) ทางฝั่งลบ (\(x < 0\)) และแกนสมมาตรอยู่ทางซ้ายของแกน \(y\)

กรณีที่ 3 r₁ < 0 < r₂

รากเครื่องหมายตรงข้ามกัน

1. \(P = \frac{c}{a} < 0\) (เงื่อนไขเดียวพอ!)
พิสูจน์: \(\frac{c}{a} < 0 \implies ac < 0 \implies -4ac > 0\) ดังนั้น \(\Delta = b^2 - 4ac \ge -4ac > 0\) เสมอ

กราฟตัดแกน \(x\) ทั้งสองฝั่งของจุดกำเนิด โดยมีจุดตัดแกน \(y\) อยู่คนละฝั่งกับความหงายของกราฟ

ทฤษฎีบทการพิสูจน์: การันตีการมีรากจริงเมื่อ \(ac < 0\)

ข้อความ: ถ้าสมการ \(ax^2 + bx + c = 0\) มีสัมประสิทธิ์นำ \(a\) และพจน์ค่าคงตัว \(c\) มีเครื่องหมายต่างกัน (\(ac < 0\)) แล้วสมการนี้จะมีรากจริง 2 รากที่แตกต่างกันเสมอ ไม่ว่าสัมประสิทธิ์ \(b\) จะเป็นจำนวนจริงใดก็ตาม

พิสูจน์: เนื่องจาก \(b \in \mathbb{R} \implies b^2 \ge 0\) และจาก \(ac < 0 \implies -4ac > 0\)
ดังนั้น \(\Delta = b^2 + (-4ac) > 0\) เสมอ ส่งผลให้มีรากจริง 2 รากที่แตกต่างกันอย่างแน่นอน Q.E.D.

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

คลิกที่แต่ละคำถามเพื่อคิดวิเคราะห์และเปิดดูคำอธิบายทางคณิตศาสตร์อย่างเป็นระบบ

สามารถทำได้อย่างสมบูรณ์ โดยใช้ "กฎเครื่องหมายของเดส์การ์ตส์" หรือ "ระบบสามเงื่อนไข (\(\Delta, S, P\))":

เครื่องหมายของรากขึ้นอยู่กับเครื่องหมายของผลคูณ \(P = \frac{c}{a}\) และผลบวก \(S = -\frac{b}{a}\) ร่วมกับเงื่อนไขการมีรากจริง \(\Delta \ge 0\):

  • ถ้า \(P > 0\) แสดงว่ารากทั้งสองมีเครื่องหมายเดียวกัน (บวกคู่ หรือ ลบคู่) จากนั้นดู \(S\): ถ้า \(S > 0\) เป็นรากบวกทั้งคู่ ถ้า \(S < 0\) เป็นรากลบทั้งคู่
  • ถ้า \(P < 0\) แสดงว่ารากทั้งสองมีเครื่องหมายตรงข้ามกันทันที โดยรากที่มีค่าสัมบูรณ์มากกว่าจะมีเครื่องหมายตาม \(S\)

เงื่อนไขเดียวที่เพียงพอคือ: \(P = \frac{c}{a} < 0\) (หรือ \(ac < 0\))

หลายคนเข้าใจผิดว่าต้องตรวจสอบทั้ง \(\Delta > 0\) และ \(P < 0\) แต่ในทางคณิตศาสตร์ เงื่อนไข \(ac < 0\) จะการันตีให้ \(\Delta > 0\) โดยอัตโนมัติ:

$$\Delta = b^2 - 4ac$$

เนื่องจาก \(b^2 \ge 0\) สำหรับทุกจำนวนจริง และเมื่อ \(ac < 0\) จะทำให้ \(-4ac > 0\) เสมอ ผลบวกระหว่างจำนวนที่ไม่เป็นลบกับจำนวนบวกแท้ ย่อมได้ \(\Delta > 0\) แน่นอน ดังนั้นการตรวจสอบเพียง \(P < 0\) จึงเพียงพอและลดขั้นตอนได้มหาศาล

ประโยชน์หลัก 3 ประการในการวิเคราะห์ขั้นสูง:

  1. หลีกเลี่ยงอสมการติดเครื่องหมายกรณฑ์: หากแก้สมการเต็มรูปเพื่อนำราก \(x = \frac{-b \pm \sqrt{\Delta}}{2a}\) ไปตั้งอสมการ จะเกิดอสมการอตรรกยะที่แก้ยากมาก การใช้ \(\Delta, S, P\) แปลงปัญหาให้อยู่ในรูปอสมการพหุนามเชิงเส้นหรือกำลังสองธรรมดา
  2. ครอบคลุมเงื่อนไขการมีคำตอบจริง: ป้องกันข้อผิดพลาดจากการได้คำตอบพารามิเตอร์ที่ให้ผลบวกผลคูณถูกต้อง แต่ตัวจำแนกเป็นลบ (\(\Delta < 0\)) ซึ่งทำให้รากกลายเป็นจำนวนเชิงซ้อน
  3. เชื่อมโยงกับฟิสิกส์และเศรษฐศาสตร์: ในปัญหาเชิงประยุกต์ เช่น ปริมาณสินค้าหรือเวลา \(t\) ที่ต้องเป็นค่าจริงและเป็นบวก การใช้เงื่อนไข (\(\Delta \ge 0, S > 0, P > 0\)) ให้คำตอบที่สอดคล้องกับความเป็นจริงทันที

5. แบบฝึกหัดสำหรับนักศึกษา (Interactive Self-Assessment Quiz)

ทดสอบการวิเคราะห์สมการพารามิเตอร์ การพิสูจน์ข้อความ และการเลือกใช้ทฤษฎีบท

ข้อที่ 1: รากเครื่องหมายตรงข้าม Opposite Signs

กำหนดสมการ \(x^2 + (m - 3)x + (2m - 8) = 0\) ค่าของ \(m\) ต้องสอดคล้องกับเงื่อนไขใดเพื่อให้สมการนี้มีรากจริงสองรากที่มี เครื่องหมายตรงข้ามกัน?

ข้อที่ 2: รากจริงบวกทั้งสองค่า Both Positive

กำหนดสมการ \(x^2 - 6x + (k + 1) = 0\) ค่าของ \(k\) ต้องอยู่ในช่วงใดจึงจะทำให้สมการมี รากจริงบวกทั้งสองค่า?

ข้อที่ 3: การพิสูจน์การมีรากจริง Proof of Real Roots

พิจารณาสมการ \(x^2 + (a + b)x - ab = 0\) โดยที่ \(a, b \in \mathbb{R}\) ข้อใดอธิบายการมีรากจริงของสมการนี้ได้ถูกต้องที่สุด?

ข้อที่ 4: รากเป็นส่วนกลับของกันและกัน Reciprocal Condition

สมการ \(2x^2 + 5x + (3k - 4) = 0\) มีรากหนึ่งเป็นส่วนกลับของอีกรากหนึ่ง (\(r_1 = \frac{1}{r_2}\)) ค่าของ \(k\) คือข้อใด?
