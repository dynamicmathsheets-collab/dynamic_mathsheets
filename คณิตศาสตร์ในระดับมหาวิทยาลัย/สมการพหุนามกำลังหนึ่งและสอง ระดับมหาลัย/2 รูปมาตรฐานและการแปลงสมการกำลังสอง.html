เรื่องที่ 2: รูปมาตรฐานและการแปลงสมการกำลังสอง

Standard Form, Factoring, and Completing the Square: ศึกษาการเปลี่ยนรูปทางพีชคณิตเพื่อคงสภาพชุดคำตอบ และการเชื่อมโยงระหว่างพหุนามกับรูปเรขาคณิตพาราโบลา

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

เมื่อศึกษาหัวข้อนี้จบแล้ว ผู้เรียนสามารถ:

  • แปลงสมการพหุนามกำลังสองให้อยู่ในรูปมาตรฐาน \(ax^2 + bx + c = 0\) โดยที่ \(a \neq 0\) ได้อย่างเป็นระบบ
  • ใช้เทคนิคการแยกตัวประกอบ (Factoring) และการทำเป็นกำลังสองสมบูรณ์ (Completing the Square) เพื่อหาคำตอบทั้งในสนามจำนวนจริง (\(\mathbb{R}\)) และจำนวนเชิงซ้อน (\(\mathbb{C}\))
  • อธิบายความสัมพันธ์ระหว่างรูปทั่วไป รูปกำลังสองสมบูรณ์ (Vertex Form) และรูปแยกตัวประกอบ (Factored Form) พร้อมพิสูจน์การรักษาชุดคำตอบเดิม

2. เนื้อหาหลัก (Core Content)

มโนทัศน์สำคัญและการจัดรูปพหุนามกำลังสอง

1. รูปมาตรฐาน (Standard Form)

พิจารณาสัมประสิทธิ์

$$ax^2 + bx + c = 0, \quad a \neq 0$$

แสดงพจน์เรียงตามดีกรีจากมากไปน้อย มีประโยชน์ในการหาค่าดิสคริมิแนนต์ \(D = b^2 - 4ac\) เพื่อจำแนกชนิดของรากทันที

2. รูปแยกตัวประกอบ (Factored Form)

แสดงรากโดยตรง

$$a(x - r_1)(x - r_2) = 0$$

ใช้สมบัติผลคูณเป็นศูนย์ (\(uv = 0 \iff u=0 \lor v=0\)) ทำให้ได้ราก \(x = r_1\) หรือ \(x = r_2\) โดยไม่ต้องคำนวณซับซ้อน

3. รูปกำลังสองสมบูรณ์ (Vertex Form)

แสดงจุดยอดและแกนสมมาตร

$$a(x - h)^2 + k = 0$$

โดยที่ \(h = -\frac{b}{2a}\) และ \(k = c - \frac{b^2}{4a}\) ทำให้ยุบตัวแปร \(x\) จาก 2 ตำแหน่งเหลือเพียงตำแหน่งเดียว

การพิสูจน์ที่มาของสูตรกำลังสอง (Derivation of Quadratic Formula)

Completing the Square
1

หารด้วยสัมประสิทธิ์นำ \(a \neq 0\) ตลอดทั้งสมการ:

\(x^2 + \frac{b}{a}x + \frac{c}{a} = 0\)
2

ย้ายค่าคงตัวไปยังฝั่งขวา:

\(x^2 + \frac{b}{a}x = -\frac{c}{a}\)
3

บวกทั้งสองข้างด้วยกำลังสองของครึ่งหนึ่งของสัมประสิทธิ์ \(x\) คือ \(\left(\frac{b}{2a}\right)^2\):

\(x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = \frac{b^2}{4a^2} - \frac{c}{a}\)
4

ยุบฝั่งซ้ายเป็นกำลังสองสมบูรณ์ และรวมส่วนฝั่งขวา:

\(\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}\)
5

ถอดรากที่สองทั้งสองข้าง (Extracting Roots):

\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
ข้อสังเกต: พจน์ในเครื่องหมายกรณฑ์ \(b^2 - 4ac\) (เรียกว่า Discriminant) เป็นตัวชี้วัดว่ารากจะเป็นจำนวนจริง 2 ค่าต่างกัน (\(D > 0\)), จำนวนจริงซ้ำ (\(D = 0\)) หรือจำนวนเชิงซ้อนสังยุค (\(D < 0\))

3. แบบจำลองโต้ตอบ (Interactive Simulator)

ปรับค่าสัมประสิทธิ์ \(a, b, c\) เพื่อสังเกตการแปลงเป็นรูปกำลังสองสมบูรณ์และตำแหน่งราก

-5 (พาราโบลาคว่ำ) ห้ามเป็น 0 +5 (พาราโบลาหงาย)
-10 0 +10
-10 0 +10
การเปรียบเทียบรูปสมมูล (Equivalent Forms)
รูปมาตรฐาน: x² - 6x + 8 = 0
รูปกำลังสองสมบูรณ์: 1(x - 3)² - 1 = 0
จุดยอดพาราโบลา (h, k): (3.00, -1.00)

ขั้นตอนการแปลงรูปทางพีชคณิต

พล็อตพาราโบลา \(y = ax^2 + bx + c\) จุดตัดแกน x = รากคำตอบ
เส้นโค้งพาราโบลา
แกนสมมาตร \(x = h\)
จุดตัดแกน \(x\)
จุดยอด \((h, k)\)
การตรวจสอบว่าการแปลงรักษาชุดคำตอบเดิม (Equivalence Check):

การแปลงโดยการบวก/ลบด้วยพจน์เดียวกันทั้งสองข้าง และการคูณ/หารด้วย \(a \neq 0\) เป็นการดำเนินการที่ผันกลับได้ (Reversible Invertible Operations) ส่งผลให้ทุก \(x\) ที่ทำให้ \(a(x-h)^2 + k = 0\) จะทำให้ \(ax^2 + bx + c = 0\) เสมอ

4. คำถามนำเพื่อค้นพบ (Guiding Discovery Questions)

คลิกที่แต่ละคำถามเพื่อคิดวิเคราะห์และเปิดดูคำอธิบายเชิงทฤษฎี

หัวใจสำคัญคือ "การลดรูปตำแหน่งของตัวแปร (Isolating the Variable)":

ในรูปทั่วไป \(ax^2 + bx + c = 0\) ตัวแปร \(x\) ปรากฏอยู่สองตำแหน่งคือทั้งในพจน์กำลังสอง (\(x^2\)) และพจน์กำลังหนึ่ง (\(x\)) ซึ่งไม่สามารถรวมพจน์หรือย้ายข้างเพื่อถอดรากได้โดยตรง

การจัดรูปกำลังสองสมบูรณ์ \((x - h)^2 = M\) ช่วยยุบพจน์ของตัวแปรทั้งสองให้เหลือเพียงตำแหน่งเดียวในวงเล็บกำลังสอง ทำให้เราสามารถใช้ สมบัติการถอดรากที่สอง (Square Root Property) หาค่า \(x - h = \pm\sqrt{M}\) และได้คำตอบ \(x = h \pm \sqrt{M}\) ได้อย่างเบ็ดเสร็จ

หลักการสมมูลของการแปลงเชิงพีชคณิต (Equivalent Equations):

สมการสองสมการจะถือว่า สมมูลกัน (Equivalent) ก็ต่อเมื่อมีเซตคำตอบเดียวกัน การแปลงรูปจาก \(ax^2 + bx + c = 0\) ไปเป็น \(a(x-h)^2 + k = 0\) หรือ \(a(x-r_1)(x-r_2) = 0\) อาศัยเพียงสัจพจน์ของสนาม (Field Axioms):

  • การบวกหรือลบด้วยจำนวนเดียวกันทั้งสองข้าง (\(A = B \iff A + C = B + C\))
  • การคูณหรือหารด้วยค่าคงตัวที่ไม่เป็นศูนย์ (\(A = B \iff kA = kB, \quad k \neq 0\))
  • สมบัติการแจกแจงและการจัดกลุ่มของการบวกและการคูณ

การดำเนินการเหล่านี้เป็นฟังก์ชัน 1 ต่อ 1 (Bijective) จึงไม่มีการเพิ่มรากเทียม (Extraneous Roots) หรือทำคำตอบใดสูญหายไป

เกณฑ์การเลือกใช้วิธีตามลักษณะของสัมประสิทธิ์:

ควรใช้การแยกตัวประกอบเมื่อ:
  • ค่าดิสคริมิแนนต์ \(D = b^2 - 4ac\) เป็นกำลังสองสมบูรณ์ (เช่น 0, 1, 4, 9, 16, 25, ...)
  • สามารถหาจำนวนเต็มสองตัวที่คูณกันได้ \(ac\) และบวกกันได้ \(b\) ได้ง่ายในใจ
  • หลีกเลี่ยงการคำนวณเศษส่วนซ้อน
ควรใช้การทำกำลังสองสมบูรณ์ / สูตรเมื่อ:
  • ค่า \(D\) ไม่เป็นกำลังสองสมบูรณ์ หรือ \(D < 0\) (รากติดเครื่องหมายกรณฑ์หรือเป็นจำนวนเชิงซ้อน)
  • สัมประสิทธิ์ \(b\) เป็นเลขคี่ หรือ \(a\) ไม่เป็น 1 ซึ่งทำให้การแยกตัวประกอบด้วยตาเปล่าทำได้ยากยิ่ง
  • ต้องการหาจุดยอด (Vertex) สูงสุด/ต่ำสุดของกราฟไปพร้อมกัน

5. แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises & Self-Assessment)

ทดสอบการจัดรูปมาตรฐาน การแก้สมการด้วยวิธีต่างๆ และการพิสูจน์ความถูกต้องของคำตอบ

ข้อที่ 1: การจัดรูปมาตรฐาน Algebraic Form

จงแปลงสมการต่อไปนี้ให้อยู่ในรูปมาตรฐาน \(ax^2 + bx + c = 0\) (โดยที่ \(a > 0\)):

\(2x(x - 3) = 5 - x\)
ข้อที่ 2: การแก้ด้วยการแยกตัวประกอบ Factoring

จงหาเซตคำตอบของสมการ:

\(x^2 - 7x + 12 = 0\)
ข้อที่ 3: กำลังสองสมบูรณ์ Square Method

จัดรูปสมการ \(x^2 + 6x - 7 = 0\) ให้อยู่ในรูปกำลังสองสมบูรณ์ \((x - h)^2 = M\)

\((x - h)^2 = M\) ค่า \(h\) และ \(M\) คือข้อใด?
ข้อที่ 4: การพิสูจน์การแทนค่ากลับ Proof Verification

ถ้าแก้สมการแล้วได้รากหนึ่งคือ \(x = 2 + 3i\) ข้อใดแสดงการพิสูจน์ว่า \(x\) นี้เป็นรากของสมการ \(x^2 - 4x + 13 = 0\) ได้อย่างรัดกุมที่สุด?
