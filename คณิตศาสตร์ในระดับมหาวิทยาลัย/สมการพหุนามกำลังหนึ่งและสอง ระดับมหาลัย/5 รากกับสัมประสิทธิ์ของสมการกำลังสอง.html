เรื่องที่ 5: รากกับสัมประสิทธิ์ของสมการกำลังสอง

สูตรของวีเอตา (Vieta's Formulas): ความสัมพันธ์ระหว่างผลบวก ($r_1 + r_2 = -\frac{b}{a}$) และผลคูณของราก ($r_1 r_2 = \frac{c}{a}$) กับสัมประสิทธิ์ของสมการ พร้อมการสร้างสมการพหุนามกลับทิศทาง

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

เมื่อศึกษาหัวข้อนี้จบแล้ว ผู้เรียนสามารถ:

  • พิสูจน์และอธิบายที่มาของสูตรของวีเอตา (\(r_1 + r_2 = -\frac{b}{a}\) และ \(r_1 r_2 = \frac{c}{a}\)) จากการกระจายรูปตัวประกอบและการเทียบสัมประสิทธิ์ได้อย่างรัดกุม
  • หาผลบวกและผลคูณของรากได้โดยตรงจากสัมประสิทธิ์ โดยไม่จำเป็นต้องแก้หาสูตรรากของสมการ
  • สร้างสมการพหุนามกำลังสองจากรากที่กำหนดให้ หรือจากผลบวกและผลคูณของรากในรูป \(x^2 - Sx + P = 0\) ได้อย่างถูกต้อง
  • ประยุกต์ใช้ความสัมพันธ์ระหว่างรากกับสัมประสิทธิ์ในการแก้ปัญหาและหาค่าพารามิเตอร์คงตัวในเงื่อนไขต่างๆ

2. เนื้อหาหลักและการพิสูจน์ (Core Content & Formal Proof)

ทฤษฎีบทของวีเอตา การเทียบสัมประสิทธิ์ และการสร้างสมการกลับทาง

ทฤษฎีบทของวีเอตาสำหรับสมการกำลังสอง (Vieta's Theorem) François Viète (1540–1603)

ถ้า \(r_1\) และ \(r_2\) เป็นราก (ทั้งที่เป็นจำนวนจริงหรือจำนวนเชิงซ้อน) ของสมการกำลังสอง \(ax^2 + bx + c = 0\) โดยที่ \(a \neq 0\) แล้ว:

ผลบวกของราก (Sum of Roots, \(S\)) $$r_1 + r_2 = -\frac{b}{a}$$
ผลคูณของราก (Product of Roots, \(P\)) $$r_1 r_2 = \frac{c}{a}$$

การพิสูจน์เชิงพีชคณิตโดยการเทียบสัมประสิทธิ์ (Algebraic Proof)

1
ตามทฤษฎีบทตัวประกอบ (Factor Theorem) ถ้า \(r_1, r_2\) เป็นรากของสมการ พหุนามสามารถแยกตัวประกอบเชิงเส้นได้ในรูป:
$$a(x - r_1)(x - r_2) = 0$$
2
กระจายผลคูณในวงเล็บ:
$$a\big(x^2 - r_1 x - r_2 x + r_1 r_2\big) = a\big(x^2 - (r_1 + r_2)x + r_1 r_2\big) = 0$$
3
แจกแจงสัมประสิทธิ์นำ \(a\) เข้าไปในแต่ละพจน์:
$$ax^2 - a(r_1 + r_2)x + a(r_1 r_2) = 0$$
4
เปรียบเทียบสัมประสิทธิ์กับสมการรูปมาตรฐาน \(ax^2 + bx + c = 0\) พจน์ต่อพจน์:
สัมประสิทธิ์พจน์ \(x\):
-a(r₁ + r₂) = b &implies; r₁ + r₂ = -b/a
พจน์ค่าคงตัว:
a(r₁ r₂) = c &implies; r₁ r₂ = c/a

กรณีพิเศษที่ควรสังเกต (Notable Special Cases)

1. รากเป็นจำนวนตรงข้ามกัน

r₂ = -r₁ (S = 0)

ทำให้ \(r_1 + r_2 = -\frac{b}{a} = 0 \implies b = 0\) สมการจะไม่มีพจน์กำลังหนึ่ง (\(ax^2 + c = 0\)) และแกนสมมาตรของพาราโบลาคือแกน \(y\) (\(x = 0\)) พอดี

2. รากเป็นส่วนกลับของกันและกัน

r₂ = 1/r₁ (P = 1)

ทำให้ \(r_1 r_2 = \frac{c}{a} = 1 \implies c = a\) สัมประสิทธิ์นำและพจน์ค่าคงตัวจะมีค่าเท่ากันเสมอ

3. รากตัวหนึ่งมีค่าเป็นศูนย์

r₁ = 0 หรือ r₂ = 0 (P = 0)

ทำให้ \(r_1 r_2 = \frac{c}{a} = 0 \implies c = 0\) สมการจะผ่านจุดกำเนิด \((0, 0)\) เสมอ และสามารถดึงตัวประกอบร่วม \(x\) ออกมาได้

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

คลิกที่แต่ละคำถามเพื่อคิดวิเคราะห์และเปิดดูคำอธิบายทางคณิตศาสตร์

ได้แน่นอน และนี่คือพลังสำคัญของสูตรของวีเอตา:

เราสามารถอ่านค่าผลบวกและผลคูณของรากได้จากอัตราส่วนของสัมประสิทธิ์ทันที:

  • ผลบวกของรากคือ \(-\frac{b}{a}\)
  • ผลคูณของรากคือ \(\frac{c}{a}\)

ตัวอย่างเช่น สมการ \(5x^2 - 13x + 2 = 0\) แม้ว่ารากแต่ละตัวจะติดเครื่องหมายกรณฑ์ที่ซับซ้อน แต่เราสามารถบอกได้ทันทีว่าผลบวกของรากคือ \(\frac{13}{5} = 2.6\) และผลคูณของรากคือ \(\frac{2}{5} = 0.4\) โดยไม่ต้องคำนวณรากแต่ละตัวออกมาเลย

ใช้รูปสมการโมนิก (Monic Form) มาตรฐาน:

ถ้ากำหนดให้ผลบวกของรากคือ \(S\) และผลคูณของรากคือ \(P\) สมการพหุนามกำลังสองที่ง่ายที่สุด (เมื่อ \(a=1\)) จะอยู่ในรูป:

$$x^2 - Sx + P = 0$$

หรือหากต้องการสมการที่มีสัมประสิทธิ์นำเป็น \(a\) ใดๆ ที่ไม่เป็นศูนย์ สมการทั่วไปคือ \(a(x^2 - Sx + P) = 0\) ทำให้เราสามารถสร้างสมการที่มีสัมประสิทธิ์เป็นจำนวนเต็มได้เสมอแม้รากจะเป็นเศษส่วน

ผลต่อสัมประสิทธิ์ \(b\) และกราฟของพหุนาม:

เมื่อรากทั้งสองเป็นจำนวนตรงข้ามกัน กล่าวคือ \(r_2 = -r_1\) (เช่น \(3\) และ \(-3\)):

  • ผลบวกของรากจะเป็นศูนย์เสมอ: \(S = r_1 + (-r_1) = 0\)
  • จาก \(S = -\frac{b}{a} = 0\) สรุปได้ทันทีว่า \(b = 0\) (ไม่มีพจน์ดีกรีหนึ่ง \(x\))
  • สมการจะอยู่ในรูป \(ax^2 + c = 0\)
  • ในเชิงเรขาคณิต แกนสมมาตรของพาราโบลาจะทับกับ แกน \(y\) พอดี (\(x = 0\))

5. แบบฝึกหัดสำหรับนักศึกษา (Practice Exercises & Assessment)

สร้างสมการจากราก หาผลบวกผลคูณ และหาค่าพารามิเตอร์โดยใช้ความสัมพันธ์ของวีเอตา

ข้อที่ 1: การสร้างสมการจากราก Equation Synthesis

สมการกำลังสองที่มีรากคือ \(3\) และ \(-5\) (โดยมีสัมประสิทธิ์หน้า \(x^2\) เป็น \(1\)) คือสมการในข้อใด?

ข้อที่ 2: การอ่านค่าผลบวกและผลคูณ Direct Reading

ผลบวกของราก (\(r_1 + r_2\)) และผลคูณของราก (\(r_1 r_2\)) ของสมการ \(3x^2 - 12x + 7 = 0\) คือข้อใด?

ข้อที่ 3: การหาค่าพารามิเตอร์ Parameter Search

กำหนดสมการ \(x^2 - (k - 2)x + 12 = 0\) ถ้าผลบวกของรากมีค่าเท่ากับ \(8\) ค่าของ \(k\) คือข้อใด?

ข้อที่ 4: รากมีอัตราส่วนสัมพันธ์กัน Ratio Condition

สมการ \(x^2 - 8x + m = 0\) มีรากหนึ่งเป็น \(3\) เท่าของอีกรากหนึ่ง ค่าของ \(m\) คือข้อใด?
