เรื่องที่ 1: สมการพหุนามกำลังหนึ่ง

Linear Polynomial Equations in One Variable: ธรรมชาติของการมีคำตอบ รากของสมการ และการวิเคราะห์ภาวะคู่ควบเชิงเรขาคณิต

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

เมื่อศึกษาหัวข้อนี้จบแล้ว ผู้เรียนสามารถ:

  • อธิบายรูปทั่วไปของสมการพหุนามกำลังหนึ่งและจำแนกเงื่อนไขของสัมประสิทธิ์ได้อย่างถูกต้อง
  • แก้สมการในสนามจำนวนจริง (\(\mathbb{R}\)) และสนามจำนวนเชิงซ้อน (\(\mathbb{C}\)) ได้อย่างแม่นยำ
  • วิเคราะห์และอธิบายเงื่อนไขทางพีชคณิตที่ส่งผลให้สมการ มีคำตอบเดียว, ไม่มีคำตอบ, หรือ มีคำตอบนับไม่ถ้วน ได้อย่างสมเหตุสมผลตามหลักตรรกศาสตร์

2. เนื้อหาหลัก (Core Concepts)

รูปทั่วไป (Standard Form)

สมการพหุนามกำลังหนึ่งในตัวแปรเดียว \(x\) คือสมการที่สามารถเขียนอยู่ในรูป:

$$ax + b = 0, \quad a \neq 0$$

โดยที่ \(a, b \in \mathbb{R}\) (หรือ \(\mathbb{C}\)) และเรียก \(a\) ว่าสัมประสิทธิ์นำ (Leading Coefficient)

คำตอบทั่วไป (General Solution)

จากการใช้สมบัติการบวกและสมบัติการคูณด้วยอินเวอร์สของสนาม:

$$x = -\frac{b}{a}$$

คำตอบนี้คงอยู่และเป็นค่าเดียวเสมอ ไม่ว่าจะเป็นในสนาม \(\mathbb{R}\) หรือ \(\mathbb{C}\)

การวิเคราะห์เงื่อนไขการมีคำตอบของรูปพจน์ \(ax + b = 0\)

กรณีที่ 1 Unique Solution

\(a \neq 0\)

มีสัมประสิทธิ์ของตัวแปร

ผลลัพธ์: มีคำตอบเดียวเสมอคือ \(x = -\frac{b}{a}\)
กราฟ \(y = ax+b\) ตัดแกน \(x\) ที่จุด \((-\frac{b}{a}, 0)\) จุดเดียว
กรณีที่ 2 Inconsistent

\(a = 0\) และ \(b \neq 0\)

สมการกลายเป็น \(0 \cdot x + b = 0\)

ผลลัพธ์: ไม่มีคำตอบ (No Solution) เนื่องจากได้ประโยค \(b = 0\) ซึ่งขัดแย้งกับสมมติฐาน กราฟขนานกับแกน \(x\) ไม่ตัดกันเลย
กรณีที่ 3 Identity / Dependent

\(a = 0\) และ \(b = 0\)

สมการกลายเป็น \(0 \cdot x + 0 = 0\)

ผลลัพธ์: มีคำตอบนับไม่ถ้วน (Infinitely Many) เป็นเอกลักษณ์ทางพีชคณิต กราฟคือเส้นตรงทับแกน \(x\) ทุกจำนวนจึงเป็นคำตอบ

4. คำถามนำเพื่อค้นพบ (Guiding Discovery Questions)

คลิกที่แต่ละคำถามเพื่อคิดวิเคราะห์และเปิดดูคำอธิบายทางคณิตศาสตร์

คำอธิบายเชิงพีชคณิตและเรขาคณิต:

1. เชิงพีชคณิต (Field Axioms): เมื่อ \(a \neq 0\) ตามสัจพจน์ของระบบจำนวนจริง (หรือจำนวนเชิงซ้อน) จะมีตัวผกผันการคูณ \(a^{-1} = \frac{1}{a}\) เพียงหนึ่งเดียวเสมอ ทำให้เมื่อดำเนินการคูณตลอดสมการ \(x = a^{-1}(-b) = -\frac{b}{a}\) ซึ่งได้ผลลัพธ์ที่เป็นเอกลักษณ์และแน่นอนเพียงหนึ่งค่าเท่านั้น

2. เชิงเรขาคณิต (Geometric Interpretation): เส้นตรง \(y = ax + b\) ที่มีความชัน \(a \neq 0\) จะไม่ขนานกับแกน \(x\) (ซึ่งคือเส้นตรง \(y = 0\)) ตามสัจพจน์แบบยุคลิด เส้นตรงที่ไม่ขนานกันบนระนาบจะตัดกันได้เพียง จุดเดียวเท่านั้น พิกัด \(x\) ของจุดตัดนั้นจึงเป็นคำตอบเดียวของสมการ

เงื่อนไขหลัก: สัมประสิทธิ์ตัวหารต้อง ไม่เท่ากับศูนย์ (\(a \neq 0\)) เสมอ

ในการหารด้วยสัมประสิทธิ์ \(a\) เพื่อย้ายข้างหรือหาค่า \(x = -\frac{b}{a}\) นั้น กระทำได้ก็ต่อเมื่อ \(a \neq 0\) เนื่องจากการหารด้วยศูนย์ไม่มีนิยามในระบบจำนวน (Undefined) หาก \(a = 0\) เราไม่สามารถนำศูนย์ไปหารทั้งสองข้างได้ แต่ต้องวิเคราะห์พจน์เดิม \(0 \cdot x = -b\) แยกเป็นสองกรณีคือ:

  • ถ้า \(b \neq 0\): \(0 = -b\) เป็นข้อความที่เป็นเท็จ จึงไม่มีคำตอบ
  • ถ้า \(b = 0\): \(0 = 0\) เป็นข้อความที่เป็นจริงสำหรับทุกจำนวน จึงมีคำตอบเป็นจำนวนใดๆ ก็ได้

คำตอบ: จัดเป็นสมการได้ และขึ้นอยู่กับค่าความจริงของความสัมพันธ์ทางตัวเลข:

  • กรณี \(0 = 0\) (หรือ \(b = 0\)): สมการถือว่ามี เซตคำตอบเป็นสากล (Universal Set) นั่นคือจำนวนใด ๆ ไม่ว่าจะเป็นจำนวนจริง (\(\mathbb{R}\)) หรือจำนวนเชิงซ้อน (\(\mathbb{C}\)) นำมาแทนค่าก็ทำให้สมการเป็นจริงเสมอ เรียกว่าเป็น เอกลักษณ์ (Identity Equation)
  • กรณี \(5 = 0\) (เมื่อ \(b \neq 0\)): สมการนี้เป็นเท็จเสมอ เซตคำตอบคือเซตว่าง (\(\emptyset\)) จึงจัดว่าเป็นสมการที่ ไม่มีคำตอบ (Contradiction)

*หมายเหตุ: ตามนิยามเชิงพหุนาม หากสัมประสิทธิ์ของ \(x\) เป็น 0 จะไม่จัดว่าเป็นพหุนามดีกรี 1 (เพราะดีกรีคือ 0 หรือไม่มีดีกรีหากพหุนามเป็นศูนย์) แต่มักถูกพิจารณาเป็นกรณีสุดขั้ว (Degenerate Case) ของการแก้สมการ
