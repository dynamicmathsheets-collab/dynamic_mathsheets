เรื่องที่ 6: การสร้างสมการและการแปลงนิพจน์เกี่ยวกับราก

Forming Equations, Root Transformation, and Symmetric Polynomials: เทคนิคการสร้างสมการใหม่ การคำนวณค่านิพจน์สมมาตรของราก เช่น $r_1^2 + r_2^2$ และ $(r_1 - r_2)^2$ โดยตรงจาก $S$ และ $P$ พร้อมการแทนที่ตัวแปรเชิงพีชคณิตเพื่อลดทอนขั้นตอนคำนวณ

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

เมื่อศึกษาหัวข้อนี้จบแล้ว ผู้เรียนสามารถ:

  • สร้างสมการพหุนามกำลังสองจากข้อมูลที่กำหนด เช่น รากของสมการ ผลบวกและผลคูณของราก ได้อย่างถูกต้อง
  • หาค่าของนิพจน์สมมาตรของราก เช่น \(r_1^2 + r_2^2\), \((r_1 - r_2)^2\), \(r_1^3 + r_2^3\) และ \(\frac{1}{r_1} + \frac{1}{r_2}\) โดยใช้ความสัมพันธ์ของวีเอตาโดยไม่จำเป็นต้องแก้หารากแต่ละตัวโดยตรง
  • สร้างสมการใหม่เมื่อรากเดิมถูกแปลง เช่น เลื่อนค่าคงตัว (\(r_i + k\)) กลับเศษส่วน (\(1/r_i\)) หรือคูณด้วยสเกลาร์ (\(m \cdot r_i\)) ทั้งด้วยวิธีผลบวก-ผลคูณของรากใหม่และวิธีแทนที่ตัวแปร (\(x = g(y)\))
  • อธิบายหลักการลดทอนขั้นตอนการคำนวณทางพีชคณิตได้อย่างสมเหตุสมผลตามหลักตรรกศาสตร์

2. เนื้อหาหลัก (Core Mathematical Concepts)

มโนทัศน์นิพจน์สมมาตร การสร้างสมการ และกลวิธีการแปลงตัวแปร

การสร้างสมการจากผลบวกและผลคูณ

รูปทั่วไปของสมการโมนิก (Monic Form)

ถ้า \(r_1, r_2\) เป็นรากของสมการ และกำหนดให้ \(S = r_1 + r_2 = -\frac{b}{a}\) กับ \(P = r_1 r_2 = \frac{c}{a}\) สมการกำลังสองที่มีรากดังกล่าวคือ:

$$x^2 - Sx + P = 0$$

สำหรับตัวคูณร่วมใดๆ \(a \neq 0\): \(a(x^2 - Sx + P) = 0\)

นิยาม: นิพจน์สมมาตรของราก (Symmetric Expressions)

ความไม่แปรเปลี่ยนเมื่อสลับราก

นิพจน์ \(f(r_1, r_2)\) เรียกว่า นิพจน์สมมาตร หากค่าของนิพจน์คงเดิมเมื่อสลับตำแหน่งของราก นั่นคือ \(f(r_1, r_2) = f(r_2, r_1)\)

$$f(r_1, r_2) = \Phi(S, P)$$

ตามทฤษฎีบทมูลฐานของพหุนามสมมาตร ทุกนิพจน์สมมาตรสามารถเขียนแทนด้วย \(S\) และ \(P\) ได้เสมอ

เอกลักษณ์นิพจน์สมมาตรพื้นฐานที่สำคัญ (Fundamental Symmetric Identities)

1. ผลบวกกำลังสอง
\(r_1^2 + r_2^2\)
\(= S^2 - 2P\)

มาจาก \((r_1 + r_2)^2 = r_1^2 + 2r_1 r_2 + r_2^2\)

2. กำลังสองของผลต่าง
\((r_1 - r_2)^2\)
\(= S^2 - 4P = \frac{\Delta}{a^2}\)

สอดคล้องโดยตรงกับดิสคริมิแนนต์ \(\Delta = b^2 - 4ac\)

3. ผลบวกกำลังสาม
\(r_1^3 + r_2^3\)
\(= S(S^2 - 3P)\)

มาจาก \((r_1+r_2)(r_1^2 - r_1 r_2 + r_2^2)\)

4. ผลบวกส่วนกลับ
\(\frac{1}{r_1} + \frac{1}{r_2}\)
\(= \frac{S}{P} = -\frac{b}{c}\)

หา ครน. ได้ \(\frac{r_1+r_2}{r_1 r_2}\) (เมื่อ \(r_1, r_2 \neq 0\))

กลวิธีการแปลงรากเพื่อสร้างสมการใหม่ (Root Transformation Techniques)

1. การเลื่อนค่าคงที่ (\(r_i \to r_i + k\)) Shift

ให้ตัวแปรใหม่ \(y = x + k \iff x = y - k\) แทนค่าลงในสมการเดิม:

$$a(y - k)^2 + b(y - k) + c = 0$$

กราฟของพาราโบลาจะเลื่อนขนานไปทางขวา \(k\) หน่วยบนแกนพิกัด

2. การกลับเศษส่วน (\(r_i \to 1/r_i\)) Reciprocal

ให้ \(y = \frac{1}{x} \iff x = \frac{1}{y}\) แทนค่าลงในสมการแล้วคูณด้วย \(y^2\):

$$c y^2 + b y + a = 0$$

สัมประสิทธิ์นำ \(a\) และค่าคงตัว \(c\) จะ สลับตำแหน่งกัน เสมอ

3. การคูณด้วยสเกลาร์ (\(r_i \to m \cdot r_i\)) Scale

ให้ \(y = mx \iff x = \frac{y}{m}\) แทนค่าลงในสมการแล้วคูณด้วย \(m^2\):

$$a y^2 + (bm) y + (c m^2) = 0$$

ผลบวกของรากขยายเป็น \(mS\) และผลคูณขยายเป็น \(m^2 P\)

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

คลิกที่แต่ละคำถามเพื่อคิดวิเคราะห์และเปิดดูคำอธิบายทางคณิตศาสตร์อย่างเป็นระบบ

อาศัยเอกลักษณ์กำลังสองสมบูรณ์ของทวินาม:

เริ่มต้นจากสูตรกำลังสองสมบูรณ์ \((r_1 + r_2)^2 = r_1^2 + 2r_1 r_2 + r_2^2\) จากนั้นย้ายพจน์กลาง \(2r_1 r_2\) ไปฝั่งซ้าย:

$$r_1^2 + r_2^2 = (r_1 + r_2)^2 - 2r_1 r_2 = S^2 - 2P$$

วิธีนี้ทำให้เราได้ค่าผลบวกกำลังสองทันทีโดยไม่จำเป็นต้องถอดรากที่สองของดิสคริมิแนนต์ ซึ่งช่วยป้องกันความผิดพลาดจากการคำนวณติดกรณฑ์หรือจำนวนเชิงซ้อนได้อย่างดีเยี่ยม

ผลการแปลงเชิงโครงสร้างของสัมประสิทธิ์:

  • รากกลับเศษส่วน (\(r_i \to 1/r_i\)): สัมประสิทธิ์กลับลำดับจากหน้าไปหลัง กล่าวคือ \(ax^2 + bx + c = 0 \to cy^2 + by + a = 0\) โดยสัมประสิทธิ์กลาง \(b\) ยังคงเดิม
  • รากเลื่อนค่าคงตัว (\(r_i \to r_i + k\)): สัมประสิทธิ์นำ \(a\) จะมีค่าคงเดิมเสมอ แต่สัมประสิทธิ์กลางจะเปลี่ยนเป็น \(b' = b - 2ak\) และค่าคงตัวใหม่คือ \(c' = ak^2 - bk + c\)
  • รากคูณสเกลาร์ (\(r_i \to m \cdot r_i\)): สัมประสิทธิ์แต่ละพจน์จะถูกถ่วงน้ำหนักด้วยกำลังของ \(m\) คือ \(a, bm, cm^2\)

การแทนที่ตัวแปรแบบย้อนกลับ (Algebraic Substitution \(x = g^{-1}(y)\)):

เมื่อต้องการสร้างสมการใหม่ การใช้ความสัมพันธ์ \(y = g(x) \iff x = g^{-1}(y)\) แล้วนำ \(x\) ไปแทนค่าลงในสมการเดิมโดยตรง เป็นวิธีที่ ทรงพลังและรวดเร็วที่สุด เพราะ:

  1. ไม่ต้องคำนวณค่าราก \(r_1, r_2\) ที่อาจติดจำนวนอตรรกยะหรือจำนวนเชิงซ้อน
  2. ไม่ต้องคำนวณหาผลบวกและผลคูณของรากใหม่แยกต่างหาก
  3. วิธีนี้ใช้ได้กับพหุนามกำลังสาม กำลังสี่ หรือกำลังใดๆ ได้เหมือนกันทั้งหมด
