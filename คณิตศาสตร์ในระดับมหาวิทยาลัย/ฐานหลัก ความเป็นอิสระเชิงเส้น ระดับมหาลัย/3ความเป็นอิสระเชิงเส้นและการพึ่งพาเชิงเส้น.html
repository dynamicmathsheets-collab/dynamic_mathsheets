เรื่องที่ 3: ความเป็นอิสระเชิงเส้นและการพึ่งพาเชิงเส้น

ตรวจจับ "ความซ้ำซ้อน" ในชุดข้อมูลเวกเตอร์ ผ่านสมการเอกพันธ์ $c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$ สู่การวิเคราะห์ตำแหน่งตัวนำ (Pivot Positions) ในเมทริกซ์ $A\mathbf{c} = \mathbf{0}$

1. วัตถุประสงค์การเรียนรู้

  • นักศึกษาสามารถตรวจสอบความเป็นอิสระเชิงเส้น (Linear Independence) ของเวกเตอร์ชุดหนึ่งได้อย่างถูกต้องเป็นขั้นตอน
  • นักศึกษาสามารถอธิบายความหมายของการพึ่งพาเชิงเส้น (Linear Dependence) ในเชิงความซ้ำซ้อนของข้อมูลและเชิงเรขาคณิตได้

2. เนื้อหาหลัก (Core Mathematical Concepts)

การวิเคราะห์สมการเวกเตอร์เอกพันธ์และเงื่อนไขการมีคำตอบศูนย์เพียงคำตอบเดียว

1 นิยามความเป็นอิสระเชิงเส้น (Linear Independence)

เซตของเวกเตอร์ $\{\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_k\}$ ใน $\mathbb{R}^n$ จะเรียกว่า เป็นอิสระเชิงเส้นต่อกัน ก็ต่อเมื่อ สมการเอกพันธ์:

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$$

มีเพียง "คำตอบศูนย์ทั้งหมด" (Trivial Solution) เท่านั้น นั่นคือ $c_1 = c_2 = \cdots = c_k = 0$

2 การพึ่งพาเชิงเส้น (Linear Dependence)

เซตของเวกเตอร์จะเรียกว่า พึ่งพาเชิงเส้นต่อกัน ถ้ามีค่าสเกลาร์ $c_1, c_2, \dots, c_k$ ที่ไม่เป็นศูนย์พร้อมกันทุกตัว (Non-trivial Solution) ที่ทำให้:

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \mathbf{0} \quad (\exists c_i \neq 0)$$

หมายความว่า เราสามารถรวมเวกเตอร์เหล่านี้ให้กลับมาที่จุดกำเนิด $\mathbf{0}$ ได้ โดยไม่ต้องตั้งค่าสัมประสิทธิ์ให้เป็นศูนย์ทั้งหมด

3 เวกเตอร์ที่ซ้ำซ้อน (Redundancy)

ทฤษฎีบทการพึ่งพาเชิงเส้นระบุว่า: เซต $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ (เมื่อ $k \ge 2$) จะพึ่งพาเชิงเส้นก็ต่อเมื่อ:

"มีเวกเตอร์อย่างน้อย 1 ตัวในเซต สามารถเขียนเป็นการรวมเชิงเส้นของเวกเตอร์ตัวที่เหลือได้"

เวกเตอร์ตัวนั้นเปรียบเสมือน "ข้อมูลซ้ำซ้อน" หากตัดออกไป ค่า $\operatorname{span}$ ก็จะยังคงเท่าเดิมไม่ลดลง

4 การตรวจสอบผ่านเมทริกซ์ $A\mathbf{c} = \mathbf{0}$

นำเวกเตอร์มาตั้งเป็นคอลัมน์ของเมทริกซ์ $A = [\mathbf{v}_1\ \mathbf{v}_2\ \cdots\ \mathbf{v}_k]$ แล้วลดรูปสู่ขั้นบันไดแถวลดรูป (RREF):

  • อิสระเชิงเส้น: ทุกคอลัมน์มีตำแหน่งตัวนำ (Pivot Column ครบทุกคอลัมน์) ไม่มีตัวแปรเสรี (No Free Variable) $\implies \mathbf{c} = \mathbf{0}$ ตัวเดียว
  • พึ่งพาเชิงเส้น: มีอย่างน้อยหนึ่งคอลัมน์ที่ไม่มี Pivot (มีตัวแปรเสรี Free Variable) $\implies$ มีผลเฉลยที่ไม่เป็นศูนย์นับไม่ถ้วน

สรุปเปรียบเทียบ: อิสระเชิงเส้น vs พึ่งพาเชิงเส้น

คุณสมบัติ เป็นอิสระเชิงเส้น (Linearly Independent) พึ่งพาเชิงเส้น (Linearly Dependent)
คำตอบของ $A\mathbf{c} = \mathbf{0}$ มีเฉพาะ Trivial Solution ($\mathbf{c}=\mathbf{0}$) มี Non-trivial Solutions นับไม่ถ้วน
ตำแหน่ง Pivot ใน RREF ครบทุกคอลัมน์ (Pivot in every column) มีคอลัมน์ที่ไม่มี Pivot (เกิด Free Variable)
ความซ้ำซ้อนของข้อมูล ไม่มีเวกเตอร์ใดซ้ำซ้อน ทุกตัวให้ทิศทางใหม่ มีเวกเตอร์ซ้ำซ้อน (เขียนเป็นผลรวมของตัวอื่นได้)
ในระนาบ 2 มิติ (2 เวกเตอร์) ไม่ขนานกัน (Not Collinear, $\det \neq 0$) ขนานกัน หรือมีเวกเตอร์ศูนย์ ($\det = 0$)

3. แบบจำลองโต้ตอบ: ตรวจสอบระบบ $A\mathbf{c} = \mathbf{0}$ ด้วยการดำเนินการตามแถว

นำเวกเตอร์มาเป็นคอลัมน์ของเมทริกซ์ $A$ ปรับค่าตัวเลข หรือเลือก Presets แล้วดูการคำนวณขั้นบันไดแถวลดรูป (RREF) และสถานะความเป็นอิสระทันที

มิติเมทริกซ์:
ชุดทดลองมาตรฐาน (Presets):

เมทริกซ์ $A = [\mathbf{v}_1 \mid \mathbf{v}_2 \mid \cdots]$:

สามารถแก้ไขตัวเลขในช่องได้
ภาพเวกเตอร์คอลัมน์บนระนาบ 2D: ไม่ขนานกัน (ชี้คนละแนว)

สังเกต: หากเวกเตอร์ขนานกันหรือทับเส้นเดียวกัน จะเกิดการพึ่งพาเชิงเส้นทันที

เวกเตอร์ชุดนี้ "เป็นอิสระเชิงเส้น" (Linearly Independent)
Trivial Solution Only

ทุกคอลัมน์ของเมทริกซ์ $A$ มีตำแหน่งตัวนำ (Pivot Column) ครบถ้วน ไม่มีตัวแปรเสรี ทำให้สมการ $A\mathbf{c} = \mathbf{0}$ มีเพียงคำตอบเดียวคือ $c_1 = 0, c_2 = 0$

ตำแหน่งคอลัมน์ตัวนำ (Pivot Columns): คอลัมน์ 1, คอลัมน์ 2
ตัวแปรเสรี (Free Variables): ไม่มี (0 ตัวแปร)

4. คำถามนำเพื่อค้นพบ (Guided Discovery Question)

"ถ้าเวกเตอร์ตัวหนึ่งเขียนเป็นการรวมเชิงเส้นของเวกเตอร์ตัวอื่นในชุดเดียวกันได้ จะสรุปอะไรเกี่ยวกับความเป็นอิสระเชิงเส้นของชุดนั้น?"

สมมติเรามีเซต $\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$ และพบว่าเวกเตอร์ตัวที่ 3 เกิดจากสองตัวแรกรวมกัน นั่นคือ $\mathbf{v}_3 = 2\mathbf{v}_1 + 5\mathbf{v}_2$ เราจะจัดรูปสมการเข้าสู่นิยาม $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + c_3\mathbf{v}_3 = \mathbf{0}$ เพื่อดูคำตอบได้อย่างไร?

ข้อสรุป: เซตของเวกเตอร์ชุดนั้นจะ "พึ่งพาเชิงเส้นต่อกัน (Linearly Dependent)" ทันที!

การพิสูจน์ด้วยการย้ายข้างเชิงพีชคณิต:

สมมติว่าเวกเตอร์ $\mathbf{v}_k$ เขียนเป็นการรวมเชิงเส้นของตัวอื่นได้:

$$\mathbf{v}_k = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_{k-1}\mathbf{v}_{k-1}$$

เมื่อเราย้ายข้าง $\mathbf{v}_k$ มาไว้ฝั่งเดียวกันของสมการ จะได้:

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_{k-1}\mathbf{v}_{k-1} + (-1)\mathbf{v}_k = \mathbf{0}$$

สังเกตสัมประสิทธิ์หน้า $\mathbf{v}_k$ คือ $-1 \neq 0$ นี่คือหลักฐานชัดเจนว่าเราได้สร้างสมการเอกพันธ์ $= \mathbf{0}$ ที่มี สัมประสิทธิ์อย่างน้อยหนึ่งตัวที่ไม่เป็นศูนย์ สำเร็จแล้ว!

💡 หัวใจสำคัญ: "ความเป็นอิสระเชิงเส้น" หมายถึง ไม่มีเวกเตอร์ตัวใดเป็นภาระหรือซ้ำซ้อน แต่ละตัวทำหน้าที่เปิดมิติใหม่ของทิศทางเสมอ

5. แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

โจทย์ประจำโมดูล:

จงตรวจสอบว่าเซตของเวกเตอร์ $S_1 = \{(1,2), (2,4)\}$ เป็นอิสระเชิงเส้นหรือไม่ และเปรียบเทียบกับชุด $S_2 = \{(1,0), (0,1)\}$ โดยแสดงวิธีแก้ระบบสมการ $A\mathbf{c} = \mathbf{0}$

เลือกข้อสรุปที่ถูกต้องตามหลักคณิตศาสตร์:

การแสดงวิธีทำเปรียบเทียบระบบสมการ

ตอนที่ 1: ตรวจสอบชุด $S_1 = \{(1,2), (2,4)\}$

ตั้งสมการเวกเตอร์เอกพันธ์ $c_1\begin{bmatrix} 1 \\ 2 \end{bmatrix} + c_2\begin{bmatrix} 2 \\ 4 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$ ซึ่งเขียนเป็นเมทริกซ์แต่งเติม (Augmented Matrix) ได้เป็น:

$$\left[\begin{array}{cc|c} 1 & 2 & 0 \\ 2 & 4 & 0 \end{array}\right] \xrightarrow{R_2 \to R_2 - 2R_1} \left[\begin{array}{cc|c} \mathbf{1} & 2 & 0 \\ 0 & 0 & 0 \end{array}\right]$$

• ตำแหน่ง Pivot มีเพียงคอลัมน์ที่ 1 (ตัวแปรหลักคือ $c_1$)

• คอลัมน์ที่ 2 ไม่มีตำแหน่งตัวนำ $\implies c_2$ เป็นตัวแปรเสรี (Free Variable)

• จากแถวที่ 1 จะได้ $c_1 + 2c_2 = 0 \implies c_1 = -2c_2$

• หากกำหนดให้ $c_2 = 1$ จะได้ $c_1 = -2$ ซึ่งทำให้ $(-2)(1,2) + 1(2,4) = (0,0)$

$\implies$ ระบบสมการมีคำตอบที่ไม่เป็นศูนย์ (Non-trivial solution) ดังนั้น $S_1$ จึงเป็น เซตที่พึ่งพาเชิงเส้น (Linearly Dependent)

ตอนที่ 2: ตรวจสอบชุด $S_2 = \{(1,0), (0,1)\}$

ตั้งสมการเวกเตอร์เอกพันธ์ $c_1\begin{bmatrix} 1 \\ 0 \end{bmatrix} + c_2\begin{bmatrix} 0 \\ 1 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$ เขียนเป็นเมทริกซ์แต่งเติม:

$$\left[\begin{array}{cc|c} \mathbf{1} & 0 & 0 \\ 0 & \mathbf{1} & 0 \end{array}\right]$$

• เมทริกซ์อยู่ในรูป RREF อยู่แล้ว และมี Pivot ครบทั้ง 2 คอลัมน์

• ไม่มีตัวแปรเสรี (No Free Variable)

• คำตอบเดียวของระบบสมการคือ $c_1 = 0$ และ $c_2 = 0$ (Trivial Solution Only)

$\implies$ ดังนั้น $S_2$ จึงเป็น เซตที่เป็นอิสระเชิงเส้น (Linearly Independent)
