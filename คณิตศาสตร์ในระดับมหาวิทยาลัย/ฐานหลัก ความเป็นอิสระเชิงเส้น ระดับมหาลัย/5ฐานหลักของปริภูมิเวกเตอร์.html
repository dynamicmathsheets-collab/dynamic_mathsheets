เรื่องที่ 5: ฐานหลักของปริภูมิเวกเตอร์ (Basis)

จุดสมดุลอันสมบูรณ์แบบระหว่าง "การครอบคลุมพื้นที่ทั้งหมด (Spanning)" และ "ความประหยัดไร้ความซ้ำซ้อน (Linear Independence)" สู่ระบบพิกัดอ้างอิงที่มีประสิทธิภาพสูงสุด

1. วัตถุประสงค์การเรียนรู้ (Learning Objectives)

นักศึกษาสามารถตรวจสอบว่าเซตของเวกเตอร์ที่กำหนดให้เป็นฐานหลัก (Basis) ของปริภูมิเวกเตอร์หรือไม่ โดยประยุกต์ใช้และแยกแยะเงื่อนไขการแผ่ทั่ว (Spanning) และความเป็นอิสระเชิงเส้น (Linear Independence) ได้อย่างถูกต้องและเป็นระบบ

2. เนื้อหาหลัก (Core Mathematical Concepts)

นิยาม เงื่อนไขเชิงคู่ และการขยายแนวคิดสู่ปริภูมิพหุนามและเมทริกซ์

1 นิยามฐานหลัก (Basis Definition)

ให้ $V$ เป็นปริภูมิเวกเตอร์ สับเซต $B = \{\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_n\} \subseteq V$ จะเรียกว่าเป็น ฐานหลัก (Basis) ของ $V$ ก็ต่อเมื่อสอดคล้องกับทั้งสองเงื่อนไข:

(1) $B$ เป็นอิสระเชิงเส้น (Linearly Independent)
(2) $B$ แผ่ทั่ว $V$ นั่นคือ $\operatorname{span}(B) = V$

ฐานหลักคือเซตตัวกำเนิดที่ "เล็กและกะทัดรัดที่สุด (Minimal Spanning Set)"

2 ฐานมาตรฐานของ $\mathbb{R}^n$ (Standard Basis)

ฐานหลักที่คุ้นเคยที่สุดคือเวกเตอร์หนึ่งหน่วยตามแนวแกนพิกัด:

$$\mathbf{e}_1 = \begin{bmatrix} 1 \\ 0 \\ \vdots \\ 0 \end{bmatrix}, \mathbf{e}_2 = \begin{bmatrix} 0 \\ 1 \\ \vdots \\ 0 \end{bmatrix}, \dots, \mathbf{e}_n = \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 1 \end{bmatrix}$$

ใน $\mathbb{R}^2$: $B = \{(1,0), (0,1)\}$
ใน $\mathbb{R}^3$: $B = \{(1,0,0), (0,1,0), (0,0,1)\}$

จำนวนเวกเตอร์ในฐานหลักเท่ากับมิติของปริภูมิ: $\dim(\mathbb{R}^n) = n$

3 ฐานของพหุนามและเมทริกซ์

แนวคิดฐานหลักใช้ได้กับปริภูมิเวกเตอร์นามธรรมทุกประเภท:

ปริภูมิพหุนาม $\mathbb{P}_n$:
ฐานมาตรฐานของ $\mathbb{P}_2$ คือ $\{1, x, x^2\}$
$\dim(\mathbb{P}_n) = n + 1$
ปริภูมิเมทริกซ์ $M_{2\times2}$:
ฐานมาตรฐานคือเมทริกซ์มูลฐาน $\{E_{11}, E_{12}, E_{21}, E_{22}\}$ มีมิติ $= 4$

สมาชิกทุกตัวเขียนเป็นผลรวมเชิงเส้นของฐานหลักชุดนี้ได้แบบเดียว

ความแตกต่างอย่างลึกซึ้ง: เซตตัวกำเนิด (Spanning Set) กับ ฐานหลัก (Basis)

เซตตัวกำเนิด (Spanning Set):

สนใจเพียงว่า "ครอบคลุมทั่วทั้งปริภูมิหรือไม่" ไม่สนใจว่าจะมีเวกเตอร์ส่วนเกินหรือซ้ำซ้อนหรือไม่ (อาจมี 10 เวกเตอร์ใน $\mathbb{R}^2$ ก็ยังเรียกว่าเซตตัวกำเนิดได้)

ฐานหลัก (Basis):

ต้องครอบคลุมทั่วทั้งปริภูมิ และต้องไม่มีเวกเตอร์ซ้ำซ้อนแม้แต่ตัวเดียว (Minimal Spanning Set) ทำให้การแทนพิกัดของเวกเตอร์ใดๆ มีเพียงแบบเดียวเท่านั้น (Unique Coordinates)

3. แบบจำลองโต้ตอบ: เครื่องมือตรวจสอบเงื่อนไขฐานหลักแบบแยกส่วน

เลือกหรือกำหนดชุดเวกเตอร์ในระนาบ $\mathbb{R}^2$ เพื่อตรวจสอบ 2 เงื่อนไขทีละข้อ และสังเกตการสรุปสถานะฐานหลักทันที

ปริภูมิเป้าหมาย: $\mathbb{R}^2$ ($\dim = 2$)
อันดับ $\operatorname{rank}(A)$: 2
$\mathbf{v}_1$ (สีน้ำเงิน)
$\mathbf{v}_2$ (สีส้ม)
$\mathbf{v}_3$ (สีม่วง)

พื้นที่แรเงาแสดงอาณาเขต $\operatorname{span}$ ของเวกเตอร์ชุดที่เลือก

เวกเตอร์ในเซต $S$:

$\mathbf{v}_1 = (x_1, y_1)$
$\mathbf{v}_2 = (x_2, y_2)$
$\mathbf{v}_3 = (x_3, y_3)$
✓ เงื่อนไขที่ 1: เป็นอิสระเชิงเส้น (Linear Independence)
ผ่าน (Passed)

เมทริกซ์ $A$ มี $\operatorname{rank} = 2$ เท่ากับจำนวนเวกเตอร์ (ไม่มี Free Variables) ทุกคอลัมน์เป็น Pivot

✓ เงื่อนไขที่ 2: แผ่ทั่วปริภูมิ $\mathbb{R}^2$ ($\operatorname{span}(S) = \mathbb{R}^2$)
ผ่าน (Passed)

มิติของพื้นที่ที่แผ่ทั่วคือ $\dim(\operatorname{span}(S)) = 2$ ซึ่งเท่ากับมิติของ $\mathbb{R}^2$ พอดี

ข้อสรุปสุดท้าย (Final Verdict): เป็นฐานหลักของ R²

เซตเวกเตอร์นี้สอดคล้องกับทั้งสองเงื่อนไข จึงเป็น "ฐานหลัก (Basis)" ของ $\mathbb{R}^2$

4. คำถามนำเพื่อค้นพบ (Guided Discovery Question)

"เหตุใดเซตที่แผ่ทั่ว (Spanning Set) แต่มีเวกเตอร์ซ้ำซ้อน จึงไม่ได้รับอนุญาตให้เป็นฐานหลัก?"

ในเมื่อเซตที่มีเวกเตอร์เกินมา ก็ยังคงสร้างเวกเตอร์ทุกตัวในปริภูมิได้เหมือนเดิม ทำไมนักคณิตศาสตร์จึงต้องตัดเวกเตอร์ส่วนเกินออกจนกลายเป็นฐานหลัก?

เหตุผลสำคัญที่สุด: "ความเป็นเอกลักษณ์ของระบบพิกัด (Uniqueness of Coordinates)"

ถ้าเซตของเวกเตอร์เป็น ฐานหลัก (Basis) เวกเตอร์ $\mathbf{v}$ ใดๆ ในปริภูมิ จะสามารถเขียนเป็นการรวมเชิงเส้นของฐานหลักได้ เพียงวิธีเดียวเท่านั้น (Unique Linear Combination):

$$\mathbf{v} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_n\mathbf{v}_n$$

ทำให้เราสามารถใช้ชุดสเกลาร์ $(c_1, c_2, \dots, c_n)$ เป็น "พิกัดเฉพาะตัว (Coordinate Vector $[\mathbf{v}]_B$)" ของเวกเตอร์นั้นได้ เหมือนพิกัด GPS ที่ระบุตำแหน่งได้แน่ชัด

จะเกิดอะไรขึ้นถ้ามีเวกเตอร์ซ้ำซ้อน (พึ่งพาเชิงเส้น)?

หากเซตนั้นพึ่งพาเชิงเส้น จะทำให้เขียน $\mathbf{v}$ ได้นับไม่ถ้วนแบบ เช่น ใน $\mathbb{R}^2$ ถ้าใช้เซต $S = \{(1,0), (0,1), (1,1)\}$ เวกเตอร์ $\mathbf{v} = (3, 3)$ สามารถเขียนได้หลายแบบ เช่น:

  • แบบที่ 1: $3(1,0) + 3(0,1) + 0(1,1) = (3,3)$ $\implies$ พิกัดคือ $(3, 3, 0)$
  • แบบที่ 2: $0(1,0) + 0(0,1) + 3(1,1) = (3,3)$ $\implies$ พิกัดคือ $(0, 0, 3)$
  • แบบที่ 3: $1(1,0) + 1(0,1) + 2(1,1) = (3,3)$ $\implies$ พิกัดคือ $(1, 1, 2)$

ส่งผลให้ระบบพิกัดเกิดความคลุมเครือ สับสน และขาดความเป็นมาตรฐานทางคณิตศาสตร์

💡 บทสรุป: ฐานหลักจึงถูกกำหนดให้ต้อง "เป็นอิสระเชิงเส้น" เสมอ เพื่อขจัดความซ้ำซ้อนและรับประกันว่า พิกัดอ้างอิงแต่ละตำแหน่งจะมีได้เพียงชุดเดียวเท่านั้น

5. แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercise)

โจทย์ประจำโมดูล:

จงตรวจสอบว่าเซต $S_1 = \{(1,0), (0,1)\}$ และเซต $S_2 = \{(1,0), (0,1), (1,1)\}$ เป็นฐานหลักของ $\mathbb{R}^2$ หรือไม่ พร้อมให้เหตุผลประกอบอย่างชัดเจน

เลือกข้อสรุปที่ถูกต้องตามทฤษฎีบทฐานหลัก:

การพิสูจน์ตรวจสอบ 2 เงื่อนไขสำหรับทั้ง 2 เซต

1. พิจารณาเซต $S_1 = \{(1,0), (0,1)\}$:

เงื่อนไขที่ 1 (ความเป็นอิสระเชิงเส้น):
ตั้งสมการ $c_1(1,0) + c_2(0,1) = (0,0) \implies (c_1, c_2) = (0,0)$ มีเพียงคำตอบศูนย์ (Trivial Solution) เท่านั้น จึงเป็นอิสระเชิงเส้น ✓ ผ่าน

เงื่อนไขที่ 2 (การแผ่ทั่ว $\mathbb{R}^2$):
สำหรับเวกเตอร์ $(x,y) \in \mathbb{R}^2$ ใดๆ สามารถเขียนได้เป็น $x(1,0) + y(0,1) = (x,y)$ เสมอ ดังนั้น $\operatorname{span}(S_1) = \mathbb{R}^2$ ✓ ผ่าน

$\implies$ สรุป: $S_1$ เป็นฐานหลักของ $\mathbb{R}^2$ (และเป็นฐานมาตรฐาน)

2. พิจารณาเซต $S_2 = \{(1,0), (0,1), (1,1)\}$:

เงื่อนไขที่ 1 (ความเป็นอิสระเชิงเส้น):
สังเกตความสัมพันธ์: $(1,1) = 1(1,0) + 1(0,1)$ หรือย้ายข้างได้เป็น $1(1,0) + 1(0,1) - 1(1,1) = (0,0)$ เนื่องจากมีสัมประสิทธิ์ที่ไม่เป็นศูนย์ $(-1 \neq 0)$ ดังนั้น $S_2$ จึง พึ่งพาเชิงเส้น (Linearly Dependent) ✗ ตกเงื่อนไข

เงื่อนไขที่ 2 (การแผ่ทั่ว $\mathbb{R}^2$):
เนื่องจากมีสองเวกเตอร์แรกที่แผ่ทั่ว $\mathbb{R}^2$ อยู่แล้ว การมีเวกเตอร์ที่ 3 เพิ่มเข้ามา ก็ยังคงแผ่ทั่ว $\mathbb{R}^2$ ได้เช่นเดิม ✓ ผ่าน

$\implies$ สรุป: $S_2$ เป็นเพียง เซตตัวกำเนิด (Spanning Set) แต่ ไม่เป็นฐานหลัก (Not a Basis) เนื่องจากมีเวกเตอร์ซ้ำซ้อนและขาดความเป็นอิสระเชิงเส้น

🔑 ทฤษฎีบทว่าด้วยขนาดของฐานหลัก (Basis Size Theorem):

ในปริภูมิเวกเตอร์ $V$ ที่มีมิติ $n$ ฐานหลักทุกชุดของ $V$ จะต้องมีจำนวนเวกเตอร์เท่ากับ $n$ ตัวพอดีเสมอ ใน $\mathbb{R}^2$ มีมิติ $= 2$ ดังนั้น เซตใดๆ ที่มีเวกเตอร์ 3 ตัว ($k=3 > 2$) จะไม่มีทางเป็นฐานหลักได้เลย เพราะต้องพึ่งพาเชิงเส้นเสมอ!
