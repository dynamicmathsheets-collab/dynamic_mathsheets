รูปทั่วไปและการลดรูปสมการกำลังสาม

การแปลงสมการพหุนามกำลังสามทั่วไปให้เป็นสมการโมนิก และการกำจัดพจน์กำลังสองด้วยการแทนตัวแปร $x = y - \frac{A}{3}$ สู่สมการรูปกด

1

วัตถุประสงค์การเรียนรู้

1. นักศึกษาสามารถอธิบายรูปทั่วไปของสมการพหุนามกำลังสามและแปลงให้เป็นสมการโมนิกได้อย่างถูกต้อง

2. นักศึกษาสามารถลดรูปสมการด้วยการแทนตัวแปร $x = y - \frac{A}{3}$ และวิเคราะห์ความสัมพันธ์ของสัมประสิทธิ์ $p, q$ ได้

2

เนื้อหาหลัก (Core Mathematical Theory)

2.1 รูปทั่วไปและการแปลงเป็นสมการโมนิก (Monic Equation)

สมการพหุนามกำลังสามทั่วไปมีรูปคือ $ax^3 + bx^2 + cx + d = 0$ โดยที่สัมประสิทธิ์นำ $a \ne 0$ เมื่อหารตลอดทั้งสมการด้วย $a$ จะได้สมการโมนิกที่มีสัมประสิทธิ์หน้า $x^3$ เป็น 1:

$$x^3 + Ax^2 + Bx + C = 0$$

โดยนิยามสัมประสิทธิ์ใหม่: $A = \frac{b}{a}$, $B = \frac{c}{a}$, และ $C = \frac{d}{a}$

2.2 การแทนตัวแปรเพื่อลดรูปพจน์กำลังสอง (Tschirnhaus Transformation)

เพื่อกำจัดพจน์ $Ax^2$ เราใช้การแทนตัวแปรด้วยการเลื่อนแกนพิกัด: $x = y - \frac{A}{3}$ เมื่อแทนลงในสมการโมนิกและกระจายทวินามจะได้:

$$\left(y - \frac{A}{3}\right)^3 + A\left(y - \frac{A}{3}\right)^2 + B\left(y - \frac{A}{3}\right) + C = 0$$
$$y^3 + \left(-A + A\right)y^2 + \left(B - \frac{A^2}{3}\right)y + \left(\frac{2A^3}{27} - \frac{AB}{3} + C\right) = 0$$

สังเกตว่าสัมประสิทธิ์หน้า $y^2$ หักล้างกันเป็นศูนย์พอดี ทำให้ได้ สมการรูปกด (Depressed Cubic Equation):

$$y^3 + py + q = 0$$
สัมประสิทธิ์ $p$: $p = B - \frac{A^2}{3}$
สัมประสิทธิ์ $q$: $q = \frac{2A^3}{27} - \frac{AB}{3} + C$
3

แบบจำลองโต้ตอบ: ปรับสัมประสิทธิ์แล้วลดรูปสมการสดทันที

ปรับแถบบาร์สัมประสิทธิ์เพื่อดูการแปลงเป็นสมการโมนิก การคำนวณ $p, q$ และการเลื่อนราก $x = y - A/3$

ตัวอย่างทดลอง:
สัมประสิทธิ์ $a$ ($a \ne 0$): 1
สัมประสิทธิ์ $b$: -3
สัมประสิทธิ์ $c$: 3
สัมประสิทธิ์ $d$: -1
การแจกแจงขั้นตอนการลดรูปสมการ
4

คำถามนำเพื่อค้นพบ

1. เหตุใดการแทนตัวแปร $x = y - \frac{A}{3}$ จึงสามารถกำจัดพจน์กำลังสองได้?

เมื่อกระจายทวินาม $(y - A/3)^3 = y^3 - Ay^2 + \dots$ สัมประสิทธิ์หน้า $y^2$ จากพจน์กำลังสามคือ $-A$ ซึ่งจะเข้าไปหักล้างกับสัมประสิทธิ์ $+A$ จากพจน์ $A(y - A/3)^2 = Ay^2 + \dots$ กลายเป็น $-A + A = 0$ พอดิบพอดี

2. การเปลี่ยนตัวแปรส่งผลต่อค่ารากอย่างไร?

เป็นการเลื่อนแกนพิกัดในแนวราบ (Horizontal Shift) ทุกๆ รากจะถูกเลื่อนไปทางขวาด้วยระยะ $\frac{A}{3}$ นั่นคือถ้าแก้สมการรูปกดได้ราก $y_k$ รากเดิมของสมการตั้งต้นจะหาได้จาก $x_k = y_k - \frac{A}{3}$

3. สมการรูปกดช่วยให้การแก้สมการง่ายขึ้นอย่างไร?

การตัดพจน์กำลังสองออกทำให้ตัวแปรลดลงเหลือเฉพาะกำลังสามและกำลังหนึ่ง ($y^3 + py + q = 0$) ซึ่งสอดคล้องกับเอกลักษณ์การกระจายกำลังสามของคาร์ดาโนและการใช้เอกลักษณ์ตรีโกณมิติ $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$ ในการหาคำตอบได้โดยตรง

5

แบบฝึกหัดสำหรับนักศึกษา

โจทย์แบบฝึกหัด

จงลดรูปสมการ $x^3 - 6x^2 + 9x - 2 = 0$ ให้อยู่ในรูปกด $y^3 + py + q = 0$ พร้อมระบุค่า $p$ และ $q$
