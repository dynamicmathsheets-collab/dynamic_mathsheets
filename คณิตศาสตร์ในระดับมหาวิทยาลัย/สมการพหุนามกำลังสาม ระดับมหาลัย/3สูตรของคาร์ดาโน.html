สูตรของคาร์ดาโน (Cardano's Formula)

การแก้สมการกำลังสามรูปกด $y^3 + py + q = 0$ ด้วยเทคนิคการแยกตัวแปร $y = u + v$ และการสร้างสมการช่วยกำลังสอง

1

วัตถุประสงค์การเรียนรู้

1. อธิบายที่มา ขั้นตอนการแทนตัวแปร และการกำจัดพจน์ผสมในสูตรของคาร์ดาโนได้

2. เชื่อมโยงระบบสมการไม่เชิงเส้นไปสู่สมการกำลังสองในตัวแปร $u^3, v^3$ ได้

3. ประยุกต์ใช้สูตรแก้สมการกำลังสามรูปกด พร้อมตรวจสอบเงื่อนไข $uv = -p/3$ ในจำนวนเชิงซ้อนได้

2

เนื้อหาหลัก (Mathematical Derivation)

ขั้นตอนที่ 1: การแทนตัวแปร $y = u + v$

กระจาย $(u+v)^3$ ลงในสมการรูปกด $y^3 + py + q = 0$:

$$(u+v)^3 + p(u+v) + q = 0 \implies u^3 + v^3 + (3uv + p)(u + v) + q = 0$$

ขั้นตอนที่ 2: การกำหนดเงื่อนไขกำจัดพจน์ผสม

กำหนดให้สัมประสิทธิ์หน้า $(u+v)$ เป็นศูนย์ เพื่อให้สมการกลายเป็นเชิงเส้น:

$$3uv + p = 0 \implies uv = -\frac{p}{3} \implies u^3v^3 = -\frac{p^3}{27}$$
$$u^3 + v^3 + q = 0 \implies u^3 + v^3 = -q$$

ขั้นตอนที่ 3: สมการช่วยกำลังสอง (Resolvent Equation)

จากทฤษฎีบทของวีเอตา ค่า $u^3$ และ $v^3$ เป็นรากของสมการกำลังสอง $t^2 - (u^3+v^3)t + u^3v^3 = 0$:

$$t^2 + qt - \left(\frac{p}{3}\right)^3 = 0$$

ใช้สูตรกำลังสองจะได้ค่า $u^3$ และ $v^3$:

$$u^3, v^3 = -\frac{q}{2} \pm \sqrt{\left(\frac{q}{2}\right)^2 + \left(\frac{p}{3}\right)^3} = -\frac{q}{2} \pm \sqrt{\Delta}$$

ขั้นตอนที่ 4: สูตรสำเร็จของคาร์ดาโน

$$y = \sqrt[3]{-\frac{q}{2} + \sqrt{\Delta}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\Delta}}$$

* โดยเลือกรากที่สามของ $u$ และ $v$ ที่สอดคล้องกับเงื่อนไข $u \cdot v = -\frac{p}{3}$ เสมอ

3

แบบจำลองโต้ตอบ: เลือกตัวเลขแล้วแสดงวิธีทำทันที

ปรับแถบบาร์เลื่อน $p$ และ $q$ เพื่อดูขั้นตอนการคำนวณแบบ Step-by-Step สดทันที

ตัวอย่างลัด:
ค่าสัมประสิทธิ์ $p$: -6
-12 -6 0 +6 +12
ค่าคงตัว $q$: -9
-12 -6 0 +6 +12
การแจกแจงวิธีทำเชิงคณิตศาสตร์
4

คำถามนำเพื่อค้นพบ

1. เหตุใดการแทน $y = u + v$ จึงช่วยให้สมการกำลังสามแก้ได้?

เนื่องจากการเพิ่มตัวแปรทำให้เกิดระดับความเป็นอิสระ (Degree of Freedom) ส่งผลให้เราสามารถตั้งเงื่อนไขบังคับ $3uv + p = 0$ เพื่อหักล้างพจน์กำลังหนึ่งได้ และแปลงความสัมพันธ์ให้อยู่ในรูปผลรวมและผลคูณของ $u^3$ และ $v^3$

2. เงื่อนไข $3uv = -p$ มีบทบาทอย่างไรในการกำจัดพจน์ผสม?

เมื่อกระจายกำลังสามสมบูรณ์ $(u+v)^3 = u^3 + v^3 + 3uv(u+v)$ พจน์ $3uv(u+v)$ จะรวมกับ $p(u+v)$ ได้ $(3uv+p)(u+v)$ การกำหนดให้ $3uv + p = 0$ จึงตัดพจน์ $(u+v)$ ออกไปได้อย่างสมบูรณ์

3. เหตุใดสูตรคาร์ดาโนจึงต้องระวังการเลือกรากที่สามในจำนวนเชิงซ้อน?

เนื่องจากรากที่สามของ $u^3$ มี 3 ค่า และ $v^3$ มี 3 ค่า ซึ่งจับคู่รวมกันได้ถึง 9 คู่ แต่จะมีเพียง 3 คู่เท่านั้นที่สอดคล้องกับข้อกำหนดเริ่มต้นคือ $uv = -p/3$ หากเลือกคู่ผิด คำตอบที่ได้จะไม่ใช่รากของสมการเดิม
