เรื่องที่ 8: พหุนามเหนือสนามและการประยุกต์ทางพีชคณิต

🎯 วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถอธิบายโครงสร้างของวงแหวนพหุนาม ดำเนินการกับพหุนามเหนือสนาม และเชื่อมโยงแนวคิดพหุนามกับพีชคณิตเชิงเส้นได้

1. เนื้อหาหลักและทฤษฎีบทสำคัญ (Key Concepts & Algebraic Structures)

โครงสร้างเชิงพีชคณิตนามธรรม

ลำดับชั้นของวงแหวนพหุนาม $F[x]$ เมื่อ $F$ เป็นสนาม

Ring Hierarchy

เมื่อ $F$ เป็นสนาม (Field) วงแหวนของพหุนาม $F[x]$ จะได้รับสมบัติอันทรงพลังถ่ายทอดมาจนเกิดโครงสร้างที่ซ้อนทับกันอย่างเป็นระเบียบ:

ระดับ 1

Integral Domain

$F[x]$ เป็นวงแหวนสลับที่ที่มีเอกลักษณ์ $1$ และไม่มีตัวหารของศูนย์: $$f(x)g(x) = 0 \implies f=0 \lor g=0$$

ระดับ 2

Euclidean Domain (ED)

มีขั้นตอนวิธีการหาร (Division Algorithm) โดยใช้ฟังก์ชันดีกรี $\deg(f)$ เป็น Euclidean Valuation สำหรับหาเศษเหลือ

ระดับ 3

Principal Ideal Domain (PID)

ทุกไอดีล (Ideal) $I \subseteq F[x]$ สามารถสร้างขึ้นจากพหุนามเพียงตัวเดียวได้เสมอ: $I = \langle d(x) \rangle$

ระดับ 4

Unique Factorization Domain (UFD)

พหุนามทุกตัวสามารถแยกเป็นผลคูณของพหุนามลดทอนไม่ได้ (Irreducible) ได้แบบเดียวเสมอ (ไม่นับลำดับและค่าคงที่หน่วย)

Field $F$ $\implies$ $F[x]$ is Euclidean Domain (ED) $\subset$ PID $\subset$ UFD $\subset$ Integral Domain
1

พหุนามเหนือสนามจำกัด $\mathbb{Z}_2[x]$

ในสนาม $\mathbb{Z}_2 = \{0, 1\}$ การดำเนินการบวกและคูณจะเป็นไปตามมอดุโล 2 โดยมีเอกลักษณ์พิเศษที่สำคัญคือ:

• $1 + 1 = 0 \pmod 2 \iff -1 \equiv 1 \pmod 2$ (การบวกและการลบคือการดำเนินการเดียวกัน!)
• กำลังสองพหุนาม: $(f(x) + g(x))^2 = f(x)^2 + g(x)^2$ (Frobenius Endomorphism)
• พหุนามลดทอนไม่ได้ดีกรี 2 ตัวเดียวใน $\mathbb{Z}_2[x]$ คือ $x^2 + x + 1$
2

ทฤษฎีบทเคย์ลีย์–แฮมิลตัน และพหุนามต่ำสุด

สะพานเชื่อมระหว่างทฤษฎีพหุนามกับพีชคณิตเชิงเส้น สำหรับเมทริกซ์จัตุรัส $A \in M_n(F)$:

• พหุนามลักษณะเฉพาะ: $p_A(t) = \det(tI - A)$
• ทฤษฎีบท Cayley–Hamilton: $p_A(A) = 0$ (เมทริกซ์สอดคล้องกับพหุนามลักษณะเฉพาะของตนเอง)
• พหุนามต่ำสุด $m_A(t)$: เป็นพหุนามโมนิกดีกรีต่ำสุดที่ทำให้ $m_A(A) = 0$ โดย $m_A(t) \mid p_A(t)$

2. แบบจำลองโต้ตอบ (Interactive Simulators)

ห้องปฏิบัติการเชิงคำนวณ

🧮 เครื่องคิดเลขเปรียบเทียบพหุนาม: $\mathbb{Z}_2[x]$ เทียบกับ $\mathbb{R}[x]$

สังเกตผลของการมอดุโลสัมประสิทธิ์ด้วย 2 ($1+1=0$ และ $-1=1$)

ตัวอย่างโจทย์:
เช่น x^2 + x + 1, x + 1
เช่น x^2 + 1, x^3 + x
การคำนวณตามปกติใน $\mathbb{R}[x]$ จำนวนจริง
ผลลัพธ์ในรูปทั่วไป:
$$2x^2 + x + 2$$
รวมสัมประสิทธิ์: $(1+1)x^2 + (1)x + (1+1)$
การคำนวณใน $\mathbb{Z}_2[x]$ (Modulo 2) 1 + 1 = 0
ผลลัพธ์สุดท้ายหลังลดทอนสัมประสิทธิ์:
$$x$$
มอดุโล 2: $2x^2 \equiv 0$, $2 \equiv 0 \implies$ เหลือเพียง $x$

🏛️ ห้องทดลองเมทริกซ์: ทฤษฎีบทเคย์ลีย์–แฮมิลตันและพหุนามต่ำสุด

พิสูจน์ $p_A(A) = 0$ และเปรียบเทียบกับพหุนามต่ำสุด $m_A(t)$

เมทริกซ์ตัวอย่าง:
เมทริกซ์ $A$ ที่กำลังพิจารณา:
1. พหุนามลักษณะเฉพาะ (Characteristic Polynomial) $p_A(t) = \det(tI - A)$
2. การทดสอบทฤษฎีบทเคย์ลีย์–แฮมิลตัน: $p_A(A) = \mathbf{0}$ Verified ✓
3. พหุนามต่ำสุด (Minimal Polynomial $m_A(t)$) ดีกรี 1

3. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

เนื่องจาก นิยามการดำเนินการบวกและการคูณของพหุนาม จำเป็นต้องอาศัยสมบัติปิดของการบวกและการคูณของสัมประสิทธิ์:

เมื่อสัมประสิทธิ์มาจากสนามเดียวกัน ($F$) สมบัติการมีตัวผกผันการคูณ ($a^{-1}$) สำหรับทุกสัมประสิทธิ์นำที่ไม่เป็นศูนย์ จะรับประกันว่าเราสามารถทำ ขั้นตอนวิธีการหาร (Division Algorithm) ได้เสมอ ซึ่งเป็นหัวใจสำคัญที่ทำให้ $F[x]$ มีโครงสร้างเป็นโดเมนยุคลิด (Euclidean Domain) และส่งผลให้หา ห.ร.ม. ได้อย่างสมบูรณ์

มีความแตกต่างพื้นฐานทางพีชคณิตที่สำคัญอย่างยิ่ง ดังนี้:

• ลักษณะเฉพาะ (Characteristic): สนาม $\mathbb{Z}_2$ มีลักษณะเฉพาะเท่ากับ 2 ทำให้ $1 + 1 = 0$ ซึ่งส่งผลให้ $-a \equiv a$ (การบวกกับการลบมีค่าเหมือนกันทุกประการ)
• พจน์คู่หายไปหมด: สัมประสิทธิ์ที่เป็นจำนวนคู่จะกลายเป็นศูนย์ทั้งหมด เช่น $x^2 + x^2 = 2x^2 \equiv 0$
• Freshman's Dream เป็นจริง: $(a + b)^2 = a^2 + 2ab + b^2 = a^2 + b^2$ ในขณะที่เหนือ $\mathbb{R}$ พจน์ $2ab$ จะไม่เป็นศูนย์

พหุนามต่ำสุด $m_A(t)$ บ่งบอกถึง โครงสร้างทางเรขาคณิตและการแปลงทางเชิงเส้น ที่ลึกซึ้งยิ่งกว่าพหุนามลักษณะเฉพาะ:

1. เกณฑ์การทแยงมุมได้ (Diagonalizability): เมทริกซ์ $A$ จะสามารถแปลงเป็นเมทริกซ์ทแยงมุมได้ ก็ต่อเมื่อ $m_A(t)$ แยกออกเป็นผลคูณของตัวประกอบเชิงเส้นที่ไม่มีรากซ้ำ
2. ขนาดของ Jordan Block: เลขชี้กำลังของรากใน $m_A(t)$ จะบอกขนาดสูงสุดของบล็อกจอร์แดนของค่านั้น ๆ

เพราะว่า พหุนามดีกรี $\ge 1$ ไม่มีตัวผกผันการคูณ (Multiplicative Inverse) ใน $F[x]$

ตัวอย่างเช่น สำหรับพหุนาม $p(x) = x \in F[x]$ จะไม่มีพหุนาม $q(x) \in F[x]$ ใดเลยที่ทำให้ $x \cdot q(x) = 1$ เพราะ $\deg(x \cdot q(x)) = 1 + \deg(q) \ge 1 \ne 0$ สิ่งที่จะมีตัวผกผันได้คือเศษส่วนของพหุนาม $\frac{1}{x}$ ซึ่งหลุดออกจาก $F[x]$ ไปอยู่ในสนามของฟังก์ชันตรรกยะ $F(x)$ (Field of Rational Functions)

4. แบบฝึกหัดสำหรับนักศึกษา (Interactive Self-Check Exercises)

ข้อที่ 1

จงคำนวณ $(x^2 + x + 1) + (x^2 + 1)$ ในริงพหุนาม $\mathbb{Z}_2[x]$

พิมพ์คำตอบในรูปผลลัพธ์พหุนาม เช่น x, x^2+1 เป็นต้น

💡 เฉลยวิธีทำอย่างละเอียด:

$(x^2 + x + 1) + (x^2 + 1) = (1+1)x^2 + (1)x + (1+1)$
ใน $\mathbb{Z}_2$ เราทราบว่า $1+1 \equiv 0 \pmod 2$ ดังนั้น:
$= 0x^2 + 1x + 0 = x$

คำตอบคือ $x$

ข้อที่ 2

จงคำนวณผลคูณ $(x + 1)(x^2 + x + 1)$ ใน $\mathbb{Z}_2[x]$

พิมพ์คำตอบที่กระจายแล้ว เช่น x^3+1

💡 เฉลยวิธีทำอย่างละเอียด:

$(x + 1)(x^2 + x + 1) = x(x^2 + x + 1) + 1(x^2 + x + 1)$
$= (x^3 + x^2 + x) + (x^2 + x + 1)$
$= x^3 + (1+1)x^2 + (1+1)x + 1$
มอดุโล 2: พจน์ $(1+1)x^2 = 0$ และ $(1+1)x = 0$
$= x^3 + 1$

คำตอบคือ $x^3 + 1$ (สังเกตว่าใน $\mathbb{Z}_2$ สูตรผลบวกกำลังสาม $x^3+1$ กับผลต่างกำลังสาม $x^3-1$ มีค่าเท่ากันเพราะ $-1=1$)

ข้อที่ 3

กรณีของเมทริกซ์เอกลักษณ์ $A = I_2 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$ ข้อใดเปรียบเทียบระหว่างพหุนามลักษณะเฉพาะ $p_A(t)$ กับพหุนามต่ำสุด $m_A(t)$ ได้ถูกต้อง?

💡 เฉลยวิธีทำอย่างละเอียด:

1. พหุนามลักษณะเฉพาะ: $$p_A(t) = \det(tI - I) = \det \begin{pmatrix} t-1 & 0 \\ 0 & t-1 \end{pmatrix} = (t-1)^2$$

2. พหุนามต่ำสุด: พิจารณาพหุนามโมนิกดีกรี 1 คือ $q(t) = t - 1$ เมื่อแทนค่า $A = I$: $$q(A) = A - I = I - I = \mathbf{0}$$ เนื่องจาก $q(A) = 0$ และเป็นพหุนามโมนิกดีกรี 1 ซึ่งต่ำสุดที่เป็นไปได้แล้ว จึงสรุปได้ว่า $m_A(t) = t - 1$

ตอบข้อ (B) ซึ่งแสดงให้เห็นว่าพหุนามต่ำสุด $m_A(t)$ สามารถมีดีกรีต่ำกว่าพหุนามลักษณะเฉพาะ $p_A(t)$ ได้!
