เรื่องที่ 4: ทฤษฎีบทเศษเหลือและทฤษฎีบทตัวประกอบ

🎯 วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถใช้ทฤษฎีบทเศษเหลือและทฤษฎีบทตัวประกอบในการตรวจสอบตัวประกอบและหารากของพหุนามได้

📖 เนื้อหาและทฤษฎีบทสำคัญ

1. การแทนค่าตัวแปรและทฤษฎีบทเศษเหลือ

เมื่อหารพหุนาม $P(x)$ ด้วยพหุนามเชิงเส้น $x - a$ ตามขั้นตอนวิธีการหาร จะได้:

$$P(x) = (x - a)Q(x) + r$$

เนื่องจากตัวหารมีดีกรีเท่ากับ $1$ เศษเหลือ $r$ จึงเป็นค่าคงที่ และเมื่อแทนค่า $x = a$ จะได้พจน์ $(a - a)Q(a) = 0$ ส่งผลให้ $P(a) = r$ ทันที โดยไม่ต้องตั้งหารจริง

2. ทฤษฎีบทตัวประกอบและรากของพหุนาม

จำนวน $a$ เรียกว่า ราก (Root / Zero) ของพหุนาม $P(x)$ ก็ต่อเมื่อ $P(a) = 0$ ซึ่งนำไปสู่ความสัมพันธ์ระดับทฤษฎีบท:

• $P(a) = 0 \iff (x - a)$ เป็นตัวประกอบหนึ่งของ $P(x)$

• ในเชิงเรขาคณิต ค่า $a$ ที่เป็นจำนวนจริงคือ จุดตัดแกน $x$ ของกราฟ $y = P(x)$ ที่จุด $(a, 0)$

📌 สรุปทฤษฎีบทสำคัญ (Remainder & Factor Theorem)

ให้ $P(x) \in F[x]$ และ $a \in F$:

ทฤษฎีบทเศษเหลือ (Remainder Theorem) $$P(x) = (x - a)Q(x) + r \implies P(a) = r$$
ทฤษฎีบทตัวประกอบ (Factor Theorem) $$P(a) = 0 \iff (x - a) \text{ เป็นตัวประกอบของ } P(x)$$

🧪 แบบจำลองโต้ตอบ: สำรวจค่า $P(a)$, เศษเหลือ และกราฟจุดตัดแกน $x$

ปรับค่า $a$ เพื่อสังเกตตำแหน่งจุดบนกราฟ ค่าเศษเหลือ และสถานะการเป็นตัวประกอบ

💡 คำถามนำเพื่อการค้นพบ

1. เหตุใดการแทน $x = a$ จึงให้ค่าเดียวกับเศษจากการหารด้วย $x - a$? ▼

จากขั้นตอนวิธีการหาร $P(x) = (x - a)Q(x) + r$ เมื่อเราแทนค่า $x = a$ พจน์แรกจะกลายเป็น $(a - a)Q(a) = 0 \cdot Q(a) = 0$ ทำให้เหลือเพียง $P(a) = r$ เสมอ ไม่ว่าผลหาร $Q(x)$ จะมีหน้าตาเป็นอย่างไรก็ตาม

2. ถ้า $P(a) \neq 0$ เราสรุปอะไรเกี่ยวกับ $x - a$ ได้? ▼

สรุปได้ทันทีว่า $x - a$ ไม่เป็นตัวประกอบของ $P(x)$ และเมื่อนำ $x - a$ ไปหาร $P(x)$ จะเหลือเศษเท่ากับค่า $P(a)$ นั้น

3. รากของพหุนามสัมพันธ์กับจุดตัดแกน $x$ อย่างไร? ▼

ในทางเรขาคณิต รากที่เป็นจำนวนจริงของพหุนาม $P(x)$ คือพิกัด $x$ ของจุดตัดแกน $x$ บนระนาบ $xy$ เนื่องจากบนแกน $x$ ค่า $y = 0$ ซึ่งตรงกับเงื่อนไข $P(x) = 0$

4. พหุนามหนึ่งสามารถมีรากซ้ำได้หรือไม่? ▼

มีได้ ตัวอย่างเช่น $P(x) = (x + 2)^2(x - 1) = x^3 + 3x^2 - 4$ มี $x = -2$ เป็นรากซ้ำอันดับสอง (Multiplicity 2) ซึ่งในทางกราฟ เส้นโค้งจะสัมผัสแกน $x$ ที่ $x = -2$ โดยไม่ตัดข้ามแกน

✏️ แบบฝึกหัดสำหรับนักศึกษา

ลองทำด้วยตนเองก่อนคลิกดูเฉลย
1. จงหาเศษจากการหาร $2x^3 - 3x^2 + x + 5$ ด้วย $x - 2$ โดยใช้ทฤษฎีบทเศษเหลือ
🔍 แสดงคำตอบและวิธีทำ

ให้ $P(x) = 2x^3 - 3x^2 + x + 5$ และตัวหารคือ $x - 2$ (ดังนั้น $a = 2$)

ตามทฤษฎีบทเศษเหลือ เศษเหลือ $r = P(2)$:

$P(2) = 2(2)^3 - 3(2)^2 + (2) + 5$
$= 2(8) - 3(4) + 2 + 5$
$= 16 - 12 + 2 + 5 = 11$

ดังนั้น เศษจากการหารเท่ากับ 11

2. ตรวจสอบว่า $x + 2$ เป็นตัวประกอบของ $x^3 + 3x^2 - 4$ หรือไม่
🔍 แสดงคำตอบและวิธีทำ

ให้ $P(x) = x^3 + 3x^2 - 4$ และตัวหารคือ $x + 2 = x - (-2)$ (ดังนั้น $a = -2$)

คำนวณค่า $P(-2)$:

$P(-2) = (-2)^3 + 3(-2)^2 - 4$
$= -8 + 3(4) - 4$
$= -8 + 12 - 4 = 0$

เนื่องจาก $P(-2) = 0$ ตามทฤษฎีบทตัวประกอบ จึงสรุปได้ว่า $x + 2$ เป็นตัวประกอบ ของ $x^3 + 3x^2 - 4$

3. ถ้า $P(3) = 0$ จงอธิบายข้อสรุปตามทฤษฎีบทตัวประกอบ
🔍 แสดงคำตอบและคำอธิบาย

สามารถสรุปข้อเท็จจริงทางคณิตศาสตร์ได้ 4 ประการ ดังนี้:

  • $x - 3$ เป็นตัวประกอบหนึ่งของ $P(x)$ นั่นคือสามารถเขียน $P(x) = (x - 3)Q(x)$ ได้โดยที่เศษเหลือ $r = 0$
  • พหุนาม $x - 3$ หาร $P(x)$ ลงตัว
  • $3$ เป็นรากหนึ่ง (Root หรือ Zero) ของสมการพหุนาม $P(x) = 0$
  • กราฟของฟังก์ชัน $y = P(x)$ จะตัดแกน $x$ ที่จุดพิกัด $(3, 0)$
