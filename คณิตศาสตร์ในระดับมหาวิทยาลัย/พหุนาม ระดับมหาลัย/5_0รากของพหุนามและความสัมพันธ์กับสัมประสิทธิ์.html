เรื่องที่ 5: รากของพหุนามและความสัมพันธ์กับสัมประสิทธิ์

🎯 วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถวิเคราะห์รากของพหุนาม และใช้ความสัมพันธ์ระหว่างรากกับสัมประสิทธิ์ในการสร้างและตรวจสอบพหุนามได้

1. เนื้อหาหลักและทฤษฎีบทสำคัญ (Key Concepts & Theorems)

1

รากของพหุนามและรากซ้ำ

ตาม ทฤษฎีบทหลักมูลของพีชคณิต (Fundamental Theorem of Algebra) พหุนามดีกรี $n \ge 1$ ที่มีสัมประสิทธิ์เป็นจำนวนเชิงซ้อน จะมีรากทั้งหมด $n$ รากในระบบจำนวนเชิงซ้อน (เมื่อนับการซ้ำ)

• รากเดี่ยว (Simple Root): ตัดผ่านแกน $X$
• รากซ้ำอันดับคู่ (เช่น ซ้ำ 2): กราฟจะสัมผัสแกน $X$ แต่ไม่ตัดข้ามฝั่ง
• รากซ้ำอันดับคี่ (เช่น ซ้ำ 3): กราฟจะตัดผ่านแกน $X$ พร้อมจุดดัดโค้งแบน
2

รากจำนวนจริงและจำนวนเชิงซ้อน

ทฤษฎีบทคู่สังยุคเชิงซ้อน (Complex Conjugate Root Theorem): สำหรับพหุนามที่มีสัมประสิทธิ์เป็นจำนวนจริงทั้งหมด หากมี $z = a + bi$ เป็นราก ($b \ne 0$) แล้ว คู่สังยุค $\bar{z} = a - bi$ จะต้องเป็นรากของพหุนามด้วยเสมอ

$$ (x - (a+bi))(x - (a-bi)) = x^2 - 2ax + (a^2 + b^2) $$ ส่งผลให้พจน์กำลังสองที่เกิดจากคู่สังยุคมีสัมประสิทธิ์เป็นจำนวนจริงเสมอ!
ทฤษฎีบทรากฐาน

สูตรของวีเอตา (Vieta's Formulas)

เชื่อมโยงระหว่าง "สัมประสิทธิ์ของสมการพหุนาม" กับ "ผลบวกและผลคูณของราก" โดยตรง

กำหนดให้ $P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$ โดยมีรากคือ $r_1, r_2, \dots, r_n$
พหุนามดีกรี 2 n = 2

$ax^2 + bx + c = 0$

ผลบวกราก ($\sum r_i$)
$$r_1 + r_2 = -\frac{b}{a}$$
ผลคูณราก ($\prod r_i$)
$$r_1 r_2 = \frac{c}{a}$$
พหุนามดีกรี 3 n = 3

$ax^3 + bx^2 + cx + d = 0$

ผลบวกราก
$$r_1 + r_2 + r_3 = -\frac{b}{a}$$
ผลบวกของผลคูณทีละ 2 ราก
$$r_1r_2 + r_2r_3 + r_3r_1 = \frac{c}{a}$$
ผลคูณรากทั้งหมด
$$r_1 r_2 r_3 = -\frac{d}{a}$$
กรณีทั่วไปดีกรี n Degree n

เครื่องหมายจะสลับบวก-ลบ (Alternating sign) ตามลำดับ:

$$\sum_{i=1}^n r_i = (-1)^1 \frac{a_{n-1}}{a_n} = -\frac{a_{n-1}}{a_n}$$
$$\sum_{1 \le i < j \le n} r_i r_j = (-1)^2 \frac{a_{n-2}}{a_n} = \frac{a_{n-2}}{a_n}$$
...
$$\prod_{i=1}^n r_i = (-1)^n \frac{a_0}{a_n}$$
💡 ข้อสังเกต: พหุนามโมนิก ($a_n = 1$) จะได้ $P(x) = (x-r_1)(x-r_2)\dots(x-r_n)$

การกระจายและรูปมาตรฐาน โมนิกพหุนาม ($a_n = 1$)
1. รูปแบบผลคูณตัวประกอบ (Factored Form):
$$P(x) = (x - 2)(x + 3)$$
2. พหุนามในรูปมาตรฐาน (Standard Form):
$$P(x) = x^2 + x - 6$$
ตรวจสอบด้วยสูตรของวีเอตา (Vieta Comparison):
ผลบวกราก: $r_1 + r_2 = 2 + (-3) = -1 = -b/a$
ผลคูณราก: $r_1 \cdot r_2 = (2)(-3) = -6 = c/a$
ผลบวกผลคูณทีละสอง: $r_1r_2 + r_2r_3 + r_3r_1 = ...$
กราฟของพหุนาม $y = P(x)$ จุดสีคือรากบนแกน $X$
แกน X: [-6, 6] ราก: {2, -3} แกน Y: อัตโนมัติ

3. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

สำหรับพหุนามกำลังสอง $P(x) = ax^2 + bx + c$ เมื่อกระจาย $(x-r_1)(x-r_2) = x^2 - (r_1+r_2)x + r_1r_2$ จะเห็นได้ว่า:

$$r_1 + r_2 = -\frac{b}{a}$$ นั่นคือ ผลบวกของรากจะมีค่าเท่ากับ "ค่าติดลบของสัมประสิทธิ์ของ $x$" หารด้วยสัมประสิทธิ์นำ ($a$) เสมอ

พจน์คงตัว ($a_0$) เกิดจากการคูณกันของรากทุกตัวพร้อมเครื่องหมายลบ $(-r_1)(-r_2)\dots(-r_n) = (-1)^n \prod r_i$ ดังนั้น:

$$\prod_{i=1}^n r_i = (-1)^n \frac{a_0}{a_n}$$ สำหรับดีกรี 2 ($n=2$): ผลคูณราก $= +c/a$ (เครื่องหมายบวก)
สำหรับดีกรี 3 ($n=3$): ผลคูณราก $= -d/a$ (เครื่องหมายลบ)

สามารถสร้างได้ทันที! สำหรับพหุนามโมนิกกำลังสอง:

$$P(x) = x^2 - (\text{ผลบวกราก})x + (\text{ผลคูณราก}) = x^2 - Sx + P$$ และพหุนามทั่วไปทั้งหมดที่มีรากชุดนี้จะอยู่ในรูป $k(x^2 - Sx + P)$ เมื่อ $k \ne 0$

สำหรับ $ax^3 + bx^2 + cx + d = 0$ สัมประสิทธิ์แต่ละตัวจะจับคู่กับผลรวมรากแบบสมมาตร ดังนี้:

1. ผลบวกเดี่ยว: $r_1 + r_2 + r_3 = -\frac{b}{a}$
2. ผลบวกผลคูณคู่: $r_1r_2 + r_2r_3 + r_3r_1 = \frac{c}{a}$
3. ผลคูณสามราก: $r_1r_2r_3 = -\frac{d}{a}$

4. แบบฝึกหัดสำหรับนักศึกษา (Interactive Practice)

ข้อที่ 1

จงหาผลบวกและผลคูณของรากสมการ $2x^2 - 7x + 3 = 0$

💡 เฉลยวิธีทำอย่างละเอียด:

จากสมการ $2x^2 - 7x + 3 = 0$ เทียบกับ $ax^2 + bx + c = 0$ จะได้ $a = 2, b = -7, c = 3$

1. ผลบวกของราก $= -b/a = -(-7)/2 = 7/2 = 3.5$
2. ผลคูณของราก $= c/a = 3/2 = 1.5$

(หากแยกตัวประกอบ: $(2x - 1)(x - 3) = 0 \implies$ รากคือ $1/2$ และ $3$ ซึ่ง $1/2 + 3 = 7/2$ และ $(1/2)(3) = 3/2$ ตรงกันสมบูรณ์!)

สำหรับ $x^3 - 6x^2 + 11x - 6 = 0$ จงหาค่าของ:

💡 เฉลยวิธีทำอย่างละเอียด:

จากพหุนาม $x^3 - 6x^2 + 11x - 6 = 0$ จะได้ $a = 1, b = -6, c = 11, d = -6$

1. ผลบวกราก: $\sum r_i = -b/a = -(-6)/1 = 6$
2. ผลบวกผลคูณทีละคู่: $\sum r_i r_j = c/a = 11/1 = 11$
3. ผลคูณรากทั้งหมด: $r_1 r_2 r_3 = -d/a = -(-6)/1 = 6$

💡 ความจริงน่าทึ่ง: รากของพหุนามนี้คือ $1, 2, 3$ สังเกตว่า $1+2+3 = 6$, $(1)(2)+(2)(3)+(3)(1) = 2+6+3 = 11$ และ $(1)(2)(3) = 6$ สอดคล้องกับสูตรของวีเอตาทุกประการ!
