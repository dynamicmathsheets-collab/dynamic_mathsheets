เรื่องที่ 1: ความรู้เบื้องต้นและโครงสร้างของพหุนาม

🎯 วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถอธิบายความหมายของพหุนาม ระบุสัมประสิทธิ์ พจน์ ดีกรี และจำแนกพหุนามตามลักษณะของสัมประสิทธิ์ได้

📖 เนื้อหาและนิยามทางคณิตศาสตร์

1. นิยามของพหุนามตัวแปรเดียว $F[x]$

ให้ $F$ เป็นฟีลด์ (เช่น $\mathbb{Q}, \mathbb{R}, \mathbb{C}$) พหุนามตัวแปรเดียว เหนือฟีลด์ $F$ คือนิพจน์ในรูป:

$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$$

โดยที่ $a_i \in F$ เรียกว่า สัมประสิทธิ์ (Coefficients) และ $n \in \{0, 1, 2, \dots\}$ เป็นจำนวนเต็มที่ไม่เป็นลบ

2. ส่วนประกอบสำคัญของพหุนาม

  • ดีกรี (Degree - $\deg P$): เลขชี้กำลังสูงสุดของตัวแปร $x$ ที่มีสัมประสิทธิ์ไม่เป็นศูนย์
  • สัมประสิทธิ์นำ (Leading Coeff): สัมประสิทธิ์ $a_n$ หน้าพจน์ที่มีดีกรีสูงสุด ($a_n \neq 0$)
  • พหุนามโมนิก (Monic): พหุนามที่มีสัมประสิทธิ์นำเป็น $1$ ($a_n = 1$)
  • พหุนามศูนย์ ($0$): พหุนามที่สัมประสิทธิ์ทุกตัวเป็น $0$ (ไม่นิยามดีกรี หรือ $\deg 0 = -\infty$)
  • พจน์คงตัว (Constant Term): สัมประสิทธิ์ $a_0$ ของพจน์ที่ไม่มีตัวแปร

💡 คำถามนำเพื่อการค้นพบ

1. พจน์ใดเป็นตัวกำหนดดีกรีของพหุนาม? ▼

พจน์ที่มีเลขชี้กำลังของตัวแปรสูงสุด โดยที่สัมประสิทธิ์หน้าพจน์นั้นต้องไม่เป็นศูนย์

2. เพราะเหตุใดพจน์ที่มีสัมประสิทธิ์เป็นศูนย์จึงไม่นำมาพิจารณาดีกรี? ▼

เพราะ $0 \cdot x^k = 0$ พจน์นั้นไม่ได้มีผลต่อค่าของฟังก์ชันหรือโครงสร้างของพหุนาม หากนำมานับ จะทำให้พหุนามเดียวกันมีดีกรีได้หลายค่าอย่างไม่สิ้นสุด (เช่น $5 = 0x^2 + 5 = 0x^{100} + 5$)

3. พหุนามศูนย์มีดีกรีหรือไม่? ▼

ตามหลักการพีชคณิตนามธรรม พหุนามศูนย์ไม่มีดีกรี หรือนิยมกำหนดให้ดีกรีเป็น $-\infty$ เพื่อรักษาความสอดคล้องของสมบัติการคูณดีกรี: $\deg(PQ) = \deg P + \deg Q$

4. พหุนามหลายตัวแปรมีวิธีพิจารณาดีกรีอย่างไร? ▼

คำนวณโดยหาผลรวมของเลขชี้กำลังของทุกตัวแปรในแต่ละเอกนาม (พจน์) แล้วเลือกค่าผลรวมที่สูงที่สุดเป็นดีกรีรวมของพหุนาม

✏️ แบบฝึกหัดสำหรับนักศึกษา

ลองทำด้วยตนเองก่อนคลิกดูเฉลย
1. จงระบุดีกรี สัมประสิทธิ์นำ และพจน์คงตัวของ $4x^5 - 3x^2 + 7$
🔍 แสดงคำตอบและคำอธิบาย

• ดีกรี: $5$ (เลขชี้กำลังสูงสุดของตัวแปร $x$ ที่สัมประสิทธิ์ไม่เป็นศูนย์)

• สัมประสิทธิ์นำ: $4$ (สัมประสิทธิ์ของพจน์ $x^5$)

• พจน์คงตัว: $7$ (พจน์ที่ไม่มีตัวแปร หรือ $x^0$)

2. จงพิจารณาว่านิพจน์ $2x^3 - x + 1, \; \frac{1}{x} + 2, \; \sqrt{x} + 1$ เป็นพหุนามหรือไม่
🔍 แสดงคำตอบและคำอธิบาย

• $2x^3 - x + 1$ เป็นพหุนาม เพราะเลขชี้กำลังของตัวแปรทั้งหมด ($3, 1, 0$) เป็นจำนวนเต็มที่ไม่เป็นลบ

• $\frac{1}{x} + 2 = x^{-1} + 2$ ไม่เป็นพหุนาม เพราะมีพจน์ที่มีเลขชี้กำลังเป็นจำนวนลบ ($-1$)

• $\sqrt{x} + 1 = x^{1/2} + 1$ ไม่เป็นพหุนาม เพราะมีพจน์ที่มีเลขชี้กำลังเป็นเศษส่วนไม่ใช่จำนวนเต็ม ($1/2$)

3. จงหาดีกรีรวมของ $3x^2y^3 - 2xy + 5$
🔍 แสดงคำตอบและคำอธิบาย

• พจน์ $3x^2y^3$ มีดีกรีคือ $2 + 3 = 5$

• พจน์ $-2xy = -2x^1y^1$ มีดีกรีคือ $1 + 1 = 2$

• พจน์ $5$ มีดีกรีคือ $0$

ดังนั้น ดีกรีรวมของพหุนามคือ $5$ (ค่าสูงสุดของผลรวมเลขชี้กำลังแต่ละพจน์)
