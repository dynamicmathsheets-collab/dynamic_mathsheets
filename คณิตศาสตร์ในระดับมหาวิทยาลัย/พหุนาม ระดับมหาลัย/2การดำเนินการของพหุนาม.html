เรื่องที่ 2: การดำเนินการของพหุนาม

🎯 วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถบวก ลบ คูณพหุนาม และอธิบายสมบัติของการดำเนินการได้

📖 เนื้อหาและสมบัติการดำเนินการ

1. การบวก ลบ และคูณพหุนาม

ให้ $P(x) = \sum_{i=0}^n a_i x^i$ และ $Q(x) = \sum_{i=0}^m b_i x^i$ เป็นพหุนามใน $F[x]$:

  • การบวก/ลบ: รวมสัมประสิทธิ์ของพจน์ที่มีดีกรีเดียวกัน $(P \pm Q)(x) = \sum (a_i \pm b_i)x^i$
  • การคูณ: กระจายพจน์ตามสมบัติการแจกแจง $(PQ)(x) = \sum_{k} c_k x^k$ โดยที่ $c_k = \sum_{i+j=k} a_i b_j$ (Cauchy product)

2. โครงสร้างพีชคณิตและสมบัติ

  • สมบัติการปิด: ผลบวก ผลต่าง และผลคูณของพหุนามใน $F[x]$ ยังคงเป็นพหุนามใน $F[x]$
  • สลับที่และเปลี่ยนหมู่: เป็นจริงทั้งสำหรับการบวกและการคูณ
  • เอกลักษณ์: เอกลักษณ์การบวกคือพหุนามศูนย์ $0$ และเอกลักษณ์การคูณคือ $1$
  • สมบัติการแจกแจง: $P(Q + R) = PQ + PR$

📌 ทฤษฎีบทสำคัญ: ดีกรีของผลบวกและผลคูณ

สำหรับพหุนาม $P(x), Q(x) \in F[x]$ เมื่อ $F$ เป็นฟีลด์:

ดีกรีของผลคูณ (เมื่อ $P, Q \neq 0$) $$\deg(PQ) = \deg P + \deg Q$$
ดีกรีของผลบวก $$\deg(P + Q) \le \max(\deg P, \deg Q)$$

*หมายเหตุ: ในกรณีที่พจน์ดีกรีสูงสุดของ $P$ และ $Q$ หักล้างกันหมด ดีกรีของผลบวกจะน้อยกว่า $\max(\deg P, \deg Q)$

💡 คำถามนำเพื่อการค้นพบ

1. เหตุใดจึงรวมพจน์ที่มีตัวแปรและเลขชี้กำลังเหมือนกันได้? ▼

เพราะอาศัยสมบัติการแจกแจง (Distributive Property) ในระบบจำนวน เช่น $ax^k + bx^k = (a + b)x^k$ ทำให้สามารถนำสัมประสิทธิ์มาบวกหรือลบกันโดยตรงได้

2. ดีกรีของผลคูณสัมพันธ์กับดีกรีของพหุนามแต่ละตัวอย่างไร? ▼

สำหรับพหุนามที่ไม่เป็นศูนย์เหนือฟีลด์ ดีกรีของผลคูณเท่ากับผลบวกของดีกรีของแต่ละพหุนามเสมอ นั่นคือ $\deg(PQ) = \deg P + \deg Q$ เนื่องจากพจน์ดีกรีสูงสุดเกิดจากผลคูณของสัมประสิทธิ์นำ $a_n b_m x^{n+m}$ ซึ่ง $a_n b_m \neq 0$

3. ผลบวกของพหุนามสองพหุนามมีดีกรีเท่ากับดีกรีสูงสุดของพหุนามทั้งสองเสมอหรือไม่? ▼

ไม่เสมอไป ดีกรีจะเท่ากับค่าสูงสุดเมื่อดีกรีของพหุนามทั้งสองไม่เท่ากัน หรือสัมประสิทธิ์นำไม่หักล้างกัน แต่หากพหุนามมีดีกรีเท่ากันและสัมประสิทธิ์นำเป็นจำนวนตรงข้ามกัน พจน์ดีกรีสูงสุดจะบวกกันได้ศูนย์ ส่งผลให้ดีกรีของผลบวกลดลง

4. การคูณพหุนามแสดงสมบัติการแจกแจงอย่างไร? ▼

การคูณพหุนามเป็นการนำแต่ละพจน์ของพหุนามตัวแรกกระจายไปคูณกับทุกพจน์ของพหุนามตัวหลังตามหลัก $A(B + C) = AB + AC$ จากนั้นจึงจัดกลุ่มและรวมพจน์ที่คล้ายกันเข้าด้วยกัน

✏️ แบบฝึกหัดสำหรับนักศึกษา

ลองทำด้วยตนเองก่อนคลิกดูเฉลย
1. จงหาผลบวกและผลต่างของ $2x^3 - x + 4$ กับ $x^3 + 3x^2 - 2$
🔍 แสดงคำตอบและวิธีทำ
• ผลบวก:

$(2x^3 - x + 4) + (x^3 + 3x^2 - 2) = (2+1)x^3 + 3x^2 - x + (4-2) = \mathbf{3x^3 + 3x^2 - x + 2}$

• ผลต่าง:

$(2x^3 - x + 4) - (x^3 + 3x^2 - 2) = (2-1)x^3 - 3x^2 - x + (4 - (-2)) = \mathbf{x^3 - 3x^2 - x + 6}$

2. จงหาผลคูณ $(x^2 + 2x - 1)(2x - 3)$
🔍 แสดงคำตอบและวิธีทำ

กระจายการคูณทีละพจน์:

$= x^2(2x - 3) + 2x(2x - 3) - 1(2x - 3)$

$= (2x^3 - 3x^2) + (4x^2 - 6x) - (2x - 3)$

$= 2x^3 + (-3 + 4)x^2 + (-6 - 2)x + 3$

$= \mathbf{2x^3 + x^2 - 8x + 3}$

3. ยกตัวอย่างพหุนามสองพหุนามที่ผลบวกมีดีกรีน้อยกว่าดีกรีของพหุนามแต่ละตัว
🔍 แสดงตัวอย่างคำตอบ

ให้ $P(x) = x^2 + 3x + 1$ (มีดีกรีเท่ากับ $2$)

และ $Q(x) = -x^2 + 5$ (มีดีกรีเท่ากับ $2$)

ผลบวกคือ $P(x) + Q(x) = (x^2 - x^2) + 3x + (1 + 5) = \mathbf{3x + 6}$

ซึ่งมีดีกรีเท่ากับ $1$ ซึ่งน้อยกว่าดีกรีเดิมของทั้งสองพหุนาม
