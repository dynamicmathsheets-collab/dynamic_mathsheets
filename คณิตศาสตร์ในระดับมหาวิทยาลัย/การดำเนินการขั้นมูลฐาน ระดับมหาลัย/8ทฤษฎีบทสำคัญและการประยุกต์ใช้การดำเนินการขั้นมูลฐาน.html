1. วัตถุประสงค์การเรียนรู้

ผลการเรียนรู้ที่คาดหวังประจำหัวข้อที่ 8

เมื่อศึกษาจบหัวข้อนี้ นักศึกษาสามารถ:

  • ประยุกต์ใช้การดำเนินการขั้นมูลฐานตามแถว (EROs) ในการพิสูจน์สมบัติสำคัญของเมทริกซ์และตรวจสอบความสมมูลตามแถวได้อย่างเป็นทางการ
  • ใช้เกณฑ์พิจารณาการผกผันได้ (Invertibility Criterion) เพื่อตรวจสอบว่าเมทริกซ์จัตุรัสหาตัวผกผันได้หรือไม่ พร้อมหา $A^{-1}$ ผ่านการขยาย $[A \mid I_n]$
  • วิเคราะห์ระบบสมการเชิงเส้น โดยเปรียบเทียบอันดับของเมทริกซ์สัมประสิทธิ์กับเมทริกซ์แต่งเติม ($\operatorname{rank}(A)$ vs $\operatorname{rank}([A \mid \mathbf{b}])$) และเชื่อมโยงความรู้เข้ากับบทที่ 2 และบทที่ 3 อย่างบูรณาการ

2. เนื้อหาหลัก (Core Mathematical Theorems)

สามเสาหลักทฤษฎีบทการแปลงเมทริกซ์และการประยุกต์

ทฤษฎีบท 3.5 (Theorem 3.5)

ความเป็นเอกลักษณ์ของรูปขั้นบันไดลดรูป (Uniqueness of RREF)

"เมทริกซ์ทุกเมทริกซ์มีรูปขั้นบันไดลดรูป (RREF) ที่กำหนดได้ เพียงรูปเดียวเท่านั้น (Unique) แม้ลำดับการดำเนินการขั้นมูลฐานที่เลือกใช้ในการแปลงจะแตกต่างกัน"

แนวทางการพิสูจน์เชิงทฤษฎี:

การพิสูจน์ทฤษฎีบทนี้อาศัย ความเป็นอิสระเชิงเส้นของเวกเตอร์คอลัมน์: ถ้า $A \sim R_1$ และ $A \sim R_2$ โดยที่ทั้งคู่เป็น RREF ระบบสมการเอกพันธุ์ $A\mathbf{x} = \mathbf{0}$, $R_1\mathbf{x} = \mathbf{0}$, และ $R_2\mathbf{x} = \mathbf{0}$ ต้องมีเซตคำตอบเดียวกันทุกประการ ความสัมพันธ์เชิงเส้นของคอลัมน์ใน $R_1$ และ $R_2$ จึงต้องเหมือนกันทุกคอลัมน์ ซึ่งบังคับให้ตำแหน่งหลัก (Pivot positions) และสัมประสิทธิ์ทุกตำแหน่งต้องเท่ากันทุกประการ (การพิสูจน์ต้องกระทำอย่างเป็นระบบ ไม่เพียงอาศัยการสุ่มทดลองตัวเลข)

ทฤษฎีบท 3.6 (Theorem 3.6)

เกณฑ์พิจารณาเมทริกซ์ผกผัน (Invertibility Criterion)

"สำหรับเมทริกซ์จัตุรัส $A$ ขนาด $n \times n$ ใดๆ เมทริกซ์ $A$ จะผกผันได้ (Invertible / Non-singular) ก็ต่อเมื่อรูปขั้นบันไดลดรูปของ $A$ คือเมทริกซ์เอกลักษณ์ $I_n$"

$$A \text{ ผกผันได้} \iff \operatorname{rref}(A) = I_n \iff \operatorname{rank}(A) = n \text{ (มีตำแหน่งหลักครบทุกคอลัมน์)}$$
อัลกอริทึมการหาตัวผกผัน: สร้างเมทริกซ์คู่ขนาน $[A \mid I_n]$ แล้วดำเนินการขั้นมูลฐานตามแถวจนด้านซ้ายกลายเป็น $I_n$ ด้านขวาจะกลายเป็น $A^{-1}$ โดยอัตโนมัติ:
$$[A \mid I_n] \xrightarrow{\text{EROs}} [I_n \mid A^{-1}]$$
หากระหว่างการดำเนินการพบแถวศูนย์ในฝั่งซ้าย แสดงว่า $A$ มีตำแหน่งหลักไม่ครบ $n$ คอลัมน์ และ ไม่มีตัวผกผัน ($A$ เป็น Singular Matrix) ทันที
ทฤษฎีบท 3.7 (Theorem 3.7)

ความสัมพันธ์ระหว่างอันดับกับระบบสมการ (Rouché–Capelli Theorem)

"ระบบสมการเชิงเส้น $A\mathbf{x} = \mathbf{b}$ ที่มีตัวแปร $n$ ตัว จะมีคำตอบ (Consistent) ก็ต่อเมื่ออันดับของเมทริกซ์สัมประสิทธิ์เท่ากับอันดับของเมทริกซ์แต่งเติม"

$$\text{ระบบมีคำตอบ (Consistent)} \iff \operatorname{rank}(A) = \operatorname{rank}([A \mid \mathbf{b}])$$
กรณีไม่มีคำตอบ (Inconsistent):

$\operatorname{rank}(A) < \operatorname{rank}([A \mid \mathbf{b}])$ เกิดแถวขัดแย้งในรูป $[0 \ 0 \ \dots \ 0 \mid c]$ เมื่อ $c \neq 0$

กรณีมีคำตอบ ($\operatorname{rank}(A) = \operatorname{rank}([A \mid \mathbf{b}]) = r$):
  • ถ้า $r = n$ (เท่ากับจำนวนตัวแปร): มีคำตอบเดียว (Unique solution)
  • ถ้า $r < n$ (น้อยกว่าจำนวนตัวแปร): มีคำตอบอนันต์ (Infinitely many solutions) มี $n - r$ ตัวแปรอิสระ
การเชื่อมโยงกับบทที่ 2: เนื้อหานี้เป็นการอธิบายเชิงรูปนัยของระบบสมการเชิงเส้นผ่านมุมมองของ ปริภูมิย่อย อันดับของเมทริกซ์ และการดำเนินการตามแถว ช่วยให้ไม่ต้องแก้สมการจนจบก็สามารถทำนายพฤติกรรมของคำตอบได้

4. คำถามนำเพื่อค้นพบ (Guided Discovery Questions)

ใคร่ครวญความเชื่อมโยงเชิงโครงสร้าง แล้วคลิกเพื่อเปิดดูบทวิเคราะห์

บทวิเคราะห์ผ่านเมทริกซ์ขั้นมูลฐาน (Elementary Matrices):

ถ้าเมทริกซ์จัตุรัส $A \in \mathbb{R}^{n \times n}$ มีตำแหน่งหลักครบทั้ง $n$ คอลัมน์ รูปขั้นบันไดลดรูปของ $A$ ย่อมเป็นเมทริกซ์เอกลักษณ์ $I_n$ หมายความว่ามีลำดับของเมทริกซ์ขั้นมูลฐาน $E_1, E_2, \dots, E_k$ ซึ่ง:

$$E_k E_{k-1} \cdots E_2 E_1 A = I_n$$

เนื่องจากเมทริกซ์ขั้นมูลฐานทุกตัวสามารถผกผันได้ ผลคูณของพวกมันย่อมผกผันได้ด้วย จึงทำให้ $A^{-1} = E_k \cdots E_1$ และในเชิงการแปลงเชิงเส้น การมีตำแหน่งหลักครบทุกคอลัมน์หมายถึงฟังก์ชัน $T(\mathbf{x}) = A\mathbf{x}$ เป็นฟังก์ชันแบบหนึ่งต่อหนึ่งและทั่วถึง (Bijective) จึงมีฟังก์ชันผกผัน $T^{-1}$ เสมอ

บ่งบอกว่าเวกเตอร์ $\mathbf{b}$ อยู่ในปริภูมิคอลัมน์ของ $A$ ($\mathbf{b} \in \operatorname{Col}(A)$)

การที่ $\operatorname{rank}([A \mid \mathbf{b}]) = \operatorname{rank}(A)$ หมายความว่าการเพิ่มคอลัมน์ $\mathbf{b}$ เข้าไป ไม่ได้เพิ่มมิติใหม่ หรือทิศทางใหม่ให้กับปริภูมิที่แผ่คลุมโดยคอลัมน์ของ $A$ นั่นคือเวกเตอร์ $\mathbf{b}$ สามารถเขียนเป็นการรวมเชิงเส้น (Linear Combination) ของคอลัมน์ใน $A$ ได้อย่างแน่นอน ซึ่งก็คือนิยามของการมีคำตอบของสมการ $A\mathbf{x} = \mathbf{b}$ นั่นเอง

กระบวนการทางคณิตศาสตร์ (Conjecture vs Formal Proof):

  • การทดลองคำนวณ (Empirical Experimentation): ช่วยให้เกิดการสังเกตแบบแผน (Pattern Recognition) และนำไปสู่การตั้ง ข้อความคาดการณ์ (Conjecture) เช่น สังเกตว่าเมทริกซ์ที่มีแถวศูนย์จะหาตัวผกผันไม่ได้
  • การพิสูจน์ทางคณิตศาสตร์ (Mathematical Proof): เป็นสิ่งจำเป็นอย่างยิ่งในการยืนยันว่าข้อสรุปนั้นเป็น สัจนิรันดร์และเป็นจริงสากล ครอบคลุมเมทริกซ์ทุกขนาดและทุกมิติ ไม่จำกัดเฉพาะตัวเลขที่สุ่มทดสอบ

5. แบบฝึกหัดสำหรับนักศึกษา (Exercises & Structured Proofs)

ฝึกฝนการเขียนบทพิสูจน์เชิงตรรกะและการวิเคราะห์ระบบสมการขนาด 4–5 ตัวแปร

ข้อที่ 1

พิสูจน์เกณฑ์การมีเมทริกซ์ผกผันโดยใช้รูปขั้นบันไดลดรูป (ทฤษฎีบท 3.6)

จงแสดงบทพิสูจน์ทั้งสองทิศทาง ($\iff$) ว่าเมทริกซ์จัตุรัส $A$ ผกผันได้ก็ต่อเมื่อ $\operatorname{rref}(A) = I_n$

($\implies$) สมมติว่า $A$ ผกผันได้:

ระบบสมการ $A\mathbf{x} = \mathbf{0}$ มีเพียงผลเฉลยชัด (Trivial solution) คือ $\mathbf{x} = A^{-1}\mathbf{0} = \mathbf{0}$ เพียงคำตอบเดียวเท่านั้น ส่งผลให้ไม่มีตัวแปรอิสระ ดังนั้นตำแหน่งหลักของ $A$ ต้องมีครบทุกคอลัมน์ ($n$ ตำแหน่ง) เมทริกซ์จัตุรัสขนาด $n \times n$ ที่มีตำแหน่งหลัก $n$ ตำแหน่งในรูป RREF มีเพียงเมทริกซ์เดียวคือ $I_n$ ดังนั้น $\operatorname{rref}(A) = I_n$

($\impliedby$) สมมติว่า $\operatorname{rref}(A) = I_n$:

ย่อมมีลำดับของเมทริกซ์ขั้นมูลฐาน $E_1, \dots, E_k$ ที่ทำให้ $E_k \cdots E_1 A = I_n$ ให้ $B = E_k \cdots E_1$ จะได้ $BA = I_n$ และเนื่องจากเมทริกซ์ขั้นมูลฐานผกผันได้ ผลคูณ $B$ จึงผกผันได้และเป็นตัวผกผันของ $A$ โดยสมบูรณ์ ดังนั้น $A$ ผกผันได้ $\blacksquare$

ข้อที่ 2

วิเคราะห์ระบบสมการที่มีตัวแปร 4–5 ตัวด้วยอันดับของเมทริกซ์

กำหนดระบบสมการ 3 สมการ 5 ตัวแปรที่มีเมทริกซ์แต่งเติมคือ $[A \mid \mathbf{b}]$ จงวิเคราะห์ความเป็นไปได้ของคำตอบโดยใช้ทฤษฎีบท 3.7

บทวิเคราะห์เชิงมิติ (Dimensional Analysis):

• จำนวนตัวแปร $n = 5$ และจำนวนแถว $m = 3$ ดังนั้น $\operatorname{rank}(A) \le \min(3, 5) = 3$
• กรณีที่ 1 ($\operatorname{rank}(A) < \operatorname{rank}([A \mid \mathbf{b}])$): ระบบจะไม่มีผลเฉลย (Inconsistent) เช่น เมื่อแถวสุดท้ายของ RREF คือ $[0 \ 0 \ 0 \ 0 \ 0 \mid 1]$
• กรณีที่ 2 ($\operatorname{rank}(A) = \operatorname{rank}([A \mid \mathbf{b}]) = r$): เนื่องจาก $r \le 3 < 5$ (อันดับน้อยกว่าจำนวนตัวแปรอย่างแน่นอน) ระบบจึง ไม่มีโอกาสมีคำตอบเดียว แต่จะมีคำตอบอนันต์เสมอ โดยมีตัวแปรอิสระอย่างน้อย $5 - 3 = 2$ ตัว
ข้อที่ 3

เขียนข้อพิสูจน์โดยระบุสมมติฐาน ทฤษฎีบทที่ใช้ และข้อสรุปอย่างครบถ้วน

จงเขียนโครงสร้างการพิสูจน์ทางคณิตศาสตร์ 3 ส่วน เพื่อพิสูจน์ว่า: "ถ้า $A$ และ $B$ เป็นเมทริกซ์จัตุรัสขนาด $n \times n$ ที่ผกผันได้ แล้วผลคูณ $AB$ ย่อมมีอันดับเท่ากับ $n$"

1. สมมติฐาน (Hypothesis):

กำหนดให้ $A, B \in \mathbb{R}^{n \times n}$ โดยที่ $A$ และ $B$ เป็นเมทริกซ์ที่ผกผันได้ทั้งคู่

2. ทฤษฎีบทที่ใช้ (Theorems Applied):

• สมบัติการผกผันของผลคูณ: $(AB)^{-1} = B^{-1} A^{-1}$

• ทฤษฎีบท 3.6 (Invertibility Criterion): เมทริกซ์จัตุรัส $M$ ผกผันได้ $\iff \operatorname{rank}(M) = n$

3. ข้อสรุปและการอนุมาน (Deduction & Conclusion):

เนื่องจาก $A^{-1}$ และ $B^{-1}$ มีอยู่จริง เมทริกซ์ $B^{-1}A^{-1}$ จึงเป็นตัวผกผันของ $AB$ ส่งผลให้ $AB$ ผกผันได้ จากทฤษฎีบท 3.6 จึงสรุปได้โดยตรงว่า $\operatorname{rank}(AB) = n \ \blacksquare$
