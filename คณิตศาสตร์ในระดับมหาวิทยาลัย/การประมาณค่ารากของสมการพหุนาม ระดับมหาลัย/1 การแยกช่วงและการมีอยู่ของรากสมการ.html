เรื่องที่ 1: การแยกช่วงและการมีอยู่ของรากสมการ

Root Bracketing & Intermediate Value Theorem (IVT) — ศึกษาทฤษฎีบทค่าระหว่างกลาง การตรวจสอบเครื่องหมาย และข้อควรระวังในการหาค่าราก

1. วัตถุประสงค์การเรียนรู้

เมื่อสิ้นสุดการเรียนรู้ในหัวข้อนี้ นักศึกษาจะมีความรู้ความสามารถดังต่อไปนี้:

1 อธิบายเงื่อนไข

อธิบายเงื่อนไขทางคณิตศาสตร์ของการมีอยู่ของรากจริงในช่วงที่กำหนดได้อย่างถูกต้อง

2 ประยุกต์ใช้ IVT

ใช้ทฤษฎีบทค่าระหว่างกลาง (Intermediate Value Theorem) ในการทดสอบและระบุช่วงที่มีรากสมการ

3 เข้าใจข้อจำกัด

อธิบายข้อจำกัดของการตรวจสอบเครื่องหมายของฟังก์ชัน และวิเคราะห์กรณีรากซ้ำหรือรากหลายตัวได้

2. เนื้อหาหลัก

ทฤษฎีบทค่าระหว่างกลาง (Intermediate Value Theorem: IVT)

ให้ \(f(x)\) เป็นพหุนาม ซึ่งมีสมบัติเป็นฟังก์ชันต่อเนื่องบนจำนวนจริง หาก \(f(a)\) และ \(f(b)\) มีเครื่องหมายตรงข้ามกัน กล่าวคือ

\[ f(a)f(b) < 0 \]

จะมีจำนวนจริง \(c\) อย่างน้อยหนึ่งจำนวนในช่วง \((a, b)\) ซึ่งทำให้

\[ f(c) = 0 \]

หลักการพื้นฐานนี้เป็นหัวใจสำคัญของระเบียบวิธีเชิงตัวเลขแบบครอบราก (Bracketing Methods) เช่น วิธีแบ่งครึ่งช่วง (Bisection Method) และ วิธีระเบียบตำแหน่งผิด (False Position Method)

ตัวอย่าง การตรวจสอบช่วงที่มีรากของพหุนาม

กำหนดสมการพหุนาม:

\[ f(x) = x^3 - x - 2 = 0 \]
เมื่อ \(x = 1\) จะได้:
\[ f(1) = (1)^3 - (1) - 2 = -2 < 0 \]
เมื่อ \(x = 2\) จะได้:
\[ f(2) = (2)^3 - (2) - 2 = 4 > 0 \]

เนื่องจาก \(f(1)f(2) = (-2)(4) = -8 < 0\) ค่าฟังก์ชันมีเครื่องหมายตรงข้ามกัน จึงสรุปตามทฤษฎีบทค่าระหว่างกลางได้ว่า มีรากอย่างน้อยหนึ่งรากในช่วง \((1, 2)\) (ซึ่งในความเป็นจริง รากจริงคือ \(x \approx 1.5214\))

ข้อควรระวังสำคัญ (Critical Caution)

การเปลี่ยนเครื่องหมาย \(f(a)f(b) < 0\) ช่วยยืนยันว่ามีรากอย่างน้อยหนึ่งราก ในช่วงเท่านั้น แต่:

  • ไม่ได้รับประกันว่าจะมีเพียงรากเดียว: ในช่วงดังกล่าวอาจมีรากจำนวนคี่ เช่น 3 ราก หรือ 5 ราก ก็ได้
  • รากที่มีอันดับซ้ำเป็นจำนวนคู่ (Even Multiplicity): เช่น \((x-1)^2 = 0\) เส้นกราฟจะเพียงแค่แตะแกน \(x\) แล้ววกกลับ ทำให้ฟังก์ชันไม่เปลี่ยนเครื่องหมาย (\(f(a)f(b) > 0\)) ส่งผลให้เงื่อนไขนี้ตรวจจับไม่พบราก
  • หาก \(f(a)f(b) > 0\): ไม่สามารถสรุปได้ว่า "ไม่มีราก" เสมอไป เพราะอาจมีรากจำนวนคู่ตัวอยู่ภายในช่วงนั้น

4. คำถามนำเพื่อค้นพบ (Guided Inquiry)

คิดไตร่ตรองคำถามเหล่านี้ก่อนคลิกดูแนวคิดและการวิเคราะห์

1

เหตุใดการเปลี่ยนเครื่องหมายของฟังก์ชันจึงช่วยยืนยันการมีอยู่ของรากได้?

พิจารณาสมบัติทางเรขาคณิตและความต่อเนื่องของเส้นกราฟ

แนวคิด: เนื่องจากพหุนามเป็น ฟังก์ชันต่อเนื่อง (Continuous function) เส้นกราฟจึงลากผ่านได้โดยไม่ขาดตอน หากปลายด้านหนึ่งอยู่ต่ำกว่าแกน \(x\) (\(f(a) < 0\)) และอีกปลายหนึ่งอยู่สูงกว่าแกน \(x\) (\(f(b) > 0\)) ในการเดินทางเชื่อมจุดทั้งสอง เส้นกราฟ ไม่มีทางเลือกอื่นนอกจากต้องตัดผ่านแกน \(x\) (\(y=0\)) อย่างน้อยหนึ่งครั้งเสมอ จุดตัดดังกล่าวคือรากของสมการ (\(f(c) = 0\))
2

หาก \(f(a)f(b) > 0\) จะสรุปได้หรือไม่ว่าไม่มีรากในช่วงนั้น?

พิจารณากรณีที่กราฟวกกลับขึ้นมาหรือตัดแกนหลายครั้ง

แนวคิด: สรุปไม่ได้! หาก \(f(a)f(b) > 0\) ค่าฟังก์ชันที่ปลายทั้งสองมีเครื่องหมายเดียวกัน แต่ภายในช่วงนั้นกราฟอาจจะ:
  • ตัดแกน \(x\) เป็นจำนวน คู่ครั้ง เช่น ตัดลงแล้วตัดขึ้นกลับมา (ทำให้มี 2, 4, ... ราก)
  • หรือกราฟอาจจะสัมผัสแกน \(x\) ณ จุดรากซ้ำอันดับคู่ (เช่น \(x=1\) ในสมการ \((x-1)^2 = 0\))
ดังนั้น \(f(a)f(b) > 0\) หมายถึง "ทฤษฎีบท IVT ไม่สามารถสรุปอะไรได้" (Inconclusive) ไม่ได้แปลว่าไม่มีราก
3

การตรวจสอบเครื่องหมายเพียงอย่างเดียวสามารถยืนยันจำนวนรากทั้งหมดได้หรือไม่?

ข้อจำกัดด้านความละเอียดของช่วง (Resolution)

แนวคิด: ไม่สามารถยืนยันได้ การตรวจสอบเครื่องหมายบอกได้เพียงว่ามีราก "อย่างน้อย 1 ราก" (หรือจำนวนคี่ของราก) เท่านั้น แต่ไม่สามารถบอกได้ว่ามี 1, 3 หรือ 5 ราก และไม่สามารถบอกตำแหน่งรากที่แน่นอนได้หากไม่ทำการแบ่งย่อยช่วงให้เล็กลงเรื่อยๆ (Bracketing refinement)

5. แบบฝึกหัดสำหรับนักศึกษา

ทดสอบความเข้าใจผ่านโจทย์และตรวจสอบคำตอบด้วยตนเอง

ข้อ 1. จงหาช่วงที่มีรากอย่างน้อยหนึ่งรากของสมการ \(x^3 - 4x + 1 = 0\)

ค้นหาช่วง

ให้ทดลองเลือกจำนวนเต็มที่เรียงติดกันเป็นปลายช่วง \([a, b]\) ที่ทำให้ \(f(a)f(b) < 0\)

เฉลยละเอียด:
คำนวณค่าพหุนามที่จำนวนเต็มต่างๆ:
  • f(-3) = -27 + 12 + 1 = -14 (< 0)
  • f(-2) = -8 + 8 + 1 = 1 (> 0) → มีรากในช่วง (-3, -2)
  • f(0) = 1 (> 0)
  • f(1) = 1 - 4 + 1 = -2 (< 0) → มีรากในช่วง (0, 1)
  • f(2) = 8 - 8 + 1 = 1 (> 0) → มีรากในช่วง (1, 2)
สมการนี้มีรากจริง 3 ค่าอยู่ในช่วง \((-3, -2)\), \((0, 1)\), และ \((1, 2)\)

ข้อ 2. จงตรวจสอบว่าช่วง \((-1, 1)\) สามารถใช้ยืนยันการมีอยู่ของรากของ \(x^2 - 1 = 0\) ได้หรือไม่?

วิเคราะห์เงื่อนไข

พิจารณาค่า \(f(-1)\) และ \(f(1)\) แล้วเลือกว่าทฤษฎีบทนี้สามารถใช้ยืนยันราก ภายใน ช่วงเปิด \((-1, 1)\) ได้หรือไม่

คำอธิบายละเอียด:
สำหรับสมการ \(f(x) = x^2 - 1 = 0\) ค่าที่ปลายช่วงคือ \(f(-1) = (-1)^2 - 1 = 0\) และ \(f(1) = (1)^2 - 1 = 0\)
เนื่องจากรากของสมการอยู่ที่ปลายช่วงพอดิบพอดี (\(x = \pm 1\)) จึงไม่มีรากใดๆ อยู่ ภายในช่วงเปิด \((-1, 1)\) (เพราะตลอดช่วง \((-1, 1)\) ค่า \(f(x) < 0\) ทั้งหมด) ดังนั้นช่วงนี้จึง ไม่สามารถ ใช้ยืนยันการมีอยู่ของรากภายในช่วงตามเงื่อนไข \(f(a)f(b) < 0\) ได้

ข้อ 3. ยกตัวอย่างสมการพหุนามที่มีรากในช่วงหนึ่ง แต่ค่าฟังก์ชันที่ปลายช่วงมีเครื่องหมายเดียวกัน

การคิดเชิงวิพากษ์

สมมติสถานการณ์ที่เป็นไปได้สองกรณี: กรณีรากซ้ำ หรือกรณีที่มีราก 2 รากอยู่ในช่วงเดียวกัน

ตัวอย่างคำตอบและแนวคิด:
กรณีที่ 1: รากซ้ำอันดับคู่ (Double Root)
สมการ \(f(x) = (x-1)^2 = 0\) บนช่วง \([0, 2]\)
คำนวณ: \(f(0) = (0-1)^2 = 1 > 0\) และ \(f(2) = (2-1)^2 = 1 > 0\)
จะเห็นว่า \(f(0)f(2) = 1 > 0\) (เครื่องหมายบวกทั้งคู่) แต่มีรากจริง \(x = 1\) อยู่ในช่วง \((0, 2)\)
กรณีที่ 2: มีรากจำนวนคู่ตัวในช่วง
สมการ \(f(x) = x^2 - 1 = 0\) บนช่วง \([-2, 2]\)
คำนวณ: \(f(-2) = (-2)^2 - 1 = 3 > 0\) และ \(f(2) = (2)^2 - 1 = 3 > 0\)
จะเห็นว่า \(f(-2)f(2) = 9 > 0\) (เครื่องหมายบวกทั้งคู่) แต่มีรากจริงถึง 2 ราก คือ \(x = -1\) และ \(x = 1\) อยู่ภายในช่วง \((-2, 2)\)
