เรื่องที่ 3: วิธีนิวตัน–ราฟสัน (Newton–Raphson Method)

ระเบียบวิธีแบบเปิด (Open Method) ที่ใช้อนุพันธ์และสมการเส้นสัมผัสเพื่อประมาณค่ารากอย่างรวดเร็ว — การวิเคราะห์การลู่เข้าและเงื่อนไขความล้มเหลว

1. วัตถุประสงค์การเรียนรู้

เมื่อเสร็จสิ้นการศึกษาชุดการเรียนรู้นี้แล้ว นักศึกษาจะมีความสามารถดังต่อไปนี้:

1 เข้าใจที่มาของสูตร

อธิบายที่มาของสูตรนิวตัน–ราฟสันจากสมการเส้นสัมผัสเส้นโค้งและจุดตัดแกน \(x\) ได้อย่างถูกต้อง

2 คำนวณการวนซ้ำ

ใช้อนุพันธ์สร้างลำดับค่าประมาณราก \(x_{n+1}\) และตรวจสอบเกณฑ์การหยุดทำซ้ำตามที่กำหนดได้

3 วิเคราะห์ความล้มเหลว

วิเคราะห์เงื่อนไขที่อาจทำให้วิธีนี้ไม่ลู่เข้า เช่น เมื่อ \(f'(x_n) \approx 0\) หรือเกิดการแกว่งวนรอบ

2. เนื้อหาหลัก

ที่มาของสูตรทำซ้ำ (Derivation via Tangent Line)

วิธีนิวตัน–ราฟสันอาศัยแนวคิดเชิงเรขาคณิต โดยพิจารณาเส้นสัมผัสของกราฟ \(y = f(x)\) ที่จุด \((x_n, f(x_n))\) ซึ่งมีความชันเท่ากับอนุพันธ์ \(f'(x_n)\) สมการของเส้นสัมผัสเขียนได้เป็น:

\[ y = f(x_n) + f'(x_n)(x - x_n) \]

กำหนดให้ \(x_{n+1}\) เป็นจุดที่เส้นสัมผัสนี้ตัดแกน \(x\) ซึ่งมีค่า \(y = 0\):

\[ 0 = f(x_n) + f'(x_n)(x_{n+1} - x_n) \]

จัดรูปสมการเพื่อหาค่าประมาณในรอบถัดไป จะได้สูตรการทำซ้ำของนิวตัน–ราฟสัน:

\[ \boxed{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}} \]

(โดยมีเงื่อนไขจำเป็นคือ \(f'(x_n) \ne 0\))

ตัวอย่าง การประมาณรากของพหุนาม

กำหนดสมการ \(f(x) = x^3 - x - 2 = 0\) จะได้อนุพันธ์คือ:

\[ f'(x) = 3x^2 - 1 \]

ดังนั้น สูตรทำซ้ำของสมการนี้คือ:

\[ x_{n+1} = x_n - \frac{x_n^3 - x_n - 2}{3x_n^2 - 1} \]

หากเริ่มต้นจาก \(x_0 = 1.5\) จะได้:
รอบที่ 1: \(x_1 = 1.5 - \frac{(1.5)^3 - 1.5 - 2}{3(1.5)^2 - 1} = 1.5 - \frac{-0.125}{5.75} \approx 1.521739\)
รอบที่ 2: \(x_2 \approx 1.5213798\) (ลู่เข้าสู่รากจริง \(r \approx 1.5213797\) อย่างรวดเร็วด้วยอัตรากำลังสอง หรือ Quadratic Convergence)

ข้อควรระวังและข้อจำกัดของการลู่เข้า (Convergence Pitfalls)

แม้วิธีนี้จะลู่เข้าเร็วมากเมื่อเลือกค่าเริ่มต้นที่ใกล้เคียงราก แต่ ไม่รับประกันว่าจะลู่เข้าสำหรับทุกค่าเริ่มต้น โดยมีกรณีเสี่ยงดังนี้:

  • อนุพันธ์เป็นศูนย์หรือใกล้ศูนย์ (\(f'(x_n) \approx 0\)): เส้นสัมผัสจะเกือบขนานกับแกน \(x\) ทำให้ค่า \(x_{n+1}\) ถูกดีดกระเด็นออกไปไกลมาก หรือเกิดข้อผิดพลาด Division by Zero
  • การแกว่งวนรอบ (Periodic Oscillations / Cycles): บางฟังก์ชันอาจเกิดการกระโดดสลับไปมาระหว่างจุดสองจุดโดยไม่ลู่เข้าหาค่าราก
  • การลู่ออกสู่อนันต์ (Divergence): เส้นสัมผัสอาจพาค่าประมาณเดินห่างจากรากออกไปเรื่อยๆ

3. แบบจำลองโต้ตอบ (Interactive Simulation)

ฟังก์ชัน: \(f(x) = x^3 - x - 2 = 0\) (รากจริง \(r \approx 1.52138\))

รอบที่ (Iteration): 0
ค่าปัจจุบัน \(x_n\): 1.500000
ค่าฟังก์ชัน \(f(x_n)\): -0.125000
ค่าอนุพันธ์ \(f'(x_n)\): 5.750000
ค่ารอบถัดไป \(x_{n+1}\): -
ผลต่าง \(|x_{n+1} - x_n|\): -
กราฟ \(f(x)\) เส้นสัมผัส (Tangent) จุดตัดแกน \(x\)

ตารางสรุปการคำนวณแต่ละรอบ (Newton–Raphson Iteration Table) (อัปเดตอัตโนมัติ)

รอบที่ (\(n\)) ค่าประมาณ \(x_n\) \(f(x_n)\) \(f'(x_n)\) ค่าถัดไป \(x_{n+1}\) \(|x_{n+1} - x_n|\)

4. คำถามนำเพื่อค้นพบ (Guided Inquiry)

ทบทวนหลักการเชิงเรขาคณิตและข้อจำกัดก่อนเปิดดูคำตอบ

1

สูตรนิวตัน–ราฟสันเกิดจากสมการเส้นสัมผัสได้อย่างไร?

พิจารณาความสัมพันธ์ของความชัน จุดสัมผัส และจุดตัดแกน \(x\)

แนวคิด: จากนิยามความชันของเส้นสัมผัสกราฟที่จุด \((x_n, f(x_n))\) คืออนุพันธ์ \(m = f'(x_n)\) และสมการเส้นตรงคือ \(y - y_1 = m(x - x_1)\) จะได้ \(y - f(x_n) = f'(x_n)(x - x_n)\) เนื่องจากเป้าหมายคือการหารากที่ \(y=0\) เราจึงให้เส้นสัมผัสตัดแกน \(x\) ที่จุด \((x_{n+1}, 0)\) แทนค่า \(y=0\) จะได้ \(-f(x_n) = f'(x_n)(x_{n+1} - x_n)\) และเมื่อย้ายข้างจะได้ \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\)
2

เหตุใดการเลือกค่าเริ่มต้นจึงมีผลต่อการลู่เข้า?

พิจารณารูปทรงความโค้งของกราฟและจุดวิกฤต

แนวคิด: วิธีนิวตัน–ราฟสันเป็น วิธีเฉพาะที่ (Locally Convergent) ซึ่งจะการันตีการลู่เข้าก็ต่อเมื่อค่าเริ่มต้น \(x_0\) อยู่ในบริเวณใกล้เคียงรากมากพอ (Radius of Convergence) หากเลือก \(x_0\) ไปตกใกล้จุดวกกลับ (Local Extremum) ความชันจะราบเรียบ ทำให้เส้นสัมผัสตัดแกน \(x\) ไปไกลมากจนหลุดออกจากบริเวณราก หรืออาจทำให้เกิดการกระโดดสลับไปมาระหว่างแอ่งสองแอ่ง
3

ถ้า \(f'(x_n) = 0\) จะเกิดปัญหาใดกับสูตรทำซ้ำ?

พิจารณาทั้งมุมมองพีชคณิตและการตีความทางเรขาคณิต

แนวคิด:
  • เชิงพีชคณิต: เกิดการหารด้วยศูนย์ (\(\frac{f(x_n)}{0}\)) ซึ่งไม่นิยามในทางคณิตศาสตร์ และโปรแกรมคอมพิวเตอร์จะเกิดข้อผิดพลาด Division by Zero
  • เชิงเรขาคณิต: เส้นสัมผัสของกราฟจะขนานกับแกน \(x\) พอดี (ความชันเป็นศูนย์) ทำให้เส้นสัมผัสนั้น ไม่มีจุดตัดแกน \(x\) ส่งผลให้ไม่สามารถสร้างค่าประมาณ \(x_{n+1}\) สำหรับรอบถัดไปได้ และขั้นตอนวิธีจะล้มเหลวทันที

5. แบบฝึกหัดสำหรับนักศึกษา

ทดสอบการคำนวณและกรอกค่าประมาณเพื่อตรวจสอบความเข้าใจ

ข้อ 1. ใช้วิธีนิวตัน–ราฟสันประมาณรากของ \(x^3 - x - 2 = 0\) โดยกำหนด \(x_0 = 1.5\) จำนวน 3 รอบ

ประมาณค่า 3 รอบ

จงหาค่าประมาณ \(x_3\) (ตอบเป็นทศนิยมอย่างน้อย 4 ตำแหน่ง เช่น 1.5214)

ขั้นตอนการคำนวณ:
สูตร: \(x_{n+1} = x_n - \frac{x_n^3 - x_n - 2}{3x_n^2 - 1}\)
  • x₀ = 1.5
  • x₁ = 1.5 - (-0.125 / 5.75) = 1.5217391
  • x₂ = 1.5217391 - (0.002133 / 5.946125) = 1.5213799
  • x₃ = 1.5213799 - (0.000000 / 5.942918) = 1.5213797 ≈ 1.5214
จะเห็นว่าหลังทำเพียง 3 รอบ ค่าประมาณมีความถูกต้องถึงทศนิยมตำแหน่งที่ 6 แล้ว

ข้อ 2. ใช้วิธีเดียวกันประมาณรากของ \(x^2 - 2 = 0\) (หาค่า \(\sqrt{2}\)) โดยเริ่มจาก \(x_0 = 1\) จำนวน 4 รอบ

Babylonian Method

จงหาค่าประมาณ \(x_4\) (ตอบเป็นทศนิยม 6 ตำแหน่ง เช่น 1.414214)

ขั้นตอนการคำนวณ (วิธีบาบิโลเนียน):
\(f(x) = x^2 - 2 \implies f'(x) = 2x\) สูตรคือ \(x_{n+1} = \frac{1}{2}(x_n + \frac{2}{x_n})\)
  • x₀ = 1.0
  • x₁ = (1 + 2/1)/2 = 1.5
  • x₂ = (1.5 + 2/1.5)/2 = 1.4166667
  • x₃ = (1.4166667 + 2/1.4166667)/2 = 1.4142157
  • x₄ = 1.4142136 ≈ 1.414214

ข้อ 3. เหตุผลทางคณิตศาสตร์ที่ทำให้วิธีนิวตัน–ราฟสันอาจไม่เหมาะกับค่าเริ่มต้นบางค่า

การวิเคราะห์เงื่อนไข

พิจารณาข้อความต่อไปนี้ ข้อใดเป็นสาเหตุทางคณิตศาสตร์ที่ทำให้วิธีนิวตัน–ราฟสันล้มเหลว?

คำตอบที่ถูกต้อง: ถูกทุกข้อที่กล่าวมา
วิธีนิวตัน–ราฟสันเป็น Open Method ซึ่งไม่มีการตีกรอบราก (No Bracketing) หากค่าเริ่มต้น \(x_0\) อยู่ไกลเกินไป หรือเจอบริเวณที่อนุพันธ์เข้าใกล้ศูนย์ เส้นสัมผัสสามารถพาตัวแปรลู่ออกสู่อนันต์ หรือตกเข้าไปในวงวนซ้ำ (Cycle) ได้เสมอ จึงจำเป็นต้องระมัดระวังในการเลือกค่าเริ่มต้น
