สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 5: ทฤษฎีบทเดอมัวฟร์และรากที่ \(n\) De Moivre's Theorem & \(n\)-th Roots

การยกกำลังจำนวนเชิงซ้อนในรูปเชิงขั้ว การหารากที่ \(n\) ทั้งหมด และการกระจายตัวแบบสมมาตรเป็นรูป \(n\) เหลี่ยมด้านเท่าบนระนาบเชิงซ้อน

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถใช้ทฤษฎีบทเดอมัวฟร์ในการยกกำลังจำนวนเชิงซ้อน และหารากที่ \(n\) ของจำนวนเชิงซ้อนโดยแสดงคำตอบทั้งหมดได้อย่างถูกต้อง

1-5 บทสรุปสาระสำคัญทางทฤษฎี

1 & 2. ทฤษฎีบทเดอมัวฟร์ (De Moivre's Theorem)

สำหรับการยกกำลังจำนวนเต็ม \(n \in \mathbb{Z}\) ของจำนวนเชิงซ้อนในรูปเชิงขั้ว:

\[ [r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta) \]

หลักการ: ยกกำลังโมดูลัสเป็น \(r^n\) และคูณมุมอาร์กิวเมนต์ด้วย \(n\)

3. ความหมายของรากที่ \(n\) ของจำนวนเชิงซ้อน

จำนวนเชิงซ้อน \(w\) จะเป็นรากที่ \(n\) ของ \(z\) ก็ต่อเมื่อ \(w^n = z\)

สำหรับ \(z \neq 0\) ใดๆ จะมีรากที่ \(n\) ที่แตกต่างกันพอดี \(n\) ค่าเสมอในระบบจำนวนเชิงซ้อน

4. สูตรการหารากที่ \(n\) ของจำนวนเชิงซ้อน

ให้ \(z = r(\cos\theta + i\sin\theta)\) โดย \(r > 0\) รากที่ \(n\) ของ \(z\) คือ:

\[ w_k = r^{1/n}\left[\cos\left(\frac{\theta + 360^\circ k}{n}\right) + i\sin\left(\frac{\theta + 360^\circ k}{n}\right)\right] \]

โดยแทนค่าดัชนี \(k = 0, 1, 2, \dots, n-1\)

5. การกระจายตัวของรากบนระนาบเชิงซ้อน

  • รากทั้งหมด \(w_0, \dots, w_{n-1}\) อยู่บนวงกลมรัศมีเท่ากันคือ \(R = r^{1/n} = \sqrt[n]{r}\)
  • รากแต่ละตัวที่อยู่ติดกันทำมุมห่างกันเท่าๆ กันคือ \(\Delta\theta = \frac{360^\circ}{n}\) หรือ \(\frac{2\pi}{n}\)
  • จุดยอดของรากทั้ง \(n\) ตัวจะประกอบกันเป็นรูปหลายเหลี่ยมด้านเท่ามุมเท่า (Regular \(n\)-gon) แนบในวงกลม

แบบจำลองรากที่ \(n\) และการยกกำลัง (Simulator)

เลือกโหมดการคำนวณ ปรับค่าตัวแปร และสังเกตรูปหลายเหลี่ยมของรากบนระนาบ

รัศมีราก R = 2.000
Δθ = 120° (รูป 3 เหลี่ยม)
เลือกพรีเซ็ตตัวอย่างสำคัญ (Presets):
โมดูลัสตัวตั้ง \(r = |z|\) 8.0
มุมตัวตั้ง \(\theta\) (องศา) 0°
ดัชนีรากที่ \(n\) (จำนวนราก: 2 ถึง 8) n = 3
โหมดนี้แสดงการใช้ \([r\operatorname{cis}\theta]^n = r^n\operatorname{cis}(n\theta)\) เมื่อยกกำลังจำนวนเชิงซ้อน
โมดูลัสฐาน \(r\): 1.414
มุมฐาน \(\theta\) (องศา): 45°
เลขชี้กำลัง \(n\): n = 4
ผลการยกกำลัง \(z^n\):
รายการรากทั้งหมด (All \(n\) Roots): ทั้งหมด 3 คำตอบ

คำถามนำเพื่อการค้นพบ (Guided Discovery)

คลิกที่แต่ละคำถามเพื่อเปิดดูแนวคิดและคำอธิบายทางเรขาคณิต

แนวคิดคำตอบ:

มีทั้งหมด \(n\) ค่าพอดี (Exactly \(n\) distinct values)

เป็นผลมาจากทฤษฎีบทมูลฐานของพีชคณิต (Fundamental Theorem of Algebra) เพราะสมการ \(w^n - z = 0\) เป็นพหุนามดีกรี \(n\) จึงมีคำตอบในระบบจำนวนเชิงซ้อนพอดี \(n\) ราก ซึ่งเกิดขึ้นจากการแทนค่าดัชนี \(k = 0, 1, 2, \dots, n-1\) หากแทนค่า \(k = n\) จะได้มุมที่วนครบรอบ \(360^\circ\) กลับมาซ้ำกับค่าของ \(k = 0\)

แนวคิดคำตอบ:

รากทั้ง \(n\) ตัวจะ กระจายตัวอย่างสม่ำเสมอสมมาตรบนวงกลมรัศมี \(R = r^{1/n}\) ที่มีจุดศูนย์กลางที่จุดกำเนิด \((0,0)\)

โดยจุดปลายของเวกเตอร์รากแต่ละตัวทำหน้าที่เป็น จุดยอดของรูปหลายเหลี่ยมด้านเท่ามุมเท่า (Regular \(n\)-gon) แนบในวงกลม เช่น:

\(n=3\): สามเหลี่ยมด้านเท่า
\(n=4\): สี่เหลี่ยมจัตุรัส
\(n=5\): ห้าเหลี่ยมด้านเท่า
\(n=6\): หกเหลี่ยมด้านเท่า

แนวคิดคำตอบ:

ระยะเชิงมุมระหว่างรากที่อยู่ติดกันคือ \(\Delta\theta = \frac{360^\circ}{n}\) (หรือ \(\frac{2\pi}{n}\))

ดังนั้น เมื่อ \(n\) มีค่าเพิ่มขึ้น ระยะเชิงมุมระหว่างรากที่อยู่ติดกันจะลดลง (เล็กลงเรื่อยๆ) ทำให้รากแต่ละตัวอยู่ใกล้ชิดกันมากขึ้นรอบเส้นรอบวง และเมื่อ \(n \to \infty\) จุดของรากจะเรียงตัวชิดกันจนเกือบกลายเป็นเส้นรอบวงต่อเนื่องของวงกลม

แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

ฝึกคำนวณกำลังและรากที่ \(n\) พร้อมตรวจคำตอบและดูเฉลยละเอียด

1 ใช้ทฤษฎีบทเดอมัวฟร์คำนวณ \((1 + i)^4\)

ผลลัพธ์ \(a + bi\): + i
วิธีทำ:
1. เขียน \(1 + i\) ในรูปเชิงขั้ว: \(r = \sqrt{1^2 + 1^2} = \sqrt{2}\) และ \(\theta = 45^\circ\)
\(1 + i = \sqrt{2}(\cos 45^\circ + i\sin 45^\circ)\)
2. ใช้ทฤษฎีบทเดอมัวฟร์ยกกำลัง 4:
\((1 + i)^4 = (\sqrt{2})^4 [\cos(4 \times 45^\circ) + i\sin(4 \times 45^\circ)]\)
\( = 4 [\cos 180^\circ + i\sin 180^\circ] = 4(-1 + 0i) = -4\)
ดังนั้น ส่วนจริงคือ -4 และ ส่วนจินตภาพคือ 0 (คำตอบคือ -4)

2 จงหารากที่สามทั้งหมดของ \(8\) (ระบุรัศมีราก \(R\) และมุมทั้ง 3 ค่า)

วิธีทำ:
เขียน \(8 = 8(\cos 0^\circ + i\sin 0^\circ)\)
รัศมีราก: \(R = 8^{1/3} = 2\)
มุมของรากทั้งสาม: \(\frac{0^\circ + 360^\circ k}{3}\) สำหรับ \(k = 0, 1, 2\)
• \(k = 0 \implies \theta_0 = 0^\circ \implies w_0 = 2(\cos 0^\circ + i\sin 0^\circ) = 2\)
• \(k = 1 \implies \theta_1 = 120^\circ \implies w_1 = 2(\cos 120^\circ + i\sin 120^\circ) = -1 + \sqrt{3}i\)
• \(k = 2 \implies \theta_2 = 240^\circ \implies w_2 = 2(\cos 240^\circ + i\sin 240^\circ) = -1 - \sqrt{3}i\)
รากทั้งสามคือ \(2\), \(-1+\sqrt{3}i\), และ \(-1-\sqrt{3}i\)

3 จงหารากที่สี่ทั้งหมดของ \(-16\) และแสดงคำตอบในรูปเชิงขั้ว

เลือกเซตของคำตอบเชิงขั้วที่ถูกต้องสมบูรณ์:

วิธีทำ:
เขียน \(-16\) ในรูปเชิงขั้ว: \(-16 = 16(\cos 180^\circ + i\sin 180^\circ)\)
รัศมีราก: \(R = 16^{1/4} = 2\)
มุมของรากที่สี่: \(\frac{180^\circ + 360^\circ k}{4} = 45^\circ + 90^\circ k\) สำหรับ \(k = 0, 1, 2, 3\)
• \(k=0 \implies 45^\circ \implies 2\operatorname{cis}45^\circ = \sqrt{2} + \sqrt{2}i\)
• \(k=1 \implies 135^\circ \implies 2\operatorname{cis}135^\circ = -\sqrt{2} + \sqrt{2}i\)
• \(k=2 \implies 225^\circ \implies 2\operatorname{cis}225^\circ = -\sqrt{2} - \sqrt{2}i\)
• \(k=3 \implies 315^\circ \implies 2\operatorname{cis}315^\circ = \sqrt{2} - \sqrt{2}i\)
เป็นรูปสี่เหลี่ยมจัตุรัสแนบในวงกลมรัศมี 2 พอดี
