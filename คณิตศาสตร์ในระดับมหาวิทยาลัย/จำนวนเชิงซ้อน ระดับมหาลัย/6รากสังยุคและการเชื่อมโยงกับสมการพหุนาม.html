สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 6: รากสังยุคและการเชื่อมโยงกับสมการพหุนาม Complex Conjugate Roots & Polynomials

ทฤษฎีบทรากสังยุคของพหุนามสัมประสิทธิ์จริง การสร้างสมการพหุนามจากราก และการเชื่อมโยงกับกราฟพาราโบลาที่ไม่ตัดแกนจริง

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถอธิบายสมบัติของรากสังยุค และใช้สมบัตินี้สร้างสมการพหุนามสัมประสิทธิ์จริงจากรากที่กำหนดได้อย่างถูกต้องและเป็นระบบ

1-5 บทสรุปสาระสำคัญทางทฤษฎี

1. จำนวนเชิงซ้อนสังยุค (Complex Conjugate)

ถ้า \(z = a + bi\) จำนวนเชิงซ้อนสังยุคของ \(z\) เขียนแทนด้วย \(\overline{z}\) คือ:

\[ \overline{z} = a - bi \]

บนระนาบเชิงซ้อน \(\overline{z}\) คือภาพสะท้อนของจุด \(z\) ข้ามแกนจริง (\(\operatorname{Re}\)-axis)

2. สมบัติสำคัญในการกำจัดหน่วยจินตภาพ

• ผลบวก: \(z + \overline{z} = (a+bi) + (a-bi) = 2a \in \mathbb{R}\)
• ผลคูณ: \(z \cdot \overline{z} = a^2 - (bi)^2 = a^2 + b^2 \in \mathbb{R}\)

ทั้งผลบวกและผลคูณของคู่สังยุคจะเป็นจำนวนจริงเสมอ

3. ทฤษฎีบทรากสังยุค (Complex Conjugate Root Theorem)

ถ้าพหุนาม \(P(x)\) มีสัมประสิทธิ์ทั้งหมดเป็นจำนวนจริง และมี \(z = a + bi\) (\(b \neq 0\)) เป็นรากของสมการ \(P(x) = 0\) แล้ว

\(\overline{z} = a - bi\) จะต้องเป็นรากของสมการ \(P(x)=0\) ด้วยเสมอ

นั่นคือ รากเชิงซ้อนที่ไม่ใช่จำนวนจริงของพหุนามสัมประสิทธิ์จริงจะเกิดเป็นคู่สังยุคเสมอ (Occur in conjugate pairs)

4. การสร้างสมการพหุนามจากรากคู่สังยุค

จากตัวประกอบ \((x - z)(x - \overline{z})\):

\[ \begin{aligned} P(x) &= (x - (a+bi))(x - (a-bi)) \\ &= (x - a)^2 - (bi)^2 \\ &= (x - a)^2 + b^2 \\ &= x^2 - 2ax + (a^2 + b^2) \end{aligned} \]
สูตรลัดผลบวก-ผลคูณ: \(x^2 - Sx + P = 0\)
โดย \(S = z + \overline{z} = 2a\) และ \(P = z\overline{z} = a^2 + b^2\)
ตัวอย่างมาตรฐาน:

ถ้ารากของสมการคือ \(2+3i\) และ \(2-3i\):

\(P(x) = (x-2)^2 + 3^2 = x^2 - 4x + 13 = 0\)

แบบจำลองรากสังยุคและพหุนาม (Interactive Visualizer)

ปรับค่า \(a\) และ \(b\) เพื่อดูการสะท้อนของคู่สังยุคบนระนาบ และการก่อตัวของพหุนาม

z = 2 + 3i | z̄ = 2 - 3i
สมมาตรรอบแกนจริง
เลือกตัวอย่างพิกัดราก (Presets):
ส่วนจริง \(a\) (แกนสมมาตรของราก): 2.0
ส่วนจินตภาพ \(b\) (ระยะห่างจากแกนจริง): 3.0
สมการพหุนามที่สร้างได้ (Generated Polynomial): P(x) = 0
ผลบวกของราก (Sum S = 2a): S = 4
ผลคูณของราก (Product P = a² + b²): P = 13
รูปกำลังสองสมบูรณ์: (x - 2)² + 9 = 0 กราฟพาราโบลาจริง \(y = P(x)\) มีจุดยอดอยู่ที่ \((a, b^2)\) ซึ่งลอยเหนือแกน x เมื่อ \(b \neq 0\) จึงไม่มีจุดตัดบนแกนจริง

คำถามนำเพื่อการค้นพบ (Guided Discovery)

คลิกที่แต่ละคำถามเพื่อเปิดดูแนวคิดและคำอธิบายทางคณิตศาสตร์

แนวคิดคำตอบ:

เมื่อเรากระจายผลคูณ \((x - z)(x - \overline{z})\) จะได้:

\((x - z)(x - \overline{z}) = x^2 - (z + \overline{z})x + z\overline{z}\)

สัมประสิทธิ์หน้า \(x\) คือ \(-(z + \overline{z}) = -2a\) และพจน์คงตัวคือ \(z\overline{z} = a^2 + b^2\) ซึ่งทั้ง \(2a\) และ \(a^2 + b^2\) เป็นการคำนวณที่ทำให้พจน์จินตภาพ \(bi\) กับ \(-bi\) หักล้างกันจนหมดสิ้น และ \(i^2 = -1\) ผลลัพธ์จึงกลายเป็นจำนวนจริงอย่างสมบูรณ์

แนวคิดคำตอบ:

จะต้องมี \(3 + 2i\) (คู่สังยุคของมัน) เป็นรากด้วยอย่างแน่นอน

เนื่องจากพหุนามมีสัมประสิทธิ์เป็นจำนวนจริง ตามทฤษฎีบทรากสังยุค รากที่ไม่ใช่จำนวนจริงจะต้องปรากฏเป็นคู่สังยุคเสมอ ดังนั้น เมื่อ \(3 - 2i\) เป็นราก จะส่งผลให้ \(\overline{3 - 2i} = 3 + 2i\) ต้องเป็นรากของพหุนามนั้นด้วยเสมอ

แนวคิดคำตอบ:

พหุนามดีกรี \(n \ge 1\) ที่มีสัมประสิทธิ์เชิงซ้อนจะมี รากในระบบจำนวนเชิงซ้อนพอดี \(n\) รากเสมอ (เมื่อนับตามพหุคูณ หรือ Multiplicity)

ทฤษฎีนี้แสดงว่าระบบจำนวนเชิงซ้อนมีคุณสมบัติเป็น "ฟีลด์ปิดทางพีชคณิต" (Algebraically Closed Field) กล่าวคือ ไม่ว่าเราจะตั้งสมการพหุนามดีกรีเท่าใด คำตอบทั้งหมดจะอยู่ภายในเซตจำนวนเชิงซ้อนเสมอ โดยไม่จำเป็นต้องขยายระบบจำนวนออกไปอีกต่อไป

แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

ทดสอบความเข้าใจเรื่องรากสังยุคและการสร้างพหุนาม พร้อมระบบตรวจคำตอบ

1 พหุนามสัมประสิทธิ์จริงมีรากคือ \(-1 + 4i\) จงหารากสังยุคของมัน

รากสังยุค \(\overline{z} =\): + i
วิธีทำ:
จำนวนเชิงซ้อนสังยุคของ \(a + bi\) คือ \(a - bi\)
เมื่อ \(z = -1 + 4i\) จะได้ส่วนจริง \(a = -1\) และส่วนจินตภาพ \(b = 4\)
ดังนั้น รากสังยุคคือ \(\overline{z} = -1 - 4i\) (ส่วนจริงคือ -1 และส่วนจินตภาพคือ -4)

2 จงสร้างพหุนามดีกรีสองสัมประสิทธิ์จริงที่มีรากคือ \(1 + 2i\) และ \(1 - 2i\) ในรูป \(x^2 + Bx + C = 0\)

x² + ( )x + ( ) = 0
วิธีทำ:
วิธีที่ 1 (ใช้สูตรผลบวก-ผลคูณ):
• ผลบวกของราก \(S = (1+2i) + (1-2i) = 2\)
• ผลคูณของราก \(P = (1+2i)(1-2i) = 1^2 - (2i)^2 = 1 - 4(-1) = 5\)
จากสูตร \(x^2 - Sx + P = 0 \implies x^2 - 2x + 5 = 0\)
ดังนั้น ค่า B = -2 และ ค่า C = 5

3 จงอธิบายความเชื่อมโยงระหว่างจำนวนเชิงซ้อนกับการศึกษารากของสมการพหุนาม

เขียนคำอธิบายตามความเข้าใจ หรือคลิกเพื่อดูแนวคิดสังเคราะห์ที่สมบูรณ์:

ความเชื่อมโยงสำคัญ 3 ประการ:
  • 1. ความสมบูรณ์ของคำตอบ (Completeness): ในระบบจำนวนจริง สมการบางชนิดเช่น \(x^2 + 1 = 0\) ไม่มีคำตอบ แต่การมีอยู่ของจำนวนเชิงซ้อนทำให้พหุนามดีกรี \(n\) มีคำตอบครบ \(n\) ค่าเสมอตามทฤษฎีบทมูลฐานของพีชคณิต
  • 2. ความสมมาตรและการแยกตัวประกอบ (Conjugate Symmetry): ในพหุนามสัมประสิทธิ์จริง รากเชิงซ้อนจะมาเป็นคู่สังยุคเสมอ ทำให้เราสามารถรวมตัวประกอบเชิงซ้อนคู่หนึ่ง \((x-z)(x-\overline{z})\) กลายเป็นพหุนามกำลังสองสัมประสิทธิ์จริงที่ไม่สามารถแยกต่อใน \(\mathbb{R}\) ได้
  • 3. การอธิบายเรขาคณิตของพาราโบลา: เมื่อกราฟพาราโบลา \(y = ax^2 + bx + c\) ลอยตัวไม่ตัดแกน \(x\) แสดงว่าไม่มีรากที่เป็นจำนวนจริง แต่มีรากเชิงซ้อนคู่สังยุคเป็นคำตอบในมิติจินตภาพ
