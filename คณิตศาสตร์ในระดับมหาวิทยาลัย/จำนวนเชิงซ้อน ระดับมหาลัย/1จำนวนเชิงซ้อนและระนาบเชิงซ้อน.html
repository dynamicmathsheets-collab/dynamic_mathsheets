สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 1: ความหมายของจำนวนเชิงซ้อนและระนาบเชิงซ้อน

บทนำสู่การขยายระบบจำนวน และการทำความเข้าใจระนาบเชิงซ้อน (Argand Diagram)

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถอธิบายความหมายของจำนวนเชิงซ้อน ระบุส่วนจริงและส่วนจินตภาพ ดำเนินการพื้นฐาน และแสดงจำนวนเชิงซ้อนบนระนาบเชิงซ้อนได้อย่างถูกต้อง

1-5 บทสรุปสาระสำคัญ

1. ความหมายของจำนวนเชิงซ้อน

จำนวนเชิงซ้อน (Complex Number) เขียนอยู่ในรูป:

\( z = a + bi \)

โดยที่ \(a\) และ \(b\) เป็นจำนวนจริง (\(a, b \in \mathbb{R}\))

2. หน่วยจินตภาพ (Imaginary Unit)

ใช้อักษรแทนด้วย \(i\) ซึ่งมีสมบัติพื้นฐานสำคัญคือ:

\( i^2 = -1 \quad (\text{หรือ } i = \sqrt{-1}) \)

3. ส่วนจริงและส่วนจินตภาพ

สำหรับจำนวนเชิงซ้อน \(z = a + bi\):

  • ส่วนจริง (Real part): \(\operatorname{Re}(z) = a\)
  • ส่วนจินตภาพ (Imaginary part): \(\operatorname{Im}(z) = b\) *(ระวัง: ไม่นำ \(i\) มารวมในค่าส่วนจินตภาพ)*

4. การเท่ากันของจำนวนเชิงซ้อน

ให้ \(a + bi = c + di\) จะได้ว่า

\(a = c\) และ \(b = d\)

จำนวนเชิงซ้อนจะเท่ากันก็ต่อเมื่อส่วนจริงเท่ากัน และส่วนจินตภาพต้องเท่ากันด้วย

5. การแทนบนระนาบเชิงซ้อน (Argand Plane)

เนื่องจาก \(z = a + bi\) ประกอบด้วยคู่ลำดับ \((a, b)\):

แกนนอน (Re)
แทน ส่วนจริง (\(a\))
แกนตั้ง (Im)
แทน ส่วนจินตภาพ (\(b\))

คำถามนำเพื่อการค้นพบ (Guided Discovery)

ทดลองตอบด้วยความเข้าใจตนเอง จากนั้นคลิกเพื่อตรวจสอบแนวคิด

แนวคิดคำตอบ:

จุดจะเคลื่อนที่ไปตาม แนวนอน (ขนานกับแกนส่วนจริง หรือ Real Axis) โดย:

  • ถ้า \(a\) เพิ่มขึ้น จุดจะเลื่อนไปทางขวา
  • ถ้า \(a\) ลดลง จุดจะเลื่อนไปทางซ้าย
  • ระดับความสูงตามแกนตั้ง (\(b\)) จะคงที่เสมอ

แนวคิดคำตอบ:

ให้ \(z_1 = a + bi\) และ \(z_2 = c + di\) จะได้ว่า \(z_1 = z_2\) ก็ต่อเมื่อ ส่วนจริงเท่ากัน และส่วนจินตภาพต้องเท่ากันด้วยพร้อมกัน

\(a = c\) และ \(b = d\)

ในมุมมองเรขาคณิต หมายถึง จุดทั้งสองต้องทับเป็นจุดเดียวกันบนระนาบเชิงซ้อน

แนวคิดคำตอบ:

1. จำนวนจริงแท้ (Pure Real Number) คือจำนวนเชิงซ้อนที่มี ส่วนจินตภาพเป็น 0 (\(b = 0\)) ทำให้เหลือเพียง \(z = a + 0i = a\) ซึ่งอยู่บน แกนนอน
2. จำนวนจินตภาพแท้ (Pure Imaginary) คือจำนวนเชิงซ้อนที่มี ส่วนจริงเป็น 0 (\(a = 0\)) แต่ \(b \neq 0\) ทำให้เหลือ \(z = 0 + bi = bi\) ซึ่งอยู่บน แกนตั้ง

ดังนั้น เซตของจำนวนจริง (\(\mathbb{R}\)) จึงเป็นสับเซตของเซตจำนวนเชิงซ้อน (\(\mathbb{C}\))

แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

ตอบคำถามแล้วกดปุ่ม "ตรวจคำตอบ" หรือ "แสดงเฉลย"

1 จงระบุส่วนจริงและส่วนจินตภาพของ \(z = -4 + 7i\)

เฉลย: ส่วนจริงคือ \(\operatorname{Re}(z) = -4\) และส่วนจินตภาพคือ \(\operatorname{Im}(z) = 7\) (ข้อควรระวัง: ส่วนจินตภาพคือค่าสัมประสิทธิ์หน้า \(i\) ไม่ต้องใส่ตัวอักษร \(i\) มาด้วย)

2 จงแทน \(z = -2 - 3i\) เป็นจุดบนระนาบเชิงซ้อน พร้อมระบุพิกัด \((x, y)\)

( , )
เฉลย: พิกัดคือ \((-2, -3)\) อยู่ในควอดรันต์ที่ 3 (ด้านล่างซ้าย) โดยมีแกนนอน \(= -2\) และแกนตั้ง \(= -3\)

3 จงอธิบายว่าเหตุใด \(3 + 2i \neq 3 - 2i\)

เลือกเหตุผลที่ถูกต้องที่สุดตามนิยามการเท่ากันของจำนวนเชิงซ้อน:

คำอธิบาย: จำนวนเชิงซ้อนจะเท่ากันได้ ทั้งส่วนจริงและส่วนจินตภาพต้องมีค่าตรงกันทุกประการ ในกรณีนี้ ส่วนจริงเท่ากันคือ \(3 = 3\) แต่ส่วนจินตภาพคือ \(2\) และ \(-2\) ซึ่ง \(2 \neq -2\) จึงทำให้ \(3+2i \neq 3-2i\)
ในเชิงเรขาคณิต: \(3+2i\) แทนจุด \((3, 2)\) ซึ่งอยู่เหนือแกนนอน ส่วน \(3-2i\) แทนจุด \((3, -2)\) ซึ่งอยู่ใต้แกนนอน (ทั้งสองเป็นสังยุคซึ่งกันและกัน ไม่ใช่จุดเดียวกัน)
