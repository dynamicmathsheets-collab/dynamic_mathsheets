สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 2: การดำเนินการกับจำนวนเชิงซ้อน (Operations on Complex Numbers)

การบวก การลบ การคูณ การหาร จำนวนเชิงซ้อนสังยุค และการมองภาพผลลัพธ์บนระนาบเชิงซ้อน

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถบวก ลบ คูณ และหารจำนวนเชิงซ้อน พร้อมแสดงวิธีคำนวณและเขียนคำตอบในรูป \(a+bi\) ได้

1-6 สรุปหลักการและสูตรสำคัญ

กำหนดให้ \(z_1 = a + bi\) และ \(z_2 = c + di\) โดย \(a, b, c, d \in \mathbb{R}\)

1. การบวกและการลบ (Addition & Subtraction)

รวมส่วนจริงเข้าด้วยกัน และรวมส่วนจินตภาพเข้าด้วยกัน

\( z_1 + z_2 = (a+c) + (b+d)i \)
\( z_1 - z_2 = (a-c) + (b-d)i \)

2 & 3. การคูณและสมบัติ \(i^2 = -1\)

กระจายพจน์เหมือนพหุนาม แล้วแทนที่ \(i^2\) ด้วย \(-1\)

\( (a+bi)(c+di) = ac + adi + bci + bdi^2 \)
\( \phantom{(a+bi)(c+di)} = (ac - bd) + (ad + bc)i \)

4. สังยุคของจำนวนเชิงซ้อน (Conjugate)

เปลี่ยนเครื่องหมายเฉพาะหน้าส่วนจินตภาพ

\( \bar{z}_2 = c - di \quad \Longrightarrow \quad z_2 \bar{z}_2 = c^2 + d^2 \)

5. การหาร (Division เมื่อ \(z_2 \neq 0\))

คูณทั้งเศษและส่วนด้วยสังยุคของตัวส่วน (\(\bar{z}_2\))

\[ \frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{z_2 \bar{z}_2} = \frac{(ac+bd) + (bc-ad)i}{c^2+d^2} \]

6. สมบัติพื้นฐานของการดำเนินการ

  • การสลับที่และการเปลี่ยนหมู่ของการบวกและการคูณ
  • การแจกแจง: \(z_1(z_2 + z_3) = z_1z_2 + z_1z_3\)
  • เอกลักษณ์การบวกคือ \(0\) และเอกลักษณ์การคูณคือ \(1\)

เครื่องคำนวณและแบบจำลองการดำเนินการ (Simulator)

ปรับค่า \(z_1, z_2\) และเลือกตัวดำเนินการเพื่อดูการคำนวณแบบสดๆ

ตัวตั้ง \(z_1 = a + bi\) 2 + 3i
ตัวกระทำ \(z_2 = c + di\) 1 - 2i
ผลลัพธ์การคำนวณ (Result)
ส่วนจริง \(\operatorname{Re}\): 0
ส่วนจินตภาพ \(\operatorname{Im}\): 0

ขั้นตอนแสดงวิธีคำนวณละเอียด (Step-by-step Solution):

ตำแหน่งเวกเตอร์บนระนาบเชิงซ้อน
\(z_1\) \(z_2\) ผลลัพธ์

คำถามนำเพื่อการค้นพบ (Guided Discovery)

คลิกที่แต่ละคำถามเพื่อตรวจสอบแนวคิดและทำความเข้าใจเชิงลึก

แนวคิดคำตอบ:

เมื่อเราคูณพจน์ที่มีหน่วยจินตภาพเข้าด้วยกัน คือ \((bi)(di) = bd(i^2)\)

เนื่องจากตามนิยาม \(i^2 = -1\) ดังนั้นพจน์ดังกล่าวจึงเปลี่ยนสภาพกลายเป็นจำนวนจริง:

\(bd(i^2) = bd(-1) = -bd\)

จึงถูกนำมารวมเข้ากับพจน์ \(ac\) ในฐานะส่วนหนึ่งของส่วนจริง กลายเป็น \((ac - bd)\)

แนวคิดคำตอบ:

ในเชิงเรขาคณิต การคูณจำนวนเชิงซ้อน \(z\) ด้วย \(i\) เทียบเท่ากับ การหมุนเวกเตอร์ทวนเข็มนาฬิกาเป็นมุม 90 องศา (\(\frac{\pi}{2}\) เรเดียน) โดยขนาดของเวกเตอร์ยังคงเท่าเดิม

ให้ \(z = a + bi\) จะได้ว่า \(i \cdot z = i(a + bi) = ai + bi^2 = -b + ai\)
ซึ่งพิกัดเปลี่ยนจาก \((a, b)\) ไปเป็น \((-b, a)\) ซึ่งคือพิกัดหลังจากการหมุน 90° ทวนเข็มนาฬิกา

แนวคิดคำตอบ:

เพราะเมื่อนำจำนวนเชิงซ้อนคูณกับสังยุคของตัวมันเอง จะทำให้ พจน์จินตภาพหักล้างกันหมด และผลลัพธ์จะกลายเป็นจำนวนจริงเสมอ

\( (c + di)(c - di) = c^2 - (di)^2 = c^2 - d^2(-1) = c^2 + d^2 \)

การทำให้ตัวส่วนเป็นจำนวนจริง (\(c^2 + d^2\)) ช่วยให้เราสามารถแยกเขียนเศษส่วนเป็น \(\frac{\text{ส่วนจริง}}{\text{ตัวส่วน}} + \frac{\text{ส่วนจินตภาพ}}{\text{ตัวส่วน}}i\) ในรูปมาตรฐาน \(a + bi\) ได้โดยตรง

แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

กรอกค่าส่วนจริงและส่วนจินตภาพของคำตอบ แล้วกดปุ่มตรวจคำตอบ

1 จงคำนวณ \( (3 + 2i) + (1 - 5i) \)

คำตอบ: + i
วิธีทำ:
\( (3 + 2i) + (1 - 5i) = (3 + 1) + (2 - 5)i \)
\( \phantom{(3 + 2i) + (1 - 5i)} = 4 - 3i \)
ดังนั้น ส่วนจริงคือ 4 และ ส่วนจินตภาพคือ -3

2 จงคำนวณ \( (2 + i)(3 - 4i) \)

คำตอบ: + i
วิธีทำ:
กระจายการคูณ:
\( (2 + i)(3 - 4i) = (2)(3) + (2)(-4i) + (i)(3) + (i)(-4i) \)
\( \phantom{(2 + i)(3 - 4i)} = 6 - 8i + 3i - 4i^2 \)
เนื่องจาก \(i^2 = -1\) จะได้ \(-4(-1) = +4\):
\( \phantom{(2 + i)(3 - 4i)} = 6 - 5i + 4 = 10 - 5i \)
ดังนั้น ส่วนจริงคือ 10 และ ส่วนจินตภาพคือ -5

3 จงเขียน \( \dfrac{1 + 2i}{2 - i} \) ในรูป \( a + bi \)

คำตอบ: + i
วิธีทำ:
คูณด้วยสังยุคของตัวส่วน คือ \(2 + i\) ทั้งเศษและส่วน:
\( \dfrac{1+2i}{2-i} = \dfrac{(1+2i)(2+i)}{(2-i)(2+i)} \)
ตัวเศษ: \( (1)(2) + 1(i) + 2i(2) + 2i^2 = 2 + i + 4i - 2 = 0 + 5i = 5i \)
ตัวส่วน: \( 2^2 + (-1)^2 = 4 + 1 = 5 \)
ดังนั้น \( \dfrac{5i}{5} = i = 0 + 1i \)
ดังนั้น ส่วนจริงคือ 0 และ ส่วนจินตภาพคือ 1
