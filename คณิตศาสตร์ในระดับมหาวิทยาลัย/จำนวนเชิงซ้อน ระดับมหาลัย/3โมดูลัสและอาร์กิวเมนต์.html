สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 3: โมดูลัสและอาร์กิวเมนต์ของจำนวนเชิงซ้อน

(Modulus and Argument of Complex Numbers & Introduction to Polar Form)

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถหาโมดูลัสและอาร์กิวเมนต์ของจำนวนเชิงซ้อน อธิบายความหมายทางเรขาคณิต และเชื่อมโยงกับการเขียนจำนวนเชิงซ้อนในรูปเชิงขั้วได้

1-5 บทสรุปสาระสำคัญทางทฤษฎี

1. โมดูลัส (Modulus: \(|z|\) หรือ \(r\))

คือระยะทางจากจุดกำเนิด \((0,0)\) ถึงจุด \((a, b)\) บนระนาบ

\[ |z| = \sqrt{a^2 + b^2} \]

โดยที่ \(|z| \ge 0\) เสมอ และ \(|z| = 0 \iff z = 0\)

2. อาร์กิวเมนต์ (Argument: \(\arg z\))

สำหรับ \(z \neq 0\) คือมุมที่วัดทวนเข็มนาฬิกาจากแกนจริงบวก (\(+{\rm Re}\)) ไปยังเวกเตอร์ \(z\) ซึ่งมุมนี้มีได้ไม่สิ้นสุด:

\( \arg z = \theta + 360^\circ k \quad (k \in \mathbb{Z}) \)
⚠️ ข้อควรระวัง: ในกรณีจำนวนเชิงซ้อนศูนย์ \(z = 0\) จะไม่นิยามอาร์กิวเมนต์

3. การหาอาร์กิวเมนต์ในแต่ละจตุภาค

กำหนดมุมอ้างอิง \(\alpha = \arctan\left|\frac{b}{a}\right|\):

Q1 (\(a>0, b>0\)):
\(\theta = \alpha\)
Q2 (\(a<0, b>0\)):
\(\theta = 180^\circ - \alpha\)
Q3 (\(a<0, b<0\)):
\(\theta = 180^\circ + \alpha\) หรือ \(-180^\circ + \alpha\)
Q4 (\(a>0, b<0\)):
\(\theta = 360^\circ - \alpha\) หรือ \(-\alpha\)

4. อาร์กิวเมนต์หลัก (Principal Argument: \(\operatorname{Arg} z\))

นิยมกำหนดให้อยู่ในช่วงมาตรฐาน:

\( -\pi < \operatorname{Arg}(z) \le \pi \quad (\text{หรือ } -180^\circ < \theta \le 180^\circ) \)

หรือในบางตำราใช้ช่วง \([0, 2\pi) \equiv [0^\circ, 360^\circ)\)

5. การเชื่อมโยงกับรูปเชิงขั้ว (Polar Form)

เนื่องจาก \(a = r\cos\theta\) และ \(b = r\sin\theta\):

\( z = r(\cos\theta + i\sin\theta) = r\,\operatorname{cis}\theta \)

แบบจำลองระนาบเชิงขั้วและระนาบเชิงซ้อน (Simulator)

คลิกลากจุด หรือเลื่อนสไลเดอร์เพื่อดูการเปลี่ยนแปลงของระยะ \(r\) และมุม \(\theta\)

คำถามนำเพื่อการค้นพบ (Guided Discovery)

คลิกที่แต่ละคำถามเพื่อเปิดดูแนวคิดและคำอธิบายทางเรขาคณิต

แนวคิดคำตอบ:

อยู่บน "วงกลม" (Circle) ที่มีจุดศูนย์กลางอยู่ที่จุดกำเนิด \((0,0)\) และมีรัศมี \(r = |z|\)

\(|z| = r \iff \sqrt{a^2 + b^2} = r \iff a^2 + b^2 = r^2\)

ซึ่งตรงกับสมการวงกลมมาตรฐานในเรขาคณิตวิเคราะห์อย่างสมบูรณ์ บนระนาบจำลองด้านบน คุณจะสังเกตเห็นเส้นประวงกลมสีฟ้าอ่อนที่หมุนผ่านจุด \(z\) เสมอ

แนวคิดคำตอบ:

ต้องพิจารณา เครื่องหมายของส่วนจริง (\(a\)) และส่วนจินตภาพ (\(b\)) เพื่อระบุจตุภาคที่ถูกต้อง เพราะฟังก์ชันตรีโกณมิติผกผัน (\(\arctan\)) เพียงอย่างเดียวไม่สามารถแยกความแตกต่างระหว่าง Q1 กับ Q3 หรือ Q2 กับ Q4 ได้:

  • ตัวอย่าง: \(1+i\) (\(\frac{1}{1} = 1\)) อยู่ใน Q1 ให้มุม \(45^\circ\)
  • แต่ \(-1-i\) (\(\frac{-1}{-1} = 1\)) อัตราส่วนเท่ากัน แต่อยู่ใน Q3 จึงต้องปรับเป็น \(180^\circ + 45^\circ = 225^\circ\) (หรือ \(-135^\circ\))

แนวคิดคำตอบ:

จำเป็นต้องเป็นจำนวนเดียวกันอย่างแน่นอน

เนื่องจากพิกัดเชิงขั้ว \((r, \theta)\) สามารถแปลงกลับเป็นพิกัดคาร์ทีเซียน \((a, b)\) ได้เพียงรูปแบบเดียวเสมอ ผ่านสูตร:

\(a = r\cos\theta \quad\text{และ}\quad b = r\sin\theta\)

เมื่อ \(r_1 = r_2\) และ \(\theta_1 \equiv \theta_2\) ย่อมทำให้ \(a_1 = a_2\) และ \(b_1 = b_2\) เสมอ ส่งผลให้ \(z_1 = z_2\)

2 จงหาอาร์กิวเมนต์หลัก (หน่วยองศา) ของ \(z_1 = 1 + i\) และ \(z_2 = -1 - i\)

วิธีทำ:

1. สำหรับ \(z_1 = 1 + i\): มี \(a=1, b=1\) (อยู่ใน Q1)
\(\theta = \arctan(1/1) = 45^\circ\) (หรือ \(\frac{\pi}{4}\) rad)

2. สำหรับ \(z_2 = -1 - i\): มี \(a=-1, b=-1\) (อยู่ใน Q3)
มุมอ้างอิง \(\alpha = \arctan(1) = 45^\circ\)
• หากอยู่ในช่วง \((-\pi, \pi]\): \(\theta = -180^\circ + 45^\circ = -135^\circ\) (หรือ \(-\frac{3\pi}{4}\) rad)
• หากอยู่ในช่วง \([0, 2\pi)\): \(\theta = 180^\circ + 45^\circ = 225^\circ\) (หรือ \(\frac{5\pi}{4}\) rad)

ระบบยอมรับทั้ง -135° และ 225°

โมดูลัส (\(|z|\) หรือ \(r\))
  • ความหมาย: "ขนาด" หรือระยะห่างจากจุดกำเนิด
  • ค่า: เป็นจำนวนจริงที่ไม่เป็นลบ (\(\ge 0\)) เสมอ
  • หน่วย: หน่วยความยาว
  • รูปทรง: กำหนดขนาดของวงกลม
อาร์กิวเมนต์ (\(\arg z\) หรือ \(\theta\))
  • ความหมาย: "ทิศทาง" หรือมุมที่ทำกับแกนจริงบวก
  • ค่า: มีได้อนันต์ค่าตามการวนรอบ (\(+2k\pi\))
  • หน่วย: องศา (Degrees) หรือ เรเดียน (Radians)
  • รูปทรง: กำหนดแนวเส้นรังสี (Ray) จากจุดกำเนิด
