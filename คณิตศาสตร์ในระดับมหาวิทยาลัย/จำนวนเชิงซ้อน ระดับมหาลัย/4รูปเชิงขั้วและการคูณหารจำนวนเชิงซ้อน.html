สื่อการเรียนรู้เชิงโต้ตอบ (Interactive Learning)

เรื่องที่ 4: รูปเชิงขั้วและการคูณหารจำนวนเชิงซ้อน

(Polar Form, Multiplication, and Division of Complex Numbers)

วัตถุประสงค์การเรียนรู้

นักศึกษาสามารถเปลี่ยนจำนวนเชิงซ้อนจากรูปมาตรฐานเป็นรูปเชิงขั้ว และใช้รูปเชิงขั้วในการคูณและหารจำนวนเชิงซ้อนได้อย่างถูกต้องและคล่องแคล่ว

1-5 บทสรุปสาระสำคัญทางทฤษฎี

1 & 2. ความหมายของรูปเชิงขั้ว (Polar Form)

จำนวนเชิงซ้อนที่ไม่เป็นศูนย์ \(z = a + bi\) สามารถเขียนด้วยระยะ \(r\) และมุม \(\theta\):

\[ z = r(\cos\theta + i\sin\theta) = r\,\operatorname{cis}\theta \]
\(r = |z| = \sqrt{a^2 + b^2} > 0\)
\(\tan\theta = \frac{b}{a}\)

3. การแปลงรูปมาตรฐานสู่รูปเชิงขั้ว

  • หาขนาด \(r = \sqrt{a^2 + b^2}\)
  • หามุมอาร์กิวเมนต์ \(\theta\) โดยพิจารณาเครื่องหมาย \((a, b)\) เพื่อเลือกจตุภาคที่ถูกต้อง
  • เขียนในรูป \(r(\cos\theta + i\sin\theta)\)

4. การคูณจำนวนเชิงซ้อนในรูปเชิงขั้ว

"คูณโมดูลัส นำมุมมาบวกกัน"

\[ z_1 z_2 = r_1 r_2 [\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)] \]

ในเชิงเรขาคณิต: ขนาดเวกเตอร์ถูกขยายด้วย \(r_2\) และหมุนทวนเข็มนาฬิกาไปเป็นมุม \(\theta_2\)

5. การหารจำนวนเชิงซ้อนในรูปเชิงขั้ว

"หารโมดูลัส นำมุมมาลบกัน" (เมื่อ \(z_2 \neq 0\))

\[ \frac{z_1}{z_2} = \frac{r_1}{r_2} [\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)] \]

ในเชิงเรขาคณิต: ขนาดถูกหารด้วย \(r_2\) และหมุนตามเข็มนาฬิกาเป็นมุม \(\theta_2\)

แบบจำลองเชิงขั้ว (Interactive Polar Simulator)

เลือกโหมดสำรวจ: แปลงรูปเชิงขั้วเดี่ยว หรือดำเนินการคูณ/หาร 2 จำนวน

📐 แสดงเวกเตอร์และมุมบนระนาบเชิงขั้ว
ปรับโมดูลัส \(r\) และมุม \(\theta\)
โมดูลัส \(r = |z|\) 4.0
มุม \(\theta\) (องศา) 30°
รูปเชิงขั้ว (Polar Form):
\(z = 4(\cos 30^\circ + i\sin 30^\circ)\)
แปลงเป็นรูปมาตรฐาน \(a + bi\):
เลือกการดำเนินการ:
\(z_1 = r_1 \operatorname{cis} \theta_1\) 2 cis 30°
\(r_1\): 2.0
\(\theta_1\): 30°
\(z_2 = r_2 \operatorname{cis} \theta_2\) 3 cis 40°
\(r_2\): 3.0
\(\theta_2\): 40°
ขั้นตอนและผลลัพธ์การคำนวณ (Calculation Breakdown):

คำถามนำเพื่อการค้นพบ (Guided Discovery)

คลิกที่แต่ละคำถามเพื่อเปิดดูแนวคิดและคำอธิบายทางเรขาคณิต

แนวคิดคำตอบ:

การคูณจำนวนเชิงซ้อนสองจำนวนส่งผล 2 ประการพร้อมกัน:

  • โมดูลัส (ขนาด): จะถูก คูณกัน (\(r_{\text{new}} = r_1 \times r_2\)) คือการยืดหรือหดความยาวเวกเตอร์
  • อาร์กิวเมนต์ (มุม): จะถูก นำมาบวกกัน (\(\theta_{\text{new}} = \theta_1 + \theta_2\)) เทียบเท่ากับการหมุนเวกเตอร์ทวนเข็มนาฬิกา

ดังนั้น การคูณด้วยจำนวนเชิงซ้อนจึงมีสมบัติทางเรขาคณิตเป็น "การย่อขยายขนาดพร้อมกับการหมุน" (Dilation & Rotation)

แนวคิดคำตอบ:

ไม่จำเป็นต้องเท่ากัน

เพราะโมดูลัสบ่งบอกเพียง ระยะห่างจากจุดกำเนิด (รัศมีวงกลม) เท่านั้น หากมุมอาร์กิวเมนต์ (\(\theta\)) แตกต่างกัน จุดจะอยู่คนละตำแหน่งบนเส้นรอบวงวงกลมเดียวกัน

ตัวอย่าง: \(z_1 = 3 + 4i\) และ \(z_2 = 4 + 3i\)
ทั้งสองมีขนาดเท่ากันคือ \(|z_1| = |z_2| = 5\) แต่ \(z_1 \neq z_2\) เพราะ \(\theta_1 \approx 53.13^\circ\) และ \(\theta_2 \approx 36.87^\circ\)

แนวคิดคำตอบ:

ในรูปมาตรฐาน \(a + bi\):

  • การคูณต้องกระจายถึง 4 พจน์ และแทนค่า \(i^2 = -1\)
  • การหารต้องหาคอนจูเกตมาคูณทั้งเศษและส่วน ซึ่งยุ่งยากซับซ้อน

แต่ใน รูปเชิงขั้ว การคูณและการหารเปลี่ยนเป็นเพียง การคูณ/หารตัวเลขขนาด (\(r\)) และ การบวก/ลบมุม (\(\theta\)) เท่านั้น โดยเฉพาะอย่างยิ่งเมื่อต้องยกกำลังสูงๆ เช่น \(z^{10}\) (ทฤษฎีบทเดอมัวฟวร์: \(z^n = r^n \operatorname{cis}(n\theta)\)) รูปเชิงขั้วจะรวดเร็วกว่าอย่างมหาศาล

แบบฝึกหัดสำหรับนักศึกษา (Interactive Exercises)

ฝึกเปลี่ยนรูปและดำเนินการในรูปเชิงขั้ว พร้อมตรวจคำตอบและดูเฉลยละเอียด

1 จงเขียน \(1 + i\) ในรูปเชิงขั้ว \(r(\cos\theta + i\sin\theta)\)

°
วิธีทำ:
จาก \(z = 1 + i\) จะได้ \(a = 1, b = 1\):
1. หาโมดูลัส: \(r = \sqrt{1^2 + 1^2} = \sqrt{2} \approx 1.414\)
2. หามุม: จุด \((1, 1)\) อยู่ในควอดรันต์ที่ 1 และ \(\tan\theta = \frac{1}{1} = 1 \implies \theta = 45^\circ\) (หรือ \(\frac{\pi}{4}\) rad)
ดังนั้น \(1 + i = \sqrt{2}(\cos 45^\circ + i\sin 45^\circ)\)

2 จงคำนวณ \(2(\cos 30^\circ + i\sin 30^\circ) \times 3(\cos 40^\circ + i\sin 40^\circ)\)

°
วิธีทำ:
จากสูตร \(z_1 z_2 = r_1 r_2 [\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)]\)
• ขนาดใหม่ = \(2 \times 3 = 6\)
• มุมใหม่ = \(30^\circ + 40^\circ = 70^\circ\)
ดังนั้น คำตอบคือ \(6(\cos 70^\circ + i\sin 70^\circ)\)

3 จงอธิบายว่าเหตุใดการหารจำนวนเชิงซ้อนจึงต้องมีตัวหารที่ไม่เป็นศูนย์ (\(z_2 \neq 0\))

เลือกเหตุผลที่ถูกต้องและครอบคลุมที่สุดในเชิงคณิตศาสตร์:

คำอธิบายเชิงลึก:
1. ในแง่ของโมดูลัส: สูตรการหารคือ \(\frac{r_1}{r_2}\) ถ้า \(z_2 = 0\) จะได้ \(r_2 = 0\) ซึ่งการหารด้วยศูนย์ในระบบจำนวนจริงไม่นิยาม (Undefined)
2. ในแง่ของอาร์กิวเมนต์: สำหรับจำนวนเชิงซ้อนศูนย์ \((0, 0)\) จะไม่มีทิศทางหรือมุม \(\theta_2\) ที่กำหนดได้ ทำให้ไม่สามารถหาพจน์ \(\theta_1 - \theta_2\) ได้อย่างมีความหมาย
ดังนั้น การหารจำนวนเชิงซ้อนจึงต้องกำหนดเงื่อนไข \(z_2 \neq 0\) ไว้อย่างเคร่งครัด
สื่อประกอบการสอนวิชาคณิตศาสตร์ • เรื่องที่ 4 รูปเชิงขั้วและการคูณหารจำนวนเชิงซ้อน
