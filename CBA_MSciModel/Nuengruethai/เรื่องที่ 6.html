เรื่อง เวกเตอร์ในสามมิติ

ขยายความรู้จากระบบพิกัด 2 มิติ สู่ปริภูมิ 3 มิติ การเขียนเวกเตอร์จากจุดหนึ่งไปยังอีกจุดหนึ่ง และการแยกองค์ประกอบ 3 ทิศทาง

การขยายความรู้จากเวกเตอร์ 2 มิติไปสู่ 3 มิติ

เวกเตอร์ในระบบพิกัดฉากสามมิติสามารถเขียนในรูปผลบวกเชิงเส้นของเวกเตอร์หนึ่งหน่วยมาตรฐานสามแกน $i, j, k$ ได้เป็น:

$$\vec{v} = ai + bj + ck$$

โดยที่ $a, b, c$ เป็นองค์ประกอบของเวกเตอร์ในทิศทางของแกน $X, Y, Z$ ตามลำดับ

การเขียนเวกเตอร์จากจุดเริ่มต้นถึงจุดปลาย

ถ้านักเรียนกำหนดจุดเริ่มต้นคือ $A(x_1, y_1, z_1)$ และจุดปลายคือ $B(x_2, y_2, z_2)$ ในปริภูมิสามมิติ เวกเตอร์ $\vec{AB}$ คือ:

$$\vec{AB} = (x_2 - x_1)i + (y_2 - y_1)j + (z_2 - z_1)k$$

หรือเขียนในรูปองค์ประกอบ $\vec{AB} = \Delta x\,i + \Delta y\,j + \Delta z\,k$

ขนาดของเวกเตอร์ในสามมิติ

ขนาดหรือความยาวของเวกเตอร์ $\vec{AB}$ คำนวณได้โดยการขยายทฤษฎีบทพีทาโกรัสสู่ระบบสามมิติ:

$$|\vec{AB}| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2} = \sqrt{(\Delta x)^2 + (\Delta y)^2 + (\Delta z)^2}$$

💡 จุดสำคัญ: การเชื่อมโยงมโนทัศน์จาก 2 มิติ สู่ 3 มิติ

เวกเตอร์ 3 มิติไม่ได้เป็นเรื่องใหม่ทั้งหมด แต่เป็นการขยายแนวคิดเดิมจาก 2 มิติ:
เมื่อนักเรียนกดปุ่ม "ดูแบบ 2 มิติ" (แกน $Z$ เป็นศูนย์) เวกเตอร์จะลดรูปลงเหลือเพียง $\vec{AB} = \Delta x\,i + \Delta y\,j$ และเมื่อขยายเข้าสู่ "ระบบ 3 มิติ" เราเพียงแค่บวกการเคลื่อนที่ในมิติความสูงตามแนวแกน $Z$ ($\Delta z\,k$) เพิ่มเข้ามาอีกหนึ่งทิศทางเท่านั้น

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดจุดเริ่มต้น $A(2, -1, 4)$ และจุดปลาย $B(-3, 2, 8)$ จงแสดงวิธีเขียนเวกเตอร์ $\vec{AB}$ ในรูป $ai + bj + ck$
เฉลยวิธีทำ:
จากสูตร $\vec{AB} = (x_2 - x_1)i + (y_2 - y_1)j + (z_2 - z_1)k$
แทนค่า: $\vec{AB} = (-3 - 2)i + (2 - (-1))j + (8 - 4)k$
จะได้ $\vec{AB} = -5i + 3j + 4k$
2. จากเวกเตอร์ $\vec{AB} = -5i + 3j + 4k$ ในข้อ 1 จงแสดงวิธีคำนวณหาขนาดของเวกเตอร์ $|\vec{AB}|$
เฉลยวิธีทำ:
$|\vec{AB}| = \sqrt{a^2 + b^2 + c^2} = \sqrt{(-5)^2 + 3^2 + 4^2} = \sqrt{25 + 9 + 16} = \sqrt{50} = 5\sqrt{2}\text{ หน่วย}$
3. กำหนดเวกเตอร์ $\vec{u} = 4i - 2j + 5k$ มีจุดเริ่มต้นอยู่ที่ $P(1, 3, -2)$ จงแสดงวิธีหาพิกัดของจุดปลาย $Q(x_2, y_2, z_2)$
เฉลยวิธีทำ:
เนื่องจาก $\vec{PQ} = (x_2 - 1)i + (y_2 - 3)j + (z_2 - (-2))k = 4i - 2j + 5k$
• เทียบสัมประสิทธิ์หน้า $i$: $x_2 - 1 = 4 \implies x_2 = 5$
• เทียบสัมประสิทธิ์หน้า $j$: $y_2 - 3 = -2 \implies y_2 = 1$
• เทียบสัมประสิทธิ์หน้า $k$: $z_2 + 2 = 5 \implies z_2 = 3$
ตอบ: พิกัดของจุดปลายคือ $Q(5, 1, 3)$
4. กำหนด $\vec{u} = 3i - j + 2k$ และ $\vec{v} = -i + 4j - 5k$ จงแสดงวิธีหาเวกเตอร์ $2\vec{u} + 3\vec{v}$
เฉลยวิธีทำ:
• $2\vec{u} = 2(3i - j + 2k) = 6i - 2j + 4k$
• $3\vec{v} = 3(-i + 4j - 5k) = -3i + 12j - 15k$
• นำมารวมกัน: $2\vec{u} + 3\vec{v} = (6 + (-3))i + (-2 + 12)j + (4 + (-15))k = 3i + 10j - 11k$
5. จงอธิบายเปรียบเทียบว่าการหาเวกเตอร์ $\vec{AB}$ ในระบบ 2 มิติ กับในระบบ 3 มิติ มีความเหมือนและแตกต่างกันอย่างไร
เฉลยวิธีทำ:
• ความเหมือน: ใช้หลักการเดียวกัน คือนำพิกัดจุดปลายลบด้วยพิกัดจุดเริ่มต้น ($\text{จุดปลาย} - \text{จุดเริ่มต้น}$) และหาขนาดด้วยแนวคิดทฤษฎีบทพีทาโกรัสจากผลรวมกำลังสองขององค์ประกอบ
• ความแตกต่าง: ใน 2 มิติจะมีเฉพาะองค์ประกอบตามแกน $X$ และ $Y$ ($\Delta x\,i + \Delta y\,j$) ส่วนใน 3 มิติจะมีองค์ประกอบความสูงตามแนวแกน $Z$ เพิ่มเข้ามา ($\Delta z\,k$)

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง เวกเตอร์ในสามมิติ

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. การเขียนเวกเตอร์ $\vec{AB}$ ใน 3 มิติ คำนวณผลต่างพิกัดจุดปลายลบจุดเริ่มต้น และเขียนในรูป $ai + bj + ck$ ได้ถูกต้องสมบูรณ์ เครื่องหมายแม่นยำ 100% ตั้งสูตรผลต่างได้ถูกต้อง แต่มีข้อผิดพลาดเรื่องการคิดคำนวณเครื่องหมายบวกลบเล็กน้อย ไม่เข้าใจสูตร หรือนำจุดเริ่มต้นไปลบจุดปลาย สลับพิกัดจนผลลัพธ์ผิดพลาด
2. การคำนวณขนาดเวกเตอร์ใน 3 มิติ แสดงขั้นตอนแทนค่าสูตร $|\vec{v}| = \sqrt{a^2 + b^2 + c^2}$ คิดเลขถูกต้อง ถอดกรณฑ์และระบุหน่วยครบถ้วน ใช้สูตรถูกต้อง มีข้อผิดพลาดในขั้นตอนคิดคำนวณตัวเลข หรือลืมถอดกรณฑ์ในคำตอบสุดท้าย เขียนสูตรคำนวณไม่ถูกต้อง หรือคำนวณเฉพาะในระบบ 2 มิติ
3. พีชคณิตและการดำเนินการกับเวกเตอร์ แสดงขั้นตอนการคูณสเกลาร์และบวกลบเวกเตอร์ในรูป $ai + bj + ck$ ได้อย่างเป็นระบบ ถูกต้องครบถ้วน ดำเนินการคูณสเกลาร์ได้ถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยในขั้นตอนรวมสัมประสิทธิ์ ไม่สามารถดำเนินการทางพีชคณิตกับเวกเตอร์ในระบบ 3 มิติได้
4. การเชื่อมโยงมโนทัศน์ 2 มิติ สู่ 3 มิติ อธิบายเปรียบเทียบความเหมือนและความแตกต่างของเวกเตอร์ใน 2 มิติ และ 3 มิติ ได้อย่างชัดเจนและมีเหตุผล อธิบายความเหมือนและความแตกต่างได้ แต่ยังระบุเหตุผลเชื่อมโยงเชิงมิติสัมพันธ์ไม่สมบูรณ์ ไม่สามารถอธิบายความเชื่อมโยงระหว่างเวกเตอร์ 2 มิติ และ 3 มิติได้
