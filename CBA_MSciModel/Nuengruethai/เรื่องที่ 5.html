เรื่อง ระบบพิกัดสามมิติ

ทำความเข้าใจปริภูมิสามมิติ แกนอ้างอิง การกำหนดพิกัดจุด และการเชื่อมโยงกับระนาบพิกัดฉาก

แกนพิกัดฉากและระนาบในระบบสามมิติ

นักเรียนทำความเข้าใจระบบพิกัดฉากสามมิติ ซึ่งประกอบด้วยแกนที่ตั้งฉากซึ่งกันและกัน 3 แกน คือ แกน $X$, แกน $Y$ และ แกน $Z$ โดยตัดกันที่จุดกำเนิด $O(0, 0, 0)$ และตำแหน่งของจุดใด ๆ ในปริภูมิสามมิติจะระบุด้วยสามสิ่งอันดับ (Ordered Triple) เขียนเป็น:

$$P(x, y, z)$$
📌 ประเด็นสำคัญที่นักเรียนต้องทำความเข้าใจ:
ตำแหน่งในระบบ 3 มิติต้องพิจารณา "ความลึก" (Depth) ด้วย ไม่ใช่พิจารณาเพียงแค่ ซ้าย–ขวา (แกน $X$) และ ขึ้น–ลง (แกน $Z$) เท่านั้น การมีแกนทั้งสามทำให้เกิด ระนาบอ้างอิงหลัก 3 ระนาบ ที่แบ่งปริภูมิออกเป็น 8 อัฐภาค (Octants) ได้แก่:

ระนาบ $XY$ (มีสมการคือ $z = 0$)

เป็นระนาบแนวนอนที่เกิดจากแกน $X$ และแกน $Y$ ตัดกัน ทุกจุดบนระนาบนี้จะมีพิกัดความสูงเป็นศูนย์ $(x, y, 0)$

ระนาบ $YZ$ (มีสมการคือ $x = 0$)

เป็นระนาบแนวดิ่งที่เกิดจากแกน $Y$ และแกน $Z$ ตัดกัน ทุกจุดบนระนาบนี้จะไม่มีระยะขจัดตามแนวแกน $X$ นั่นคือ $(0, y, z)$

ระนาบ $XZ$ (มีสมการคือ $y = 0$)

เป็นระนาบแนวดิ่งที่เกิดจากแกน $X$ และแกน $Z$ ตัดกัน ทุกจุดบนระนาบนี้จะไม่มีความลึกตามแนวแกน $Y$ นั่นคือ $(x, 0, z)$

สร้างความเข้าใจเชิงพื้นที่ (Spatial Understanding):
• ให้นักเรียนลองกำหนดพิกัดในใจ แล้วหมุนมุมมองเพื่อดูว่าจุด $A$ ลอยอยู่สูงหรือต่ำ ลึกหรือตื้น
• สังเกตว่าเมื่อจุด $A$ มีค่า $z = 0$ จุดจะตกอยู่บน ระนาบ $XY$ พอดี และเมื่อค่า $y = 0$ จุดจะแนบติดกับ ระนาบ $XZ$
• การเปิดเส้นกล่องพิกัดฉากจะช่วยให้เห็นภาพลูกบาศก์ที่ตีกรอบจากแกน $X, Y, Z$ ไปยังจุดพิกัดจริง

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดจุด $P(4, -3, 5)$ ในระบบพิกัดฉากสามมิติ จงหาภาพฉาย (Projection) ของจุด $P$ บนระนาบ $XY$, ระนาบ $YZ$ และระนาบ $XZ$
เฉลยวิธีทำ:
• ภาพฉายบนระนาบ $XY$ (ตัดแกน $Z$ เป็นศูนย์): คือจุด $(4, -3, 0)$
• ภาพฉายบนระนาบ $YZ$ (ตัดแกน $X$ เป็นศูนย์): คือจุด $(0, -3, 5)$
• ภาพฉายบนระนาบ $XZ$ (ตัดแกน $Y$ เป็นศูนย์): คือจุด $(4, 0, 5)$
2. จงหาภาพฉายของจุด $Q(-2, 6, -4)$ ลงบน แกน $X$, แกน $Y$ และ แกน $Z$
เฉลยวิธีทำ:
• ภาพฉายบนแกน $X$ (พิกัด $y, z$ เป็นศูนย์): คือจุด $(-2, 0, 0)$
• ภาพฉายบนแกน $Y$ (พิกัด $x, z$ เป็นศูนย์): คือจุด $(0, 6, 0)$
• ภาพฉายบนแกน $Z$ (พิกัด $x, y$ เป็นศูนย์): คือจุด $(0, 0, -4)$
3. จงแสดงวิธีคำนวณหาระยะห่างระหว่างจุดกำเนิด $O(0, 0, 0)$ กับจุด $A(2, -3, 6)$ ในระบบพิกัดฉากสามมิติ
เฉลยวิธีทำ:
จากสูตรระยะห่างจากจุดกำเนิด: $d = \sqrt{x^2 + y^2 + z^2}$
แทนค่า: $d = \sqrt{2^2 + (-3)^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7\text{ หน่วย}$
4. กำหนดจุด $A(1, 2, -1)$ และจุด $B(4, -2, 3)$ จงแสดงวิธีคำนวณหาระยะทางระหว่างจุด $A$ และจุด $B$
เฉลยวิธีทำ:
จากสูตรระยะทางระหว่างสองจุดใน 3 มิติ: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$
$d = \sqrt{(4 - 1)^2 + (-2 - 2)^2 + (3 - (-1))^2} = \sqrt{3^2 + (-4)^2 + 4^2} = \sqrt{9 + 16 + 16} = \sqrt{41}\text{ หน่วย}$
5. จุด $M$ มีระยะห่างจากระนาบ $XY$ เท่ากับ $4$ หน่วย (อยู่เหนือระนาบ), ห่างจากระนาบ $XZ$ ไปทางขวา $3$ หน่วย และห่างจากระนาบ $YZ$ ไปทางด้านหน้า $2$ หน่วย จงเขียนพิกัดของจุด $M(x, y, z)$ พร้อมอธิบายความหมายของค่าแต่ละแกน
เฉลยวิธีทำ:
• ห่างจากระนาบ $YZ$ ไปทางด้านหน้า แปลว่าค่าตามแนวแกน $X$ คือ $x = 2$
• ห่างจากระนาบ $XZ$ ไปทางขวา แปลว่าค่าตามแนวแกน $Y$ คือ $y = 3$
• ห่างจากระนาบ $XY$ ไปทางด้านบน แปลว่าค่าตามแนวแกน $Z$ คือ $z = 4$
ดังนั้น พิกัดของจุดคือ $M(2, 3, 4)$

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง ระบบพิกัดสามมิติ

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจระบบแกนและพิกัด $(x, y, z)$ ระบุและอธิบายตำแหน่งของจุดใน 3 มิติ เชื่อมโยงมโนทัศน์ความลึก กว้าง สูง ได้อย่างถูกต้องแม่นยำทุกกรณี ระบุพิกัดใน 3 มิติได้ถูกต้องเป็นส่วนใหญ่ แต่สับสนทิศทางบวกลบของแกนความลึกเล็กน้อย ไม่สามารถระบุพิกัดสามมิติได้ถูกต้อง หรือสับสนลำดับของแกน $x, y, z$
2. ภาพฉายบนระนาบและบนแกนพิกัด หาจุดภาพฉายบนระนาบ $XY, YZ, XZ$ และบนแกนหลักได้อย่างถูกต้องสมบูรณ์ พร้อมเข้าใจว่าค่าใดต้องเป็นศูนย์ หาภาพฉายได้ถูกต้องเป็นส่วนใหญ่ แต่มีข้อผิดพลาดบางจุดเรื่องการกำหนดค่าคงที่ศูนย์ ไม่เข้าใจมโนทัศน์เรื่องภาพฉายบนระนาบและแกนพิกัด
3. การคำนวณระยะทางในระบบสามมิติ แสดงการแทนค่าสูตรระยะทาง $d = \sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}$ ได้ถูกต้อง ดำเนินการคิดเลขและถอดกรณฑ์ครบถ้วน ใช้สูตรระยะทางได้ถูกต้อง แต่มีข้อผิดพลาดในการคิดคำนวณตัวเลขทางพีชคณิต เขียนสูตรระยะทางไม่ถูกต้อง หรือคำนวณเฉพาะในระบบ 2 มิติ
4. ทักษะการนึกภาพเชิงมิติสัมพันธ์ (Spatial) สามารถแปลความหมายระยะห่างระหว่างจุดกับระนาบอ้างอิงเพื่อสร้างเป็นพิกัด $(x, y, z)$ ได้อย่างถูกต้องมีเหตุผล บอกพิกัดจากระยะห่างได้ แต่การอธิบายความสัมพันธ์เชิงมิติยังไม่สมบูรณ์ ไม่สามารถเชื่อมโยงระยะห่างจากระนาบเข้าสู่พิกัดของจุดได้
