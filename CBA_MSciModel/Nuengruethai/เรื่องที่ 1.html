สาระการเรียนรู้คณิตศาสตร์เพิ่มเติม

เรื่อง ความหมายและองค์ประกอบของเวกเตอร์

เรียนรู้มโนทัศน์พื้นฐาน การแทนปริมาณทางเรขาคณิตด้วยทิศทางและขนาด พร้อมเชื่อมโยงสู่เวกเตอร์บนระนาบพิกัดฉาก

เวกเตอร์และส่วนประกอบเชิงเรขาคณิต

เวกเตอร์ (Vector) เป็นปริมาณที่มีทั้ง ขนาด (Magnitude) และ ทิศทาง (Direction) สามารถแสดงด้วยสัญลักษณ์ "ลูกศร" โดยมี จุดเริ่มต้น (Initial Point) และ จุดปลาย (Terminal Point) นักเรียนทำความเข้าใจความแตกต่างระหว่างเวกเตอร์กับปริมาณสเกลาร์ และเรียนรู้การเขียนเวกเตอร์จากจุดหนึ่งไปยังอีกจุดหนึ่ง

ปริมาณสเกลาร์ (Scalar Quantity)

เป็นปริมาณที่ระบุเฉพาะ ขนาด (ตัวเลขพร้อมหน่วย) ก็ได้ใจความสมบูรณ์ ไม่ต้องบอกทิศทาง

  • ระยะทาง (Distance) เช่น $10\text{ m}$
  • มวล (Mass) เช่น $5\text{ kg}$
  • เวลา (Time) เช่น $15\text{ s}$
  • อุณหภูมิ, พื้นที่, ปริมาตร

ปริมาณเวกเตอร์ (Vector Quantity)

เป็นปริมาณที่ต้องบอกทั้ง ขนาด และ ทิศทาง จึงจะสื่อความหมายได้ครบถ้วนสมบูรณ์

  • การกระจัด (Displacement) เช่น $10\text{ m}$ ไปทางทิศเหนือ
  • ความเร็ว (Velocity) เช่น $60\text{ km/h}$ ไปทางทิศตะวันออก
  • แรง (Force) เช่น $25\text{ N}$ ผลักลงในแนวดิ่ง
  • ความเร่ง, โมเมนตัม

การเขียนเวกเตอร์จากจุดหนึ่งไปยังอีกจุดหนึ่ง

ถ้ากำหนดจุดเริ่มต้นคือ $A(x_1, y_1)$ และจุดปลายคือ $B(x_2, y_2)$ สัญลักษณ์เวกเตอร์จาก $A$ ไปยัง $B$ เขียนแทนด้วย $\vec{AB}$ โดยมี:

  • เวกเตอร์ในรูปผลบวกเชิงเส้น: $\vec{AB} = (x_2 - x_1)i + (y_2 - y_1)j = \Delta x\,i + \Delta y\,j$
  • วิธีคำนวณขนาด: $|\vec{AB}| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} = \sqrt{(\Delta x)^2 + (\Delta y)^2}$
  • วิธีคำนวณทิศทาง: หามุม $\theta$ ที่ทำกับแกน $+X$ จาก $\tan\theta = \dfrac{\Delta y}{\Delta x}$

Interactive Model: ระนาบพิกัด 2 มิติ

ลากจุด $A$ และ $B$ เพื่อสังเกตการเปลี่ยนแปลงของทิศทาง ขนาด และองค์ประกอบตามแนวแกน

1. จุดเริ่มต้น $A$ และจุดปลาย $B$
$A(-3, -2), \; B(2, 2)$
2. องค์ประกอบในแนวแกน $X$ และ $Y$
$\Delta x = 5, \; \Delta y = 4$
3. การเขียนเวกเตอร์ $\vec{u} = \vec{AB} = \Delta x\,i + \Delta y\,j$
$\vec{u} = 5i + 4j$
4. วิธีคำนวณขนาด $|\vec{u}| = \sqrt{(\Delta x)^2 + (\Delta y)^2}$
$|\vec{u}| = \sqrt{5^2 + 4^2} = \sqrt{25 + 16} = \sqrt{41} \approx 6.40\text{ หน่วย}$
5. วิธีคำนวณทิศทาง $\tan\theta = \dfrac{\Delta y}{\Delta x}$
$\tan\theta = \frac{4}{5} = 0.800 \implies \theta = \arctan(0.800) \approx 38.7^\circ$

💡 สิ่งที่นักเรียนค้นพบจากโมเดล

"เวกเตอร์ไม่ได้ขึ้นอยู่กับตำแหน่งที่วางลูกศร แต่ขึ้นอยู่กับ ขนาด และ ทิศทาง ของเวกเตอร์"
แม้ว่าเราจะเลื่อนตำแหน่งของจุดเริ่มต้น $A$ และจุดปลาย $B$ ไปอยู่ที่ใดก็ตาม หากการเปลี่ยนแปลงในแนวแกน $X$ ($\Delta x$) และแนวแกน $Y$ ($\Delta y$) ยังคงเดิม เวกเตอร์ที่ได้ก็ยังคงมีขนาดเดิมและชี้ไปในทิศทางเดิมเสมอ

ใบงานคณิตศาสตร์: เรื่อง ความหมายและองค์ประกอบของเวกเตอร์

ชื่อ-นามสกุล: ................................................................... ชั้น: ................ เลขที่: ........... วันที่: ........................

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. จงจำแนกปริมาณต่อไปนี้ว่าเป็น ปริมาณสเกลาร์ หรือ ปริมาณเวกเตอร์:

(1.1) ลมพัดด้วยอัตราเร็ว $25\text{ km/h}$ ไปทางทิศตะวันออกเฉียงเหนือ
(1.2) น้ำในแก้วมีอุณหภูมิ $28^\circ\text{C}$
(1.3) แรงผลักโต๊ะขนาด $50\text{ N}$ ในทิศขนานกับพื้นห้อง

เฉลย:
• (1.1) ปริมาณเวกเตอร์ (มีทั้งขนาด $25\text{ km/h}$ และทิศตะวันออกเฉียงเหนือ)
• (1.2) ปริมาณสเกลาร์ (มีเฉพาะขนาดอุณหภูมิ $28^\circ\text{C}$ ไม่ต้องระบุทิศทาง)
• (1.3) ปริมาณเวกเตอร์ (มีทั้งขนาดแรง $50\text{ N}$ และทิศทางขนานกับพื้นห้อง)
2. กำหนดจุด $P(2, -3)$ และจุด $Q(-4, 5)$ บนระนาบพิกัดฉาก จงแสดงวิธีทำเขียนเวกเตอร์ $\vec{PQ}$ ในรูป $ai + bj$
เฉลยวิธีทำ:
จากสูตร $\vec{PQ} = (x_Q - x_P)i + (y_Q - y_P)j$
แทนค่าพิกัด: $\vec{PQ} = (-4 - 2)i + (5 - (-3))j$
จะได้ $\vec{PQ} = -6i + 8j$
3. จากเวกเตอร์ $\vec{PQ} = -6i + 8j$ ในข้อ 2 จงแสดงวิธีทำหาขนาด $|\vec{PQ}|$ และหามุมทิศทางที่ทำกับแกน $+X$
เฉลยวิธีทำ:
1) หาขนาด: จากสูตร $|\vec{PQ}| = \sqrt{a^2 + b^2} = \sqrt{(-6)^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\text{ หน่วย}$
2) หาทิศทาง: เนื่องจาก $\Delta x = -6 < 0$ และ $\Delta y = 8 > 0$ เวกเตอร์ชี้ตกอยู่ใน Quadrant ที่ 2
หามุมอ้างอิง $\alpha$: $\tan\alpha = \left|\dfrac{8}{-6}\right| = \dfrac{4}{3} \approx 1.333 \implies \alpha \approx 53.1^\circ$
ดังนั้น ทิศทางเทียบแกน $+X$ คือ $\theta = 180^\circ - 53.1^\circ = 126.9^\circ$
4. กำหนดเวกเตอร์ $\vec{u} = 4i - 3j$ มีจุดเริ่มต้นอยู่ที่จุด $A(-1, 2)$ จงแสดงวิธีหาพิกัดของจุดปลาย $B(x_2, y_2)$
เฉลยวิธีทำ:
เนื่องจาก $\vec{AB} = (x_2 - x_1)i + (y_2 - y_1)j = 4i - 3j$
แทนค่าจุดเริ่มต้น $A(-1, 2)$ จะได้ $(x_2 - (-1))i + (y_2 - 2)j = 4i - 3j$
• เทียบสัมประสิทธิ์หน้า $i$: $x_2 + 1 = 4 \implies x_2 = 4 - 1 = 3$
• เทียบสัมประสิทธิ์หน้า $j$: $y_2 - 2 = -3 \implies y_2 = -3 + 2 = -1$
ดังนั้น พิกัดของจุดปลายคือ $B(3, -1)$
5. เวกเตอร์ $\vec{u}$ เริ่มจากจุด $(1, 1)$ ไปยัง $(4, 5)$ และเวกเตอร์ $\vec{v}$ เริ่มจากจุด $(-2, 0)$ ไปยัง $(1, 4)$ จงแสดงการคำนวณและสรุปว่า $\vec{u} = \vec{v}$ หรือไม่
เฉลยวิธีทำ:
• คำนวณเวกเตอร์ $\vec{u} = (4 - 1)i + (5 - 1)j = 3i + 4j$
  ขนาด $|\vec{u}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$ หน่วย, ทิศทาง $\tan\theta = \frac{4}{3}$
• คำนวณเวกเตอร์ $\vec{v} = (1 - (-2))i + (4 - 0)j = 3i + 4j$
  ขนาด $|\vec{v}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$ หน่วย, ทิศทาง $\tan\theta = \frac{4}{3}$
สรุป: เวกเตอร์ทั้งสองเท่ากัน ($\vec{u} = \vec{v}$) เพราะมีขนาดเท่ากัน ($5$ หน่วย) และมีทิศทางเดียวกัน ($3i + 4j$) แม้ตำแหน่งจุดเริ่มต้นจะต่างกัน

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง ความหมายและองค์ประกอบของเวกเตอร์

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจมโนทัศน์เวกเตอร์และสเกลาร์ จำแนกปริมาณสเกลาร์และเวกเตอร์ได้ถูกต้องครบถ้วน ระบุเหตุผลเชื่อมโยงขนาดและทิศทางได้ชัดเจนทุกกรณี จำแนกปริมาณได้ถูกต้องเป็นส่วนใหญ่ แต่การระบุเหตุผลเรื่องทิศทางยังคลาดเคลื่อนบางข้อ จำแนกประเภทปริมาณไม่ถูกต้อง หรือไม่สามารถระบุความแตกต่างระหว่างขนาดและทิศทางได้
2. การเขียนเวกเตอร์ในรูป $ai + bj$ แสดงวิธีทำหาผลต่างของพิกัดและเขียนในรูป $ai + bj$ ได้ถูกต้องแม่นยำ เครื่องหมายบวกลบถูกต้องสมบูรณ์ ตั้งสูตรผลต่างได้ถูกต้อง แต่มีข้อผิดพลาดเรื่องการคิดคำนวณเครื่องหมาย หรือสลับสัมประสิทธิ์หน้า $i$ และ $j$ ไม่สามารถหาผลต่างของพิกัดหรือเขียนในรูปเวกเตอร์หนึ่งหน่วย $ai + bj$ ได้ถูกต้อง
3. การแสดงวิธีคำนวณขนาดและทิศทาง แสดงขั้นตอนแทนค่าสูตร $|\vec{u}| = \sqrt{a^2 + b^2}$ และการหามุมทิศทางจาก $\tan\theta = \frac{b}{a}$ ได้ถูกต้องครบถ้วน พร้อมระบุหน่วย ใช้สูตรถูกต้อง มีข้อผิดพลาดในขั้นตอนคิดคำนวณตัวเลข หรือแสดงวิธีทำไม่ครบขั้นตอน เขียนสูตรคำนวณไม่ถูกต้อง หรือไม่มีการแสดงขั้นตอนวิธีคิดทางคณิตศาสตร์
4. การสรุปสมบัติความเท่ากันของเวกเตอร์ แสดงการคำนวณเปรียบเทียบขนาดและทิศทางชัดเจน สรุปได้ถูกต้องว่าความเท่ากันไม่ขึ้นกับจุดเริ่มต้น ระบุได้ว่าเวกเตอร์เท่ากัน แต่การแสดงวิธีทำหรือการให้เหตุผลเชิงคณิตศาสตร์ยังไม่สมบูรณ์ เข้าใจผิดว่าเวกเตอร์ต้องมีจุดเริ่มต้นและจุดปลายที่พิกัดเดียวกันเท่านั้นจึงจะเท่ากันได้
