สาระการเรียนรู้คณิตศาสตร์เพิ่มเติม

เรื่อง การบวก ลบ และคูณเวกเตอร์ด้วยสเกลาร์

เรียนรู้การดำเนินการพีชคณิตกับเวกเตอร์ พร้อมเชื่อมโยงสู่การเปลี่ยนแปลงขนาด ทิศทาง และรูปเรขาคณิต

การดำเนินการกับเวกเตอร์ทางเรขาคณิตและพีชคณิต

นักเรียนศึกษาการดำเนินการกับเวกเตอร์ ได้แก่ การบวก การลบ และการคูณเวกเตอร์ด้วยจำนวนจริง (สเกลาร์) โดยเชื่อมโยงการคำนวณเชิงตัวเลขกับการเปลี่ยนแปลงของขนาด ทิศทาง และตำแหน่งทางเรขาคณิต

การบวกเวกเตอร์ ($\vec{u} + \vec{v}$)

ทางเรขาคณิต: ใช้วิธี "หางต่อหัว" (Head-to-Tail) โดยนำจุดเริ่มต้นของ $\vec{v}$ มาต่อที่จุดปลายของ $\vec{u}$ เวกเตอร์ผลลัพธ์จะลากจากจุดเริ่มต้นของ $\vec{u}$ ไปยังจุดปลายของ $\vec{v}$
ทางพีชคณิต: ถ้านำ $\vec{u} = a_1 i + b_1 j$ และ $\vec{v} = a_2 i + b_2 j$

$$\vec{u} + \vec{v} = (a_1 + a_2)i + (b_1 + b_2)j$$

การลบเวกเตอร์ ($\vec{u} - \vec{v}$)

นิยาม: คือการบวกด้วยนิเสธของเวกเตอร์ นั่นคือ $\vec{u} - \vec{v} = \vec{u} + (-\vec{v})$
โดย $-\vec{v}$ คือเวกเตอร์ที่มีขนาดเท่าเดิมแต่ ทิศทางตรงกันข้าม ($180^\circ$)
ทางพีชคณิต:

$$\vec{u} - \vec{v} = (a_1 - a_2)i + (b_1 - b_2)j$$

การคูณด้วยสเกลาร์ ($k\vec{u}$)

เมื่อ $k$ เป็นจำนวนจริงใด ๆ:
• ถ้า $k > 0$: ขนาดเปลี่ยนเป็น $|k||\vec{u}|$ ทิศทาง เดิม
• ถ้า $k < 0$: ขนาดเปลี่ยนเป็น $|k||\vec{u}|$ ทิศทาง ตรงข้าม
ทางพีชคณิต:

$$k\vec{u} = (ka_1)i + (kb_1)j$$

Interactive Model: การดำเนินการกับเวกเตอร์

ลากปลายลูกศร $\vec{u}$ (สีน้ำเงิน) และ $\vec{v}$ (สีส้ม) แล้วเลือกโหมดเพื่อดูเรขาคณิตของการคำนวณ

$\vec{u} = 3i + 2j, \; \vec{v} = 1i + 3j$
เวกเตอร์ผลลัพธ์เชิงพีชคณิต
$\vec{u} + \vec{v} = 4i + 5j$
วิธีคำนวณทีละขั้นตอน (Step-by-Step)
$\vec{u} + \vec{v} = (3 + 1)i + (2 + 3)j = 4i + 5j$
ขนาดของผลลัพธ์
$|\vec{u} + \vec{v}| = \sqrt{4^2 + 5^2} = \sqrt{16 + 25} = \sqrt{41} \approx 6.40\text{ หน่วย}$

💡 จุดเด่นของโมเดล: สิ่งที่นักเรียนค้นพบ

"การคำนวณเปลี่ยนรูปเรขาคณิตอย่างไร"
• การบวก: การนำสัมประสิทธิ์มาบวกกัน $(a_1+a_2)i + (b_1+b_2)j$ มีความหมายเทียบเท่ากับการยกเวกเตอร์ตัวที่สองไปต่อที่ปลายของตัวแรก (หางต่อหัว)
• การลบ: เวกเตอร์ $\vec{u} - \vec{v}$ คือการบวกด้วย $-\vec{v}$ ซึ่งชี้กลับทิศ $180^\circ$
• การคูณสเกลาร์: เมื่อ $k$ เป็นลบ เวกเตอร์จะกลับทิศตรงข้ามทันที และขนาดยืด-หดตามค่าสัมบูรณ์ของ $k$

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดเวกเตอร์ $\vec{u} = 3i - 2j$ และ $\vec{v} = -5i + 6j$ จงแสดงวิธีทำหาเวกเตอร์ผลลัพธ์ $\vec{u} + \vec{v}$ และคำนวณขนาด $|\vec{u} + \vec{v}|$
เฉลยวิธีทำ:
• $\vec{u} + \vec{v} = (3 + (-5))i + (-2 + 6)j = -2i + 4j$
• หาขนาด: $|\vec{u} + \vec{v}| = \sqrt{(-2)^2 + 4^2} = \sqrt{4 + 16} = \sqrt{20} = 2\sqrt{5}\text{ หน่วย}$
2. จากเวกเตอร์ $\vec{u} = 3i - 2j$ และ $\vec{v} = -5i + 6j$ ในข้อ 1 จงแสดงวิธีทำหาเวกเตอร์ $\vec{u} - \vec{v}$ พร้อมทั้งอธิบายความหมายเชิงเรขาคณิตของการลบ
เฉลยวิธีทำ:
• $\vec{u} - \vec{v} = \vec{u} + (-\vec{v}) = (3 - (-5))i + (-2 - 6)j = 8i - 8j$
• ความหมายเชิงเรขาคณิต: คือการนำเวกเตอร์ $\vec{u}$ มาบวกกับเวกเตอร์นิเสธ $-\vec{v}$ (ซึ่งกลับทิศทาง $180^\circ$ เป็น $5i - 6j$) โดยนำหางของ $-\vec{v}$ มาต่อที่หัวของ $\vec{u}$
3. กำหนดเวกเตอร์ $\vec{w} = -4i + 3j$ จงหาเวกเตอร์ $-2\vec{w}$ พร้อมเปรียบเทียบขนาดและทิศทางของ $-2\vec{w}$ กับ $\vec{w}$
เฉลยวิธีทำ:
• $-2\vec{w} = -2(-4i + 3j) = 8i - 6j$
• เปรียบเทียบขนาด: $|\vec{w}| = \sqrt{(-4)^2 + 3^2} = 5$ หน่วย และ $|-2\vec{w}| = \sqrt{8^2 + (-6)^2} = 10$ หน่วย (มีขนาดเป็น $2$ เท่า)
• เปรียบเทียบทิศทาง: มีทิศทางตรงกันข้ามกับ $\vec{w}$ เนื่องจากสเกลาร์เป็นจำนวนลบ ($k = -2$)
4. กำหนด $\vec{a} = 2i + j$ และ $\vec{b} = -i + 4j$ จงแสดงวิธีหาเวกเตอร์ $3\vec{a} - 2\vec{b}$
เฉลยวิธีทำ:
• คำนวณ $3\vec{a} = 3(2i + j) = 6i + 3j$
• คำนวณ $2\vec{b} = 2(-i + 4j) = -2i + 8j$
• หาผลต่าง: $3\vec{a} - 2\vec{b} = (6 - (-2))i + (3 - 8)j = 8i - 5j$
5. ถ้า $\vec{u} + \vec{v} = 6i - j$ และ $\vec{u} - \vec{v} = 2i + 5j$ จงแสดงวิธีทำแก้ระบบสมการเพื่อหาเวกเตอร์ $\vec{u}$ และเวกเตอร์ $\vec{v}$
เฉลยวิธีทำ:
กำหนดเป็นสมการ (1) $\vec{u} + \vec{v} = 6i - j$ และ (2) $\vec{u} - \vec{v} = 2i + 5j$
• นำ (1) + (2): $2\vec{u} = (6 + 2)i + (-1 + 5)j = 8i + 4j \implies \vec{u} = 4i + 2j$
• แทนค่า $\vec{u}$ ใน (1): $(4i + 2j) + \vec{v} = 6i - j \implies \vec{v} = (6 - 4)i + (-1 - 2)j = 2i - 3j$
ตอบ: $\vec{u} = 4i + 2j$ และ $\vec{v} = 2i - 3j$

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง การบวก ลบ และคูณเวกเตอร์ด้วยสเกลาร์

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ทักษะการบวกและลบเวกเตอร์เชิงพีชคณิต คำนวณการบวกและลบเวกเตอร์ในรูป $ai + bj$ ได้ถูกต้องแม่นยำ 100% จัดการเครื่องหมายลบของพิกัดได้อย่างถูกต้องสมบูรณ์ ใช้สูตรบวกและลบสัมประสิทธิ์หน้า $i$ และ $j$ ได้ถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยเรื่องการคิดคำนวณเครื่องหมาย ไม่เข้าใจหลักการบวกและลบเวกเตอร์ สลับสัมประสิทธิ์หรือคำนวณผลลัพธ์ไม่ถูกต้อง
2. ความเข้าใจการคูณเวกเตอร์ด้วยสเกลาร์ กระจายสเกลาร์ $k$ เข้าคูณทุกองค์ประกอบถูกต้อง และอธิบายผลของ $k$ ต่อขนาดและทิศทาง (ตรงข้ามเมื่อ $k < 0$) ได้ชัดเจน คูณกระจายตัวเลขสเกลาร์ได้ถูกต้อง แต่อธิบายความสัมพันธ์ของทิศทางเมื่อสเกลาร์ติดลบยังไม่สมบูรณ์ ไม่สามารถคูณสเกลาร์เข้ากับเวกเตอร์ได้ หรือคูณเฉพาะองค์ประกอบใดองค์ประกอบหนึ่ง
3. การเชื่อมโยงพีชคณิตกับเรขาคณิต อธิบายมโนทัศน์หางต่อหัว การกลับทิศของเวกเตอร์นิเสธ $-\vec{v}$ และการยืด-หดของขนาดได้อย่างเป็นเหตุเป็นผล ระบุวิธีการต่อเวกเตอร์ได้ แต่ยังไม่สามารถเชื่อมโยงกับการกลับทิศทางของเวกเตอร์นิเสธได้อย่างชัดเจน ไม่เข้าใจความหมายเชิงเรขาคณิตของการบวก ลบ และการคูณด้วยสเกลาร์
4. การแก้ปัญหาและระบบสมการเวกเตอร์ แสดงขั้นตอนการรวมสมการเวกเตอร์เพื่อหาเวกเตอร์ที่ไม่ทราบค่าได้อย่างเป็นระบบ ถูกต้องแม่นยำ และครบถ้วน วางแผนแก้ระบบสมการได้ถูกต้อง แต่มีข้อผิดพลาดในขั้นตอนคิดคำนวณตัวเลขทางพีชคณิต ไม่สามารถตั้งสมการหรือดำเนินการกับระบบสมการเวกเตอร์ได้
