สาระการเรียนรู้คณิตศาสตร์เพิ่มเติม

เรื่อง เวกเตอร์ใน 2 มิติ

ศึกษาระบบพิกัดฉากสองมิติ การควบคุมองค์ประกอบเวกเตอร์ การคำนวณขนาด ทิศทาง และเตรียมความพร้อมสู่ระบบสามมิติ

เวกเตอร์ในระบบพิกัดฉากสองมิติ

เวกเตอร์ในระบบพิกัดฉากสองมิติสามารถเขียนในรูปผลบวกเชิงเส้นของเวกเตอร์หนึ่งหน่วยมาตรฐานได้เป็น:

$$\vec{u} = ai + bj$$

โดยที่ $a$ เป็น องค์ประกอบในทิศทาง $x$ (ตามเวกเตอร์หนึ่งหน่วย $i$) และ $b$ เป็น องค์ประกอบในทิศทาง $y$ (ตามเวกเตอร์หนึ่งหน่วย $j$)

การเปลี่ยนค่าองค์ประกอบ

การเปลี่ยนค่าขององค์ประกอบ $a$ และ $b$ จะทำให้ ขนาด และ ทิศทาง ของเวกเตอร์เปลี่ยนไปทันที:

  • เมื่อ $a$ เปลี่ยน: ความกว้างในแนวแกน $X$ และความลาดเอียงเทียบแนวราบจะเปลี่ยนไป
  • เมื่อ $b$ เปลี่ยน: ความสูงในแนวแกน $Y$ และความชันแนวดิ่งจะเปลี่ยนไป

สูตรการคำนวณพื้นฐาน

สำหรับเวกเตอร์ $\vec{u} = ai + bj$ ใด ๆ บนระนาบ:

  • ขนาด: $|\vec{u}| = \sqrt{a^2 + b^2}$
  • ทิศทาง: $\tan\theta = \dfrac{b}{a} \implies \theta = \arctan\left(\dfrac{b}{a}\right)$

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดเวกเตอร์ $\vec{u} = -5i + 12j$ จงระบุองค์ประกอบในแนวแกน $X$ และแกน $Y$ พร้อมแสดงวิธีคำนวณหาขนาด $|\vec{u}|$
เฉลยวิธีทำ:
• องค์ประกอบในแนวแกน $X$ คือ $a = -5$ และองค์ประกอบในแนวแกน $Y$ คือ $b = 12$
• วิธีหาขนาด: $|\vec{u}| = \sqrt{a^2 + b^2} = \sqrt{(-5)^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13\text{ หน่วย}$
2. กำหนดเวกเตอร์ $\vec{v} = 3i - 3j$ จงแสดงวิธีคำนวณหามุมทิศทาง $\theta$ ($0^\circ \le \theta < 360^\circ$) ที่เวกเตอร์ทำกับแกน $+X$
เฉลยวิธีทำ:
เนื่องจาก $a = 3 > 0$ และ $b = -3 < 0$ เวกเตอร์ชี้ตกอยู่ใน Quadrant ที่ 4
หามุมอ้างอิง $\alpha$: $\tan\alpha = \left|\dfrac{-3}{3}\right| = 1 \implies \alpha = 45^\circ$
ดังนั้น ทิศทางทำมุมกับแกน $+X$ คือ $\theta = 360^\circ - 45^\circ = 315^\circ$
3. ถ้าเวกเตอร์ $\vec{w}$ มีขนาด $8$ หน่วย และทำมุม $60^\circ$ กับแกน $+X$ ในทิศทวนเข็มนาฬิกา จงแสดงวิธีทำเขียน $\vec{w}$ ในรูป $ai + bj$
เฉลยวิธีทำ:
จากสูตร $a = |\vec{w}|\cos\theta$ และ $b = |\vec{w}|\sin\theta$
$a = 8\cos 60^\circ = 8\left(\dfrac{1}{2}\right) = 4$
$b = 8\sin 60^\circ = 8\left(\dfrac{\sqrt{3}}{2}\right) = 4\sqrt{3}$
ดังนั้น $\vec{w} = 4i + 4\sqrt{3}j$
4. หากเปลี่ยนองค์ประกอบของเวกเตอร์ $\vec{u} = 2i + 5j$ เป็น $\vec{u}' = 2i - 5j$ จงอธิบายว่าขนาดและทิศทางของเวกเตอร์เปลี่ยนแปลงอย่างไร
เฉลยวิธีทำ:
• ขนาด: เท่าเดิม เพราะ $|\vec{u}| = \sqrt{2^2 + 5^2} = \sqrt{29}$ และ $|\vec{u}'| = \sqrt{2^2 + (-5)^2} = \sqrt{29}$ หน่วย
• ทิศทาง: เปลี่ยนไป โดยเวกเตอร์จะสะท้อนข้ามแกน $X$ จากเดิมที่ชี้ขึ้นใน Quadrant 1 เปลี่ยนเป็นชี้ลงใน Quadrant 4
5. (เชื่อมโยงสู่ 3 มิติ) หากต่อยอดเวกเตอร์ใน 2 มิติ $\vec{u} = 2i + 3j$ เข้าสู่ระบบพิกัดฉาก 3 มิติ โดยมีองค์ประกอบตามแกน $Z$ เท่ากับ $6$ หน่วย (ทิศ $k$) จงเขียนเวกเตอร์ในรูป $ai + bj + ck$ พร้อมแสดงวิธีคำนวณหาขนาด
เฉลยวิธีทำ:
เขียนเวกเตอร์ใน 3 มิติได้เป็น: $\vec{u} = 2i + 3j + 6k$
วิธีคำนวณขนาด: $|\vec{u}| = \sqrt{a^2 + b^2 + c^2} = \sqrt{2^2 + 3^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7\text{ หน่วย}$

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง เวกเตอร์ใน 2 มิติ

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจองค์ประกอบในรูป $ai + bj$ ระบุองค์ประกอบในแนวแกน $X$ และ $Y$ ได้ถูกต้องครบถ้วน แปลงระหว่างองค์ประกอบและรูป $ai + bj$ ได้แม่นยำ 100% ระบุองค์ประกอบได้ถูกต้องเป็นส่วนใหญ่ แต่มีข้อผิดพลาดเรื่องเครื่องหมายบวกลบเล็กน้อย ไม่สามารถระบุองค์ประกอบตามแนวแกน หรือสับสนระหว่างสัมประสิทธิ์หน้า $i$ และ $j$
2. การแสดงวิธีคำนวณขนาดเวกเตอร์ แสดงการแทนค่าสูตร $|\vec{u}| = \sqrt{a^2 + b^2}$ ชัดเจน คิดเลขถูกต้อง ถอดกรณฑ์และระบุหน่วยครบถ้วน ใช้สูตรถูกต้อง แต่มีข้อผิดพลาดในการคิดคำนวณตัวเลข หรือลืมถอดกรณฑ์ในขั้นตอนสุดท้าย เขียนสูตรไม่ถูกต้อง หรือไม่สามารถคำนวณหาขนาดของเวกเตอร์ได้
3. การหามุมทิศทางและตรีโกณมิติ คำนวณ $\tan\theta = \frac{b}{a}$ และพิจารณาจตุภาค (Quadrant) เพื่อระบุมุมทิศทางเทียบแกน $+X$ ได้อย่างถูกต้อง คำนวณอัตราส่วนตรีโกณมิติได้ แต่ระบุจตุภาคผิดพลาด ทำให้มุมทิศทางคลาดเคลื่อน ไม่เข้าใจความสัมพันธ์ระหว่างองค์ประกอบเวกเตอร์กับฟังก์ชันแทนเจนต์
4. การเชื่อมโยงมโนทัศน์สู่ 3 มิติ เขียนเวกเตอร์ในรูป $ai + bj + ck$ และขยายสูตรหาขนาดเป็น $\sqrt{a^2 + b^2 + c^2}$ ได้อย่างถูกต้องสมบูรณ์ เขียนรูป $ai + bj + ck$ ได้ แต่มีข้อผิดพลาดในการแทนค่าหรือคำนวณขนาดใน 3 มิติ ไม่สามารถต่อยอดมโนทัศน์จาก 2 มิติเข้าสู่แกน $Z$ ในระบบพิกัดฉาก 3 มิติได้
เกณฑ์การตัดสินระดับคุณภาพ:
คะแนนรวม $10 - 12$ คะแนน = ระดับคุณภาพ ดีมาก | คะแนนรวม $7 - 9$ คะแนน = ระดับคุณภาพ ปานกลาง | คะแนนรวม $1 - 6$ คะแนน = ระดับคุณภาพ ควรปรับปรุง
