เรื่อง ขนาดและเวกเตอร์หนึ่งหน่วย

ศึกษาการวัดขนาดความยาวของเวกเตอร์ และการสร้างเวกเตอร์มาตรฐานที่มีขนาดเท่ากับ 1 หน่วย พร้อมชี้ในทิศทางเดิม

มโนทัศน์ขนาดและเวกเตอร์หนึ่งหน่วย

ศึกษาขนาดของเวกเตอร์ และการสร้าง เวกเตอร์หนึ่งหน่วย (Unit Vector) ซึ่งเป็นเวกเตอร์ที่มีขนาดความยาวเท่ากับ $1$ หน่วยบริบูรณ์ และมีทิศทางชี้ไปในแนวเดียวกับเวกเตอร์เดิม

1. ในระบบ 2 มิติ

สำหรับเวกเตอร์ $\vec{v} = ai + bj$ ใด ๆ ที่ไม่เป็นเวกเตอร์ศูนย์:

  • ขนาด: $|\vec{v}| = \sqrt{a^2 + b^2}$
  • เวกเตอร์หนึ่งหน่วยในทิศทางเดียวกับ $\vec{v}$: $$\hat{v} = \frac{\vec{v}}{|\vec{v}|} = \frac{a}{|\vec{v}|}i + \frac{b}{|\vec{v}|}j$$

2. ขยายสู่ระบบ 3 มิติ

สำหรับเวกเตอร์ $\vec{v} = ai + bj + ck$ ในปริภูมิ 3 มิติ:

  • ขนาด: $|\vec{v}| = \sqrt{a^2 + b^2 + c^2}$
  • เวกเตอร์หนึ่งหน่วยในทิศทางเดียวกับ $\vec{v}$: $$\hat{v} = \frac{\vec{v}}{|\vec{v}|} = \frac{a}{|\vec{v}|}i + \frac{b}{|\vec{v}|}j + \frac{c}{|\vec{v}|}k$$

Interactive Model: เวกเตอร์เดิม $\rightarrow$ ขนาด $\rightarrow$ เวกเตอร์หนึ่งหน่วย

ลากปลายเวกเตอร์ $\vec{v}$ (สีน้ำเงิน) เพื่อสังเกตเวกเตอร์หนึ่งหน่วย $\hat{v}$ (สีชมพู ขนาด 1 หน่วย) ที่รักษาทิศทางเดิมเสมอ

เวกเตอร์ยาว $\rightarrow$ ลดขนาดลง $\rightarrow$ เหลือความยาว 1 แต่ยังชี้ทิศเดิม:
เมื่อนักเรียนทดลองเลื่อนสไลเดอร์เพื่อยืดความยาวหรือหดขนาดของเวกเตอร์ $\vec{v}$ โดยที่มุมเอียงยังคงเดิม จะพบว่า เวกเตอร์หนึ่งหน่วย $\hat{v}$ (ลูกศรสีชมพู) จะยังคงชี้ไปในทิศทางเดิมและมีความยาวเท่ากับ 1 หน่วยอยู่เสมอ และเมื่อเปิดดูในระบบ 3 มิติ จะเห็นว่ามโนทัศน์นี้ยังคงเป็นจริงบนปริภูมิสามมิติด้วยเช่นกัน

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดเวกเตอร์ $\vec{u} = -6i + 8j$ จงแสดงวิธีหาขนาด $|\vec{u}|$ และหาเวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกับ $\vec{u}$
เฉลยวิธีทำ:
• ขนาด: $|\vec{u}| = \sqrt{(-6)^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\text{ หน่วย}$
• เวกเตอร์หนึ่งหน่วยในทิศเดียวกับ $\vec{u}$: $\hat{u} = \dfrac{\vec{u}}{|\vec{u}|} = \dfrac{-6i + 8j}{10} = -\dfrac{3}{5}i + \dfrac{4}{5}j$
2. กำหนดเวกเตอร์ $\vec{v} = 5i - 12j$ จงแสดงวิธีทำหาเวกเตอร์ที่มีขนาด $1$ หน่วย แต่มี ทิศทางตรงกันข้าม กับ $\vec{v}$
เฉลยวิธีทำ:
• ขนาด: $|\vec{v}| = \sqrt{5^2 + (-12)^2} = \sqrt{25 + 144} = \sqrt{169} = 13\text{ หน่วย}$
• เวกเตอร์หนึ่งหน่วยที่มีทิศทางตรงกันข้าม คือ $-\dfrac{\vec{v}}{|\vec{v}|} = -\left(\dfrac{5i - 12j}{13}\right) = -\dfrac{5}{13}i + \dfrac{12}{13}j$
3. จงหาเวกเตอร์ที่มีขนาดเท่ากับ $7$ หน่วย และมีทิศทางเดียวกับเวกเตอร์ $\vec{w} = 3i - 4j$
เฉลยวิธีทำ:
• ขนาดของ $\vec{w}$: $|\vec{w}| = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = 5\text{ หน่วย}$
• เวกเตอร์หนึ่งหน่วยในทิศ $\vec{w}$: $\hat{w} = \dfrac{3}{5}i - \dfrac{4}{5}j$
• เวกเตอร์ขนาด $7$ หน่วยในทิศเดียวกัน คือ $7\hat{w} = 7\left(\dfrac{3}{5}i - \dfrac{4}{5}j\right) = \dfrac{21}{5}i - \dfrac{28}{5}j$
4. กำหนดจุดเริ่มต้น $A(1, -2)$ และจุดปลาย $B(4, 2)$ จงแสดงวิธีเขียนเวกเตอร์ $\vec{AB}$ ในรูป $ai + bj$ แล้วหาเวกเตอร์หนึ่งหน่วยของ $\vec{AB}$
เฉลยวิธีทำ:
• $\vec{AB} = (4 - 1)i + (2 - (-2))j = 3i + 4j$
• ขนาด $|\vec{AB}| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5\text{ หน่วย}$
• เวกเตอร์หนึ่งหน่วย คือ $\dfrac{\vec{AB}}{|\vec{AB}|} = \dfrac{3}{5}i + \dfrac{4}{5}j$
5. (ระบบ 3 มิติ) กำหนดเวกเตอร์ใน 3 มิติ $\vec{r} = 2i - 3j + 6k$ จงแสดงวิธีหาขนาด $|\vec{r}|$ และเวกเตอร์หนึ่งหน่วย $\hat{r}$
เฉลยวิธีทำ:
• ขนาด: $|\vec{r}| = \sqrt{a^2 + b^2 + c^2} = \sqrt{2^2 + (-3)^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7\text{ หน่วย}$
• เวกเตอร์หนึ่งหน่วย: $\hat{r} = \dfrac{\vec{r}}{|\vec{r}|} = \dfrac{2i - 3j + 6k}{7} = \dfrac{2}{7}i - \dfrac{3}{7}j + \dfrac{6}{7}k$

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง ขนาดและเวกเตอร์หนึ่งหน่วย

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. การคำนวณขนาดของเวกเตอร์ แทนค่าในสูตร $|\vec{v}| = \sqrt{a^2 + b^2}$ (และ 3 มิติ) คำนวณตัวเลข ถอดกรณฑ์ที่สอง และระบุหน่วยได้ถูกต้องสมบูรณ์ 100% ใช้สูตรถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยในขั้นตอนยกกำลังสอง หรือคิดเลขผิดพลาดบางจุด เขียนสูตรไม่ถูกต้อง หรือไม่เข้าใจความเชื่อมโยงกับทฤษฎีบทพีทาโกรัส
2. การสร้างเวกเตอร์หนึ่งหน่วย ($\hat{v}$) นำเวกเตอร์มาหารด้วยขนาดของตนเอง $\frac{\vec{v}}{|\vec{v}|}$ ได้ถูกต้อง แยกสัมประสิทธิ์หน้า $i, j, k$ ชัดเจน เครื่องหมายถูกต้องทั้งหมด เข้าใจสูตรเวกเตอร์หนึ่งหน่วย แต่มีข้อผิดพลาดในการทอนเศษส่วน หรือเครื่องหมายบวกลบสับสน ไม่สามารถสร้างเวกเตอร์หนึ่งหน่วยได้ หรือนำเวกเตอร์ไปคูณกับขนาดแทนการหาร
3. การประยุกต์ทิศทางและขนาดที่กำหนด หาเวกเตอร์ทิศตรงข้าม ($-\hat{v}$) และเวกเตอร์ที่มีขนาดตามที่กำหนด ($c\hat{v}$) ได้อย่างถูกต้องเป็นขั้นตอนชัดเจน คำนวณเวกเตอร์หนึ่งหน่วยได้ แต่นำไปคูณขยายขนาดหรือกลับทิศทางยังคลาดเคลื่อนเล็กน้อย ไม่เข้าใจมโนทัศน์การขยายขนาดจากเวกเตอร์หนึ่งหน่วย
4. การต่อยอดสู่ระบบพิกัด 3 มิติ ขยายแนวคิดการหาขนาดและเวกเตอร์หนึ่งหน่วยจาก 2 มิติ เข้าสู่รูป $ai + bj + ck$ ได้อย่างถูกต้องสมบูรณ์ เขียนสูตรใน 3 มิติได้ แต่มีข้อผิดพลาดในการคิดคำนวณตัวเลขของแกน $Z$ ไม่สามารถเชื่อมโยงและขยายมโนทัศน์เข้าสู่ปริภูมิ 3 มิติได้
