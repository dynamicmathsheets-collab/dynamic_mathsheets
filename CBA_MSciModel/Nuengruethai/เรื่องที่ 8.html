เรื่อง ผลคูณเชิงเวกเตอร์และการประยุกต์

ศึกษาผลคูณเชิงเวกเตอร์ (Cross Product) เวกเตอร์ตั้งฉาก การหาพื้นที่ของรูปเรขาคณิต และการประยุกต์ในสามมิติ

ผลคูณเชิงเวกเตอร์ (Cross Product) และความหมายทางเรขาคณิต

ผลคูณเชิงเวกเตอร์ หรือ ครอสโพรดักต์ (Cross Product) ระหว่างเวกเตอร์ $\vec{u}$ และ $\vec{v}$ เขียนแทนด้วย $\vec{u} \times \vec{v}$ จะให้ผลลัพธ์เป็น เวกเตอร์ใหม่ ที่มีทิศทาง ตั้งฉากกับทั้ง $\vec{u}$ และ $\vec{v}$ (ตั้งฉากกับระนาบที่เกิดจากเวกเตอร์ทั้งสอง) โดยทิศทางเป็นไปตาม กฎมือขวา (Right-Hand Rule)

$$|\vec{u} \times \vec{v}| = |\vec{u}||\vec{v}|\sin\theta$$

ขนาดของ $\vec{u} \times \vec{v}$ จะเท่ากับ พื้นที่ของรูปสี่เหลี่ยมด้านขนาน ที่มี $\vec{u}$ และ $\vec{v}$ เป็นด้านประกอบ

การคำนวณผ่านดีเทอร์มิแนนต์

ถ้า $\vec{u} = u_1 i + u_2 j + u_3 k$ และ $\vec{v} = v_1 i + v_2 j + v_3 k$ จะคำนวณได้จาก:

$$\vec{u} \times \vec{v} = (u_2 v_3 - u_3 v_2)i - (u_1 v_3 - u_3 v_1)j + (u_1 v_2 - u_2 v_1)k$$

สมบัติสำคัญและการประยุกต์

  • สมบัติการสลับที่: $\vec{u} \times \vec{v} = -(\vec{v} \times \vec{u})$ (ทิศทางกลับด้าน $180^\circ$)
  • เวกเตอร์ขนานกัน: ถ้า $\vec{u}$ ขนานกับ $\vec{v}$ ($\theta = 0^\circ$ หรือ $180^\circ$) จะได้ $\mathbf{\vec{u} \times \vec{v} = \vec{0}}$
  • พื้นที่สามเหลี่ยม: $\text{พื้นที่} = \dfrac{1}{2}|\vec{u} \times \vec{v}|$

💡 ข้อค้นพบสำคัญจากโมเดล 3 มิติ

1. ทิศทางของผลคูณเชิงเวกเตอร์ (Cross Product): ลูกศรสีชมพู $\vec{u} \times \vec{v}$ จะชี้ ตั้งฉาก $90^\circ$ กับระนาบสี่เหลี่ยมด้านขนานเสมอ เมื่อสลับเป็น $\vec{v} \times \vec{u}$ ลูกศรจะชี้กลับทิศ $180^\circ$ ทันทีตามกฎมือขวา
2. เมื่อเวกเตอร์ทั้งสองขนานกัน ($\vec{u} \parallel \vec{v}$): เวกเตอร์ทั้งสองจะทับกัน ไม่สามารถเกิดระนาบสี่เหลี่ยมด้านขนานได้ (พื้นที่เป็น 0) ส่งผลให้ $\mathbf{\vec{u} \times \vec{v} = \vec{0}}$ (เวกเตอร์ศูนย์)

ใบงานตรวจสอบความเข้าใจ (5 ข้อ)

1. กำหนดเวกเตอร์ $\vec{u} = 2i + j - k$ และ $\vec{v} = i - 3j + 2k$ จงแสดงวิธีหาผลคูณเชิงเวกเตอร์ $\vec{u} \times \vec{v}$
เฉลยวิธีทำ:
$\vec{u} \times \vec{v} = \begin{vmatrix} i & j & k \\ 2 & 1 & -1 \\ 1 & -3 & 2 \end{vmatrix}$
• สัมประสิทธิ์หน้า $i$: $(1)(2) - (-1)(-3) = 2 - 3 = -1$
• สัมประสิทธิ์หน้า $j$: $-[(2)(2) - (-1)(1)] = -[4 - (-1)] = -5$
• สัมประสิทธิ์หน้า $k$: $(2)(-3) - (1)(1) = -6 - 1 = -7$
ดังนั้น $\vec{u} \times \vec{v} = -i - 5j - 7k$
2. จากเวกเตอร์ $\vec{u} \times \vec{v} = -i - 5j - 7k$ ในข้อ 1 จงหาเวกเตอร์ $\vec{v} \times \vec{u}$ โดยอาศัยสมบัติของผลคูณเชิงเวกเตอร์
เฉลยวิธีทำ:
จากสมบัติการสลับที่ของผลคูณเชิงเวกเตอร์: $\vec{v} \times \vec{u} = -(\vec{u} \times \vec{v})$
จะได้ $\vec{v} \times \vec{u} = -(-i - 5j - 7k) = i + 5j + 7k$
3. จงแสดงวิธีคำนวณหาพื้นที่ของรูปสี่เหลี่ยมด้านขนานที่มีด้านประชิดเป็นเวกเตอร์ $\vec{u} = 3i - 2j + k$ และ $\vec{v} = 0i + 4j - 3k$
เฉลยวิธีทำ:
1) คำนวณ $\vec{u} \times \vec{v} = [(-2)(-3) - (1)(4)]i - [(3)(-3) - (1)(0)]j + [(3)(4) - (-2)(0)]k = 2i + 9j + 12k$
2) หาขนาด $|\vec{u} \times \vec{v}| = \sqrt{2^2 + 9^2 + 12^2} = \sqrt{4 + 81 + 144} = \sqrt{229} \approx 15.13$
ตอบ: พื้นที่ของรูปสี่เหลี่ยมด้านขนานเท่ากับ $\sqrt{229}$ ตารางหน่วย (หรือประมาณ $15.13$ ตารางหน่วย)
4. กำหนดจุดยอดสามจุดของรูปสามเหลี่ยมในปริภูมิสามมิติคือ $A(1, 0, 1), B(2, 2, 0)$ และ $C(0, 3, 2)$ จงแสดงวิธีหาพื้นที่ของรูปสามเหลี่ยม $ABC$
เฉลยวิธีทำ:
• $\vec{AB} = (2 - 1)i + (2 - 0)j + (0 - 1)k = i + 2j - k$
• $\vec{AC} = (0 - 1)i + (3 - 0)j + (2 - 1)k = -i + 3j + k$
• $\vec{AB} \times \vec{AC} = [(2)(1) - (-1)(3)]i - [(1)(1) - (-1)(-1)]j + [(1)(3) - (2)(-1)]k = 5i - 0j + 5k$
• $|\vec{AB} \times \vec{AC}| = \sqrt{5^2 + 0^2 + 5^2} = \sqrt{50} = 5\sqrt{2}$
• พื้นที่สามเหลี่ยม $= \dfrac{1}{2}|\vec{AB} \times \vec{AC}| = \dfrac{5\sqrt{2}}{2}$ ตารางหน่วย
5. กำหนดเวกเตอร์ $\vec{u} = 2i - 4j + 6k$ และ $\vec{v} = -i + 2j - 3k$ จงแสดงการคำนวณและอธิบายว่าเวกเตอร์ทั้งสองขนานกันหรือไม่
เฉลยวิธีทำ:
• คำนวณ $\vec{u} \times \vec{v} = [(-4)(-3) - (6)(2)]i - [(2)(-3) - (6)(-1)]j + [(2)(2) - (-4)(-1)]k$
$\vec{u} \times \vec{v} = (12 - 12)i - (-6 + 6)j + (4 - 4)k = 0i + 0j + 0k = \vec{0}$
ตอบ: เวกเตอร์ทั้งสองขนานกัน เนื่องจากผลคูณเชิงเวกเตอร์ $\vec{u} \times \vec{v} = \vec{0}$ (หรือสังเกตว่า $\vec{u} = -2\vec{v}$)

เกณฑ์การประเมินใบงาน (Scoring Rubric - 3 ระดับ)

การวัดและประเมินผลทักษะกระบวนการคิดทางคณิตศาสตร์ เรื่อง ผลคูณเชิงเวกเตอร์และการประยุกต์

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 3 คะแนน) ระดับ 2 (พอใช้ : 2 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. การคำนวณผลคูณเชิงเวกเตอร์ ($\vec{u} \times \vec{v}$) ตั้งดีเทอร์มิแนนต์และคำนวณผลคูณในรูป $ai + bj + ck$ ได้อย่างถูกต้องแม่นยำ จัดการเครื่องหมายลบของพิกัดถูกต้อง 100% ตั้งดีเทอร์มิแนนต์ถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยเรื่องการคิดคำนวณเครื่องหมาย (โดยเฉพาะหน้าแกน $j$) ไม่เข้าใจสูตรผลคูณเชิงเวกเตอร์ หรือคำนวณสมาชิกผิดพลาดอย่างมีนัยสำคัญ
2. การประยุกต์หาพื้นที่รูปเรขาคณิต แสดงขั้นตอนหาเวกเตอร์ประกอบ คำนวณขนาด $|\vec{u} \times \vec{v}|$ เพื่อหาพื้นที่สี่เหลี่ยมด้านขนานและสามเหลี่ยมได้อย่างถูกต้องสมบูรณ์ ใช้สูตรถูกต้อง แต่มีข้อผิดพลาดในขั้นตอนหาขนาดเวกเตอร์ หรือลืมหารสองในกรณีหาพื้นที่สามเหลี่ยม ไม่ทราบความสัมพันธ์ระหว่างขนาดของผลคูณเชิงเวกเตอร์กับพื้นที่ของรูปเรขาคณิต
3. การตรวจสอบเวกเตอร์ขนาน ($\vec{u} \times \vec{v} = \vec{0}$) แสดงการคำนวณและอธิบายสมบัติการขนานกันของเวกเตอร์ผ่านเงื่อนไข $\vec{u} \times \vec{v} = \vec{0}$ ได้อย่างเป็นเหตุเป็นผล คำนวณผลคูณได้เป็นเวกเตอร์ศูนย์ แต่การอธิบายเชื่อมโยงกับสมบัติการขนานยังไม่ชัดเจน ไม่สามารถระบุได้ว่าเวกเตอร์ขนานกันเมื่อผลคูณเชิงเวกเตอร์เท่ากับเวกเตอร์ศูนย์
4. ทักษะความเข้าใจเชิงมิติและทิศทาง เข้าใจกฎมือขวา อธิบายสมบัติการสลับที่ $\vec{v} \times \vec{u} = -(\vec{u} \times \vec{v})$ และการตั้งฉากกับระนาบได้อย่างถูกต้อง บอกทิศทางการสลับที่ได้ แต่ยังมีข้อผิดพลาดเรื่องการระบุเวกเตอร์นิเสธ ไม่เข้าใจมโนทัศน์เรื่องทิศทางและเวกเตอร์ตั้งฉากของผลคูณเชิงเวกเตอร์
