ด้านความรู้ (K) ระดับ: ง่าย
ผลลัพธ์การเรียนรู้ (LO): เข้าใจและระบุค่าของหน่วยจินตภาพและสมบัติการยกกำลังของ $i$ ได้
ข้อที่ 1. ค่าของ $i^{2567} + i^{2568}$ มีค่าตรงกับข้อใดต่อไปนี้
ก. $0$
ข. $1 - i$
ค. $-1 + i$
ง. $1 + i$
เฉลยละเอียด: ข้อ ค. ($1 - i$) — แก้ไขเป็น ข.
พิจารณาเศษจากการหารด้วย 4:
- $2567 \div 4 = 641$ เศษ $3 \implies i^{2567} = i^3 = -i$
- $2568 \div 4 = 642$ เศษ $0 \implies i^{2568} = i^0 = 1$
ดังนั้น $i^{2567} + i^{2568} = -i + 1 = 1 - i$
คำตอบที่ถูกต้องคือ ข้อ ข.
ด้านความรู้ (K) ระดับ: ง่าย
ผลลัพธ์การเรียนรู้ (LO): บอกความหมาย สมบัติของสังยุคและค่าสัมบูรณ์ของจำนวนเชิงซ้อนได้
ข้อที่ 2. กำหนดจำนวนเชิงซ้อน $z = 3 - 4i$ ข้อความใดต่อไปนี้ไม่ถูกต้อง
ก. สังยุคของ $z$ คือ $\bar{z} = 3 + 4i$
ข. ค่าสัมบูรณ์ $|z| = 5$
ค. ผลคูณ $z \cdot \bar{z} = 25$
ง. ส่วนจินตภาพของ $z$ คือ $\operatorname{Im}(z) = -4i$
เฉลยละเอียด: ข้อ ง.
นิยามส่วนจินตภาพของ $z = a + bi$ คือสัมประสิทธิ์หน้า $i$ ซึ่งเป็นจำนวนจริง นั่นคือ $\operatorname{Im}(z) = b = -4$ ไม่ใช่ $-4i$ จึงเป็นข้อความที่ไม่ถูกต้อง
ด้านความรู้ (K) ระดับ: ปานกลาง
ผลลัพธ์การเรียนรู้ (LO): อธิบายโครงสร้างและความสัมพันธ์ของรูปเชิงขั้วของจำนวนเชิงซ้อนได้
ข้อที่ 3. ถ้า $z = r(\cos\theta + i\sin\theta)$ เป็นรูปเชิงขั้วของจำนวนเชิงซ้อน $z \neq 0$ ข้อใดสรุปเงื่อนไขและสมบัติได้ถูกต้องสมบูรณ์
ก. $r$ สามารถเป็นจำนวนจริงใด ๆ และ $\tan\theta = \frac{a}{b}$
ข. $r = |z| > 0$ เสมอ และอาร์กิวเมนต์หลัก $\theta \in (-\pi, \pi]$ หรือ $[0, 2\pi)$
ค. $\bar{z} = r(\cos\theta - i\sin\theta)$ ซึ่งไม่ใช่รูปเชิงขั้วมาตรฐาน
ง. $z^{-1} = r(\cos(-\theta) + i\sin(-\theta))$
เฉลยละเอียด: ข้อ ข.
ตามนิยามรูปเชิงขั้ว $r = |z| = \sqrt{a^2+b^2}$ เป็นระยะทางจึงต้องมีค่าเป็นบวกเสมอ ($r > 0$) และอาร์กิวเมนต์หลัก (Principal Argument) ถูกกำหนดอยู่ในช่วง $(-\pi, \pi]$ หรือ $[0, 2\pi)$ ส่วนตัวเลือกอื่นผิด: ตัวเลือก ก. $r$ ต้องไม่เป็นลบ, ตัวเลือก ง. ขนาดต้องเป็น $\frac{1}{r}$
ด้านความรู้ (K) ระดับ: ปานกลาง
ผลลัพธ์การเรียนรู้ (LO): ระบุเงื่อนไขของทฤษฎีบทรากคู่สังยุคสำหรับสมการพหุนามได้
ข้อที่ 4. สมการพหุนาม $P(x) = 0$ จะมีสมบัติว่า "ถ้า $a + bi$ (เมื่อ $b \neq 0$) เป็นรากของสมการ แล้ว $a - bi$ จะต้องเป็นรากของสมการด้วยเสมอ" ภายใต้เงื่อนไขใดต่อไปนี้
ก. สัมประสิทธิ์ทุกตัวของ $P(x)$ ต้องเป็นจำนวนเต็มเท่านั้น
ข. สัมประสิทธิ์ทุกตัวของ $P(x)$ ต้องเป็นจำนวนจริง
ค. ดีกรีของ $P(x)$ ต้องเป็นจำนวนคู่เท่านั้น
ง. เป็นจริงสำหรับสมการพหุนามทุกสมการโดยไม่มีเงื่อนไขของสัมประสิทธิ์
เฉลยละเอียด: ข้อ ข.
ทฤษฎีบทรากคู่สังยุค (Complex Conjugate Root Theorem) บังคับเงื่อนไขสำคัญคือ **สัมประสิทธิ์ทุกตัวของพหุนามต้องเป็นจำนวนจริง** (Real Coefficients) หากสัมประสิทธิ์บางตัวเป็นจำนวนเชิงซ้อน เช่น $x - i = 0$ จะมีรากคือ $i$ แต่ $-i$ ไม่ได้เป็นราก
ด้านความรู้ (K) ระดับ: ยาก
ผลลัพธ์การเรียนรู้ (LO): อธิบายทฤษฎีบทรากที่ $n$ และสมบัติการกระจายตัวของรากบนระนาบเชิงซ้อนได้
ข้อที่ 5. ให้ $z \neq 0$ เป็นจำนวนเชิงซ้อนใด ๆ และ $n$ เป็นจำนวนเต็มบวกที่มากกว่า 2 ข้อความใดเกี่ยวกับรากที่ $n$ ทั้งหมดของ $z$ เป็นจริงเสมอ
ก. มีรากอย่างน้อย 1 รากที่เป็นจำนวนจริงเสมอ
ข. ผลบวกของรากที่ $n$ ทั้งหมดของ $z$ จะมีค่าเท่ากับ $0$ เสมอ
ค. ผลคูณของรากที่ $n$ ทั้งหมดของ $z$ จะมีค่าเท่ากับ $z$ เสมอ
ง. จุดยอดของรากที่ $n$ จะเกิดเป็นรูปหลายเหลี่ยมที่แนบในวงกลมที่มีรัศมีเท่ากับ $|z|$
เฉลยละเอียด: ข้อ ข.
ผลบวกของรากที่ $n$ ทั้งหมดของจำนวนเชิงซ้อนใด ๆ ($n \ge 2$) มีค่าเท่ากับ $0$ เสมอ ($\sum_{k=0}^{n-1} z_k = 0$) ตามสมบัติของจุดศูนย์ถ่วงของรูปหลายเหลี่ยมด้านเท่ามุมเท่าที่มีจุดศูนย์กลางที่ $(0,0)$ หรือวิเคราะห์จากสมการ $w^n - z = 0$ ซึ่งสัมประสิทธิ์ของพจน์ $w^{n-1}$ เป็น $0$
(ตัวเลือก ง. ผิดเพราะรัศมีต้องเท่ากับ $\sqrt[n]{|z|}$ ไม่ใช่ $|z|$)
ด้านทักษะกระบวนการ (P) ระดับ: ง่าย
ผลลัพธ์การเรียนรู้ (LO): ดำเนินการคำนวณบวก ลบ คูณ และหารจำนวนเชิงซ้อนในรูปมาตรฐานได้
ข้อที่ 6. จงหาผลลัพธ์ของ $\dfrac{2 + 4i}{1 - i}$ ให้อยู่ในรูปมาตรฐาน $a + bi$
ก. $-1 + 3i$
ข. $1 + 3i$
ค. $-1 + 2i$
ง. $3 + 3i$
เฉลยละเอียด: ข้อ ก.
คูณด้วยสังยุคของตัวส่วนทั้งเศษและส่วน:
$\dfrac{2 + 4i}{1 - i} = \dfrac{(2 + 4i)(1 + i)}{(1 - i)(1 + i)} = \dfrac{2 + 2i + 4i + 4i^2}{1 - i^2} = \dfrac{2 + 6i - 4}{1 - (-1)} = \dfrac{-2 + 6i}{2} = -1 + 3i$
ด้านทักษะกระบวนการ (P) ระดับ: ปานกลาง
ผลลัพธ์การเรียนรู้ (LO): แปลงจำนวนเชิงซ้อนในรูป $a+bi$ เป็นรูปเชิงขั้วได้อย่างถูกต้องตามควอดแรนต์
ข้อที่ 7. รูปเชิงขั้วของจำนวนเชิงซ้อน $z = -\sqrt{3} - i$ มีค่าตรงกับข้อใดต่อไปนี้
ก. $2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)$
ข. $2\left(\cos\dfrac{5\pi}{6} + i\sin\dfrac{5\pi}{6}\right)$
ค. $2\left(\cos\dfrac{7\pi}{6} + i\sin\dfrac{7\pi}{6}\right)$
ง. $4\left(\cos\dfrac{7\pi}{6} + i\sin\dfrac{7\pi}{6}\right)$
เฉลยละเอียด: ข้อ ค.
1. หาขนาด: $r = \sqrt{(-\sqrt{3})^2 + (-1)^2} = \sqrt{3 + 1} = 2$
2. หามุม: $a = -\sqrt{3} < 0$ และ $b = -1 < 0$ จุดตกใน ควอดแรนต์ที่ 3
มุมอ้างอิง $\tan\alpha = \left|\frac{-1}{-\sqrt{3}}\right| = \frac{1}{\sqrt{3}} \implies \alpha = \frac{\pi}{6}$ ($30^\circ$)
มุมจริง $\theta = \pi + \frac{\pi}{6} = \frac{7\pi}{6}$ ($210^\circ$)
ดังนั้น $z = 2\left(\cos\dfrac{7\pi}{6} + i\sin\dfrac{7\pi}{6}\right)$
ด้านทักษะกระบวนการ (P) ระดับ: ปานกลาง
ผลลัพธ์การเรียนรู้ (LO): ประยุกต์ใช้ทฤษฎีบทเดอมัวฟร์คำนวณการยกกำลังของจำนวนเชิงซ้อนได้
ข้อที่ 8. จงหาค่าของ $(1 + \sqrt{3}i)^6$ ในรูปมาตรฐาน $a + bi$
ก. $-64$
ข. $64$
ค. $64i$
ง. $-64i$
เฉลยละเอียด: ข้อ ข.
1. แปลง $1 + \sqrt{3}i$ เป็นเชิงขั้ว: $r = \sqrt{1^2 + (\sqrt{3})^2} = 2$, $\theta = 60^\circ$ ($Q_1$)
จะได้ $1 + \sqrt{3}i = 2(\cos 60^\circ + i\sin 60^\circ)$
2. ใช้สูตรเดอมัวฟร์ $z^6 = 2^6 [\cos(6 \times 60^\circ) + i\sin(6 \times 60^\circ)] = 64(\cos 360^\circ + i\sin 360^\circ)$
เนื่องจาก $\cos 360^\circ = 1$ และ $\sin 360^\circ = 0$
ดังนั้น $(1 + \sqrt{3}i)^6 = 64(1 + 0i) = 64$
ด้านทักษะกระบวนการ (P) ระดับ: ยาก
ผลลัพธ์การเรียนรู้ (LO): แก้สมการพหุนามและหาเซตคำตอบทั้งรากจริงและรากเชิงซ้อนได้
ข้อที่ 9. เซตคำตอบของสมการพหุนาม $x^3 - 2x^2 + 9x - 18 = 0$ ในระบบจำนวนเชิงซ้อนคือข้อใด
ก. $\{2, 3i, -3i\}$
ข. $\{-2, 3i, -3i\}$
ค. $\{2, 3, -3\}$
ง. $\{2, \sqrt{3}i, -\sqrt{3}i\}$
เฉลยละเอียด: ข้อ ก.
แยกตัวประกอบโดยการจัดกลุ่ม:
$x^2(x - 2) + 9(x - 2) = 0 \implies (x - 2)(x^2 + 9) = 0$
- จาก $x - 2 = 0 \implies x = 2$
- จาก $x^2 + 9 = 0 \implies x^2 = -9 \implies x = \pm \sqrt{-9} = \pm 3i$
ดังนั้น เซตคำตอบคือ $\{2, 3i, -3i\}$
ด้านทักษะกระบวนการ (P) ระดับ: ยาก
ผลลัพธ์การเรียนรู้ (LO): คำนวณหารากที่ $n$ ทั้งหมดของจำนวนเชิงซ้อนได้อย่างเป็นระบบ
ข้อที่ 10. รากที่ 3 ทั้งหมดของจำนวนเชิงซ้อน $z = -27i$ มีค่าตรงกับข้อใดต่อไปนี้
ก. $3(\cos 30^\circ + i\sin 30^\circ), 3(\cos 150^\circ + i\sin 150^\circ), 3(\cos 270^\circ + i\sin 270^\circ)$
ข. $3(\cos 90^\circ + i\sin 90^\circ), 3(\cos 210^\circ + i\sin 210^\circ), 3(\cos 330^\circ + i\sin 330^\circ)$
ค. $3(\cos 60^\circ + i\sin 60^\circ), 3(\cos 180^\circ + i\sin 180^\circ), 3(\cos 300^\circ + i\sin 300^\circ)$
ง. $27(\cos 90^\circ + i\sin 90^\circ), 27(\cos 210^\circ + i\sin 210^\circ), 27(\cos 330^\circ + i\sin 330^\circ)$
เฉลยละเอียด: ข้อ ข.
1. เขียน $z = -27i$ ในรูปเชิงขั้ว: $r = 27$, $\theta = 270^\circ$ (อยู่บนแกนจินตภาพลบ)
2. คำนวณรากที่ 3 ($n=3$):
ขนาดราก: $R = \sqrt[3]{27} = 3$
มุมของราก: $\theta_k = \frac{270^\circ + k(360^\circ)}{3} = 90^\circ + k(120^\circ)$ เมื่อ $k = 0, 1, 2$
- $k = 0: \theta_0 = 90^\circ$
- $k = 1: \theta_1 = 90^\circ + 120^\circ = 210^\circ$
- $k = 2: \theta_2 = 90^\circ + 240^\circ = 330^\circ$
ดังนั้น รากทั้งสามคือ $3\operatorname{cis} 90^\circ, 3\operatorname{cis} 210^\circ, 3\operatorname{cis} 330^\circ$
ด้านเจตคติ/การให้เหตุผล (A) ระดับ: ง่าย
ผลลัพธ์การเรียนรู้ (LO): มีวิจารณญาณในการตรวจสอบความถูกต้องและข้อผิดพลาดของการใช้สมบัติกรณฑ์
ข้อที่ 11. พิจารณาขั้นตอนการให้เหตุผลทางคณิตศาสตร์ต่อไปนี้ของนักเรียนคนหนึ่ง:
$$\text{บรรทัดที่ (1): } 1 = \sqrt{1}$$ $$\text{บรรทัดที่ (2): } 1 = \sqrt{(-1)(-1)}$$ $$\text{บรรทัดที่ (3): } 1 = \sqrt{-1} \cdot \sqrt{-1}$$ $$\text{บรรทัดที่ (4): } 1 = i \cdot i = i^2 = -1 \implies 1 = -1$$ ข้อผิดพลาดเกิดขึ้นที่บรรทัดใด และเกิดจากสาเหตุใด
ก. บรรทัดที่ (2) เพราะไม่สามารถแยก $1$ เป็น $(-1)(-1)$ ได้
ข. บรรทัดที่ (3) เพราะสมบัติ $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ใช้ได้เฉพาะเมื่อ $a \ge 0$ หรือ $b \ge 0$ เท่านั้น
ค. บรรทัดที่ (4) เพราะนิยาม $i = \sqrt{-1}$ ไม่สามารถนำมาคูณกันได้
ง. บรรทัดที่ (4) เพราะ $i^2$ มีค่าเท่ากับ $1$ ไม่ใช่ $-1$
เฉลยละเอียด: ข้อ ข.
การแยกกรณฑ์ $\sqrt{a \cdot b} = \sqrt{a}\sqrt{b}$ เป็นเอกลักษณ์ที่จริงเฉพาะเมื่อ $a$ และ $b$ ไม่เป็นจำนวนลบพร้อมกันทั้งคู่ หาก $a < 0$ และ $b < 0$ จะไม่สามารถแยกกรณฑ์ในลักษณะนี้ได้ การกระทำในบรรทัดที่ (3) จึงขัดแย้งกับหลักการทางคณิตศาสตร์อย่างร้ายแรง
