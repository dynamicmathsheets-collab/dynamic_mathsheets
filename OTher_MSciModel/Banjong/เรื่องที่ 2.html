สมบัติเชิงพีชคณิตและสังยุค

ศึกษาระบบพีชคณิตของจำนวนเชิงซ้อน เอกลักษณ์ ตัวผกผัน การลบ การหาร และบทบาทอันทรงพลังของสังยุค (Conjugate)

สังยุคและบรรทัดฐาน $z\bar{z} = a^2 + b^2$ $\bar{z} = a - bi \in \mathbb{C}$

สรุปมโนทัศน์และโครงสร้างพีชคณิต

สมบัติของฟีลด์จำนวนเชิงซ้อน $(\mathbb{C}, +, \cdot)$ และสังยุค

โครงสร้างที่ 1

เอกลักษณ์ & ตัวผกผันการบวก

สำหรับทุก $z = a + bi \in \mathbb{C}$

เอกลักษณ์การบวก: $0 = 0 + 0i = (0, 0)$
ตัวผกผันการบวก: $-z = -a - bi = (-a, -b)$
$z + (-z) = 0$

การลบ: $z_1 - z_2 = z_1 + (-z_2) = (a-c) + (b-d)i$

โครงสร้างที่ 2

เอกลักษณ์ & ตัวผกผันการคูณ

สำหรับ $z = a + bi \neq 0$ ($a^2+b^2 \neq 0$)

เอกลักษณ์การคูณ: $1 = 1 + 0i = (1, 0)$
ตัวผกผันการคูณ: $z^{-1} = \frac{a - bi}{a^2 + b^2} = \frac{\bar{z}}{|z|^2}$
$z \cdot z^{-1} = 1$

มีบทบาทหลักในการนิยามการหารจำนวนเชิงซ้อน

มโนทัศน์ที่ 3

สังยุค (Complex Conjugate)

ถ้า $z = a + bi$ สังยุคของ $z$ เขียนแทนด้วย $\bar{z}$ คือ

$\bar{z} = a - bi = (a, -b)$
เปลี่ยนเครื่องหมายเฉพาะหน้าส่วนจินตภาพ

ตัวอย่าง: $\overline{4 - 3i} = 4 + 3i, \; \overline{-5i} = 5i, \; \overline{7} = 7$

สมบัติเอกลักษณ์

สมบัติผลคูณ $z \bar{z}$

เมื่อนำจำนวนเชิงซ้อนคูณกับสังยุคของตัวเอง:

$z \bar{z} = (a+bi)(a-bi)$
$z \bar{z} = a^2 + b^2 \in \mathbb{R}$
ผลลัพธ์เป็นจำนวนจริงเสมอ และ $\ge 0$

สมบัตินี้ช่วยขจัดหน่วยจินตภาพ $i$ ออกจากตัวส่วน

ทฤษฎีบท

สมบัติของสังยุค

1. $\overline{\bar{z}} = z$
2. $\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$
3. $\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$  และ  $\overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}$
4. $z + \bar{z} = 2a = 2\text{Re}(z)$
5. $z - \bar{z} = 2bi = 2i\text{Im}(z)$

กระจายผ่านการบวก ลบ คูณ หาร และยกกำลังได้

เทคนิคการคำนวณ

การหารด้วยการคูณสังยุค

การหา $\frac{z_1}{z_2}$ ให้คูณด้วย $\bar{z}_2$ ทั้งเศษและส่วน:

$\frac{z_1}{z_2} = \frac{z_1 \cdot \bar{z}_2}{z_2 \cdot \bar{z}_2} = \frac{z_1 \bar{z}_2}{c^2 + d^2}$
ทำให้ตัวส่วนกลายเป็นจำนวนจริงเสมอ

สมมูลกับการคำนวณ $z_1 \cdot z_2^{-1}$

โมเดลจำลองการทดลอง: สังยุคและการหาร

ปรับค่าสัมประสิทธิ์เพื่อสังเกตการตัดกันของพจน์จินตภาพ และเปรียบเทียบวิธีการหาร

ตัวตั้ง: $z_1 = a + bi$ $z_1 = 4 + 2i$
สังยุค $\bar{z}_1$: $4 - 2i$
ตัวหาร: $z_2 = c + di$ $z_2 = 1 - 3i$
สังยุค $\bar{z}_2$: $1 + 3i$
ชุดตัวเลขทดสอบ:

การทดลองที่ 1: ผลคูณของจำนวนเชิงซ้อนกับสังยุคของตัวเอง ($z_1 \cdot \bar{z}_1$)

การทดลองที่ 2: การหาร $\frac{z_1}{z_2}$ และการเปรียบเทียบ 2 วิธี

สรุปการเปรียบเทียบ: ทั้งสองวิธีให้ผลลัพธ์เดียวกันทุกประการ โดยวิธีสังยุคช่วยให้คำนวณง่ายขึ้นเพราะลดขั้นตอนการจำสูตรตัวผกผันการคูณ

สิ่งที่นักเรียนควรค้นพบ (Key Discovery):

“ผลคูณของจำนวนเชิงซ้อนกับสังยุคของมันมีค่าเป็นจำนวนจริงเสมอ ($z\bar{z} = a^2 + b^2 \in \mathbb{R}$) เนื่องจากพจน์ $abi$ และ $-abi$ หักล้างกันหมด และด้วยคุณสมบัตินี้ทำให้ สังยุคเป็นเครื่องมือสำคัญที่สุดในการหารจำนวนเชิงซ้อน เพื่อกำจัดหน่วยจินตภาพ $i$ ออกจากตัวส่วนให้เหลือเพียงจำนวนจริง”

ข้อ 1. กำหนด $z = 3 - 4i$ จงหาตัวผกผันการบวก $(-z)$ และตัวผกผันการคูณ $(z^{-1})$ (2 คะแนน)
$-z =$ .................................................................................................................................................................
$z^{-1} =$ ...............................................................................................................................................................
เฉลย: ตัวผกผันการบวก: $-z = -(3 - 4i) = -3 + 4i$
ตัวผกผันการคูณ: $z^{-1} = \frac{a - bi}{a^2 + b^2} = \frac{3 - (-4i)}{3^2 + (-4)^2} = \frac{3 + 4i}{9 + 16} = \frac{3 + 4i}{25} = \frac{3}{25} + \frac{4}{25}i$
ข้อ 2. กำหนด $z = -2 + 5i$ จงหาสังยุค $\bar{z}$ และคำนวณผลคูณ $z \cdot \bar{z}$ (3 คะแนน)
$\bar{z} =$ ...................................................................................................................................................................
วิธีทำ $z \cdot \bar{z} =$ ....................................................................................................................................................
เฉลย: สังยุค $\bar{z} = -2 - 5i$
คำนวณ $z \cdot \bar{z} = (-2 + 5i)(-2 - 5i) = (-2)^2 + 5^2 = 4 + 25 = 29$ (ผลลัพธ์เป็นจำนวนจริง)
ข้อ 3. จงหาผลลัพธ์ของ $\frac{4 + 2i}{1 - 3i}$ ในรูป $a + bi$ โดยใช้สังยุคของตัวส่วน (3 คะแนน)
วิธีทำ: นำสังยุคของตัวส่วน $(1 + 3i)$ คูณทั้งเศษและส่วน:
$\frac{4+2i}{1-3i} = \frac{(4+2i)(............)}{(1-3i)(............)} =$ ........................................................................................................................
เฉลย: $\frac{4+2i}{1-3i} = \frac{(4+2i)(1+3i)}{(1-3i)(1+3i)} = \frac{4 + 12i + 2i + 6i^2}{1^2 + (-3)^2} = \frac{4 + 14i - 6}{1 + 9} = \frac{-2 + 14i}{10} = -\frac{1}{5} + \frac{7}{5}i$ (หรือ $-0.2 + 1.4i$)
ข้อ 4. กำหนด $z_1 = 2 + 3i$ และ $z_2 = 1 - 2i$ จงหา $\overline{z_1 \cdot z_2}$ และเปรียบเทียบกับ $\bar{z}_1 \cdot \bar{z}_2$ (3 คะแนน)
$z_1 \cdot z_2 = (2+3i)(1-2i) = $ ...................................... ดังนั้น $\overline{z_1 \cdot z_2} = $ ......................................
$\bar{z}_1 \cdot \bar{z}_2 = (2-3i)(1+2i) = $ ...................................... สรุปผล: ...............................................................
เฉลย: $z_1 z_2 = (2 - (-6)) + (-4 + 3)i = 8 - i \implies \overline{z_1 z_2} = 8 + i$
$\bar{z}_1 \bar{z}_2 = (2 - 3i)(1 + 2i) = (2 - (-6)) + (4 - 3)i = 8 + i$
สรุป: $\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2 = 8 + i$ สอดคล้องกับสมบัติของสังยุค
ข้อ 5. กำหนด $z = 1 + i$ จงหาค่าของ $\frac{z}{\bar{z}} + \frac{\bar{z}}{z}$ (4 คะแนน)
จัดรูป: $\frac{z^2 + (\bar{z})^2}{z\bar{z}}$ หรือคำนวณแต่ละพจน์:
แสดงวิธีทำ: .......................................................................................................................................................
เฉลย: $z = 1+i \implies \bar{z} = 1-i$
$\frac{z}{\bar{z}} = \frac{1+i}{1-i} \cdot \frac{1+i}{1+i} = \frac{(1+i)^2}{1^2+1^2} = \frac{2i}{2} = i$
$\frac{\bar{z}}{z} = \frac{1-i}{1+i} \cdot \frac{1-i}{1-i} = \frac{(1-i)^2}{2} = \frac{-2i}{2} = -i$
$\therefore \frac{z}{\bar{z}} + \frac{\bar{z}}{z} = i + (-i) = 0$

เกณฑ์การประเมินรูบริก (Rubric Assessment)

เกณฑ์การตัดสินคุณภาพผลงาน 3 ระดับ สำหรับเรื่องสมบัติเชิงพีชคณิตและสังยุค

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 5 คะแนน) ระดับ 2 (พอใช้ : 3 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจมโนทัศน์สังยุคและตัวผกผัน
$\bar{z}$, $-z$, $z^{-1}$ และสมบัติ $z\bar{z} \in \mathbb{R}$ 		ระบุสังยุคและตัวผกผันได้ถูกต้องครบถ้วน อธิบายได้ว่าผลคูณ $z\bar{z} = a^2+b^2$ ปราศจากส่วนจินตภาพ และเข้าใจความสัมพันธ์ของสมบัติสังยุคอย่างถ่องแท้ หาสังยุคได้ถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยในการหาตัวผกผันการคูณ เช่น ลืมตัวส่วน $a^2+b^2$ หรือคำนวณเครื่องหมายผิดใน 1 จุด สับสนระหว่างตัวผกผันการบวก $(-z)$ กับสังยุค $(\bar{z})$ หรือคิดว่า $z\bar{z}$ ยังคงติดค่า $i$ อยู่
2. ทักษะการหารและการจัดรูป
การคูณสังยุคทั้งเศษและส่วนให้อยู่ในรูป $a+bi$ 		เลือกใช้สังยุคของตัวส่วนคูณทั้งเศษและส่วนได้อย่างถูกต้อง กระจายพจน์ แทนค่า $i^2 = -1$ และแยกส่วนจริงส่วนจินตภาพเป็นเศษส่วนอย่างต่ำสมบูรณ์ เลือกสังยุคมาคูณถูกต้อง แต่มักผิดพลาดทางพีชคณิตในขั้นตอนกระจายเศษ หรือบวกลบเศษส่วนในขั้นตอนสุดท้าย ไม่ทราบวิธีนำสังยุคมาขจัดส่วนจินตภาพ นำตัวเลขหารกันตรงๆ หรือไม่สามารถจัดรูปให้อยู่ในแบบมาตรฐาน $a+bi$ ได้
3. การให้เหตุผลและการสื่อสารทางคณิตศาสตร์
การแสดงวิธีทำเป็นลำดับขั้นตอน การใช้สัญลักษณ์ 		เขียนแสดงวิธีทำเป็นขั้นตอนอย่างมีตรรกะ ใช้สัญลักษณ์สังยุคและตัวผกผันได้ถูกต้องตามหลักคณิตศาสตร์ ชัดเจนและอ่านง่าย แสดงวิธีทำถูกต้องเป็นส่วนใหญ่ แต่มีการข้ามขั้นตอนสำคัญ หรือละเลยการเขียนสัญลักษณ์กำกับบางจุด เขียนเฉพาะคำตอบสุดท้ายโดยไม่มีร่องรอยแสดงวิธีทำ หรือขั้นตอนที่แสดงไม่สอดคล้องกับผลลัพธ์
