รากที่ $n$ ของจำนวนเชิงซ้อน

The $n$-th Roots of Complex Numbers: การกระจายตัวเชิงเรขาคณิตและทฤษฎีบทการหารากบนระนาบเชิงซ้อน

สรุปสาระสำคัญ

1. ความหมายของรากที่ $n$

กำหนดให้ $z$ เป็นจำนวนเชิงซ้อน และ $n$ เป็นจำนวนเต็มบวกที่มากกว่า 1 จำนวนเชิงซ้อน $w$ จะเป็นรากที่ $n$ ของ $z$ ก็ต่อเมื่อ:

$$w^n = z$$
  • ถ้า $z = 0$ จะมีรากเดียวคือ $w = 0$
  • ถ้า $z \neq 0$ จะมีรากที่ $n$ ที่แตกต่างกันทั้งหมด $n$ ค่าเสมอ

2. การหารากที่ $n$ เมื่อ $n > 1$

ถ้าเขียน $z$ ในรูปเชิงขั้ว $z = r(\cos\theta + i\sin\theta)$ รากที่ $n$ ทั้งหมด $z_k$ จะหาได้จากสูตร:

$$z_k = \sqrt[n]{r} \left( \cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n} \right)$$

หรือในหน่วยองศา: $\frac{\theta + k(360^\circ)}{n}$ เมื่อ $k = 0, 1, 2, \dots, n-1$

3. การคำนวณขนาดและมุมของราก

รากที่ $n$ ทั้งหมด $n$ จำนวน จะมีคุณสมบัติเฉพาะที่น่าสนใจ:

ขนาดเท่ากันทุกราก: $|z_k| = \sqrt[n]{r}$
มุมห่างกันเท่ากัน: $\Delta\theta = \frac{360^\circ}{n} \text{ หรือ } \frac{2\pi}{n}$
  • รากแรก ($k=0$): มีมุมเริ่มต้นที่ $\theta_0 = \frac{\theta}{n}$
  • รากถัดไป: เกิดจากการบวกมุมเพิ่มทีละ $\frac{360^\circ}{n}$

4. การหารากทั้งหมดที่แตกต่างกัน

การแทนค่าดัชนี $k$ ตั้งแต่ $0$ ถึง $n-1$ ทำให้ได้มุมที่แตกต่างกัน $n$ มุมพอดี:

$$k \in \{0, 1, 2, \dots, n-1\}$$
  • หากแทน $k = n$ มุมจะวนกลับมาซ้ำกับ $k = 0$ (บวกไป $360^\circ$)
  • ดังนั้น จึงมีรากที่แตกต่างกันเพียง $n$ ค่าเท่านั้น

5. การแสดงตำแหน่งรากบนระนาบเชิงซ้อน

ในเชิงเรขาคณิต รากที่ $n$ ทั้งหมดจะอยู่ที่จุดยอดของรูปหลายเหลี่ยมด้านเท่ามุมเท่า:

รูปหลายเหลี่ยมด้านเท่า $n$ เหลี่ยม (Regular $n$-gon)
  • ทุกจุดอยู่บนเส้นรอบวงของวงกลมรัศมี $R = \sqrt[n]{r}$ ศูนย์กลางที่ $(0,0)$
  • เช่น $n=3$ เป็นสามเหลี่ยมด้านเท่า, $n=4$ เป็นสี่เหลี่ยมจัตุรัส

6. การใช้ความรู้เรื่องรากที่ $n$ แก้ปัญหา

ประยุกต์แก้สมการพหุนามในรูป $x^n - c = 0$ หรือ $x^n = c$:

$$x^n = a + bi \implies x = \sqrt[n]{a+bi}$$
  • เช่น การหารากของสมการ $x^3 + 8 = 0 \iff x^3 = -8$
  • การหารากที่ $n$ ของหนึ่ง (Roots of Unity: $x^n = 1$) และสมบัติทางพีชคณิต

ข้อที่ 1. การหารากที่สองของจำนวนเชิงซ้อนในรูปเชิงขั้ว (3 คะแนน)
จงหารากที่สองทั้งหมดของจำนวนเชิงซ้อน $z = 4\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)$ และเขียนคำตอบในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. จากโจทย์ $r = 4, \theta = \frac{2\pi}{3} = 120^\circ$ และ $n = 2$
ขนาดของราก: $R = \sqrt{4} = 2$
2. มุมของรากทั้งสอง: $\theta_k = \frac{120^\circ + k(360^\circ)}{2} = 60^\circ + k(180^\circ)$ สำหรับ $k = 0, 1$
- เมื่อ $k = 0$: $z_0 = 2(\cos 60^\circ + i\sin 60^\circ) = 2\left(\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = 1 + \sqrt{3}i$
- เมื่อ $k = 1$: $z_1 = 2(\cos 240^\circ + i\sin 240^\circ) = 2\left(-\frac{1}{2} - \frac{\sqrt{3}}{2}i\right) = -1 - \sqrt{3}i$
คำตอบ: $1 + \sqrt{3}i$ และ $-1 - \sqrt{3}i$
ข้อที่ 2. การหารากที่สามของจำนวนจริงลบ (3 คะแนน)
จงหารากที่ 3 ทั้งหมดของ $-8$ ในรูปเชิงขั้ว
เฉลยและวิธีทำ:
1. แปลง $z = -8$ เป็นรูปเชิงขั้ว: ขนาด $r = 8$, มุม $\theta = 180^\circ$ (เนื่องจากอยู่บนแกนจริงลบ)
จะได้ $z = 8(\cos 180^\circ + i\sin 180^\circ)$
2. คำนวณรากที่ $n = 3$: ขนาด $R = \sqrt[3]{8} = 2$
มุม: $\theta_k = \frac{180^\circ + k(360^\circ)}{3} = 60^\circ + k(120^\circ)$ สำหรับ $k = 0, 1, 2$
- $k = 0$: $z_0 = 2(\cos 60^\circ + i\sin 60^\circ)$
- $k = 1$: $z_1 = 2(\cos 180^\circ + i\sin 180^\circ) = -2$
- $k = 2$: $z_2 = 2(\cos 300^\circ + i\sin 300^\circ)$
คำตอบ: $2(\cos 60^\circ + i\sin 60^\circ)$, $2(\cos 180^\circ + i\sin 180^\circ)$, และ $2(\cos 300^\circ + i\sin 300^\circ)$
ข้อที่ 3. การหารากที่สี่ของจำนวนจินตภาพแท้ (3 คะแนน)
จงหารากที่ 4 ทั้งหมดของ $z = 81i$ ในรูปเชิงขั้ว
เฉลยและวิธีทำ:
1. เขียน $z = 81i$ ในรูปเชิงขั้ว: $r = 81$, $\theta = 90^\circ$ (แกนจินตภาพบวก)
$z = 81(\cos 90^\circ + i\sin 90^\circ)$
2. คำนวณรากที่ $n = 4$: ขนาด $R = \sqrt[4]{81} = 3$
มุม: $\theta_k = \frac{90^\circ + k(360^\circ)}{4} = 22.5^\circ + k(90^\circ)$ สำหรับ $k = 0, 1, 2, 3$
- $k = 0$: $z_0 = 3(\cos 22.5^\circ + i\sin 22.5^\circ)$
- $k = 1$: $z_1 = 3(\cos 112.5^\circ + i\sin 112.5^\circ)$
- $k = 2$: $z_2 = 3(\cos 202.5^\circ + i\sin 202.5^\circ)$
- $k = 3$: $z_3 = 3(\cos 292.5^\circ + i\sin 292.5^\circ)$
คำตอบ: $3(\cos 22.5^\circ + i\sin 22.5^\circ)$, $3(\cos 112.5^\circ + i\sin 112.5^\circ)$, $3(\cos 202.5^\circ + i\sin 202.5^\circ)$, $3(\cos 292.5^\circ + i\sin 292.5^\circ)$
ข้อที่ 4. การแก้สมการพหุนามโดยใช้รากที่ $n$ (3 คะแนน)
จงหาเซตคำตอบของสมการ $x^3 - 1 = 0$ ในระบบจำนวนเชิงซ้อนทั้งหมด ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. จัดรูปสมการ: $x^3 = 1$ (การหารากที่ 3 ของ 1)
2. เขียน 1 ในรูปเชิงขั้ว: $1 = 1(\cos 0^\circ + i\sin 0^\circ)$
ขนาด $R = \sqrt[3]{1} = 1$, มุม $\theta_k = \frac{0^\circ + k(360^\circ)}{3} = k(120^\circ)$ สำหรับ $k = 0, 1, 2$
- $k = 0$: $x_0 = 1(\cos 0^\circ + i\sin 0^\circ) = 1$
- $k = 1$: $x_1 = 1(\cos 120^\circ + i\sin 120^\circ) = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$
- $k = 2$: $x_2 = 1(\cos 240^\circ + i\sin 240^\circ) = -\frac{1}{2} - \frac{\sqrt{3}}{2}i$
คำตอบ: $\left\{ 1, -\frac{1}{2} + \frac{\sqrt{3}}{2}i, -\frac{1}{2} - \frac{\sqrt{3}}{2}i \right\}$
ข้อที่ 5. การวิเคราะห์เรขาคณิตของรากที่ $n$ (3 คะแนน)
ถ้ารากที่ 4 ทั้งหมดของจำนวนเชิงซ้อน $z$ เป็นจุดยอดของรูปสี่เหลี่ยมจัตุรัสที่แนบในวงกลมที่มีรัศมีเท่ากับ $2$ หน่วย โดยมีรากหนึ่งคือ $z_0 = 2(\cos 30^\circ + i\sin 30^\circ)$ จงหาจำนวนเชิงซ้อน $z$ ตั้งต้น ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. จากความหมายของรากที่ 4 จะได้ว่า $z = (z_0)^4$
2. คำนวณโดยใช้ทฤษฎีบทเดอมัวฟร์:
$z = [2(\cos 30^\circ + i\sin 30^\circ)]^4$
$z = 2^4 [\cos(4 \times 30^\circ) + i\sin(4 \times 30^\circ)] = 16(\cos 120^\circ + i\sin 120^\circ)$
3. แปลงเป็นรูปมาตรฐาน:
$\cos 120^\circ = -\frac{1}{2}$ และ $\sin 120^\circ = \frac{\sqrt{3}}{2}$
$z = 16\left(-\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = -8 + 8\sqrt{3}i$
คำตอบ: $-8 + 8\sqrt{3}i$

เกณฑ์การประเมินผลแบบรูบริก (Rubric Assessment)

เกณฑ์การให้คะแนน 3 ระดับคุณภาพสำหรับการหารากที่ $n$ ของจำนวนเชิงซ้อน

ประเด็นการประเมิน ระดับ 3: ดีมาก 3 คะแนน ระดับ 2: พอใช้ 2 คะแนน ระดับ 1: ปรับปรุง 1 คะแนน
1. การแปลงรูปเชิงขั้วและการคำนวณขนาดราก แปลง $z$ เป็นรูปเชิงขั้วได้ถูกต้องสมบูรณ์ และคำนวณขนาดของราก $R = \sqrt[n]{r}$ ได้ถูกต้องแม่นยำทุกข้อ แปลงเป็นรูปเชิงขั้วได้ แต่มีข้อผิดพลาดเล็กน้อยในการถอดกรณฑ์ของขนาด $r$ ไม่สามารถแปลงเป็นรูปเชิงขั้วได้ หรือคำนวณขนาดของรากผิดพลาด
2. การคำนวณมุมและระยะห่างเชิงมุม ใช้สูตร $\frac{\theta + 2k\pi}{n}$ หามุมของรากได้ครบทุกค่า และเพิ่มมุมทีละ $\frac{360^\circ}{n}$ ได้ถูกต้องแม่นยำ คำนวณมุมของรากแรกถูกต้อง แต่บวกระยะห่างเชิงมุมผิดพลาดในบางค่า $k$ ไม่เข้าใจหลักการกระจายมุมของราก หรือหารมุมเริ่มต้นผิดพลาด
3. การหารากครบ $n$ ค่าและการแปลงกลับ หารากได้ครบทั้ง $n$ ค่าโดยไม่ตกหล่นและไม่ซ้ำซ้อน พร้อมทั้งแปลงกลับเป็นรูป $a+bi$ ได้ถูกต้องสมบูรณ์ หารากได้ครบ $n$ ค่า แต่แปลงกลับเป็นรูปมาตรฐาน $a+bi$ ผิดพลาดบางส่วน หารากได้ไม่ครบ $n$ ค่า หรือเขียนรูปแบบคำตอบไม่ถูกต้องตามหลักการ
4. การประยุกต์แก้สมการและความเข้าใจเชิงเรขาคณิต ประยุกต์ทฤษฎีบทการหารากแก้สมการพหุนามและอธิบายการกระจายตัวของจุดบนระนาบได้อย่างสมเหตุสมผล ประยุกต์แก้สมการได้ แต่สรุปเซตคำตอบไม่สมบูรณ์ หรือขาดความเข้าใจความสัมพันธ์เชิงเรขาคณิต ไม่สามารถนำความรู้เรื่องรากที่ $n$ ไปใช้แก้สมการพหุนามได้
