รูปเชิงขั้วของจำนวนเชิงซ้อน

Polar Form of Complex Numbers: การเชื่อมโยงเวกเตอร์และตรีโกณมิติบนระนาบเชิงซ้อน

สรุปสาระสำคัญ

1. ขนาดของจำนวนเชิงซ้อน (Modulus)

ระยะทางจากจุดกำเนิด $(0, 0)$ ไปยังจุด $(a, b)$ แทนด้วย $|z|$ หรือ $r$ มีค่าเป็นบวกหรือศูนย์เสมอ:

$$r = |z| = \sqrt{a^2 + b^2}$$
  • สมบัติสำคัญ: $|z_1 z_2| = |z_1||z_2|$
  • $|z^n| = |z|^n$ และ $|z| = |\bar{z}| = |-z|$

2. อาร์กิวเมนต์ของจำนวนเชิงซ้อน (Argument)

มุม $\theta$ ที่เวกเตอร์ทำมุมกับแกนจริงบวกในทิศทวนเข็มนาฬิกา แทนด้วย $\arg(z)$:

$$\tan\theta = \frac{b}{a} \quad (a \neq 0)$$
  • อาร์กิวเมนต์หลัก (Principal Argument): นิยมระบุในช่วง $-\pi < \theta \le \pi$ หรือ $0^\circ \le \theta < 360^\circ$

3. การหามุมโดยพิจารณาควอดแรนต์

กำหนดมุมอ้างอิงแหลมบวก $\alpha = \arctan\left|\frac{b}{a}\right|$:

  • $Q_1$ ($a>0, b>0$): $\theta = \alpha$
  • $Q_2$ ($a<0, b>0$): $\theta = 180^\circ - \alpha$
  • $Q_3$ ($a<0, b<0$): $\theta = 180^\circ + \alpha$
  • $Q_4$ ($a>0, b<0$): $\theta = 360^\circ - \alpha$

4. การแปลงรูปมาตรฐานและรูปเชิงขั้ว

แปลงรูปมาตรฐานเป็นเชิงขั้ว:

$$z = r(\cos\theta + i\sin\theta)$$

แปลงเชิงขั้วเป็นรูปมาตรฐาน: คำนวณค่าจริง $a = r\cos\theta$ และส่วนจินตภาพ $b = r\sin\theta$

5. การใช้รูปเชิงขั้วแก้ปัญหา (ทฤษฎีบทเดอมัวฟวร์)

การคูณ:
$$z_1 z_2 = r_1 r_2 [\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)]$$
การหาร:
$$\frac{z_1}{z_2} = \frac{r_1}{r_2} [\cos(\theta_1-\theta_2) + i\sin(\theta_1-\theta_2)]$$
ทฤษฎีบทเดอมัวฟวร์:
$$z^n = r^n [\cos(n\theta) + i\sin(n\theta)]$$

โมเดลการศึกษา: สำรวจระนาบเชิงซ้อนและการเปลี่ยนรูปพิกัด

สิ่งที่นักเรียนควรค้นพบ:

จำนวนเชิงซ้อนเดียวกันสามารถแทนได้ทั้งรูปมาตรฐาน $a + bi$ และรูปเชิงขั้ว $r(\cos\theta + i\sin\theta)$ อย่างสมบูรณ์ โดยที่ขนาด $r$ จะเป็นความยาวของเวกเตอร์เสมอ และมุม $\theta$ ต้องพิจารณาเครื่องหมายของทั้ง $a$ และ $b$ เพื่อระบุควอดแรนต์ให้ถูกต้อง

ข้อที่ 1. (3 คะแนน)
จงหาขนาด $|z|$ และอาร์กิวเมนต์ $\theta$ ของจำนวนเชิงซ้อน $z = -2\sqrt{3} + 2i$ และเขียนในรูปเชิงขั้ว ($0^\circ \le \theta < 360^\circ$)
เฉลย: $r = \sqrt{(-2\sqrt{3})^2 + 2^2} = \sqrt{12+4} = 4$
พิจารณาจุดอยู่ใน $Q_2$ ($a<0, b>0$), มุมอ้างอิง $\alpha = 30^\circ \implies \theta = 180^\circ - 30^\circ = 150^\circ$
คำตอบ: $z = 4(\cos 150^\circ + i\sin 150^\circ)$
ข้อที่ 2. (3 คะแนน)
จงแปลงจำนวนเชิงซ้อน $z = -3 - 3i$ ให้อยู่ในรูปเชิงขั้ว $r(\cos\theta + i\sin\theta)$
เฉลย: $r = \sqrt{(-3)^2 + (-3)^2} = \sqrt{18} = 3\sqrt{2}$
พิจารณาจุดอยู่ใน $Q_3$ ($a<0, b<0$), มุมอ้างอิง $\alpha = 45^\circ \implies \theta = 180^\circ + 45^\circ = 225^\circ$
คำตอบ: $z = 3\sqrt{2}(\cos 225^\circ + i\sin 225^\circ)$
ข้อที่ 3. (3 คะแนน)
จงแปลง $z = 6\left(\cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3}\right)$ ให้อยู่ในรูปมาตรฐาน $a + bi$
เฉลย: $\cos\frac{4\pi}{3} = -\frac{1}{2}$ และ $\sin\frac{4\pi}{3} = -\frac{\sqrt{3}}{2}$
$z = 6\left(-\frac{1}{2} - i\frac{\sqrt{3}}{2}\right) = -3 - 3\sqrt{3}i$
คำตอบ: $-3 - 3\sqrt{3}i$
ข้อที่ 4. (3 คะแนน)
กำหนด $z_1 = 2(\cos 40^\circ + i\sin 40^\circ)$ และ $z_2 = 4(\cos 80^\circ + i\sin 80^\circ)$ จงหาผลคูณ $z_1 \cdot z_2$ ในรูป $a + bi$
เฉลย: $z_1 z_2 = (2)(4)[\cos(40^\circ+80^\circ) + i\sin(40^\circ+80^\circ)] = 8(\cos 120^\circ + i\sin 120^\circ)$
แปลงกลับ: $8\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = -4 + 4\sqrt{3}i$
คำตอบ: $-4 + 4\sqrt{3}i$
ข้อที่ 5. (3 คะแนน)
จงใช้ทฤษฎีบทเดอมัวฟวร์ (De Moivre's Theorem) คำนวณหาค่าของ $(1 + i)^{10}$ ในรูป $a + bi$
เฉลย: $1+i = \sqrt{2}(\cos 45^\circ + i\sin 45^\circ)$
$(1+i)^{10} = (\sqrt{2})^{10}[\cos(10 \times 45^\circ) + i\sin(10 \times 45^\circ)] = 32(\cos 450^\circ + i\sin 450^\circ)$
เนื่องจาก $450^\circ \equiv 90^\circ$ จะได้ $32(\cos 90^\circ + i\sin 90^\circ) = 32(0 + i) = 32i$
คำตอบ: $32i$

เกณฑ์การประเมินผลแบบรูบริก (Rubric Assessment)

เกณฑ์การให้คะแนนแบ่งเป็น 3 ระดับคุณภาพ เพื่อประเมินความเข้าใจและทักษะทางคณิตศาสตร์

ประเด็นการประเมิน ระดับ 3: ดีมาก 3 คะแนน ระดับ 2: พอใช้ 2 คะแนน ระดับ 1: ปรับปรุง 1 คะแนน
1. การหาขนาดและระบุมุม ($r$ และ $\theta$) คำนวณขนาด $r = \sqrt{a^2+b^2}$ ถูกต้อง และหามุมอ้างอิง $\alpha$ ได้ถูกต้องแม่นยำ คำนวณขนาดถูกต้อง แต่หาค่ามุมอ้างอิงผิดพลาดเล็กน้อย คำนวณขนาดผิด หรือไม่สามารถหามุมได้
2. การวิเคราะห์ควอดแรนต์ พิจารณาเครื่องหมาย $a, b$ ระบุควอดแรนต์และปรับค่ามุมจริง $\theta$ ได้ถูกต้องสมบูรณ์ ระบุควอดแรนต์ถูกต้อง แต่นำมุมอ้างอิงมาแปลงเป็นมุมจริงผิดเล็กน้อย ไม่พิจารณาควอดแรนต์ ทำให้ทิศทางมุมผิดพลาด
3. การแปลงรูปทางคณิตศาสตร์ แปลงสลับระหว่าง $a+bi$ และ $r(\cos\theta + i\sin\theta)$ ได้ถูกต้องสมบูรณ์ แปลงรูปได้ถูกต้องเป็นส่วนใหญ่ แต่ตกหล่นเครื่องหมาย $i$ หรือเครื่องหมายบวกลบ เขียนสัญลักษณ์รูปเชิงขั้วไม่ถูกต้องตามหลักการ
4. การประยุกต์ทฤษฎีบทเดอมัวฟวร์ ประยุกต์ใช้สูตร $z^n = r^n(\cos n\theta + i\sin n\theta)$ และลดทอนมุมเกิน $360^\circ$ ได้ถูกต้อง ใช้สูตรเดอมัวฟวร์ได้ แต่คำนวณเลขยกกำลัง $r^n$ หรือมุมผิดพลาดบางส่วน ไม่สามารถนำทฤษฎีบทเดอมัวฟวร์มาใช้แก้ปัญหาได้
