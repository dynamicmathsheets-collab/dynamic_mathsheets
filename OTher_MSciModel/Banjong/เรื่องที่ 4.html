กราฟ ค่าสัมบูรณ์ และเงื่อนไขบนระนาบเชิงซ้อน

เชื่อมโยงพีชคณิตเชิงซ้อนสู่เรขาคณิตบนระนาบอาร์กองด์ เข้าใจความหมายของค่าสัมบูรณ์ในฐานะระยะทาง และการแปรความหมายสมการเป็นรูปทรงเรขาคณิต

ระยะทางและระนาบ $|z| = \sqrt{a^2 + b^2}$ $|z - z_0| = r$ (วงกลม)

สรุปองค์ความรู้และมโนทัศน์เรขาคณิตเชิงซ้อน

ระนาบอาร์กองด์ ค่าสัมบูรณ์ ระยะทาง และการแทนเงื่อนไขทางเรขาคณิต

มโนทัศน์ที่ 1

ระนาบเชิงซ้อน (Argand Plane)

แทน $z = a + bi$ ด้วยจุด $(a, b)$ หรือเวกเตอร์จากจุดกำเนิด $(0, 0)$ ไปยัง $(a, b)$:

แกนนอน (Real Axis): แกนจริง $\text{Re}$ (ค่า $a$)
แกนตั้ง (Imaginary Axis): แกนจินตภาพ $\text{Im}$ (ค่า $b$)

ระนาบนี้เป็นสะพานเชื่อมระหว่างพีชคณิตกับเรขาคณิตวิเคราะห์

มโนทัศน์ที่ 2

ค่าสัมบูรณ์ (Modulus)

คือระยะทางแบบยุคลิดจากจุดกำเนิด $(0, 0)$ ไปยังจุด $z = a + bi$:

$|z| = \sqrt{a^2 + b^2}$
$|z| \ge 0$ เสมอ และ $|z| = 0 \iff z = 0$

สมมูลกับขนาด (Magnitude) ของเวกเตอร์ในระนาบ 2 มิติ

มโนทัศน์ที่ 3

สมบัติสำคัญของค่าสัมบูรณ์

1. $|z| = |-z| = |\bar{z}|$
2. $|z|^2 = z \cdot \bar{z}$
3. $|z_1 z_2| = |z_1||z_2|$  และ  $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$
4. $|z^n| = |z|^n$
5. อสมการสามเหลี่ยม: $|z_1 + z_2| \le |z_1| + |z_2|$

สมบัติเหล่านี้ช่วยลดความซับซ้อนในการคำนวณกำลังสูง

มโนทัศน์ที่ 4

ระยะทางระหว่างจุดสองจุด

ถ้า $z_1 = x_1 + y_1i$ และ $z_2 = x_2 + y_2i$ ระยะทางระหว่าง $z_1$ กับ $z_2$ คือ:

$|z_1 - z_2| = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$

เช่น $|z - (3+4i)|$ หมายถึง ระยะทางจากจุด $z$ ไปยังจุด $(3, 4)$

มโนทัศน์ที่ 5

เงื่อนไขวงกลม & บริเวณ

ให้ $z_0 = h + ki$ เป็นจุดคงที่ และ $r > 0$

$|z - z_0| = r$ : วงกลมจุดศูนย์กลาง $z_0$ รัศมี $r$
$|z - z_0| \le r$ : แผ่นวงกลมรวมเส้นรอบวง
$|z - z_0| < r$ : บริเวณภายในวงกลม (เส้นประ)

เทียบเท่ากับสมการ $(x - h)^2 + (y - k)^2 = r^2$

มโนทัศน์ที่ 6

เส้นแบ่งครึ่งและตั้งฉาก

เซตของจุด $z$ ที่อยู่ห่างจาก $z_1$ และ $z_2$ เป็นระยะทางเท่ากัน:

$|z - z_1| = |z - z_2|$
คือกราฟเส้นตรงที่แบ่งครึ่งและตั้งฉากกับส่วนของเส้นตรงที่เชื่อม $z_1$ และ $z_2$

ประยุกต์สู่เรื่องทางเดินของจุด (Locus)

โมเดลจำลองระนาบเชิงซ้อน Interactive (Argand Plane)

คลิกหรือลากจุด $z$ บนระนาบเพื่อตรวจสอบเงื่อนไขและวัดระยะทางแบบเรียลไทม์

ตั้งค่าจุดศูนย์กลาง $z_0 = h + ki$ และรัศมี $r$:

สถานะตำแหน่งจุด $z$ (Probe Point) ลากเมาส์ / แตะบนกราฟได้

พิกัด $z = x + yi$:
$z = 2.00 + 1.50i$
ค่าสัมบูรณ์ $|z|$ จาก $(0,0)$:
2.50
ระยะทางไปยังจุดศูนย์กลาง $z_0$: 2.50
ระนาบเชิงซ้อน $\mathbb{C}$ : แกนนอน $\text{Re}$ / แกนตั้ง $\text{Im}$ ลากจุดสีส้ม $z$ ได้อย่างอิสระ
จุด $z$ (Probe)

ขอบเขตเงื่อนไข

สิ่งที่นักเรียนควรค้นพบ (Geometric Insight):

“สมการและอสมการที่เกี่ยวกับค่าสัมบูรณ์สามารถแสดงเป็นวงกลม บริเวณภายในวงกลม หรือรูปทรงเรขาคณิตอื่นบนระนาบเชิงซ้อนได้อย่างแม่นยำ”
เนื่องจาก $|z - z_0|$ สื่อถึง ระยะทาง จากจุดแปรผัน $z$ ไปยังจุดคงที่ $z_0$ ดังนั้นเมื่อระยะทางคงที่เท่ากับ $r$ เซตของจุดจึงเรียงตัวเป็น วงกลม และเมื่อเป็นอสมการ $\le r$ เซตของจุดจะแผ่ขยายเป็น บริเวณแผ่นวงกลม ทั้งผืน

สมบัติ: $\left|\frac{z_1^n}{z_2^m}\right| = \frac{|z_1|^n}{|z_2|^m}$ | หา $|1+\sqrt{3}i| =$ .................. และ $|3-4i| =$ ..................
คำนวณผลลัพธ์: ...................................................................................................................................................
เฉลย: ใช้สมบัติ $\frac{|1+\sqrt{3}i|^4}{|3-4i|^2}$
$|1+\sqrt{3}i| = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2 \implies |1+\sqrt{3}i|^4 = 2^4 = 16$
$|3-4i| = \sqrt{3^2 + (-4)^2} = \sqrt{9+16} = \sqrt{25} = 5 \implies |3-4i|^2 = 5^2 = 25$

เกณฑ์การประเมินรูบริก (Rubric Assessment)

เกณฑ์การประเมินผลการเรียนรู้ตามสภาพจริง 3 ระดับคุณภาพ เรื่อง กราฟและค่าสัมบูรณ์บนระนาบเชิงซ้อน

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 5 คะแนน) ระดับ 2 (พอใช้ : 3 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจมโนทัศน์ค่าสัมบูรณ์และระยะทาง
$|z| = \sqrt{a^2+b^2}$, $|z_1 - z_2|$ และสมบัติเชิงพีชคณิต 		คำนวณค่าสัมบูรณ์และระยะทางได้อย่างถูกต้องแม่นยำ ประยุกต์สมบัติ $|z_1 z_2| = |z_1||z_2|$ และ $|z^n| = |z|^n$ ได้อย่างคล่องแคล่ว คำนวณค่าสัมบูรณ์ของจำนวนเชิงซ้อนเดี่ยวได้ถูกต้อง แต่มีข้อผิดพลาดเล็กน้อยเมื่อคำนวณระยะทางระหว่างจุดหรือสมบัติเศษส่วน สับสนนิยามค่าสัมบูรณ์ นำส่วนจริงกับส่วนจินตภาพมาบวกกันโดยตรงโดยไม่ใส่รากที่สอง หรือคิดเลขผิดพลาดอย่างมีนัยสำคัญ
2. การแปรความหมายกราฟและเงื่อนไขเรขาคณิต
สมการวงกลม $|z - z_0| = r$, อสมการ และบริเวณวงแหวน 		ระบุจุดศูนย์กลาง $z_0$ และรัศมี $r$ ได้ถูกต้องสมบูรณ์ จำแนกความแตกต่างระหว่างเส้นรอบวง บริเวณภายใน และวงแหวนได้อย่างชัดเจน ระบุลักษณะกราฟว่าเป็นวงกลมได้ถูกต้อง แต่มักสับสนเครื่องหมายของจุดศูนย์กลาง เช่น สับสนระหว่าง $z - 3$ กับ $(3, 0)$ ไม่สามารถบอกลักษณะทางเรขาคณิตของสมการค่าสัมบูรณ์ได้ ไม่เข้าใจความหมายเชิงระยะทางของ $|z - z_0|$
3. การแสดงวิธีทำและการสื่อสารทางคณิตศาสตร์
การเขียนสัญลักษณ์ การให้เหตุผลอย่างเป็นลำดับขั้นตอน 		แสดงลำดับขั้นตอนการจัดรูปทางพีชคณิตได้อย่างมีตรรกะ เขียนสัญลักษณ์ $\mathbb{C}, \text{Re}, \text{Im}$ และหน่วยระยะทางได้สมบูรณ์ แสดงวิธีทำถูกต้องเป็นส่วนใหญ่ แต่ข้ามขั้นตอนการอ้างอิงสมบัติ หรือละเลยการจัดรูปมาตรฐานก่อนตอบ เขียนเพียงคำตอบลอยๆ ขาดขั้นตอนการคำนวณ หรือการเขียนสัญลักษณ์คณิตศาสตร์ไม่ถูกต้องตามระเบียบแบบแผน
