การดำเนินการด้วยรูปเชิงขั้ว

Operations on Complex Numbers in Polar Form: การคูณ การหาร การยกกำลัง และทฤษฎีบทเดอมัวฟร์

สรุปสาระสำคัญ

1. การคูณจำนวนเชิงซ้อนในรูปเชิงขั้ว

เมื่อกำหนดให้ $z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$ และ $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$:

$$z_1 z_2 = r_1 r_2 [\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)]$$
  • ขนาด: นำขนาดมาคูณกัน ($\vert{}z_1 z_2\vert{} = r_1 r_2$)
  • มุม: นำอาร์กิวเมนต์มาบวกกัน ($\arg(z_1 z_2) = \theta_1 + \theta_2$)

2. การหารจำนวนเชิงซ้อนในรูปเชิงขั้ว

สำหรับการหารเมื่อ $z_2 \neq 0$:

$$\frac{z_1}{z_2} = \frac{r_1}{r_2} [\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)]$$
  • ขนาด: นำขนาดมาหารกัน $\left|\frac{z_1}{z_2}\right| = \frac{r_1}{r_2}$
  • มุม: นำอาร์กิวเมนต์มาลบกัน ($\arg(z_1/z_2) = \theta_1 - \theta_2$)

3. การยกกำลังจำนวนเชิงซ้อนในรูปเชิงขั้ว

การคูณตัวเองซ้ำกัน $n$ ครั้ง ทำให้ขนาดถูกยกกำลังและมุมถูกทวีคูณ:

$$z^n = [r(\cos\theta + i\sin\theta)]^n$$
  • ลดรูปการคูณพหุนามที่ยุ่งยากในรูป $a+bi$ ลงได้อย่างมาก
  • ช่วยในการคำนวณรากที่ $n$ ของจำนวนเชิงซ้อนในขั้นตอนต่อไป

4. การใช้สูตรของเดอมัวฟร์ (De Moivre's Formula)

สำหรับจำนวนเต็ม $n$ ใด ๆ จะได้ความสัมพันธ์โดยตรง:

$$z^n = r^n [\cos(n\theta) + i\sin(n\theta)]$$
  • ถ้า $n$ เป็นจำนวนเต็มลบ: $z^{-n} = r^{-n}[\cos(-n\theta) + i\sin(-n\theta)]$
  • หาก $n\theta \ge 360^\circ$ ให้ลบด้วยพหุคูณของ $360^\circ$ (หรือ $2k\pi$) เพื่อหาอาร์กิวเมนต์หลัก

5. การแปลงกลับเป็นรูปมาตรฐานเพื่อตรวจสอบคำตอบ

เมื่อได้ผลลัพธ์ในรูป $R(\cos\Phi + i\sin\Phi)$ แล้ว สามารถกระจายค่าตรีโกณมิติกลับสู่รูปมาตรฐาน $a + bi$ เพื่อตรวจทาน:

$$a = R\cos\Phi$$ $$b = R\sin\Phi$$ $$z = a + bi$$

💡 การคำนวณผลลัพธ์ทั้งสองวิธี (พีชคณิตปกติ vs รูปเชิงขั้ว) จะต้องได้ค่า $a+bi$ ที่เท่ากันเสมอ

ข้อที่ 1. การคูณจำนวนเชิงซ้อนในรูปเชิงขั้ว (3 คะแนน)
กำหนดให้ $z_1 = 3(\cos 40^\circ + i\sin 40^\circ)$ และ $z_2 = 2(\cos 80^\circ + i\sin 80^\circ)$ จงหาผลคูณ $z_1 z_2$ ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. ใช้สูตรคูณ: $z_1 z_2 = r_1 r_2 [\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)]$
2. แทนค่า: $z_1 z_2 = (3 \times 2)[\cos(40^\circ + 80^\circ) + i\sin(40^\circ + 80^\circ)] = 6(\cos 120^\circ + i\sin 120^\circ)$
3. แปลงเป็นรูปมาตรฐาน: $\cos 120^\circ = -\frac{1}{2}$ และ $\sin 120^\circ = \frac{\sqrt{3}}{2}$
$z_1 z_2 = 6\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = -3 + 3\sqrt{3}i$
คำตอบ: $-3 + 3\sqrt{3}i$
ข้อที่ 2. การหารจำนวนเชิงซ้อนในรูปเชิงขั้ว (3 คะแนน)
กำหนดให้ $z_1 = 8(\cos 105^\circ + i\sin 105^\circ)$ และ $z_2 = 4(\cos 45^\circ + i\sin 45^\circ)$ จงหาค่าของ $\frac{z_1}{z_2}$ ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. ใช้สูตรการหาร: $\frac{z_1}{z_2} = \frac{r_1}{r_2} [\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)]$
2. แทนค่า: $\frac{z_1}{z_2} = \frac{8}{4}[\cos(105^\circ - 45^\circ) + i\sin(105^\circ - 45^\circ)] = 2(\cos 60^\circ + i\sin 60^\circ)$
3. แปลงเป็นรูปมาตรฐาน: $\cos 60^\circ = \frac{1}{2}$ และ $\sin 60^\circ = \frac{\sqrt{3}}{2}$
$\frac{z_1}{z_2} = 2\left(\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = 1 + \sqrt{3}i$
คำตอบ: $1 + \sqrt{3}i$
ข้อที่ 3. การประยุกต์ทฤษฎีบทเดอมัวฟร์ (3 คะแนน)
จงใช้สูตรของเดอมัวฟร์ คำนวณหาค่าของ $\left[\sqrt{2}(\cos 15^\circ + i\sin 15^\circ)\right]^6$ ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. ใช้สูตรเดอมัวฟร์: $z^n = r^n [\cos(n\theta) + i\sin(n\theta)]$
2. คำนวณขนาด: $R = (\sqrt{2})^6 = (2^{1/2})^6 = 2^3 = 8$
3. คำนวณมุม: $\Phi = 6 \times 15^\circ = 90^\circ$
4. จะได้ $z^6 = 8(\cos 90^\circ + i\sin 90^\circ) = 8(0 + 1i) = 8i$
คำตอบ: $8i$ (หรือ $0 + 8i$)
ข้อที่ 4. การแปลงรูปมาตรฐานเพื่อยกกำลังและตรวจสอบ (3 คะแนน)
จงคำนวณหาค่าของ $(-\sqrt{3} + i)^5$ โดยการแปลงเป็นรูปเชิงขั้วก่อน แล้วเขียนคำตอบสุดท้ายในรูป $a + bi$
เฉลยและวิธีทำ:
1. แปลง $w = -\sqrt{3} + i$ เป็นรูปเชิงขั้ว:
- ขนาด $r = \sqrt{(-\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = 2$
- ควอดแรนต์: $a < 0, b > 0$ อยู่ใน $Q_2$ โดยมุมอ้างอิง $\tan\alpha = \frac{1}{\sqrt{3}} \implies \alpha = 30^\circ$
- มุมจริง $\theta = 180^\circ - 30^\circ = 150^\circ$
ดังนั้น $w = 2(\cos 150^\circ + i\sin 150^\circ)$
2. ยกกำลังด้วยสูตรเดอมัวฟร์: $w^5 = 2^5[\cos(5 \times 150^\circ) + i\sin(5 \times 150^\circ)] = 32(\cos 750^\circ + i\sin 750^\circ)$
3. ลดทอนมุม: $750^\circ = 2(360^\circ) + 30^\circ \equiv 30^\circ$
$w^5 = 32(\cos 30^\circ + i\sin 30^\circ) = 32\left(\frac{\sqrt{3}}{2} + \frac{1}{2}i\right) = 16\sqrt{3} + 16i$
คำตอบ: $16\sqrt{3} + 16i$
ข้อที่ 5. การดำเนินการผสมและแปลงกลับ (3 คะแนน)
กำหนดให้ $z_1 = 4(\cos 70^\circ + i\sin 70^\circ)$, $z_2 = 2(\cos 25^\circ + i\sin 25^\circ)$ และ $z_3 = \cos 15^\circ + i\sin 15^\circ$
จงหาค่าของ $\frac{z_1 \cdot z_2}{z_3}$ ในรูปมาตรฐาน $a + bi$
เฉลยและวิธีทำ:
1. จัดการขนาด: $R = \frac{r_1 \cdot r_2}{r_3} = \frac{4 \times 2}{1} = 8$
2. จัดการมุม: $\Phi = \theta_1 + \theta_2 - \theta_3 = 70^\circ + 25^\circ - 15^\circ = 80^\circ$
(หรือหากมุมเป็น $60^\circ$ จะแปลงลงตัว: ในที่นี้ $\Phi = 80^\circ$)
$z = 8(\cos 80^\circ + i\sin 80^\circ)$
แปลงเป็นทศนิยมเพื่อตรวจสอบ: $\cos 80^\circ \approx 0.1736$, $\sin 80^\circ \approx 0.9848$
$z \approx 8(0.1736 + 0.9848i) \approx 1.39 + 7.88i$
คำตอบ: $8(\cos 80^\circ + i\sin 80^\circ)$ หรือประมาณ $1.39 + 7.88i$

เกณฑ์การประเมินผลแบบรูบริก (Rubric Assessment)

เกณฑ์การให้คะแนน 3 ระดับคุณภาพสำหรับการดำเนินการด้วยรูปเชิงขั้ว

ประเด็นการประเมิน ระดับ 3: ดีมาก 3 คะแนน ระดับ 2: พอใช้ 2 คะแนน ระดับ 1: ปรับปรุง 1 คะแนน
1. การคูณและการหารในรูปเชิงขั้ว คำนวณขนาดและมุมของการคูณ (บวกมุม) และการหาร (ลบมุม) ได้อย่างถูกต้องแม่นยำทุกขั้นตอน เข้าใจหลักการนำมุมมาบวกหรือลบกัน แต่คำนวณตัวเลขขนาดหรือมุมผิดพลาดเล็กน้อย สับสนกฎการคูณ/หาร เช่น นำมุมมาคูณกัน หรือไม่สามารถใช้สูตรได้ถูกต้อง
2. การใช้สูตรของเดอมัวฟร์ ประยุกต์ $z^n = r^n(\cos n\theta + i\sin n\theta)$ ได้ถูกต้อง และลดทอนมุมเกิน $360^\circ$ ได้ถูกต้องสมบูรณ์ นำสูตรเดอมัวฟร์มาใช้ได้ แต่คำนวณเลขยกกำลัง $r^n$ ผิด หรือคำนวณผลคูณ $n\theta$ ผิดพลาด ไม่สามารถระบุหรือประยุกต์ใช้สูตรเดอมัวฟร์ในการยกกำลังจำนวนเชิงซ้อนได้
3. การแปลงกลับเป็นรูปมาตรฐานและการตรวจคำตอบ แปลงกลับเป็นรูป $a+bi$ ได้ถูกต้องแม่นยำทุกข้อ รวมถึงการแทนค่าฟังก์ชันตรีโกณมิติมุมสำคัญได้ถูกต้อง เข้าใจการแปลงกลับ แต่แทนค่า $\cos\theta$ หรือ $\sin\theta$ คลาดเคลื่อน หรือตกหล่นเครื่องหมาย $i$ ไม่สามารถแปลงค่าผลลัพธ์จากรูปเชิงขั้วกลับสู่รูปมาตรฐาน $a+bi$ ได้
4. กระบวนการแก้ปัญหาอย่างเป็นระบบ แสดงขั้นตอนการแปลงรูป การคำนวณขนาด-มุม และการสรุปคำตอบเป็นระเบียบชัดเจนและสมบูรณ์ แสดงวิธีทำเป็นขั้นตอนพอใช้ได้ มีการข้ามขั้นตอนสำคัญ หรือตกหล่นการสรุปผลบางส่วน เขียนคำตอบโดยไม่แสดงวิธีทำ หรือขั้นตอนไม่ต่อเนื่องและขาดความสมเหตุสมผล
