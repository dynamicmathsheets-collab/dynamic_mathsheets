คณิตศาสตร์เพิ่มเติม ชั้นมัธยมศึกษาปีที่ 5

การสร้างจำนวนเชิงซ้อนและสมบัติพื้นฐาน

ขยายขอบเขตจากระบบจำนวนจริงสู่ระบบจำนวนเชิงซ้อน ทำความเข้าใจหน่วยจินตภาพ $i$ การเท่ากัน และการดำเนินการพีชคณิตอย่างเป็นระบบ

นิยามแก่นสำคัญ $i^2 = -1$ $\mathbb{C} = \{a+bi \mid a,b \in \mathbb{R}\}$

สรุปองค์ความรู้และมโนทัศน์สำคัญ

สาระการเรียนรู้แกนกลางตามหลักสูตรคณิตศาสตร์ ม.ปลาย

มโนทัศน์ที่ 1

จำนวนเชิงซ้อนในรูปคู่อันดับ & $a+bi$

กำหนดจำนวนเชิงซ้อน $z$ สามารถเขียนได้ 2 รูปแบบที่สมมูลกัน:

รูปคู่อันดับ: $(a, b)$
รูปมาตรฐาน: $a + bi$

โดยที่ $a, b \in \mathbb{R}$ และ $i$ เป็นหน่วยจินตภาพ

มโนทัศน์ที่ 2

หน่วยจินตภาพ (Imaginary Unit)

จำนวนที่ไม่สามารถหาค่าได้ในระบบจำนวนจริง ถูกกำหนดขึ้นเพื่อแก้สมการ $x^2 + 1 = 0$

$i = \sqrt{-1} \iff (0, 1)$
$i^2 = -1$

สมบัตินี้เป็นหัวใจหลักในการคูณจำนวนเชิงซ้อน

มโนทัศน์ที่ 3

ส่วนจริง และ ส่วนจินตภาพ

สำหรับจำนวนเชิงซ้อน $z = a + bi = (a, b)$

ส่วนจริง (Real part): $\text{Re}(z) = a$
ส่วนจินตภาพ (Imaginary part): $\text{Im}(z) = b$

**ข้อควรระวัง: $\text{Im}(z)$ มีค่าเป็น $b$ (ไม่รวม $i$)

มโนทัศน์ที่ 4

การเท่ากันของจำนวนเชิงซ้อน

จำนวนเชิงซ้อนสองจำนวนจะเท่ากัน ก็ต่อเมื่อส่วนจริงเท่ากัน และส่วนจินตภาพเท่ากันพร้อมกัน

$(a, b) = (c, d) \iff a = c \text{ และ } b = d$
$a+bi = c+di \iff a = c \land b = d$

นำไปใช้ในการแก้สมการเทียบสัมประสิทธิ์

มโนทัศน์ที่ 5

ความสัมพันธ์ระหว่าง $\mathbb{R}$ กับ $\mathbb{C}$

เมื่อกำหนด $b = 0$ จะได้ $a + 0i = a \in \mathbb{R}$ นั่นคือจำนวนจริงทุกจำนวนเป็นจำนวนเชิงซ้อน

$\mathbb{R} \subset \mathbb{C}$

ถ้า $a=0, b \neq 0$ เรียกว่า จำนวนจินตภาพแท้ (Pure Imaginary)

มโนทัศน์ที่ 6

กำลังของหน่วยจินตภาพ ($i^n$)

ค่าของ $i^n$ มีการวนซ้ำตามวัฏจักร 4 ค่า โดยนำเลขชี้กำลัง $n$ หารด้วย 4:

เศษ 1 $\rightarrow i$
เศษ 2 $\rightarrow -1$
เศษ 3 $\rightarrow -i$
เศษ 0 (ลงตัว) $\rightarrow 1$

ตัวอย่าง: $i^{102} = i^2 = -1$ (เพราะ $102 \div 4$ เหลือเศษ 2)

สูตรการบวกและการคูณจำนวนเชิงซ้อน

การบวก (Addition)

ในรูปคู่อันดับ: $(a, b) + (c, d) = (a + c, b + d)$

ในรูป $a+bi$: $(a + bi) + (c + di) = (a + c) + (b + d)i$

การคูณ (Multiplication)

ในรูปคู่อันดับ: $(a, b) \cdot (c, d) = (ac - bd, ad + bc)$

ในรูป $a+bi$: $(a + bi)(c + di) = (ac - bd) + (ad + bc)i$

โมเดลการศึกษาและจำลองการคำนวณ

ทดลองป้อนค่าจำนวนจริง $a, b, c, d$ เพื่อสำรวจผลลัพธ์แบบขั้นตอนต่อขั้นตอน

จำนวนเชิงซ้อนที่ 1: $z_1 = a + bi$ $(3, 4) \iff 3 + 4i$
จำนวนเชิงซ้อนที่ 2: $z_2 = c + di$ $(1, -2) \iff 1 - 2i$
ชุดข้อมูลตัวอย่าง:

1 การตรวจสอบความเท่ากัน ($z_1 = z_2$)

2 การบวกจำนวนเชิงซ้อน ($z_1 + z_2$)

3 การคูณจำนวนเชิงซ้อน ($z_1 \cdot z_2$)

สิ่งที่นักเรียนควรค้นพบจากการสังเกต (Mathematical Insight):

“จำนวนจริงเป็นส่วนหนึ่งของจำนวนเชิงซ้อน $(\mathbb{R} \subset \mathbb{C})$ เมื่อส่วนจินตภาพเป็นศูนย์ $(a, 0) = a$ และจำนวนเชิงซ้อนสามารถดำเนินการทางพีชคณิต (บวกและคูณ) ได้ตามกฎที่กำหนด โดยมีสมบัติปิด การสลับที่ การเปลี่ยนหมู่ และเอกลักษณ์ สอดคล้องกับระบบจำนวนที่สมบูรณ์”

ข้อ 1. จงระบุส่วนจริง $\text{Re}(z)$ และส่วนจินตภาพ $\text{Im}(z)$ ของจำนวนต่อไปนี้ (2 คะแนน)
1.1) $z_1 = 5 - 7i$
1.2) $z_2 = (0, -9)$
พื้นที่ตอบ: 1.1) $\text{Re}(z_1) = \dots\dots,\; \text{Im}(z_1) = \dots\dots$      1.2) $\text{Re}(z_2) = \dots\dots,\; \text{Im}(z_2) = \dots\dots$
เฉลย: 1.1) $\text{Re}(z_1) = 5$, $\text{Im}(z_1) = -7$  |  1.2) $\text{Re}(z_2) = 0$, $\text{Im}(z_2) = -9$
ข้อ 2. กำหนดให้ $(2x + 1, 3y - 4) = (7, 5)$ จงหาค่าของจำนวนจริง $x$ และ $y$ (3 คะแนน)
แสดงวิธีทำ: เทียบส่วนจริง: .............................................................. เทียบส่วนจินตภาพ: ..............................................................
เฉลย: จากสมบัติความเท่ากัน:
ส่วนจริง: $2x + 1 = 7 \implies 2x = 6 \implies x = 3$
ส่วนจินตภาพ: $3y - 4 = 5 \implies 3y = 9 \implies y = 3$  ตอบ $x = 3, y = 3$
ข้อ 3. จงหาผลบวกและผลคูณของจำนวนเชิงซ้อน $z_1 = 3 + 2i$ และ $z_2 = 1 - 4i$ (3 คะแนน)
แสดงวิธีทำ:
$z_1 + z_2 = $ .........................................................................................................................................
$z_1 \cdot z_2 = $ .........................................................................................................................................
เฉลย:
$z_1 + z_2 = (3+1) + (2 + (-4))i = 4 - 2i$
$z_1 \cdot z_2 = (3 \cdot 1 - 2(-4)) + (3(-4) + 2(1))i = (3 + 8) + (-12 + 2)i = 11 - 10i$
ข้อ 4. การดำเนินการในรูปคู่อันดับ จงหาผลลัพธ์ของ $(2, -3) \cdot (-1, 5)$ (3 คะแนน)

...........................................................................................................................................................
เฉลย: ให้ $(a, b) = (2, -3)$ และ $(c, d) = (-1, 5)$
$(ac - bd, ad + bc) = (2(-1) - (-3)(5), \; 2(5) + (-3)(-1)) = (-2 - (-15), \; 10 + 3) = (13, 13)$
ข้อ 5. จงหาค่าของ $i^{25} + i^{50} + i^{75} + i^{100}$ โดยใช้สมบัติกำลังของ $i$ (4 คะแนน)
แสดงวิธีทำ: นำเลขชี้กำลังหารด้วย 4 เพื่อหาเศษ:
...........................................................................................................................................................
เฉลย:
$25 \div 4$ เหลือเศษ 1 $\implies i^{25} = i^1 = i$
$50 \div 4$ เหลือเศษ 2 $\implies i^{50} = i^2 = -1$
$75 \div 4$ เหลือเศษ 3 $\implies i^{75} = i^3 = -i$
$100 \div 4$ เหลือเศษ 0 $\implies i^{100} = 1$
$\therefore i^{25} + i^{50} + i^{75} + i^{100} = i + (-1) + (-i) + 1 = 0$

เกณฑ์การประเมินตามสภาพจริง (Rubric Assessment)

เกณฑ์การให้คะแนนแบบแยกองค์ประกอบ 3 ระดับคุณภาพ สำหรับชุดกิจกรรมการเรียนรู้นี้

ประเด็นการประเมิน ระดับ 3 (ดีเยี่ยม : 5 คะแนน) ระดับ 2 (พอใช้ : 3 คะแนน) ระดับ 1 (ปรับปรุง : 1 คะแนน)
1. ความเข้าใจมโนทัศน์
ความหมาย, $a+bi$, $(a,b)$, $\text{Re}(z)$, $\text{Im}(z)$ และสมบัติ $i^2 = -1$ 		จำแนกส่วนจริงและส่วนจินตภาพได้ถูกต้องแม่นยำทุกข้อ อธิบายความสัมพันธ์ของ $i^n$ และแปลงระหว่างคู่อันดับกับ $a+bi$ ได้อย่างสมบูรณ์ จำแนกส่วนจริงและส่วนจินตภาพได้ถูกต้องส่วนใหญ่ มีข้อผิดพลาดเล็กน้อยในการหาค่า $i^n$ หรือสับสนเครื่องหมายลบ สับสนระหว่างส่วนจริงและส่วนจินตภาพ (เช่น เขียน $bi$ แทน $b$) ไม่สามารถคำนวณกำลังของ $i$ ได้อย่างถูกต้อง
2. ทักษะการคำนวณพีชคณิต
การบวก, การคูณ และการแก้สมการความเท่ากัน 		คำนวณการบวกและคูณตามสูตร $(ac-bd, ad+bc)$ ได้ถูกต้องทุกขั้นตอน คำนวณเศษส่วนและเครื่องหมายทางคณิตศาสตร์ได้อย่างแม่นยำ เข้าใจขั้นตอนสูตรการบวกและคูณ แต่มีจุดผิดพลาดจากการคิดเลขหรือการกระจายพจน์ลบ เช่น ลืมเปลี่ยน $i^2$ เป็น $-1$ ใน 1-2 จุด ไม่สามารถประยุกต์สูตรการคูณจำนวนเชิงซ้อนได้ นำจำนวนคูณกันแบบสมาชิกตรงกัน $(ac, bd)$ ซึ่งไม่เป็นไปตามนิยาม
3. การสื่อสารและการให้เหตุผล
การแสดงวิธีทำเป็นขั้นตอนและการสรุปข้อค้นพบ 		แสดงขั้นตอนวิธีทำเป็นระเบียบชัดเจน อ้างอิงสมบัติทางคณิตศาสตร์ถูกต้อง เขียนสัญลักษณ์ LaTeX / สัญลักษณ์ทางคณิตศาสตร์ครบถ้วน แสดงวิธีทำข้ามขั้นตอนบางส่วน แต่ยังสามารถเข้าใจกระบวนการคิดและได้คำตอบปลายทางที่ถูกต้อง เขียนเพียงคำตอบโดยไม่แสดงวิธีทำ หรือขั้นตอนไม่สมเหตุสมผล ไม่เป็นไปตามตรรกะทางคณิตศาสตร์
