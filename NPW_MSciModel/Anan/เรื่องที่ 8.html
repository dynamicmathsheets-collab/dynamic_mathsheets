เรื่องที่ 8: ไฮเพอร์โบลา (The Hyperbola)

ศึกษาเซตของจุดซึ่งมีผลต่างของระยะทางไปยังจุดคงที่สองจุด (โฟกัส) เป็นค่าคงตัว ทำความเข้าใจสมการรูปมาตรฐาน จุดยอด แกนตามขวาง แกนสังยุค และบทบาทของเส้นกำกับ (Asymptotes) ในการควบคุมทิศทางและรูปร่างของกราฟ

$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$

สาระและทฤษฎี: มโนทัศน์และสมการรูปมาตรฐานของไฮเพอร์โบลา

นิยามผลต่างระยะทางคงตัว แกนตามขวาง และบทบาทของเส้นกำกับ

นิยามและสมการรูปมาตรฐาน

ไฮเพอร์โบลา (Hyperbola) คือ ทางเดินของจุด $P(x, y)$ ซึ่งมีผลต่างสัมบูรณ์ของระยะทางจาก $P$ ไปยังจุดโฟกัสสองจุด $F_1$ และ $F_2$ เป็นค่าคงตัวเท่ากับ $2a$ ($\vert{}\vert{}PF_1\vert{} - \vert{}PF_2\vert{}\vert{} = 2a$):

1. แกนตามขวางขนานแกน X (เปิดซ้าย-ขวา) $$\frac{(x - h)^2}{a^2} - \frac{(y - k)^2}{b^2} = 1$$ พจน์ $x$ เป็นบวก กราฟตัดแกนขนานแกน X ที่จุดยอด $(h \pm a, k)$
2. แกนตามขวางขนานแกน Y (เปิดบน-ล่าง) $$\frac{(y - k)^2}{a^2} - \frac{(x - h)^2}{b^2} = 1$$ พจน์ $y$ เป็นบวก กราฟตัดแกนขนานแกน Y ที่จุดยอด $(h, k \pm a)$

* ในไฮเพอร์โบลา $a^2$ คือตัวส่วนของพจน์ที่มีเครื่องหมายบวกเสมอ (ไม่จำเป็นต้องมากกว่า $b^2$)

ความสัมพันธ์ $a, b, c$ และเส้นกำกับ

• ความสัมพันธ์หลักระหว่าง $a, b, c$:
$$c^2 = a^2 + b^2 \quad \Longleftrightarrow \quad c = \sqrt{a^2 + b^2}$$
โดย $c > a$ เสมอ ($c$ คือระยะจากจุดศูนย์กลางไปยังจุดโฟกัส)
• แกนสำคัญและความยาว:
  • แกนตามขวาง (Transverse Axis): ยาว $2a$ (เชื่อมต่อระหว่างจุดยอด $V_1, V_2$)
  • แกนสังยุค (Conjugate Axis): ยาว $2b$ (ตั้งฉากกับแกนตามขวางที่จุดศูนย์กลาง)
• สมการเส้นกำกับ (Asymptotes):

เส้นตรงที่กราฟไฮเพอร์โบลาเข้าใกล้เรื่อย ๆ เมื่อจุดห่างออกไป โดยผ่านจุดตัดเส้นทแยงมุมของกล่องสี่เหลี่ยมผืนผ้าช่วยสร้างรูป:

เปิดซ้าย-ขวา: $y - k = \pm \frac{b}{a}(x - h) \quad \Big| \quad$ เปิดบน-ล่าง: $y - k = \pm \frac{a}{b}(x - h)$
ความเยื้องศูนย์กลาง (Eccentricity): $e = \frac{c}{a} > 1$ เสมอ ยิ่ง $e$ มาก กราฟจะยิ่งเปิดบานกว้าง

โมเดลปฏิสัมพันธ์: สำรวจพารามิเตอร์ไฮเพอร์โบลา $(h, k, a, b)$

ปรับตำแหน่งจุดศูนย์กลาง $(h, k)$ และขนาดครึ่งแกน $(a, b)$ เพื่อสังเกตจุดยอด โฟกัส กล่องกำกับ และการเปลี่ยนความชันของเส้นกำกับแบบเรียลไทม์

พรีเซ็ตตัวอย่าง:
ศูนย์กลาง $C$ จุดยอด $V$ โฟกัส $F$ เส้นกำกับ
แกนตามขวางและทิศทางการเปิด:
พิกัด $h$: 0
พิกัด $k$: 0
ครึ่งแกนตามขวาง $a$: 4
ครึ่งแกนสังยุค $b$: 3
สมการรูปมาตรฐาน (Standard Form)
$\frac{x^2}{16} - \frac{y^2}{9} = 1$
ไฮเพอร์โบลาเปิดซ้าย-ขวา จุดศูนย์กลาง $C(0, 0)$

ค่าพารามิเตอร์และจุดสำคัญ

จุดศูนย์กลาง $C(h, k)$ $(0, 0)$
ระยะโฟกัส $c = \sqrt{a^2 + b^2}$ $c = 5.00$
จุดยอด $V_1, V_2$ ($2a$) $(-4, 0), (4, 0)$
จุดโฟกัส $F_1, F_2$ ($2c$) $(-5, 0), (5, 0)$
สมการเส้นกำกับ (Asymptotes) $y = \pm \frac{3}{4}x$

การแปลงรูปทั่วไป ($Ax^2 + Cy^2 + Dx + Ey + F = 0$)

เกณฑ์การประเมินรูบริก (Scoring Rubric - 15 คะแนน)

เกณฑ์การประเมิน 3 ระดับ สอดคล้องตามตัวชี้วัด 5 ข้อ ข้อละ 3 คะแนน

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การวิเคราะห์องค์ประกอบไฮเพอร์โบลาแนวนอน ระบุ $a=4, b=3$ คำนวณ $c=5$ หาจุดศูนย์กลาง จุดยอด โฟกัส และสมการเส้นกำกับ $y = \pm\frac{3}{4}x$ ได้ถูกต้องสมบูรณ์ หาค่า $a, b, c$ ได้ถูกต้อง แต่เขียนสมการเส้นกำกับสลับเศษส่วนความชันเป็น $\pm\frac{4}{3}$ สับสนความสัมพันธ์ $c^2 = a^2 + b^2$ (นำไปลบกันเหมือนวงรี) หรือหาเส้นกำกับไม่ได้
2. การวิเคราะห์ไฮเพอร์โบลาแนวตั้งที่มีการเลื่อนขนาน ระบุว่าเปิดบน-ล่าง จุดศูนย์กลาง $(-1, 2)$ จุดยอด จุดโฟกัส และแกนตามขวางยาว $2a = 10$ ได้ครบถ้วนถูกต้อง หาค่า $a=5, b=12, c=13$ ได้ แต่สับสนเครื่องหมายพิกัดศูนย์กลาง $(h, k)$ สลับตัวเลข $x$ กับ $y$ จำแนกทิศทางผิด หรือคิดว่า $a^2$ ต้องเป็นตัวเลขที่มากกว่าเสมอ ($144 > 25$)
3. การสร้างสมการจากจุดยอดและโฟกัส วิเคราะห์แกนแนวนอน ระบุ $a=3, c=5$ คำนวณ $b^2 = c^2 - a^2 = 16$ และสร้างสมการมาตรฐานได้ถูกต้อง หาค่า $a$ และ $c$ ได้ แต่คำนวณ $b^2$ คลาดเคลื่อน หรือสลับเครื่องหมายลบหน้าพจน์ ใช้สูตรความสัมพันธ์ผิด เช่น คำนวณ $b^2 = a^2 + c^2$ ทำให้ได้ค่าไม่ถูกต้อง
4. การแปลงสมการทั่วไปสู่รูปมาตรฐาน จัดกำลังสองสมบูรณ์ทั้ง $x$ และ $y$ ระวังเครื่องหมายลบหน้าพจน์ $y$ ได้รูปมาตรฐาน ศูนย์กลาง $(1, -2)$ และจุดยอดสมบูรณ์ จัดรูปได้ แต่ผิดพลาดในการกระจายเครื่องหมายลบ หรือคำนวณตัวเลขบวกเข้าฝั่งขวาคลาดเคลื่อน ไม่เข้าใจการดึงตัวร่วมสัมประสิทธิ์ที่ติดลบ $(-16)$ ทำให้จัดกำลังสองสมบูรณ์ไม่ได้
5. การประยุกต์นิยามผลต่างระยะทางและเส้นกำกับ เชื่อมโยงผลต่าง $2a = 6 \implies a=3$, หาศูนย์กลาง $(1, 4), c=5 \implies b=4$ และเขียนสมการเส้นกำกับได้ถูกต้องสมบูรณ์ สร้างสมการรูปมาตรฐานได้ถูกต้อง แต่เขียนสมการเส้นกำกับสับสนความชันตามแนวตั้ง ไม่เข้าใจนิยามผลต่างคงตัวของไฮเพอร์โบลา ($2a$) หรือไม่สามารถหาจุดศูนย์กลางได้

ข้อ 1. กำหนดสมการไฮเพอร์โบลา $\frac{x^2}{16} - \frac{y^2}{9} = 1$ จงหาพิกัดจุดศูนย์กลาง จุดยอด จุดโฟกัส และสมการเส้นกำกับทั้งสองเส้น

(3 คะแนน)

วิธีทำ: พจน์ $x^2$ เป็นบวก เป็นไฮเพอร์โบลาเปิดซ้าย-ขวา โดย $a^2 = 16 \implies a = 4$ และ $b^2 = 9 \implies b = 3$

1) จุดศูนย์กลาง $C(0, 0)$ และ จุดยอด $V(\pm a, 0) = (\pm 4, 0)$

2) หาค่า $c$: $c = \sqrt{a^2 + b^2} = \sqrt{16 + 9} = \sqrt{25} = 5 \implies$ โฟกัส $F(\pm 5, 0)$

3) สมการเส้นกำกับ: $y - k = \pm \frac{b}{a}(x - h) \implies y = \pm \frac{3}{4}x$ หรือ $3x \pm 4y = 0$

ตอบ ศูนย์กลาง $(0, 0)$, จุดยอด $(\pm 4, 0)$, โฟกัส $(\pm 5, 0)$ และเส้นกำกับคือ $y = \pm \frac{3}{4}x$

ข้อ 2. กำหนดสมการไฮเพอร์โบลา $\frac{(y - 2)^2}{25} - \frac{(x + 1)^2}{144} = 1$ จงระบุทิศทางการเปิด จุดยอด จุดโฟกัส และความยาวแกนตามขวาง

(3 คะแนน)

วิธีทำ: พจน์ $(y - 2)^2$ เป็นบวก กราฟเปิดบน-ล่าง จุดศูนย์กลางอยู่ที่ $(h, k) = (-1, 2)$

ค่า $a^2 = 25 \implies a = 5$ และ $b^2 = 144 \implies b = 12$

หา $c = \sqrt{25 + 144} = \sqrt{169} = 13$

จุดยอด: $(-1, 2 \pm 5) \implies V_1(-1, 7)$ และ $V_2(-1, -3)$ | โฟกัส: $(-1, 2 \pm 13) \implies F_1(-1, 15)$ และ $F_2(-1, -11)$

ตอบ เปิดบน-ล่าง, จุดยอด $(-1, 7), (-1, -3)$, จุดโฟกัส $(-1, 15), (-1, -11)$ และแกนตามขวางยาว $10$ หน่วย

ข้อ 3. จงหาสมการรูปมาตรฐานของไฮเพอร์โบลาที่มีจุดศูนย์กลางอยู่ที่จุดกำเนิด จุดยอดอยู่ที่ $(\pm 3, 0)$ และจุดโฟกัสอยู่ที่ $(\pm 5, 0)$

(3 คะแนน)

วิธีทำ: จุดยอดและโฟกัสอยู่บนแกน X แสดงว่ากราฟเปิดซ้าย-ขวา โดย $a = 3 \implies a^2 = 9$ และ $c = 5$

จากความสัมพันธ์ $c^2 = a^2 + b^2 \implies b^2 = c^2 - a^2 = 5^2 - 3^2 = 25 - 9 = 16$

สมการรูปมาตรฐานคือ $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ แทนค่า $a^2 = 9$ และ $b^2 = 16$

ตอบ $\frac{x^2}{9} - \frac{y^2}{16} = 1$

หน้า 1 จาก 2

ข้อ 4. จงจัดสมการ $9x^2 - 16y^2 - 18x - 64y - 199 = 0$ ให้อยู่ในรูปมาตรฐาน พร้อมหาพิกัดจุดศูนย์กลาง และพิกัดจุดยอด

(3 คะแนน)

วิธีทำ: จัดกลุ่มพจน์ $x$ และ $y$: $9(x^2 - 2x) - 16(y^2 + 4y) = 199$

ทำกำลังสองสมบูรณ์: $9(x^2 - 2x + 1) - 16(y^2 + 4y + 4) = 199 + 9(1) - 16(4) \implies 9(x - 1)^2 - 16(y + 2)^2 = 144$

หารด้วย 144 ตลอด: $\frac{(x - 1)^2}{16} - \frac{(y + 2)^2}{9} = 1$

จุดศูนย์กลางอยู่ที่ $(h, k) = (1, -2)$ และ $a^2 = 16 \implies a = 4$

จุดยอด (เปิดซ้าย-ขวา): $(1 \pm 4, -2) \implies V_1(5, -2)$ และ $V_2(-3, -2)$

ตอบ รูปมาตรฐาน $\frac{(x - 1)^2}{16} - \frac{(y + 2)^2}{9} = 1$, ศูนย์กลาง $(1, -2)$ และจุดยอดคือ $(5, -2), (-3, -2)$

ข้อ 5. ไฮเพอร์โบลารูปหนึ่งมีจุดโฟกัสอยู่ที่ $(1, -1)$ และ $(1, 9)$ มีผลต่างของระยะทางจากจุดใด ๆ บนกราฟไปยังโฟกัสทั้งสองเท่ากับ $6$ หน่วย จงหาสมการรูปมาตรฐานและสมการเส้นกำกับ

(3 คะแนน)

วิธีทำ: โฟกัสมีค่า $x = 1$ เท่ากัน แสดงว่าแกนตามขวางขนานแกน Y (เปิดบน-ล่าง)

จุดศูนย์กลางคือจุดกึ่งกลางโฟกัส: $C = \left(1, \frac{-1+9}{2}\right) = (1, 4)$ และระยะ $2c = 9 - (-1) = 10 \implies c = 5$

ผลต่างระยะทางตามนิยาม $2a = 6 \implies a = 3 \implies a^2 = 9$

หา $b^2 = c^2 - a^2 = 5^2 - 3^2 = 25 - 9 = 16 \implies b = 4$

สมการรูปมาตรฐาน: $\frac{(y - 4)^2}{9} - \frac{(x - 1)^2}{16} = 1$ | เส้นกำกับ: $y - 4 = \pm \frac{3}{4}(x - 1)$

ตอบ $\frac{(y - 4)^2}{9} - \frac{(x - 1)^2}{16} = 1$ และสมการเส้นกำกับคือ $y - 4 = \pm \frac{3}{4}(x - 1)$
