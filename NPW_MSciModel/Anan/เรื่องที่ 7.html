เรื่องที่ 7: พาราโบลา (The Parabola)

ศึกษาเซตของจุดที่มีระยะห่างจากจุดคงที่ (โฟกัส) เท่ากับระยะห่างไปยังเส้นตรงคงที่ (เส้นไดเรกทริกซ์) ทำความเข้าใจสมการรูปมาตรฐาน จุดยอด แกนสมมาตร ทิศทางการเปิด และความกว้างของกราฟผ่านพารามิเตอร์ $c$

$x^2=4cy$

สาระและทฤษฎี: มโนทัศน์และสมการรูปมาตรฐานของพาราโบลา

นิยามทางเรขาคณิต แกนสมมาตร จุดโฟกัส และเส้นไดเรกทริกซ์

นิยามและสมการรูปมาตรฐาน

พาราโบลา (Parabola) คือ ทางเดินของจุด $P(x, y)$ ซึ่งอยู่ห่างจากจุดคงที่จุดหนึ่งเรียกว่า จุดโฟกัส ($F$) เท่ากับระยะห่างจากจุด $P$ ไปยังเส้นตรงคงที่เส้นหนึ่งเรียกว่า เส้นไดเรกทริกซ์ ($l$):

1. แกนตั้ง (แกนสมมาตรขนานแกน Y) $$(x - h)^2 = 4c(y - k)$$ ถ้า $c > 0$ กราฟหงายขึ้น | ถ้า $c < 0$ กราฟคว่ำลง
2. แกนนอน (แกนสมมาตรขนานแกน X) $$(y - k)^2 = 4c(x - h)$$ ถ้า $c > 0$ กราฟเปิดขวา | ถ้า $c < 0$ กราฟเปิดซ้าย

* จุดยอดอยู่ที่ $V(h, k)$ และระยะห่างจากจุดยอดถึงโฟกัสเท่ากับ $\vert{}c\vert{}$ เสมอ

พารามิเตอร์ $c$ และองค์ประกอบสำคัญ

• บทบาทของพารามิเตอร์ $c$:
  • เครื่องหมายของ $c$: กำหนดทิศทางการเปิดของพาราโบลา (บวก: หงาย/ขวา, ลบ: คว่ำ/ซ้าย)
  • ขนาดของ $|c|$: ยิ่ง $|c|$ มีค่ามาก กราฟจะยิ่งกว้างและบานออก โฟกัสและไดเรกทริกซ์จะอยู่ห่างจากจุดยอดมากขึ้น
• ความยาวคอร์ดลาตัสเรกตัม (Latus Rectum):

คือส่วนของเส้นตรงที่ผ่านจุดโฟกัสและตั้งฉากกับแกนสมมาตร มีความยาวเท่ากับ $|4c|$ หน่วย ซึ่งเป็นตัวชี้วัดความกว้างของกราฟ ณ ตำแหน่งโฟกัส

• เส้นไดเรกทริกซ์ (Directrix):

เป็นเส้นตรงที่อยู่นอกพาราโบลาขนานกับคอร์ดลาตัสเรกตัม โดยจุดยอด $V$ จะอยู่กึ่งกลางระหว่างจุดโฟกัสและเส้นไดเรกทริกซ์พอดี

รูปทั่วไป (General Form): $Ax^2 + Dx + Ey + F = 0$ (แกนตั้ง) หรือ $Cy^2 + Dx + Ey + F = 0$ (แกนนอน)

โมเดลปฏิสัมพันธ์: สำรวจพารามิเตอร์พาราโบลา $(h, k, c)$

ปรับเปลี่ยนจุดยอด $(h, k)$ และระยะโฟกัส $c$ เพื่อสังเกตจุดยอด โฟกัส ไดเรกทริกซ์ แกนสมมาตร และความกว้างของกราฟแบบเรียลไทม์

พรีเซ็ตตัวอย่าง:
จุดยอด $V$ โฟกัส $F$ ไดเรกทริกซ์ ลาตัสเรกตัม
แกนสมมาตรและทิศทาง:
พิกัด $h$ (เลื่อน ซ้าย-ขวา): 0
พิกัด $k$ (เลื่อน ขึ้น-ลง): 0
ระยะโฟกัส $c$ (ทิศทาง/ความกว้าง): 2
สมการรูปมาตรฐาน (Standard Form)
$x^2 = 8y$
พาราโบลาหงาย จุดยอด $V(0, 0)$

ค่าพารามิเตอร์และองค์ประกอบสำคัญ

จุดยอด $V(h, k)$ $(0, 0)$
จุดโฟกัส $F$ $(0, 2)$
สมการไดเรกทริกซ์ $y = -2$
สมการแกนสมมาตร $x = 0$
ความยาวลาตัสเรกตัม ($\vert{}4c\vert{}$) 8 หน่วย (กว้าง $4c = 8$)

เกณฑ์การประเมินรูบริก (Scoring Rubric - 15 คะแนน)

เกณฑ์การประเมิน 3 ระดับ สอดคล้องตามตัวชี้วัด 5 ข้อ ข้อละ 3 คะแนน

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การวิเคราะห์องค์ประกอบพาราโบลาแกนตั้ง เทียบรูปมาตรฐานหา $4c = 12 \implies c = 3$ ระบุจุดยอด โฟกัส ไดเรกทริกซ์ และลาตัสเรกตัมได้ถูกต้องสมบูรณ์ หาค่า $c$ ถูกต้อง แต่คำนวณสมการไดเรกทริกซ์หรือเครื่องหมายจุดยอดผิดพลาด 1 จุด สับสนระหว่างแกนตั้งกับแกนนอน หรือคิดว่า $c = 12$
2. การวิเคราะห์พาราโบลาแกนนอนที่เปิดซ้าย ระบุทิศทางเปิดซ้ายได้ถูกต้อง จุดยอด $(1, -3)$ โฟกัส $(-1, -3)$ และแกนสมมาตร $y = -3$ ครบถ้วนสมบูรณ์ ระบุจุดยอดถูกต้อง แต่นำค่า $c$ ไปบวกลบผิดแกนทำให้พิกัดโฟกัสคลาดเคลื่อน สับสนพิกัดจุดยอด $(h, k)$ สลับตัวแปร $x$ กับ $y$
3. การสร้างสมการจากแกนสมมาตรและจุดผ่าน เลือกรูป $y^2 = 4cx$ แทนค่าจุด $(2, -4)$ แก้สมการหา $c = 2$ และสร้างสมการ $y^2 = 8x$ ได้ถูกต้อง เลือกรูปสมการถูกต้อง แต่คำนวณเลขยกกำลังสองหรือแก้หาค่า $c$ ผิดพลาดเล็กน้อย เลือกรูปสมการผิด เช่น ใช้ $x^2 = 4cy$ ทำให้หาค่าไม่สอดคล้อง
4. การแปลงสมการทั่วไปสู่รูปมาตรฐาน จัดกำลังสองสมบูรณ์พจน์ $y$ ได้ $(y-2)^2 = 8(x+3)$ ระบุจุดยอด $(-3, 2)$ และโฟกัส $(-1, 2)$ ได้ครบถ้วน จัดรูปกำลังสองสมบูรณ์ได้ แต่ดึงตัวร่วมฝั่งขวาคลาดเคลื่อนทำให้ค่า $h$ หรือ $c$ ผิด ไม่สามารถจัดรูปกำลังสองสมบูรณ์เพื่อแยกตัวแปรได้
5. การประยุกต์นิยามระยะโฟกัสและไดเรกทริกซ์ วิเคราะห์แกนตั้ง หาจุดยอดกึ่งกลาง $(3, 3)$ ระยะ $c = 2$ และสร้างสมการ $(x-3)^2 = 8(y-3)$ ได้ถูกต้องสมบูรณ์ หาจุดยอดถูกต้อง แต่คำนวณระยะ $c$ ผิด หรือเขียนสมการสลับแกน ไม่เข้าใจความสัมพันธ์ระหว่างโฟกัส จุดยอด และไดเรกทริกซ์

ข้อ 1. กำหนดสมการพาราโบลา $(x - 2)^2 = 12(y + 1)$ จงหาจุดยอด จุดโฟกัส สมการไดเรกทริกซ์ และความยาวลาตัสเรกตัม

(3 คะแนน)

วิธีทำ: เทียบกับ $(x - h)^2 = 4c(y - k)$ จะได้จุดยอด $V(h, k) = (2, -1)$

เทียบค่า $4c = 12 \implies c = 3 > 0$ แสดงว่าเป็นพาราโบลาหงายขึ้น

1) จุดโฟกัส: $F(h, k + c) = (2, -1 + 3) = (2, 2)$

2) สมการเส้นไดเรกทริกซ์: $y = k - c \implies y = -1 - 3 \implies y = -4$

3) ความยาวลาตัสเรกตัม: $|4c| = |12| = 12$ หน่วย

ตอบ จุดยอด $(2, -1)$, จุดโฟกัส $(2, 2)$, ไดเรกทริกซ์ $y = -4$, ลาตัสเรกตัมยาว $12$ หน่วย

ข้อ 2. กำหนดสมการพาราโบลา $(y + 3)^2 = -8(x - 1)$ จงบอกทิศทางการเปิด จุดยอด จุดโฟกัส และสมการแกนสมมาตร

(3 คะแนน)

วิธีทำ: เทียบกับ $(y - k)^2 = 4c(x - h)$ จะได้จุดยอด $V(1, -3)$

เทียบค่า $4c = -8 \implies c = -2 < 0$ แสดงว่าเป็นพาราโบลาแกนนอน เปิดไปทางซ้าย

1) จุดโฟกัส: $F(h + c, k) = (1 + (-2), -3) = (-1, -3)$

2) แกนสมมาตรคือเส้นแนวนอนผ่านจุดยอด: $y = k \implies y = -3$

ตอบ เปิดทางซ้าย, จุดยอด $(1, -3)$, จุดโฟกัส $(-1, -3)$ และแกนสมมาตรคือ $y = -3$

ข้อ 3. จงหาสมการรูปมาตรฐานของพาราโบลาที่มีจุดยอดอยู่ที่ $(0, 0)$ มีแกนสมมาตรทับแกน X และผ่านจุด $(2, -4)$

(3 คะแนน)

วิธีทำ: แกนสมมาตรทับแกน X ($y = 0$) และจุดยอดที่ $(0, 0)$ สมการอยู่ในรูป $y^2 = 4cx$

พาราโบลาผ่านจุด $(2, -4)$ แทนค่า $x = 2, y = -4$:

$$(-4)^2 = 4c(2) \implies 16 = 8c \implies c = 2$$

แทนค่า $4c = 4(2) = 8$ ในรูปสมการมาตรฐาน:

ตอบ $y^2 = 8x$

หน้า 1 จาก 2

ข้อ 4. จงจัดรูปสมการ $y^2 - 4y - 8x - 20 = 0$ ให้อยู่ในรูปมาตรฐาน พร้อมหาพิกัดจุดยอด และพิกัดจุดโฟกัส

(3 คะแนน)

วิธีทำ: จัดกลุ่มพจน์กำลังสองของ $y$: $y^2 - 4y = 8x + 20$

บวก 4 ทั้งสองข้าง: $(y^2 - 4y + 4) = 8x + 20 + 4 \implies (y - 2)^2 = 8x + 24$

ดึงตัวร่วมฝั่งขวา: $(y - 2)^2 = 8(x + 3)$

เทียบรูปมาตรฐานจะได้ $4c = 8 \implies c = 2 > 0$ (เปิดขวา) และจุดยอด $V(-3, 2)$

โฟกัส: $F(h + c, k) = (-3 + 2, 2) = (-1, 2)$

ตอบ รูปมาตรฐานคือ $(y - 2)^2 = 8(x + 3)$, จุดยอด $(-3, 2)$ และจุดโฟกัส $(-1, 2)$

ข้อ 5. พาราโบลารูปหนึ่งมีจุดโฟกัสอยู่ที่ $(3, 5)$ และมีสมการเส้นไดเรกทริกซ์คือ $y = 1$ จงหาสมการรูปมาตรฐานของพาราโบลานี้

(3 คะแนน)

วิธีทำ: ไดเรกทริกซ์เป็นแนวนอน ($y = 1$) แสดงว่าแกนสมมาตรเป็นแนวตั้ง ($x = 3$)

จุดยอด $V$ อยู่กึ่งกลางระหว่างโฟกัสกับไดเรกทริกซ์: $k = \frac{5 + 1}{2} = 3 \implies V(3, 3)$

ระยะโฟกัส: $c = 5 - 3 = 2 > 0$ (หงายขึ้น) ดังนั้น $4c = 4(2) = 8$

สร้างสมการมาตรฐานตามแนวตั้ง: $(x - h)^2 = 4c(y - k)$

ตอบ $(x - 3)^2 = 8(y - 3)$
