เรื่องที่ 5: วงกลม (The Circle)

ศึกษาเซตของจุดที่มีระยะห่างจากจุดคงที่เป็นค่าคงตัว ทำความเข้าใจสมการวงกลมในรูปมาตรฐาน เชื่อมโยงพารามิเตอร์จุดศูนย์กลาง $(h, k)$ และรัศมี $r$ สู่ตำแหน่ง ขนาด และการแปลงสมการในรูปทั่วไป

$(x-h)^2$

สาระและทฤษฎี: มโนทัศน์และสมการวงกลม

การกำหนดตำแหน่งและขนาดของวงกลมบนระนาบพิกัดฉาก

นิยามและสมการรูปมาตรฐาน

วงกลม (Circle) คือ ทางเดินของจุด $P(x, y)$ ซึ่งอยู่ห่างจากจุดคงที่จุดหนึ่งเรียกว่า จุดศูนย์กลาง $C(h, k)$ เป็นระยะทางคงตัวเท่ากับ รัศมี $r$ ($r > 0$):

$$(x - h)^2 + (y - k)^2 = r^2$$

หากจุดศูนย์กลางอยู่ที่จุดกำเนิด $(0, 0)$ สมการจะลดรูปเหลือ $x^2 + y^2 = r^2$

อิทธิพลของพารามิเตอร์ต่อกราฟ

  • • ค่า $h$: กำหนดตำแหน่งในแนวนอน (ปรับค่า $h$ เพิ่มขึ้นวงกลมเลื่อนไปทางขวา ลดลงเลื่อนไปทางซ้าย)
  • • ค่า $k$: กำหนดตำแหน่งในแนวตั้ง (ปรับค่า $k$ เพิ่มขึ้นวงกลมเลื่อนขึ้นบน ลดลงเลื่อนลงล่าง)
  • • ค่า $r$: กำหนดขนาดของวงกลม ($r$ มากขึ้นวงกลมขยายใหญ่, $r$ ลดลงวงกลมหดเล็กลง)
รูปทั่วไป: $x^2 + y^2 + Dx + Ey + F = 0$ โดยจัดรูปหากำลังสองสมบูรณ์จะได้ $h = -\frac{D}{2}$, $k = -\frac{E}{2}$ และ $r = \sqrt{h^2 + k^2 - F}$

โมเดลปฏิสัมพันธ์: สำรวจพารามิเตอร์วงกลม $(h, k, r)$

เลื่อนปรับค่าพารามิเตอร์เพื่อค้นพบผลลัพธ์ที่มีต่อตำแหน่ง ขนาด และสมการวงกลมทั้งรูปมาตรฐานและรูปทั่วไป

พรีเซ็ตตำแหน่ง:
จุดศูนย์กลาง $C(h,k)$ รัศมี $r$ เส้นรอบวง
แกนนอน $h$ (เลื่อน ซ้าย-ขวา): 2
แกนตั้ง $k$ (เลื่อน ขึ้น-ลง): 3
รัศมี $r$ (ขนาด ใหญ่-เล็ก): 5
สมการรูปมาตรฐาน (Standard Form)
$(x - 2)^2 + (y - 3)^2 = 25$
จุดศูนย์กลาง $C(2, 3)$ รัศมี $r = 5$ หน่วย
ข้อค้นพบพฤติกรรมของพารามิเตอร์

การแปลงสู่สมการรูปทั่วไป ($Ax^2 + Cy^2 + \dots$)

เกณฑ์การประเมินรูบริก (Scoring Rubric - 15 คะแนน)

เกณฑ์การประเมิน 3 ระดับ สอดคล้องตามตัวชี้วัด 5 ข้อ ข้อละ 3 คะแนน

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การสร้างสมการวงกลมจากศูนย์กลางและรัศมี แทนค่า $(h, k)$ และ $r$ ได้ถูกต้อง จัดรูปมาตรฐานและกระจายเป็นรูปทั่วไปได้ถูกต้องสมบูรณ์ เขียนรูปมาตรฐานถูกต้อง แต่ผิดพลาดในขั้นตอนการกระจายพจน์หรือคำนวณตัวเลขในรูปทั่วไป จำสูตรผิด หรือสับสนเครื่องหมายลบของพิกัดจุดศูนย์กลาง เช่น เขียน $(x - 3)$ แทนที่จะเป็น $(x + 3)$
2. การหาศูนย์กลางและรัศมีจากสมการทั่วไป จัดกำลังสองสมบูรณ์ทั้งพจน์ $x$ และ $y$ ถูกต้อง ระบุพิกัด $(h, k)$ และรัศมี $r$ ได้ถูกต้องครบถ้วน จัดกำลังสองสมบูรณ์ได้ แต่คำนวณตัวเลขบวกเข้าฝั่งขวาคลาดเคลื่อนทำให้ค่า $r$ ผิดพลาด ไม่เข้าใจหลักการจัดรูปกำลังสองสมบูรณ์ หรือสับสนการดึงเครื่องหมายของจุดศูนย์กลาง
3. การสร้างสมการเมื่อทราบจุดศูนย์กลางและจุดผ่าน ใช้สูตรระยะทางคำนวณหาค่ารัศมี $r$ หรือ $r^2$ ได้ถูกต้อง และเขียนสมการวงกลมได้สมบูรณ์ ตั้งสูตรระยะทางถูกต้อง แต่คำนวณผลต่างพิกัดหรือยกกำลังสองผิดพลาดเล็กน้อย นำพิกัดจุดผ่านไปใช้แทนที่จุดศูนย์กลาง หรือคำนวณหารัศมีไม่ได้
4. การหาสมการจากจุดปลายเส้นผ่านศูนย์กลาง หาจุดกึ่งกลางเป็น $(h, k)$ และหารัศมีจากครึ่งหนึ่งของความยาวเส้นผ่านศูนย์กลางได้อย่างถูกต้องสมบูรณ์ หาจุดศูนย์กลางได้ถูกต้อง แต่ลืมหาร 2 ในขั้นตอนการหารัศมี หรือคิดเลขยกกำลังสองผิด ไม่สามารถเชื่อมโยงแนวคิดจุดกึ่งกลางกับจุดศูนย์กลางของวงกลมได้
5. การประยุกต์วงกลมที่สัมผัสแกนพิกัด วิเคราะห์เงื่อนไขการสัมผัสแกน $Y$ เพื่อสรุปว่า $r = |h| = 4$ และเขียนสมการรูปมาตรฐานได้ถูกต้อง เข้าใจความสัมพันธ์แต่สับสนนำค่า $k$ มาใช้เป็นรัศมีแทน ($r = \vert{}k\vert{}$) ไม่สามารถวิเคราะห์หาความยาวรัศมีจากเงื่อนไขการสัมผัสแกนได้

ข้อ 1. จงหาสมการวงกลมในรูปมาตรฐานและรูปทั่วไป ที่มีจุดศูนย์กลางอยู่ที่ $(-3, 4)$ และมีรัศมียาว $6$ หน่วย

(3 คะแนน)

วิธีทำ: จากรูปมาตรฐาน $(x - h)^2 + (y - k)^2 = r^2$ แทนค่า $(h, k) = (-3, 4)$ และ $r = 6$

$$(x - (-3))^2 + (y - 4)^2 = 6^2 \implies (x + 3)^2 + (y - 4)^2 = 36$$

กระจายพจน์: $(x^2 + 6x + 9) + (y^2 - 8y + 16) = 36 \implies x^2 + y^2 + 6x - 8y - 11 = 0$

ตอบ รูปมาตรฐานคือ $(x + 3)^2 + (y - 4)^2 = 36$ และรูปทั่วไปคือ $x^2 + y^2 + 6x - 8y - 11 = 0$

ข้อ 2. จงหาจุดศูนย์กลางและรัศมีของวงกลมที่มีสมการคือ $x^2 + y^2 - 6x + 8y - 11 = 0$

(3 คะแนน)

วิธีทำ: จัดกลุ่มและทำเป็นกำลังสองสมบูรณ์:

$$(x^2 - 6x + 9) + (y^2 + 8y + 16) = 11 + 9 + 16 \implies (x - 3)^2 + (y + 4)^2 = 36$$

เทียบกับ $(x - h)^2 + (y - k)^2 = r^2$ จะได้ $h = 3, k = -4$ และ $r = \sqrt{36} = 6$

ตอบ จุดศูนย์กลางอยู่ที่ $(3, -4)$ และรัศมียาว $6$ หน่วย

ข้อ 3. จงหาสมการวงกลมที่มีจุดศูนย์กลางอยู่ที่ $(2, -5)$ และผ่านจุด $P(6, -2)$

(3 คะแนน)

วิธีทำ: รัศมี $r$ คือระยะทางระหว่างจุดศูนย์กลางและจุดบนวงกลม:

$$r^2 = (6 - 2)^2 + (-2 - (-5))^2 = 4^2 + 3^2 = 16 + 9 = 25 \implies r = 5$$

สร้างสมการรูปมาตรฐานโดยใช้จุดศูนย์กลาง $(2, -5)$:

ตอบ $(x - 2)^2 + (y + 5)^2 = 25$

หน้า 1 จาก 2

ข้อ 4. วงกลมวงหนึ่งมีจุดปลายของเส้นผ่านศูนย์กลางอยู่ที่ $A(-1, 2)$ และ $B(5, -6)$ จงหาสมการรูปมาตรฐานของวงกลมนี้

(3 คะแนน)

วิธีทำ: 1) หาจุดศูนย์กลาง (จุดกึ่งกลาง $AB$): $C = \left(\frac{-1+5}{2}, \frac{2+(-6)}{2}\right) = (2, -2)$

2) หารัศมี $r$ จากระยะ $CA$: $r^2 = (2 - (-1))^2 + (-2 - 2)^2 = 3^2 + (-4)^2 = 9 + 16 = 25$

สร้างสมการมาตรฐาน: $(x - 2)^2 + (y - (-2))^2 = 25$

ตอบ $(x - 2)^2 + (y + 2)^2 = 25$

ข้อ 5. จงหาสมการวงกลมที่มีจุดศูนย์กลางอยู่ที่ $(-4, 3)$ และมีเส้นรอบวงสัมผัสกับแกน $Y$

(3 คะแนน)

วิธีทำ: วงกลมสัมผัสกับแกน $Y$ (สมการแกน $Y$ คือ $x = 0$) รัศมี $r$ จึงเท่ากับระยะห่างแนวนอนจากศูนย์กลางถึงแกน $Y$:

$$r = |h| = |-4| = 4 \implies r^2 = 16$$

สร้างสมการมาตรฐาน: $(x - (-4))^2 + (y - 3)^2 = 4^2 \implies (x + 4)^2 + (y - 3)^2 = 16$

ตอบ $(x + 4)^2 + (y - 3)^2 = 16$
