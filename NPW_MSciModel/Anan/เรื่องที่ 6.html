เรื่องที่ 6: วงรี (The Ellipse)

ศึกษาเซตของจุดซึ่งมีผลบวกของระยะทางไปยังจุดคงที่สองจุด (โฟกัส) เป็นค่าคงตัว ทำความเข้าใจสมการวงรีในรูปมาตรฐาน ความสัมพันธ์ระหว่างจุดศูนย์กลาง แกนเอก แกนโท จุดยอด และโฟกัส ผ่านพารามิเตอร์ $a, b, c$

$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$

สาระและทฤษฎี: มโนทัศน์และสมการรูปมาตรฐานของวงรี

การเชื่อมโยงระยะทางคงตัวสู่รูปทรงและพารามิเตอร์เรขาคณิต

นิยามและสมการรูปมาตรฐาน

วงรี (Ellipse) คือ เซตของจุด $P(x, y)$ ทั้งหมดบนระนาบ ซึ่งมีผลบวกของระยะทางจาก $P$ ไปยังจุดโฟกัสสองจุด $F_1$ และ $F_2$ เป็นค่าคงตัวเท่ากับ $2a$ โดยที่ $a > b > 0$:

แกนเอกขนานแกน X (แนวนอน) $$\frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1$$
แกนเอกขนานแกน Y (แนวตั้ง) $$\frac{(x - h)^2}{b^2} + \frac{(y - k)^2}{a^2} = 1$$

* สังเกตว่าตัวส่วนที่มีค่ามากกว่าเสมอคือ $a^2$ และตัวส่วนที่น้อยกว่าคือ $b^2$

ความสัมพันธ์ของพารามิเตอร์ $a, b, c$

• ความสัมพันธ์หลักระหว่าง $a, b, c$:
$$a^2 = b^2 + c^2 \quad \Longleftrightarrow \quad c = \sqrt{a^2 - b^2}$$
โดย $c$ คือระยะห่างจากจุดศูนย์กลางไปยังจุดโฟกัสแต่ละจุด
• ความยาวแกนสมมาตร:
  • แกนเอก (Major Axis): ยาว $2a$ (เชื่อมต่อระหว่างจุดยอด $V_1, V_2$)
  • แกนโท (Minor Axis): ยาว $2b$ (เชื่อมต่อระหว่างจุดปลายแกนโท $B_1, B_2$)
• รูปร่างของวงรี:

หาก $b$ มีค่าเข้าใกล้ $a$ วงรีจะมีความกลมมากขึ้น (เมื่อ $a = b$ จะกลายเป็นวงกลม) แต่ถ้า $b$ มีค่าน้อยกว่า $a$ มาก ๆ วงรีจะยิ่งมีความแบนรี

ความเยื้องศูนย์กลาง (Eccentricity): $e = \frac{c}{a}$ ($0 \le e < 1$) ยิ่ง $e$ เข้าใกล้ 1 วงรียิ่งแบนรีมาก แต่ถ้า $e = 0$ จะกลายเป็นวงกลม

โมเดลปฏิสัมพันธ์: สำรวจพารามิเตอร์วงรี $(h, k, a, b)$

ปรับตำแหน่งศูนย์กลาง $(h, k)$ และความยาวครึ่งแกน $(a, b)$ เพื่อสังเกตรูปร่าง พิกัดจุดยอด โฟกัส และแกนสมมาตรแบบเรียลไทม์

พรีเซ็ตตัวอย่าง:
ศูนย์กลาง $C$ จุดยอด $V_1, V_2$ โฟกัส $F_1, F_2$ ปลายแกนโท $B_1, B_2$
ทิศทางของแกนเอก:
พิกัด $h$: 0
พิกัด $k$: 0
ครึ่งแกนเอก $a$: 5
ครึ่งแกนโท $b$: 3
สมการรูปมาตรฐาน (Standard Form)
$\frac{x^2}{25} + \frac{y^2}{9} = 1$
วงรีแนวนอน จุดศูนย์กลาง $C(0, 0)$

ค่าพารามิเตอร์และจุดสำคัญ

จุดศูนย์กลาง $C(h, k)$ $(0, 0)$
ระยะโฟกัส $c = \sqrt{a^2 - b^2}$ $c = 4.00$
จุดยอด $V_1, V_2$ ($2a$) $(-5, 0), (5, 0)$
จุดโฟกัส $F_1, F_2$ ($2c$) $(-4, 0), (4, 0)$
ความยาวแกนเอก ($2a$) 10 หน่วย
ความยาวแกนโท ($2b$) 6 หน่วย

เกณฑ์การประเมินรูบริก (Scoring Rubric - 15 คะแนน)

เกณฑ์การประเมิน 3 ระดับ สอดคล้องตามตัวชี้วัด 5 ข้อ ข้อละ 3 คะแนน

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การวิเคราะห์องค์ประกอบวงรีแนวนอนที่จุดกำเนิด ระบุ $a, b$ ถูกต้อง ใช้ $c = \sqrt{a^2 - b^2}$ หาโฟกัส จุดยอด จุดศูนย์กลาง และความยาวแกนเอก แกนโทได้ครบถ้วนสมบูรณ์ หาค่า $a, b, c$ ได้ถูกต้อง แต่เขียนพิกัดโฟกัสหรือจุดยอดสับสนสลับแกน สับสนความสัมพันธ์ $c^2 = a^2 - b^2$ หรือไม่เข้าใจแกนของวงรี
2. การวิเคราะห์วงรีแนวตั้งที่มีการเลื่อนขนาน จำแนกได้ว่าเป็นแนวตั้ง ระบุศูนย์กลาง $(h, k)$ และคำนวณพิกัดโฟกัสตามแนวแกนตั้งได้ถูกต้องสมบูรณ์ ระบุศูนย์กลางถูกต้อง และรู้ว่าเป็นแนวตั้ง แต่นำค่า $c$ ไปบวกลบผิดแกน (ไปบวกที่แกน $x$) สับสนเครื่องหมายของจุดศูนย์กลาง หรือระบุทิศทางแกนเอกผิดพลาด
3. การสร้างสมการวงรีจากจุดยอดและโฟกัส ระบุค่า $a, c$ จากพิกัดที่กำหนด คำนวณ $b^2 = a^2 - c^2$ และเขียนสมการมาตรฐานได้ถูกต้องสมบูรณ์ หาค่า $a$ และ $c$ ได้ แต่คำนวณ $b^2$ คลาดเคลื่อน หรือสับสนตำแหน่งตัวส่วน ใช้สูตรความสัมพันธ์ผิด เช่น คิดว่า $b^2 = a^2 + c^2$
4. การแปลงสมการทั่วไปสู่รูปมาตรฐาน ดึงตัวร่วมและจัดกำลังสองสมบูรณ์ทั้งตัวแปร $x$ และ $y$ ได้ถูกต้อง จนได้รูปมาตรฐาน ศูนย์กลาง และความยาวแกนเอกสมบูรณ์ จัดรูปกำลังสองสมบูรณ์ได้ แต่ผิดพลาดในการบวกค่าคงที่ฝั่งขวาของสมการ ไม่เข้าใจขั้นตอนการจัดกำลังสองสมบูรณ์ของสมการที่มีสัมประสิทธิ์หน้าตัวแปร
5. การประยุกต์นิยามผลบวกระยะทางโฟกัส เชื่อมโยงผลบวกระยะทาง $2a = 10$, หาจุดศูนย์กลางและระยะโฟกัส $c$ จากจุดโฟกัสทั้งสอง จนสร้างสมการแนวตั้งได้ถูกต้องสมบูรณ์ หาจุดศูนย์กลางและ $a$ ได้ถูกต้อง แต่คำนวณ $b^2$ ผิดพลาด หรือวางสลับแกน ไม่เข้าใจนิยามผลบวกคงตัวของวงรี ($2a$) ทำให้ไม่สามารถเริ่มต้นแก้ปัญหาได้

ข้อ 1. กำหนดสมการวงรี $\frac{x^2}{25} + \frac{y^2}{16} = 1$ จงหาพิกัดของจุดศูนย์กลาง จุดยอด จุดโฟกัส และความยาวของแกนเอก แกนโท

(3 คะแนน)

วิธีทำ: ตัวส่วนใต้ $x^2$ มากกว่า ($a^2 = 25 \implies a = 5$) และ $b^2 = 16 \implies b = 4$ เป็นวงรีแนวนอน

1) จุดศูนย์กลาง $C(0, 0)$

2) หาค่า $c$: $c = \sqrt{a^2 - b^2} = \sqrt{25 - 16} = \sqrt{9} = 3$

3) จุดยอด $V(\pm a, 0) = (\pm 5, 0)$ และ โฟกัส $F(\pm c, 0) = (\pm 3, 0)$

ตอบ จุดศูนย์กลาง $(0, 0)$, จุดยอด $(\pm 5, 0)$, โฟกัส $(\pm 3, 0)$, แกนเอกยาว $10$ หน่วย และแกนโทยาว $8$ หน่วย

ข้อ 2. กำหนดสมการวงรี $\frac{(x - 1)^2}{9} + \frac{(y + 2)^2}{25} = 1$ จงระบุทิศทางของแกนเอก พิกัดของจุดศูนย์กลาง และพิกัดจุดโฟกัสทั้งสองจุด

(3 คะแนน)

วิธีทำ: ตัวส่วนใต้พจน์ $y$ มากกว่า ($a^2 = 25 \implies a = 5$, $b^2 = 9 \implies b = 3$) แกนเอกขนานแกน Y (แนวตั้ง)

จุดศูนย์กลางอยู่ที่ $(h, k) = (1, -2)$

หาค่า $c$: $c = \sqrt{25 - 9} = \sqrt{16} = 4$

โฟกัสอยู่ตามแนวตั้ง: $F(h, k \pm c) = (1, -2 \pm 4) \implies F_1(1, 2)$ และ $F_2(1, -6)$

ตอบ แกนเอกแนวตั้ง, จุดศูนย์กลางอยู่ที่ $(1, -2)$ และจุดโฟกัสคือ $(1, 2)$ และ $(1, -6)$

ข้อ 3. จงหาสมการรูปมาตรฐานของวงรีที่มีจุดศูนย์กลางอยู่ที่จุดกำเนิด จุดยอดอยู่ที่ $(\pm 6, 0)$ และจุดโฟกัสอยู่ที่ $(\pm 4, 0)$

(3 คะแนน)

วิธีทำ: จุดยอดและโฟกัสอยู่บนแกน X แสดงว่าเป็นวงรีแนวนอน โดย $a = 6$ และ $c = 4$

จากความสัมพันธ์ $a^2 = b^2 + c^2 \implies b^2 = a^2 - c^2 = 6^2 - 4^2 = 36 - 16 = 20$

สมการรูปมาตรฐานคือ $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ แทนค่า $a^2 = 36$ และ $b^2 = 20$

ตอบ $\frac{x^2}{36} + \frac{y^2}{20} = 1$

หน้า 1 จาก 2

ข้อ 4. จงจัดสมการ $4x^2 + 9y^2 - 16x + 54y + 61 = 0$ ให้อยู่ในรูปมาตรฐาน พร้อมหาพิกัดจุดศูนย์กลาง และความยาวแกนเอก

(3 คะแนน)

วิธีทำ: จัดกลุ่มพจน์ $x$ และ $y$: $4(x^2 - 4x) + 9(y^2 + 6y) = -61$

ทำกำลังสองสมบูรณ์: $4(x^2 - 4x + 4) + 9(y^2 + 6y + 9) = -61 + 16 + 81 \implies 4(x - 2)^2 + 9(y + 3)^2 = 36$

หารด้วย 36 ตลอด: $\frac{(x - 2)^2}{9} + \frac{(y + 3)^2}{4} = 1$

เทียบรูปมาตรฐานจะได้ $a^2 = 9 \implies a = 3$ (แกนเอกแนวนอนยาว $2a = 6$) และจุดศูนย์กลาง $(2, -3)$

ตอบ รูปมาตรฐานคือ $\frac{(x - 2)^2}{9} + \frac{(y + 3)^2}{4} = 1$, ศูนย์กลาง $(2, -3)$ และแกนเอกยาว $6$ หน่วย

ข้อ 5. วงรีรูปหนึ่งมีจุดโฟกัสอยู่ที่ $(2, 1)$ และ $(2, 7)$ ถ้าผลบวกของระยะทางจากจุดใด ๆ บนวงรีไปยังโฟกัสทั้งสองเท่ากับ $10$ หน่วย จงหาสมการรูปมาตรฐานของวงรีนี้

(3 คะแนน)

วิธีทำ: 1) โฟกัสมีพิกัด $x = 2$ เท่ากัน แสดงว่าแกนเอกขนานกับแกน Y (แนวตั้ง)

จุดศูนย์กลาง $C$ คือจุดกึ่งกลางระหว่างโฟกัส: $C = \left(2, \frac{1+7}{2}\right) = (2, 4)$

2) ระยะระหว่างโฟกัสคือ $2c = 7 - 1 = 6 \implies c = 3$

3) ผลบวกระยะทางตามนิยาม $2a = 10 \implies a = 5 \implies a^2 = 25$

หา $b^2 = a^2 - c^2 = 25 - 9 = 16$

ตอบ $\frac{(x - 2)^2}{16} + \frac{(y - 4)^2}{25} = 1$
