ขั้นตอนที่ 1

สมการรูปทั่วไป

$Ax^2 + Cy^2 + Dx + Ey + F = 0$ สังเกตสัมประสิทธิ์ $A$ และ $C$ เพื่อคาดการณ์ประเภทกราฟเบื้องต้น

ขั้นตอนที่ 2

จัดกลุ่มและดึงตัวร่วม

รวมกลุ่มตัวแปรเดียวกัน ย้ายค่าคงตัว $F$ ไปฝั่งขวา ดึงสัมประสิทธิ์ $A$ และ $C$ ออกหน้าวงเล็บกำลังสอง

ขั้นตอนที่ 3

ทำกำลังสองสมบูรณ์

บวก $\left(\frac{b}{2}\right)^2$ เข้าในวงเล็บ และอย่าลืมคูณสัมประสิทธิ์หน้าวงเล็บแล้วบวกเข้าฝั่งขวาของสมการ

ขั้นตอนที่ 4

รูปมาตรฐานและกราฟ

หารตลอดเพื่อให้ฝั่งขวาเท่ากับ $1$ (ยกเว้นพาราโบลา) อ่านค่าจุดศูนย์กลาง $(h, k)$ รัศมี หรือแกน แล้ววาดกราฟ

สรุปฟอร์มมาตรฐานตามชนิดของกราฟ

  • วงกลม: $(x - h)^2 + (y - k)^2 = r^2$ ($r > 0$)
  • วงรี: $\frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1$ หรือสลับแกนตั้ง ($a > b > 0$)
  • พาราโบลา: $(x - h)^2 = 4c(y - k)$ หรือ $(y - k)^2 = 4c(x - h)$
  • ไฮเพอร์โบลา: $\frac{(x - h)^2}{a^2} - \frac{(y - k)^2}{b^2} = 1$ หรือ $\frac{(y - k)^2}{a^2} - \frac{(x - h)^2}{b^2} = 1$

ข้อควรระวัง: กรณีเสื่อมและไม่มีกราฟจริง

  • • ฝั่งขวาเท่ากับศูนย์ ($K = 0$): หากเครื่องหมายเหมือนกันจะได้ จุดเพียงจุดเดียว หากเครื่องหมายต่างกันจะได้ เส้นตรงสองเส้นตัดกัน
  • • ฝั่งขวาเป็นค่าลบ ($K < 0$): ผลบวกกำลังสองเท่ากับจำนวนลบ จะ ไม่มีกราฟจริงบนระนาบ (เซตว่าง)
  • • มีตัวแปรกำลังสองเพียงตัวเดียว: ต้องจัดรูปเป็น พาราโบลา เสมอ

โมเดลปฏิสัมพันธ์: ห้องปฏิบัติการจัดรูปสมการทีละขั้น (Step-by-Step Lab)

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การจัดรูปสมการวงกลม ($A=C$) จัดกลุ่มและทำกำลังสองสมบูรณ์ทั้ง $x, y$ ถูกต้อง ได้ $(x-4)^2 + (y+2)^2 = 25$ ระบุศูนย์กลาง $(4, -2)$ และ $r=5$ สมบูรณ์ จัดรูปกำลังสองสมบูรณ์ถูกต้อง แต่คำนวณผลบวกตัวเลขฝั่งขวาผิดพลาดทำให้รัศมีคลาดเคลื่อน สับสนเครื่องหมายของการทำกำลังสองสมบูรณ์ หรือไม่สามารถแยกตัวแปรได้
2. การจัดรูปสมการวงรีที่มีสัมประสิทธิ์ ($A \neq C$) ดึงตัวร่วม 9 และ 25 ทำกำลังสองสมบูรณ์ บวกรวมฝั่งขวาเท่ากับ 225 หารตลอดได้รูปมาตรฐานและศูนย์กลาง $(2, -1)$ สมบูรณ์ ดึงตัวร่วมถูกต้อง แต่ลืมคูณสัมประสิทธิ์ก่อนบวกเข้าฝั่งขวาของสมการ ไม่เข้าใจการดึงตัวร่วมออกจากพจน์กำลังหนึ่ง หรือสับสนสูตรกำลังสองสมบูรณ์
3. การจัดรูปสมการพาราโบลา ($A=0$ หรือ $C=0$) จัดกลุ่มพจน์ $x$ ทำกำลังสองสมบูรณ์ ดึงตัวร่วมพจน์ $y$ ได้ $(x-2)^2 = 8(y-2)$ ระบุจุดยอด $(2, 2)$ และ $c=2$ (หงาย) ครบถ้วน ทำกำลังสองสมบูรณ์ถูกต้อง แต่ดึงตัวร่วมฝั่งขวาผิดพลาดทำให้ค่า $4c$ หรือพิกัดจุดยอดคลาดเคลื่อน สับสนย้ายข้างตัวแปร หรือเข้าใจผิดว่าเป็นสมการวงกลม/วงรี
4. การจัดรูปสมการไฮเพอร์โบลา ($A \cdot C < 0$) จัดการเครื่องหมายลบหน้าพจน์ $y$ ได้ถูกต้อง จัดรูปได้ $\frac{(y-1)^2}{4} - \frac{(x+2)^2}{1} = 1$ ระบุจุดยอดแนวตั้งได้ถูกต้อง จัดรูปได้แต่สับสนเครื่องหมายลบตอนดึงตัวร่วม $-(y^2 - 2y)$ หรือสับสนแกนตามขวาง ผิดพลาดเรื่องเครื่องหมายลบ ทำให้สมการกลายเป็นวงรีหรือไม่สามารถแก้สมการได้
5. การวิเคราะห์กรณีเสื่อม (Degenerate Conic) หาร 2 ตลอด จัดรูปได้ $(x-2)^2 + (y+3)^2 = 0$ สรุปว่าเป็นจุดเพียงจุดเดียว $(2, -3)$ พร้อมให้เหตุผลทางคณิตศาสตร์สมบูรณ์ จัดรูปได้ฝั่งขวาเป็นศูนย์ถูกต้อง แต่สรุปว่าเป็นวงกลมรัศมี 0 (ไม่ได้ระบุว่าเป็นจุด) ไม่เข้าใจความหมายเมื่อผลรวมกำลังสองเท่ากับศูนย์ สรุปคำตอบไม่ถูกต้อง

ข้อ 1. จงจัดสมการ $x^2 + y^2 - 8x + 4y - 5 = 0$ ให้อยู่ในรูปมาตรฐาน พร้อมระบุว่าเป็นกราฟชนิดใด จุดศูนย์กลาง และรัศมี

(3 คะแนน)

วิธีทำ: จัดกลุ่มพจน์: $(x^2 - 8x) + (y^2 + 4y) = 5$

ทำกำลังสองสมบูรณ์: $(x^2 - 8x + 16) + (y^2 + 4y + 4) = 5 + 16 + 4 \implies (x - 4)^2 + (y + 2)^2 = 25$

เป็นสมการวงกลมที่มี $(h, k) = (4, -2)$ และ $r^2 = 25 \implies r = 5$

ตอบ รูปมาตรฐาน $(x - 4)^2 + (y + 2)^2 = 25$ เป็นกราฟวงกลม ศูนย์กลางที่ $(4, -2)$ รัศมี 5 หน่วย

ข้อ 2. จงจัดสมการ $9x^2 + 25y^2 - 36x + 50y - 164 = 0$ ให้อยู่ในรูปมาตรฐาน ระบุชนิดของกราฟ และหาพิกัดจุดศูนย์กลาง

(3 คะแนน)

วิธีทำ: จัดกลุ่มและดึงตัวร่วม: $9(x^2 - 4x) + 25(y^2 + 2y) = 164$

กำลังสองสมบูรณ์: $9(x^2 - 4x + 4) + 25(y^2 + 2y + 1) = 164 + 9(4) + 25(1) \implies 9(x - 2)^2 + 25(y + 1)^2 = 225$

หารด้วย 225: $\frac{(x - 2)^2}{25} + \frac{(y + 1)^2}{9} = 1$

ตอบ รูปมาตรฐาน $\frac{(x - 2)^2}{25} + \frac{(y + 1)^2}{9} = 1$ เป็นกราฟวงรีแนวนอน จุดศูนย์กลางอยู่ที่ $(2, -1)$

ข้อ 3. จงจัดสมการ $x^2 - 4x - 8y + 20 = 0$ ให้อยู่ในรูปมาตรฐาน พร้อมระบุจุดยอด ทิศทางการเปิด และระยะโฟกัส $c$

(3 คะแนน)

วิธีทำ: มีพจน์กำลังสองเฉพาะ $x$ เป็นพาราโบลาแกนตั้ง: $x^2 - 4x = 8y - 20$

ทำกำลังสองสมบูรณ์: $(x^2 - 4x + 4) = 8y - 20 + 4 \implies (x - 2)^2 = 8y - 16 \implies (x - 2)^2 = 8(y - 2)$

เทียบ $(x - h)^2 = 4c(y - k)$ จะได้จุดยอด $V(2, 2)$ และ $4c = 8 \implies c = 2 > 0$

ตอบ รูปมาตรฐาน $(x - 2)^2 = 8(y - 2)$ เป็นพาราโบลาหงายขึ้น จุดยอด $(2, 2)$ และระยะโฟกัส $c = 2$

ข้อ 4. จงจัดสมการ $4x^2 - y^2 + 16x + 2y + 11 = 0$ ให้อยู่ในรูปมาตรฐาน ระบุชนิดของกราฟ และหาพิกัดของจุดยอดทั้งสอง

(3 คะแนน)

วิธีทำ: จัดกลุ่มพจน์: $4(x^2 + 4x) - (y^2 - 2y) = -11$

ทำกำลังสองสมบูรณ์: $4(x^2 + 4x + 4) - (y^2 - 2y + 1) = -11 + 4(4) - 1(1) \implies 4(x + 2)^2 - (y - 1)^2 = 4$

หารด้วย 4 ตลอด: $\frac{(x + 2)^2}{1} - \frac{(y - 1)^2}{4} = 1$ เป็นไฮเพอร์โบลาเปิดซ้าย-ขวา

ศูนย์กลางอยู่ที่ $(-2, 1)$ และ $a^2 = 1 \implies a = 1$ จุดยอดคือ $(-2 \pm 1, 1) \implies V_1(-1, 1), V_2(-3, 1)$

ตอบ รูปมาตรฐาน $\frac{(x + 2)^2}{1} - \frac{(y - 1)^2}{4} = 1$ เป็นไฮเพอร์โบลาเปิดซ้าย-ขวา จุดยอดคือ $(-1, 1)$ และ $(-3, 1)$

ข้อ 5. จงตรวจสอบสมการ $2x^2 + 2y^2 - 8x + 12y + 26 = 0$ ว่าเป็นกรณีเสื่อมหรือไม่ เกิดกราฟลักษณะใด พร้อมให้เหตุผลประกอบ

(3 คะแนน)

วิธีทำ: นำ 2 หารตลอดทั้งสมการ: $x^2 + y^2 - 4x + 6y + 13 = 0$

จัดรูปกำลังสองสมบูรณ์: $(x^2 - 4x + 4) + (y^2 + 6y + 9) = -13 + 4 + 9 \implies (x - 2)^2 + (y + 3)^2 = 0$

เนื่องจาก $(x - 2)^2 \ge 0$ และ $(y + 3)^2 \ge 0$ ผลบวกเป็น 0 ได้กรณีเดียวคือ $x - 2 = 0$ และ $y + 3 = 0$

ตอบ เป็นกรณีเสื่อม (Degenerate Conic) เกิดกราฟเป็น "จุดเพียงจุดเดียว" คือ จุดพิกัด $(2, -3)$
