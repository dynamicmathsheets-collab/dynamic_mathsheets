เรื่องที่ 4: ความหมายและการจำแนกภาคตัดกรวย

เข้าใจที่มาทางเรขาคณิตของการตัดกรวยกลมตรงด้วยระนาบ และเรียนรู้การจำแนกประเภทของกราฟภาคตัดกรวยจากสมการกำลังสองสองตัวแปรในรูปทั่วไป รวมถึงการพิจารณากรณีเสื่อม (Degenerate Conics)

$Ax^2+Cy^2$

สาระและทฤษฎี: ภาพรวมการจำแนกภาคตัดกรวย

การเชื่อมโยงระนาบตัดกรวยกลม สู่สมการกำลังสองสองตัวแปร

นิยามและสมการรูปทั่วไป

ภาคตัดกรวย (Conic Sections) คือ เส้นโค้งที่เกิดจากการตัดกันของระนาบกับผิวกรวยกลมตรงคู่ ในระบบพิกัดฉาก (เมื่อแกนสมมาตรขนานกับแกนพิกัด) สามารถเขียนแทนด้วยสมการกำลังสองรูปทั่วไป:

$$Ax^2 + Cy^2 + Dx + Ey + F = 0$$

โดยที่ $A$ และ $C$ ต้องไม่เป็นศูนย์พร้อมกัน ($A^2 + C^2 \neq 0$)

เกณฑ์การจำแนกกราฟเบื้องต้น

วงกลม $A = C \neq 0$ (เครื่องหมายเดียวกันและค่าเท่ากัน)
วงรี $A \cdot C > 0$ และ $A \neq C$ (เครื่องหมายเหมือนกันแต่ไม่เท่ากัน)
พาราโบลา $A = 0$ หรือ $C = 0$ (มีพจน์กำลังสองเพียงตัวเดียว)
ไฮเพอร์โบลา $A \cdot C < 0$ (สัมประสิทธิ์มีเครื่องหมายต่างกัน)

หมายเหตุ: ต้องพิจารณา กรณีเสื่อม (Degenerate Conics) เช่น กราฟกลายเป็นจุดเดียว, เส้นตรงคู่ตัดกัน, เส้นตรงขนานกัน หรือไม่มีกราฟจริงบนระนาบ

โมเดลปฏิสัมพันธ์: ห้องทดลองจำแนกสมการภาคตัดกรวย

ปรับเปลี่ยนสัมประสิทธิ์ $A, C, D, E, F$ เพื่อสังเกตการวิเคราะห์ประเภทของกราฟและการพลอตระนาบพิกัดฉากแบบเรียลไทม์

พรีเซ็ตตัวอย่าง:
เส้นกราฟ $f(x,y) = 0$ ช่วงแกน $[-10, 10]$
สัมประสิทธิ์ $A$ ($x^2$): 1
สัมประสิทธิ์ $C$ ($y^2$): 1
สัมประสิทธิ์ $D$ ($x$): 0
สัมประสิทธิ์ $E$ ($y$): 0
ค่าคงตัว $F$: -16
สมการกำลังสองรูปทั่วไปที่กำลังทดสอบ
$x^2 + y^2 - 16 = 0$
ผลการจำแนกประเภท

เกณฑ์การประเมินรูบริก (Scoring Rubric - 15 คะแนน)

เกณฑ์การประเมิน 3 ระดับ สอดคล้องตามตัวชี้วัด 5 ข้อ ข้อละ 3 คะแนน

ประเด็นการประเมิน (ข้อละ 3 คะแนน) ดีเยี่ยม (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การจำแนกและจัดรูปสมการวงกลม ($A = C$) ระบุว่าเป็นวงกลมได้ถูกต้อง จัดกำลังสองสมบูรณ์จนได้รูป $(x-h)^2 + (y-k)^2 = r^2$ ครบถ้วน จำแนกถูกต้องว่าคือวงกลม แต่คำนวณกำลังสองสมบูรณ์หรือค่า $r^2$ ผิดพลาดเล็กน้อย จำแนกประเภทผิด หรือไม่สามารถจัดรูปกำลังสองสมบูรณ์ได้
2. การจำแนกสมการวงรี ($A \cdot C > 0, A \neq C$) ให้เหตุผล $A, C$ มีเครื่องหมายเดียวกันแต่ไม่เท่ากัน สรุปว่าเป็นวงรี และแสดงรูปมาตรฐานสมบูรณ์ สรุปว่าเป็นวงรีถูกต้อง แต่ดึงตัวร่วมหรือหารสัมประสิทธิ์คลาดเคลื่อน สับสนระหว่างวงรีกับวงกลม หรือไม่สามารถอธิบายเหตุผลจากสัมประสิทธิ์ได้
3. การจำแนกสมการพาราโบลา ($A=0$ หรือ $C=0$) ระบุว่ามีตัวแปรกำลังสองเพียงตัวเดียว สรุปเป็นพาราโบลา และบอกทิศทางการเปิดของกราฟได้ถูกต้อง ระบุว่าเป็นพาราโบลาถูกต้อง แต่ระบุทิศทางการเปิดของกราฟผิดพลาด ไม่สามารถจำแนกพาราโบลาจากสมการทั่วไปได้
4. การจำแนกสมการไฮเพอร์โบลา ($A \cdot C < 0$) ระบุสัมประสิทธิ์เครื่องหมายต่างกัน สรุปว่าเป็นไฮเพอร์โบลา และระบุแกนตามขวางได้ถูกต้อง ระบุว่าเป็นไฮเพอร์โบลาถูกต้อง แต่จัดรูปสมการสับสนเครื่องหมายลบ สับสนกับวงรี หรือไม่เข้าใจความหมายของเครื่องหมายต่างกัน
5. การวิเคราะห์กรณีเสื่อม (Degenerate Conic) จัดรูปได้ฝั่งขวาเท่ากับศูนย์ สรุปได้ชัดเจนว่าเป็นจุดเพียงจุดเดียว $(1, -2)$ พร้อมเหตุผล จัดรูปถูกต้อง ได้ค่าคงที่ฝั่งขวาเป็น 0 แต่สรุปว่าเป็นวงกลมรัศมี 0 (ไม่ได้ระบุว่าเป็นจุด) ไม่สามารถตรวจสอบกรณีเสื่อมได้ สรุปว่าเป็นวงกลมทั่วไป

ข้อ 1. จงพิจารณาสมการ $x^2 + y^2 - 4x + 6y - 12 = 0$ ว่าเป็นกราฟภาคตัดกรวยชนิดใด พร้อมแสดงการจัดรูปมาตรฐาน

(3 คะแนน)

วิธีทำ: สัมประสิทธิ์ $A = 1, C = 1$ เท่ากันและเป็นบวกทั้งคู่ แสดงว่าเป็น วงกลม

จัดกำลังสองสมบูรณ์: $(x^2 - 4x + 4) + (y^2 + 6y + 9) = 12 + 4 + 9 \implies (x - 2)^2 + (y + 3)^2 = 25$

ตอบ เป็นกราฟวงกลม มีจุดศูนย์กลางที่ $(2, -3)$ และรัศมี $r = 5$ หน่วย

ข้อ 2. จงจำแนกประเภทของกราฟจากสมการ $4x^2 + 9y^2 - 16x + 18y - 11 = 0$ พร้อมให้เหตุผลประกอบ

(3 คะแนน)

วิธีทำ: พิจารณาสัมประสิทธิ์ $A = 4, C = 9$ พบว่า $A \cdot C = 36 > 0$ และ $A \neq C$

จัดรูป: $4(x^2 - 4x + 4) + 9(y^2 + 2y + 1) = 11 + 16 + 9 \implies 4(x - 2)^2 + 9(y + 1)^2 = 36$

หารด้วย 36: $\frac{(x - 2)^2}{9} + \frac{(y + 1)^2}{4} = 1$ ซึ่งทางขวาเป็นค่าบวก

ตอบ เป็นกราฟวงรีแนวนอน จุดศูนย์กลางอยู่ที่ $(2, -1)$

ข้อ 3. จงจำแนกประเภทของกราฟจากสมการ $y^2 - 6y - 8x + 17 = 0$ และระบุทิศทางความโค้งของกราฟ

(3 คะแนน)

วิธีทำ: สัมประสิทธิ์พจน์กำลังสองมีเฉพาะ $y^2$ ($A = 0, C = 1$) ดังนั้นกราฟเป็น พาราโบลา

จัดกำลังสองสมบูรณ์ตัวแปร $y$: $(y^2 - 6y + 9) = 8x - 17 + 9 \implies (y - 3)^2 = 8(x - 1)$

เทียบกับรูป $(y - k)^2 = 4c(x - h)$ จะได้ $4c = 8 \implies c = 2 > 0$

ตอบ เป็นพาราโบลาที่มีแกนสมมาตรขนานกับแกน X และอ้าเปิดทางด้านขวา

หน้า 1 จาก 2

ข้อ 4. จงพิจารณาสมการ $9x^2 - 4y^2 - 36x + 8y - 4 = 0$ ว่าเป็นภาคตัดกรวยชนิดใด พร้อมอธิบายลักษณะสำคัญ

(3 คะแนน)

วิธีทำ: สัมประสิทธิ์ $A = 9$ และ $C = -4$ มีเครื่องหมายต่างกัน ($A \cdot C = -36 < 0$)

จัดรูป: $9(x^2 - 4x + 4) - 4(y^2 - 2y + 1) = 4 + 36 - 4 \implies 9(x - 2)^2 - 4(y - 1)^2 = 36$

หารด้วย 36: $\frac{(x - 2)^2}{4} - \frac{(y - 1)^2}{9} = 1$

ตอบ เป็นกราฟไฮเพอร์โบลาเปิดซ้าย-ขวา (แกนตามขวางขนานกับแกน X) จุดศูนย์กลางที่ $(2, 1)$

ข้อ 5. จงตรวจสอบว่าสมการ $2x^2 + 2y^2 - 4x + 8y + 10 = 0$ เกิดกราฟจริงบนระนาบหรือไม่ และเป็นกรณีเสื่อมลักษณะใด

(3 คะแนน)

วิธีทำ: นำ 2 หารตลอด: $x^2 + y^2 - 2x + 4y + 5 = 0$

จัดรูปกำลังสองสมบูรณ์: $(x^2 - 2x + 1) + (y^2 + 4y + 4) = -5 + 1 + 4 \implies (x - 1)^2 + (y + 2)^2 = 0$

เนื่องจากผลรวมของจำนวนจริงยกกำลังสองเท่ากับศูนย์ได้ ก็ต่อเมื่อแต่ละพจน์เป็นศูนย์พร้อมกัน

ตอบ เป็นกรณีเสื่อม (Degenerate Conic) เกิดกราฟเป็น "จุดเพียงจุดเดียว" คือ จุด $(1, -2)$
