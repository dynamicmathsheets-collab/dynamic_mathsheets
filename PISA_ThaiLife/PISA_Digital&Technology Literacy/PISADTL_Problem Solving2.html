สถานการณ์: การค้นหาและแก้ไขข้อผิดพลาด (Debugging) ในโปรแกรมควบคุมหุ่นยนต์

กลุ่มของกมลกำลังเขียนชุดคำสั่ง (Algorithm) เพื่อสั่งให้หุ่นยนต์จำลองเดินเก็บตัวอย่างขยะรีไซเคิลในสนามความยาว 20 เมตร โดยมีเป้าหมายให้หุ่นยนต์คำนวณระยะทางรวมและหยุดทำงานอย่างถูกต้อง

กมลต้องการให้โปรแกรมคำนวณตำแหน่งสะสมของหุ่นยนต์ โดยเริ่มจากตำแหน่ง \(x = 0\) และเดินหน้าครั้งละ \(d = 4\) เมตร เป็นจำนวน 5 ครั้ง เพื่อให้สิ้นสุดที่จุดหมาย: $$x_{\text{target}} = 5 \times 4 = 20\text{ เมตร}$$

แต่เมื่อรันโปรแกรม หุ่นยนต์กลับเดินเลยสนามและชนกำแพงที่ระยะ 24 เมตร ครูจึงแนะนำให้นักเรียนทำ การไล่ตรวจค่าตัวแปร (Dry Run / Variable Tracing) ทีละบรรทัด

จากการตรวจสอบโค้ดพบข้อผิดพลาดเชิงตรรกะ (Logic Bug) ในเงื่อนไขการวนซ้ำ (Loop Condition) ซึ่งเขียนไว้ว่า while (count <= 5) และมีการบวกค่าซ้ำซ้อน ทำให้ลูปทำงานทั้งหมด 6 รอบ ส่งผลให้ผลลัพธ์คณิตศาสตร์คลาดเคลื่อน:

$$x_{\text{actual}} = 6 \times 4 = 24\text{ เมตร}$$

กมลและเพื่อนๆ ต้องประยุกต์ใช้การคิดเชิงคำนวณเพื่อหาสาเหตุ แก้ไขโค้ด และทดสอบระบบให้กลับมาทำงานได้อย่างถูกต้อง

โปรแกรมจำลอง: Robot_Controller.algo
01x = 0; count = 1;
02while (count <= 5) { // จุดเกิด Logic Bug
03 x = x + 4;
04 move_forward(4);
05 count = count + 1;
06}
07stop_robot();
