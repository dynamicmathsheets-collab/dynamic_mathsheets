สถานการณ์: การเขียนโปรแกรมวาดรูปหลายเหลี่ยมด้านเท่ามุมเท่า

ในชั่วโมงวิทยาการคำนวณ นักเรียนกำลังเรียนรู้การสั่งงานตัวละครให้วาดรูปทรงเรขาคณิต โดยใช้แนวคิด **การคิดเชิงคำนวณ (Computational Thinking)** และการทำซ้ำ (Loop)

ความรู้ทางคณิตศาสตร์ระบุว่า ผลรวมของมุมภายนอกของรูปหลายเหลี่ยมใด ๆ เท่ากับ \(360^\circ\) เสมอ ดังนั้น ในการวาดรูปหลายเหลี่ยมด้านเท่ามุมเท่าที่มี \(n\) ด้าน ตัวละครจะต้องหมุนเปลี่ยนทิศทางในแต่ละมุมด้วยขนาดของมุมหมุนภายนอก \(\theta\) ดังสมการ:

$$\theta = \frac{360^\circ}{n}$$

เช่น หากต้องการวาดรูปสี่เหลี่ยมจัตุรัส (\(n=4\)) ตัวละครจะต้องหมุน \(\theta = \frac{360^\circ}{4} = 90^\circ\) และทำซ้ำ 4 รอบ

นอกจากนี้ เมื่อนักเรียนเขียนโค้ดเสร็จแล้ว จะต้องแชร์โปรเจกต์ไปยังกระดานแลกเปลี่ยนเรียนรู้ออนไลน์ของห้องเรียน ซึ่งจำเป็นต้องเคารพกฎความปลอดภัยไซเบอร์และมารยาททางดิจิทัล

โครงสร้างบล็อกคำสั่ง (Algorithm Simulation)
// ชุดคำสั่งวาดรูปทรงเรขาคณิต
วนซ้ำ [ n ] ครั้ง {
เดินหน้า [ L ] ก้าว
หันขวา [ 360 / n ] องศา
}
ตัวแปรที่ใช้:
- \(n\) : จำนวนด้าน (เช่น 3, 4, 5, 6, ...)
- \(L\) : ความยาวของแต่ละด้าน (ก้าว)
- มุมหมุนภายนอก \(\theta = \frac{360^\circ}{n}\)

บล็อกคำสั่งจำลองแสดงการวนซ้ำและการคำนวณมุมหมุน \(\theta\)
